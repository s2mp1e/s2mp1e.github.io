基准与参考源修调

概述

基准与参考源（Reference & Benchmark）是 PMIC 中所有模块工作的基石。Bandgap 产生与温度无关的基准电压 VBG（~1.2V），VBG 经缓冲分压产生 VREF1P0（1.0V）和 VREF 等参考电压；IREF 产生偏置电流供给 LDO、Buck、BUCKBOOST、ADC 等模块的 bias 电路；RC 振荡器为数字控制逻辑和开关电源提供时钟。由于芯片制造过程中的工艺偏差（Process variation），这些参考源的绝对精度会偏离设计值，必须在 CP（Chip Probing）或 FT（Final Test）阶段通过修调（Trim）电路将其校准到目标规格内。

本文档详细阐述以下六项基准修调项的原理、测试方法与注意事项：

序号修调项英文简称典型目标
1VREF1P0 电压修调VREF1P0 Trim1.000 V +/- 1~2%
2LDO 输出电压修调LDO VOUT Trim按 SPEC 要求
3RC1024K_TOP 晶振修调RC OSC Trim1024 kHz +/- 1~2%
4VBG 基准电压修调VBG Trim1.200 V +/- 0.5~1%

1. VREF1P0 电压修调

原理 (Principles)

电路架构

VREF1P0 通常由 Bandgap 产生的 VBG（~1.2V）经过电阻分压和 Buffer 缓冲后得到 1.0V 输出。典型架构如下：

VBG (1.2V) --> Resistor Divider --> Buffer (OPA) --> VREF1P0 Output
                     |
              Trim Code Control
  • 电阻分压网络：将 VBG 分压到 1.0V 附近，分压比 R2/(R1+R2) = 1.0/1.2。
  • 缓冲器（Buffer）：通常为轨到轨（Rail-to-Rail）运放，提供驱动能力并隔离负载对分压网络的影响。
  • 修调机制：在分压电阻串上并联/串联可开关的修调电阻（Trim Resistor Bank），通过 Trim Code 改变分压比，从而微调 VREF1P0 电压。

为什么需要修调

  1. VBG 本身的工艺偏差：Bandgap 输出的 VBG 存在约 +/-3~5% 的绝对偏差。
  2. 电阻绝对精度偏差：片上电阻（poly resistor / diffusion resistor）的 sheet resistance 随工艺角变化可达 +/-20%。
  3. 运放失调电压（Offset）：Buffer 运放的输入失调电压 Vos 会直接叠加在输出上。
  4. 温度系数（Tempco）：虽然分压比在理论上与温度无关，但电阻的温度系数不匹配会引入温漂。

综合以上因素，若不修调，VREF1P0 的绝对精度可能偏差 +/-5~10%，典型应用要求 1% 或更高精度。

修调电路工作原理

VREF1P0 常用的修调方式有：

  1. 电阻串分压式修调 (Resistor Ladder Trim)

    VBG ---- Rfix ---- Rtrim ---- Rtrim ---- GND
                     |  |  |
                   S0  S1  S2  (Trim Bits)

    每个修调位控制一个 MOS 开关，接通或短路对应的修调电阻。增大串联电阻使输出降低，减小串联电阻使输出升高。

    • 优点：实现简单，功耗低
    • 缺点：开关导通电阻（Ron）会引入非线性，需使用大尺寸开关

  2. 电流 DAC 补偿方式 (IDAC Trim)

    VREF1P0 Output ---+
                  |
                 Rload
                  |
IDAC ---> 注入/抽取电流到输出节点

    通过 IDAC 向输出节点注入或从输出节点抽取微小电流，利用输出负载电阻产生电压偏移。

    • 优点：不需要修改分压电阻网络
    • 缺点：受温度影响大，需额外基准电流

  3. Fuse/EFuse 存储方式

    修调码通常在 CP 测试中确定后写入 OTP (One-Time Programmable) 存储器，常用方案包括：

    • Metal Fuse：大电流熔断金属丝，未熔断为 0，熔断为 1
    • Poly Fuse：多晶硅熔丝，原理类似
    • EFuse：基于电迁移效应的可编程熔丝
    • Anti-fuse：反熔丝结构，编程后导通
    • MTP (Multi-Time Programmable)：多次可编程，常见于较为先进的 PMIC 方案

测试方法 (Test Methods)

CP 测试修调流程

1. Power ON: 施加 VDD 与 VBAT（若需要）
2. Enable: 开启 VREF1P0 LDO/模块
3. Wait: 等待输出稳定（~100 us~1 ms）
4. Measure: 用 ATE 高精度 ADC 或 DMM 测量 VREF1P0 引脚电压
5. Compare: 与目标值比较（如 1.000V +/- 0.5%）
6. Binary Search: 二分法搜索最佳 Trim Code
7. Program: 将最佳 Trim Code 写入 OTP
8. Verify: 再次测量确认修调后电压在目标范围内

测试条件设置

参数典型条件备注
温度25°C / 85°C / -40°C多温度点修调需考虑
输入电压 VDD标称值的 +/-5~10%验证电源抑制比
负载电流 Iload0 / max (如 1mA)看带载能力
测量精度+/- 0.1% 级以上ATE 需校准

Pass/Fail 判据

  • Pass：Trim 后的 VREF1P0 在所有 corner（电压、温度）下都在 SPEC 范围内
  • Fail：最大/最小修调码仍无法将电压调到目标范围内 → 可能为芯片工艺角太极端

典型 ATE 测试代码 (Pseudocode)

function trim_vref1p0(vdd, target_voltage, tolerance):
    power_up(vdd)
    enable_vref1p0()
    wait(500 us)
    
    code = binary_search(0, max_code, function(c):
        set_trim_code(c)
        v = measure_voltage(VREF1P0_PIN)
        return v - target_voltage
    )
    
    final_v = measure_voltage(VREF1P0_PIN)
    if abs(final_v - target_voltage) <= tolerance:
        program_otp(code)
        return PASS, code
    else:
        return FAIL, code

注意事项 (Considerations)

  1. 接触电阻影响：Probe 接触电阻和 Socket 接触电阻会在测量中引入额外压降，特别是大电流时。建议使用 Kelvin 四线法（Force/Sense）进行测量。
  2. 温度平衡：CP 测试中芯片与 chuck 温度需充分平衡（soak time），否则修调结果在后续测试会偏。
  3. VDD 噪声：ATE 电源的 ripple 和 noise 会耦合到输出，建议在测量引脚加去耦电容或使用 ATE 的 DC 测量单元。
  4. Buffer 稳定性：某些设计在重容性负载下 Buffer 可能振荡，需确认输出电容范围。
  5. Trim Code Margin：不要将修调码选在边界值，预留一定的余量以应对温度漂移和老化。

2. LDO 输出电压修调

原理 (Principles)

电路架构

PMIC 中的 LDO 通常用于为 SoC 的数字域或模拟域提供稳定的低压供电（如 0.6V / 0.8V / 1.0V / 1.5V 等）。LDO 输出电压修调的结构可以视为 VREF1P0 修调的泛化版本：

VREF ----+----[R1]---- VOUT
         |             |
        [Rtrim]       [R2]
         |             |
        GND           GND
  • 反馈电阻分压网络：LDO 的输出电压由反馈电阻 R1 和 R2 的分压比决定： [ VOUT = VREF \times (1 + R1/R2) ]
  • 修调方式：在 R1 或 R2 上并联/串联修调电阻，改变分压比。
  • 参考电压：通常来源于 VREF1P0 或 VBG，或者 LDO 内部自有参考源。

为什么需要修调

  1. 参考电压偏差：VREF 本身已修调但仍存在残余误差 +/-0.5~1%
  2. 反馈电阻绝对精度：片上电阻的绝对值误差
  3. 电阻匹配误差：R1 与 R2 的匹配度（Mismatch）影响输出精度
  4. 有限开环增益：误差放大器（Error Amplifier）的有限增益和失调

修调电路设计

LDO 的修调方式与 VREF1P0 类似，但修调范围通常更宽，因为负载和输出设置更灵活：

  • 双电阻修调 (Dual Resistor Trim)：上下电阻均设置修调支路，可获得双向调整能力 
    R1 = R1_fixed + R1_trim (可增大)
R2 = R2_fixed + R2_trim (可增大)
  • Current DAC Offset Trim：在误差放大器输入端注入偏移电流，改变等效输入参考电压

测试方法 (Test Methods)

CP/FT 测试修调流程

1. Enable LDO at target voltage setting (通过寄存器/I2C)
2. Apply rated load (e.g., 10mA)
3. Measure VOUT at output pin (Kelvin connection)
4. Adjust trim code to bring VOUT to target
5. Optionally: 在轻载和重载下分别测试（load regulation）
6. Program OTP (CP) or write register (FT test mode)
7. Final verification

测试条件和负载

测试项目条件测量
No-load VOUTIload = 0VOUT 精度
Full-load VOUTIload = ImaxDropout + 精度
Load Regulation0 → ImaxVOUT 变化量 (mV)
Line RegulationVDD_min → VDD_maxVOUT 变化量 (mV/V)

Pass/Fail 判据

  • PASS: Trim 后 VOUT 在目标电压 +/-2% 以内（典型值，视 SPEC 而定）
  • FAIL: Trim 到极限仍无法达标 → 可能是 R1/R2 mismatch 过大或 VREF 偏差过大

注意事项 (Considerations)

  1. 负载效应 (Load Effect)：LDO 的负载调节率（Load Regulation）会将负载变化转化为 VOUT 变化。修调时测试负载应接近实际应用负载。
  2. Dropout 电压：如果 VDD 太低导致 LDO 进入 dropout 区域，输出电压随输入变化，修调无效。
  3. 测试模式下的 LDO Enable：有些 PMIC 的 LDO 在 FT 测试时需要特殊的 test mode 来绕开 POR，需确认 test mode 配置。
  4. 多电压点 LDO：如 LDO 支持多种输出电压（通过寄存器选择），每个电压点都需要单独修调或至少验证误差是否在全范围内一致。
  5. 动态响应：修调只能保证 DC 精度，不影响瞬态响应性能（但过大的反馈电阻会劣化瞬态响应）。

3. RC1024K_TOP 晶振修调 (RC 振荡器频率修调)

原理 (Principles)

RC 振荡器基本原理

PMIC 内部的 RC 振荡器（Resistor-Capacitor Oscillator）为数字控制逻辑（如 Buck/Boost 开关管的时序控制、状态机）、Watchdog Timer、通信协议（I2C 时序）等提供时钟信号。常见架构为比较器 + 电容充放电结构：

          +---------------------------+
          |                           |
    +-----+----+               +-----+----+
    |   Iref   |               |  Buffer   |
    +----------+               +----------+
          |                          |
         [R]                        |
          |        +--[C]--+        |
    Vref -+--------+  SW   |        |
                   +-------+        |
                        |           |
                   +----+-----+    GND
                   | Comparator|
                   +----+-----+
                        |
                   +----+-----+
                   |  Control  |
                   +----------+

工作原理：

  1. 恒定电流 Iref 通过电阻 R 产生参考电压 Vref = Iref * R
  2. 电容 C 被另一路恒定电流 Icharge 充电
  3. 当电容电压 Vcap 上升到 Vref 时，比较器翻转
  4. 控制逻辑将电容放电（通过 SW 短路电容）
  5. 电容重新从 0 开始充电，如此循环

振荡频率： [ f = \frac{Icharge}{C \times Vref} ]

或者更简单的情况：如果充放电都用同一电流源，则频率由 RC 时间常数决定： [ f \approx \frac{1}{2 \times RC} \quad \text{（50% 占空比）} ]

为什么需要修调

  1. 片上 RC 时间常数随工艺变化很大：

    • 多晶硅电阻的 sheet resistance 在不同工艺角变化可达 +/-20~30%
    • MIM/MOM 电容的变化约 +/-10~15%
    • 综合 RC 乘积可变化 +/-30~40%

  2. 温度与电压影响：

    • 电阻温度系数（TCR）：~数百到数千 ppm/°C
    • 电容温度系数（TCC）：~几十到几百 ppm/°C
    • 电源电压变化影响电流源精度

  3. 频率精度要求：

    • 开关电源的开关频率需要匹配外部 LC 滤波器设计
    • I2C 等通信接口需要时钟在容差范围内
    • PMIC 内部多个 Buck/Boost 的相位交错需要精确时钟

修调电路

RC 振荡器的频率修调通常采用以下一种或组合方式：

1. 电容 Bank 修调 (Capacitor Bank Trim)

           ---- C_fixed ----+
           |                 |
    Node --+---- C_trim0 -+-S0
           |              |
           +---- C_trim1 -+-S1
           |              |
           +---- C_trim2 -+-S2

通过控制开关 S0/S1/S2 来改变接入的总电容值。增加电容 → 频率降低；减少电容 → 频率升高。

  • 分辨率：由最小修调电容决定
  • 范围：由总修调电容与固定电容之比决定
  • 单位步长：13%

2. 电流源修调 (Current Trim)

改变给电容充电的电流 Icharge 或比较器的参考阈值电流：

Icharge = Iref + I_trim (通过电流 DAC 调整)
  • 增加电流 → 频率升高
  • 减小电流 → 频率降低

3. 电阻串分压修调 (Resistor Divider Trim)

改变比较器参考电压 Vref = I * R_trim，从而改变翻转阈值。

4. 温度补偿 (Temperature Compensation)

一些高精度设计会包含温度补偿电路（如零温度系数电流源、温度传感器 + 查表补偿），在修调基础上进一步稳定频率。

测试方法 (Test Methods)

CP 测试修调流程

1. Power ON PMIC
2. Enable RC oscillator (通常上电即自动起振)
3. Measure frequency using ATE counter/timer
   - 方案 A: 直接测量 CLK 输出 pin（如有引出）
   - 方案 B: 通过 I2C 读内部计数器值
   - 方案 C: 通过 ADC 测量经 RC 时钟控制的参考电压（间接法）
4. Compare to target frequency (1024 kHz)
5. Binary search trim code
6. Program OTP
7. Measure final frequency to verify

频率测量方法 (ATE 实现)

方法一：直接频率计数

ATE 使用其板载计时器/计数器测量：

1. 在 CLK_OUT pin 捕获上升沿
2. 在已知的 Gate Time（如 1ms）内计数脉冲数
3. 频率 = 脉冲数 / Gate Time
注意事项：
  - Gate Time 越长，测量精度越高
  - 设置适当的触发阈值电平（通常 VDD/2）
  - 考虑去抖（Debounce）设置

方法二：周期测量 (Period Measurement)

1. 测量两个连续上升沿之间的时间差 T
2. 频率 = 1/T
优点：适合低频、高精度测量

方法三：PLL 倍频法

1. 将 RC 时钟作为 PLL 参考输入
2. PLL 倍频到更高频率（如 100x）
3. 测量倍频后的频率再除以倍频系数
优点：提高测量分辨率

测试条件

参数典型条件备注
VDD标称值 +/-10%验证电源敏感性
温度25°C (常温修调)高温/低温可只测不调
测量精度+/-0.1% 或更高取决于 ATE 计时器精度
输出负载CLK pin 负载 < 10pF过大负载影响频率

Pass/Fail 判据

  • PASS：Trim 后频率在 1024 kHz 的 SPEC 范围内（如 +/-2%）
  • FAIL：频率偏差过大，Trim 到极限仍无法达标
    • 常见原因：极端工艺角（FF/SS corner）、冗余修调开关故障
  • 特殊判据：较高温度和较低温度下频率漂移在可接受范围（如 +/-5% over -40~125°C）

ATE 伪代码示例

function trim_rc1024k(target_freq=1024e3, tolerance_pct=2.0):
    power_up()
    wait_for_osc_stable(1 ms)  // RC 振荡器建立时间
    
    code = binary_search(0, 63, function(c):  // 6-bit trim
        set_trim_code(c)
        f = measure_frequency(CLK_PIN, gate_time=2ms)
        return f - target_freq
    )
    
    final_f = measure_frequency(CLK_PIN, gate_time=10ms)  // high precision
    error_pct = abs(final_f - target_freq) / target_freq * 100
    if error_pct <= tolerance_pct:
        program_otp(code)
        return PASS, code, final_f
    else:
        return FAIL, code, final_f

注意事项 (Considerations)

  1. 起振时间 (Start-up Time)：RC 振荡器在使能后需要一定时间稳定（通常几十到几百 us），测量前必须等待稳定。
  2. Jitter 与测量误差：RC 振荡器存在周期性的抖动（Jitter），单周期测量可能不准确。建议测量多个周期取平均或用长 Gate Time。
  3. 电源推动 (Supply Pushing)：RC OSC 频率对电源电压敏感。测量时电源应有良好的去耦，并记录电压条件。
  4. 温度漂移 (Temperature Drift)：常温修调到目标频率后，高温和低温下的频率漂移由温度补偿电路决定。如芯片无温度补偿，需确认全温范围的漂移是否满足应用需求。
  5. 测试模式路由 (Test Mode Routing)：有些设计不直接引出 CLK 引脚，需要通过 test mode 将内部时钟路由到 GPIO 或专用测试引脚，需确认 test mode 配置正确。
  6. VCO 模式：如果 RC OSC 作为 PLL 的参考时钟，修调的是 PLL 的输出频率而非 OSC 本身，修调算法需考虑 PLL 倍频/分频系数。
  7. Trim Code 格雷码编码：某些设计使用格雷码（Gray Code）对 trim bits 编码，以减少切换时可能发生的毛刺。
  8. 环境耦合噪声：ATE 测试头、探针台的射频干扰可能耦合到 OSC 节点，引起频率偏移。

4. VBG 基准电压修调

原理 (Principles)

Bandgap 基准电压源原理

Bandgap 基准电压（Bandgap Reference Voltage）是 PMIC 中最核心的参考源。经典的 Brokaw Cell 或 BJT-based Bandgap 利用以下原理产生与温度无关的电压：

核心公式： [ VBG = V_{BE} + m \times \Delta V_{BE} ]

其中：

  • VBE：BJT 的基极-发射极电压，具有负温度系数（CTAT），约 -2 mV/°C
  • ΔVBE：两个不同电流密度下的 BJT 的 VBE 之差，具有正温度系数（PTAT），约为 (kT/q) * ln(N)
  • m：增益系数，用于放大 PTAT 电压以恰好补偿 CTAT 电压

标准电路示意：

                      VDD
                       |
                   +-------+
                   |  OPA  |
                   +---+---+
                       |
         +-------------+-------------+
         |                           |
        [R1]                        [R2]
         |                           |
    +----+----+                +----+----+
    |   Q1    |                |   Q2    |
    |  (1x)   |                |  (Nx)   |
    +----+----+                +----+----+
         |                           |
         +-------------+-------------+
                       |
                     [R3]
                       |
                      GND
  • Q1 和 Q2 的发射极面积比为 1:N
  • OPA 迫使 Q1 和 Q2 的集电极电压相等
  • 得到 ΔVBE = VBE1 - VBE2 = (kT/q) * ln(N)
  • PTAT 电流 I = ΔVBE / R1
  • VBG = VBE1 + (R2/R1) * ΔVBE

温度补偿：通过调整 R2/R1 的比例 m，使 VBG 在某一温度（如 25~30°C）拥有零温度系数。

为什么需要修调

  1. BJT 工艺参数偏差：

    • 饱和电流 IS 随工艺变化
    • 正向电流增益 β 的变化
    • Early 电压效应

  2. 电阻比值偏差：

    • 虽然电阻比（R2/R1）的匹配度较好，但绝对值偏差会影响环路工作点
    • 电阻类型（poly, diffusion, well）的电压系数

  3. 运放失调电压：

    • OPA 的输入失调 Vos 直接乘以增益系数加到 VBG 上
    • 典型 Vos ~ 1~10 mV，乘上增益 10 倍，影响可达 10100 mV

  4. 曲率补偿残余：

    • 一阶补偿（first-order compensation）后仍有残差（约几百 uV ~ 几 mV）
    • 高阶曲率补偿（curvature compensation）可以减少但无法完全消除

修调电路

VBG 修调通常有以下方式：

1. 电阻比值修调 (Resistor Ratio Trim)

VBG = VBE + (R2_trim / R1) * ΔVBE

在 R2 上添加可调修调电阻，改变电压增益系数 m：

  • 增大 R2 → 增大 PTAT 分量 → VBG 升高
  • 减小 R2 → 减小 PTAT 分量 → VBG 降低

2. 修调电阻串并联（Vbg Trim Ladder）

      VBG node
         |
       [R_fixed]
         |
    +----+----+----+
    |    |    |    |
   [S0] [S1] [S2] [S3]
    |    |    |    |
   [R0] [R1] [R2] [R3]
    |    |    |    |
    +----+----+----+
         |
        GND

通过控制开关 S0~S3，选择性地将修调电阻接入，改变分压网络的等效电阻。

3. Offset 注入修调 (Offset Trim)

在 OPA 输入端注入微小偏移电流，等效于调整 OPA 的输入参考失调，从而改变 VBG 输出。

4. 温度系数修调 (Tempco Trim)

某些高精度设计会同时修调 VBG 的绝对电压值和温度系数，需要两套修调码：

  • Coarse Trim：调整绝对电压
  • Fine Trim：调整温度系数（在高温和低温两个温度点测量后计算）

测试方法 (Test Methods)

标准 CP 修调流程

1. 上电并开启 Bandgap 模块
2. 等待 Bandgap 稳定（~100 us ~ 1 ms，取决于启动电路）
3. 用 ATE 高精度 ADC 测量 VBG pin 电压
4. 与目标 VBG（如 1.200V）比较
5. 二分法搜索最佳 Trim Code
6. 编程 OTP
7. 验证最终 VBG 电压

多温度点修调流程

对于同时修调温度系数的方案：

Step 1: 常温修调 (Trim @ 25°C)
  - 调整到目标电压 VBG_target (如 1.200V)
  - 记录 Trim Code_25C

Step 2: 高温测量 (Measure @ 85°C or 125°C)
  - 施加温度，等待热平衡
  - 测量 VBG 电压，记录偏差 ΔV_high = VBG(85°C) - VBG(25°C)

Step 3: 低温测量 (Measure @ -40°C or 0°C)
  - 施加温度，等待热平衡
  - 测量 VBG 电压，记录偏差 ΔV_low = VBG(-40°C) - VBG(25°C)

Step 4: 温度系数计算
  - TC (ppm/°C) = max(|ΔV_high|, |ΔV_low|) / (VBG_target * ΔT) * 1e6
  - 若 TC 超标，调整温度补偿 Trim Code（如有）

Step 5: 确定最终 Trim Code
  - 如有多套修调码（VBG Trim + TC Trim），分别编程

测试条件

参数典型条件备注
电压VDD = 标称值 +/-10%测试 PSRR 影响
温度25°C (主修调), 85°C, -40°C全温范围验证
负载电流0 ~ Imax (如 100 uA)验证负载调节率
测量点位尽量近芯片 pad (Kelvin)减少走线压降
热平衡时间1~5 秒/°C 变化大温差需较长 soak

Pass/Fail 判据

  • PASS：VBG 在修调范围内，全温偏移满足 SPEC (典型 +/-1% 或 +/-0.5%)
  • FAIL：
    • VBG 不可修调到目标值（Trim range 不足或电路异常）
    • 温度系数严重超标（匹配异常或曲率补偿失效）
    • 高温或低温下 VBG 跳变（启动电路失效或漏电）

注意事项 (Considerations)

  1. 电压模式下的测量准确性：VBG 节点通常高阻抗，微安级的漏电（如探针卡漏电、ATE 输入漏电）就会造成可观的误差。使用高阻抗探针或缓冲器。
  2. 热梯度（Thermal Gradient）：芯片内部的功率耗散不均可导致局部温度梯度，引起 VBG 的误差。尤其在高温测试和大电流模块工作时。
  3. 应力影响（Package Stress）：封装后的塑封应力会改变 BJT 的 VBE 特性和电阻值，导致 FT 和 CP 的 VBG 结果有偏移。高精度设计需要在 CP 预留 offset 补偿。
  4. 启动电路：Bandgap 启动电路故障可能导致 VBG = 0 或 VBG = VDD（锁定在简并偏置点）。测试时需确认 VBG 已正常启动。
  5. Trim Code 安全边界：不要选择边界处的 Trim Code，预留一定的双向调节余量应对封装应力和老化。
  6. 混合信号干扰：同一芯片上的数字电路开关噪声会通过衬底耦合到 Bandgap 节点。CP/FT 测试中需关注数字电路活动期间的 VBG 纹波。

5. VREF 输出电压精度修调

原理 (Principles)

电路架构

VREF 是 PMIC 中经过 Buffer 缓冲后的参考电压（区别于直接输出的 VBG 或 VREF1P0），通常通过以下结构产生：

VBG (1.2V) ---> [Resistor Divider] ---> [Buffer Amplifier] ---> VREF output node
                      ^                          |
                      |                          |
               Trim Code Control              [C_load]
  • VREF 可能与 VREF1P0 共用分压后的电压，也可能单独产生（如 0.6V、0.8V、1.8V 等不同电压的参考源）
  • 与 VREF1P0 的核心区别在于：VREF 修调关注的是从 Bandgap VBG 到最终 VREF 输出的全链路精度

为什么需要独立修调 VREF（而非仅修调 VBG）

  1. Buffer 失调偏差：VREF 输出的 Buffer 放大器有自己的输入失调电压，与 VBG 修调的 OPA 不一定是同一个。
  2. 分压网络偏差：分压电阻的匹配误差（即使 VBG 已修调准确）。
  3. 不同 VREF 分支各自独立：PMIC 可能有多个 VREF 电压（如 VREF_AO、VREF_IO、VREF_CORE 等），每个需要独立修调。

修调电路

VREF 修调通常采用与 VREF1P0 类似的阻性分压修调方式：

  • 改变分压电阻比例
  • 或注入偏移电流（Current-steering DAC）

测试方法 (Test Methods)

CP/FT 测试流程

VREF 修调的流程与 VREF1P0 修调高度相似：

1. Power on, enable VREF output
2. 在 VREF 引脚以 Kelvin 方式测量输出电压
3. 用 ATE 高精度 DVM 测量（精度 >= 0.1mV）
4. 与目标电压比较
5. 二分法搜索最佳 Trim Code
6. 编程 OTP
7. 验证

测试条件对比表

参数VREF TrimVREF1P0 Trim备注
典型电压0.6V / 0.8V / 1.8V1.0V视设计而定
修调精度要求+/-1~2%+/-1~2%可能更严
Buffer 驱动能力通常更弱中等测 load regulation
去耦需求强（高阻节点）中

注意事项 (Considerations)

  1. 高阻节点测量：VREF 节点可能非常高的输出阻抗，任何测量路径的漏电都会引起电压误差。建议：

    • 使用主动缓冲探针（Active Probe）
    • 测量时间尽可能短，避免电荷注入
    • 使用 Guard Ring 技术保护测量走线

  2. 电源噪声敏感性：VREF 输出上的噪声会被 LDO 和 ADC 等负载直接使用，影响系统性能。测试中应使用低噪声电源。

  3. 多 VREF 的交叉影响：若多个 VREF 共享同一个 Bandgap 源，修调其中一个可能通过电源线或衬底耦合影响其他 VREF 的输出。

6. IREF 基准电流修调

原理 (Principles)

电路架构

IREF（Reference Current）是 PMIC 中用于偏置所有模块（LDO、Buck、Buckboost、ADC、OSC 等）的基准电流。典型的 IREF 产生电路基于 Bandgap 参考电压和片上电阻：

典型实现方式：

       VDD
        |
   +----+-----+
   |   PMOS    |   <- 电流镜
   +----+-----+
        |
        +----------- IREF 输出 (给各模块镜像)
        |
    +---+---+
    |  OPA  |
    +---+---+
        |
        +---+---+
            |
       +---+---+
       |  Rref  |   <- 决定电流大小的参考电阻
       +---+---+
            |
           GND

工作原理：

  1. OPA 将 VREF（或 VBG）加在参考电阻 Rref 两端
  2. 产生电流 I = VREF / Rref
  3. PMOS 电流镜将此电流镜像输出给其他模块

电流镜分配：

IREF (master)
    |
    +---> I_LDO (1x)
    +---> I_BUCK (4x)
    +---> I_OSC (2x)
    +---> I_ADC (0.5x)
    +---> I_BIAS (0.25x)

各模块的偏置电流通过电流镜比例缩放得到。

为什么需要修调

  1. 电阻 Rref 的工艺偏差：片上电阻绝对值偏差可达 +/-20~30%，导致 IREF 同比例偏差
  2. VREF 残余误差：虽然 VREF 已修调，但仍有残余误差
  3. 电流镜匹配误差：PMOS 电流镜的沟道长度调制效应和 Vth 失配
  4. 温度系数：电阻的 TCR 导致 IREF 随温度变化

影响范围：

  • IREF 偏差 10% → LDO 静态电流偏差 10%
  • IREF 偏差 → RC OSC 频率偏差（因为充电电流直接来自 IREF）
  • IREF 偏差 → LDO/Buck 的 slew rate 变化
  • IREF 偏差 → 比较器延迟变化

所以 IREF 修调对整体 PMIC 性能有系统性影响。

修调电路

IREF 的修调主要是改变等效参考电阻 Rref 或改变 VREF 的加成系数：

1. 电阻 Bank 修调 (Resistor Array Trim)

    VREF
      |
    [R_fixed]
      |
    +--S0--[R0]--+
    |            |
    +--S1--[R1]--|
    |            |
    +--S2--[R2]--+
      |
     GND
  • 开关 S0~S2 控制是否将对应修调电阻接入
  • 总电阻 = R_fixed + Σ(Ri * Si)
  • 增大电阻 → IREF 减小
  • 减小电阻 → IREF 增大

2. 电流 DAC 修调 (Current DAC Trim)

IREF = I_master + I_trim

在主电流 I_master 的基础上，叠加一个可正可负的修调电流 I_trim：

  • 使用电流 DAC 产生精细调整的修调电流
  • 优点：调整精细、不依赖电阻匹配
  • 缺点：功耗略大

3. 电流镜比例修调

改变镜像晶体管的尺寸比（M:N），直接缩放输出电流。但芯片制造后尺寸固定，这种修调通常通过冗余的并联晶体管阵列实现。

测试方法 (Test Methods)

CP 测试修调流程

1. 上电开启 IREF 模块
2. 建立一个外部测量路径：
   - 方式 A: 直接测量 IREF pin（如有专用 pin，通过 ATE pA 级电流表）
   - 方式 B: 测量 IREF 镜像到某个测试 pin 的电流
   - 方式 C: 测量 IREF 流过某个外接电阻产生的电压（V = IREF * Rext）
3. 与目标 IREF 值比较（如 2.0 uA）
4. 二分法搜索最佳 Trim Code
5. 编程 OTP
6. 验证

小电流测量技术

IREF 通常是微安级（1~10 uA），测量小电流需特别注意：

  1. ATE pA 级电流表：直接测量 IREF pin

    • 优点：直接、准确
    • 缺点：需要高精度电流表（昂贵），测量速度慢

  2. 电阻法：IREF 流过精密外置电阻，测量电阻两端电压

    IREF pin ---[Rext (精密 0.1%)]--- GND
             |
           测量 V = IREF * Rext
    • 选择合适的 Rext 使 V 在 50~500mV 范围内
    • 使用 Kelvin 测量电压
    • 优点：成本低、测量速度快
    • 缺点：需要高精度外接电阻，且电阻值需匹配电流范围

  3. 集成电流镜法：将 IREF 镜像到 ATE 可测的更大电流路径

    • 如镜像放大 100 倍，测大电流再除回来
    • 缺点：镜像比例本身有误差

  4. 积分法 (Capacitor Integration)：

    将 IREF 对已知电容 C 充电
测量电压从 0 到 Vth 的时间 t
IREF = C * Vth / t
    • 优点：适合极微小电流
    • 缺点：测量时间较长

测试条件

参数典型条件备注
VDD标称值 +/-10%验证电流随 VDD 变化（PSRR）
温度25°C / 85°C / -40°CIREF TCR 关键
输出负载接近典型应用电流镜输出阻抗影响
测量精度+/-1% 或更高取决于 ATE 电流测量能力

Pass/Fail 判据

  • PASS：Trim 后 IREF 在目标值 +/-2~5% 内（根据不同 SPEC）
  • FAIL：
    • 修调到极限仍无法达标 → 电阻偏差过大或电流镜像故障
    • IREF 在不同 VDD 条件下变化过大（PSRR 差）
    • IREF 随温度漂移过大（电阻 TCR 异常）

注意事项 (Considerations)

  1. 电流镜输出阻抗：电流源的输出阻抗有限，当输出端电压变化时，IREF 会因沟道长度调制效应而变化。测试时需固定输出端电压（Force Voltage, Measure Current）。
  2. 漏电补偿：ATE 通道的漏电（尤其是半导体开关矩阵的漏电）在小电流测量中不能忽略。使用前需做漏电校准（Open/Short 补偿或减去背景电流）。
  3. Shielding（屏蔽）：微小电流测量路径需要良好的屏蔽（Guard Trace），减少 EMI 和串扰。
  4. 稳定时间：IREF 模块的启动时间可能在几百 us 到几 ms，特别是有启动辅助电路的设计。
  5. 对其他模块的影响：IREF 修调改变后，所有依赖 IREF 的模块行为都会变化。修调 IREF 后需重新验证关键模块的性能（如 OSC 频率、LDO 静态电流、比较器延迟）。
  6. 同步修调（Linked Trims）：IREF 和 OSC 频率修调存在耦合（OSC 频率依赖于 IREF），修调顺序很重要：
    • 通常先修 IREF（确定全局偏置电流基准）
    • 再修 OSC 频率（针对已确定的 IREF 做电容修调）
    • 最后修 VREF/VBG（如果没有交叉依赖）
  7. Trim Code 冗余 vs. 精度：IREF 修调的位数需平衡修调范围和步长。典型设计 4~6 bit。

总结与修调顺序建议

推荐的修调依赖顺序

在 PMIC 的 CP 测试中，各基准修调项之间存在依赖关系，正确的修调顺序至关重要：

Step 1: VBG Trim         ← 最底层参考（与温度无关的电压）
     |
Step 2: IREF Trim         ← 依赖 VBG，全局偏置电流
     |
Step 3: VREF1P0 Trim      ← 依赖 VBG，参考电压输出
     |
Step 4: VREF Accuracy Trim ← 依赖 VBG/VREF1P0，LDO/SAR 参考
     |
Step 5: RC OSC Trim       ← 依赖 IREF（充电电流）
     |
Step 6: LDO VOUT Trim     ← 依赖 VREF，反馈网络

严格禁止：

  • 先修 OSC 再修 IREF（OSC 频率将在 IREF 修调后被改变）
  • 先修 VREF 再修 VBG（VREF 会在 VBG 修调后偏移）

修调验证 Checklist

  • 各修调项的修调范围是否覆盖所有工艺角？
  • Trim Code 是否有单调性？（Monotonicity check）
  • 各温度点的偏移是否在 SPEC 内？
  • 修调后的芯片在不同电压下是否仍满足 SPEC？
  • OTP 编程良率？（Program Yield）
  • 封装后 FT 的修调验证？（CP vs FT correlation）
  • Trim Code 存储和读回是否正确？（Readback verification）
