HKADC / XOADC 测试 — PMIC 模数转换器 FT 测试

本文档详细阐述 PMIC 内部 HKADC（Housekeeping ADC，监测用模数转换器）和 XOADC（Crystal Oscillator ADC / 辅助模数转换器）在 FT 阶段的测试原理与测试方法。涵盖管脚漏电测试、转码精度测试、INL/DNL 测试、上拉电阻测试等关键测试项目。

第一部分：HKADC (Housekeeping ADC)

1. HKADC 概述

HKADC (Housekeeping ADC) 是 PMIC 内部用于监测各种电压、电流和温度信号的模数转换器。它不需要高速转换，但需要足够的精度和通道数来监控 PMIC 的各个工作状态。

2. 管脚漏电测试 (HKADC Pin Leakage Test)

2.1 原理

ADC 输入引脚的漏电测试用于验证输入缓冲区（Input Buffer / MUX）在高阻抗状态下的漏电流是否在规格范围内。对于 HKADC 这类监测输入而言，过大的引脚漏电会导致：

  • 外部测量信号被分压，引入系统性测量误差
  • 高阻抗传感器（如 NTC 热敏电阻、高阻分压网络）的读数偏差
  • 多个通道之间的串扰（通过 MUX 漏电路径耦合）

2.2 测试方法

2.2.1 基本漏电测试

方法: Force Voltage → Measure Current (FVMI)

测试条件:
  - DUT 上电正常 (Power ON)
  - HKADC 模块使能 (Enabled)
  - ADC 输入引脚设置为 High-Z / Input 模式
  - 所有 MUX 通道关闭（无通道被选通）

测试步骤:
  Step 1: 将 ATE SMU 连接到待测 ADC 输入引脚
  Step 2: Force 电压 V_force = VDD × 0.9 (接近供电电压)
  Step 3: 等待稳定时间 t_settle = 500μs
  Step 4: 测量该引脚的漏电流 I_leak
  Step 5: 切换 Force 电压 V_force = VSS + 0.1V (接近地电位)
  Step 6: 再次测量漏电流 I_leak
  Step 7: 验证 I_leak < I_leak_max

注意: 需分别在正电压和低电压条件下测试，以覆盖漏电的方向性。

2.3 注意事项

  1. 保护二极管：ADC 输入引脚通常有 ESD 保护二极管，当 Force 电压超过 VDD+Vf 或低于 VSS-Vf 时，保护二极管导通，测量的漏电会异常偏大。Force 电压必须在电源轨范围内。
  2. ATE 通道泄漏：ATE 系统本身的漏电（通过 Relay 矩阵、电缆等）可能与被测漏电相当。需要预先进行背景电流校准 (Background Subtraction)。
  3. 温度效应：漏电流在高温下呈指数增长。高温条件测试时，规格限值应适当放宽。
  4. 通道间串扰：所有 HKADC 输入通道共享同一输入节点，测试一个通道时应确保其他通道处于高阻态，避免串扰。

3. HKADC 转码精度测试 (HKADC Conversion Accuracy Test)

3.1 原理

HKADC 转码精度测试是验证 ADC 将模拟输入电压线性转换为数字码的全链路精度。测试覆盖 ADC Core 的转换误差、MUX 导通电阻引入的压降、PGA 增益误差以及参考电压漂移的综合影响。

对于理想 N-bit ADC，输入电压 V_in 与输出码 D_out 的关系为：

D_out = round( (V_in / V_ref) × 2^N )

其中:
  D_out: 输出数字码 (0 ~ 2^N - 1)
  V_in:  模拟输入电压
  V_ref: ADC 参考电压
  N:     ADC 分辨率 (bits)
  1 LSB = V_ref / 2^N

3.2 测试方法

3.2.1 端点法测试 (Endpoint Method)

量产 FT 中最常用的方法，通过在 ADC 输入范围的几个关键点上施加校准电压并读取转换结果来评估精度。

测试流程:
  Step 1: 初始化 HKADC 模块
    - 使能 HKADC 时钟
    - 选择测试通道
    - 设置 PGA 增益
    - 设置转换模式 (单次/连续)

  Step 2: 施加校准电压 V_cal
    - 使用高精度 SMU / DVM 校准的电压源
    - 连接到 HKADC 指定输入引脚
    - 电压必须稳定 (ripple < 0.1 LSB)

  Step 3: 触发 ADC 转换
    - 通过 I2C/SPI 发出转换命令
    - 等待转换完成 (轮询状态寄存器或等待中断)

  Step 4: 读取转换结果
    - 从结果寄存器读取 D_out
    - 可选: 多次采样取平均 (降低随机噪声)

  Step 5: 计算误差
    - 理想码 = round(V_cal / V_ref × 2^N)
    - 误差 (LSB) = D_out - 理想码
    - 误差 (mV) = (D_out × V_ref / 2^N) - V_cal

  Step 6: 重复 Step 2~5，遍历所有测试电压点

PMIC 的多个 HKADC 通道需要逐一验证：

通道 0 (VBAT_SENSE):
  V_ref = 5.0V (内部分压)
  测试点: 2.7V, 3.6V, 4.2V (对应不同电池电压)

  V_ref = 1.8V (内部基准)
  测试点: 0.3V, 0.7V, 1.2V (对应不同温度)
  
通道 2 (I_SENSE):
  V_ref = 0.1V (差分小信号)
  测试点: 0.01V, 0.05V, 0.09V (对应不同电流)

3.4 注意事项

  1. 参考电压稳定性：HKADC 的 V_ref 可能来自内部 Bandgap 或外部引脚。V_ref 的噪声和漂移直接影响转码精度，测试前需等待参考电压稳定。
  2. MUX 串扰：当切换通道时，前一个通道的残留电荷会影响新通道的转换结果。建议在通道切换后插入 dummy conversion。
  3. 输入驱动能力：HKADC 输入端的等效采样电容在采样瞬间会汲取电流脉冲，外部信号源需要有足够的驱动能力。
  4. PSRR 影响：电源噪声会通过 ADC 的参考电压路径耦合到转换结果。测试时应确保供电电源的低噪声。
  5. 温度漂移：Offset 和 Gain 随温度漂移。全温测试需建立温度补偿查表或使用比例测量方法。

4. INL / DNL 测试 (Integral / Differential Nonlinearity Test)

4.1 原理

4.1.1 DNL (微分非线性)

DNL 表示 ADC 各相邻码之间的实际步长与理想步长 (1 LSB) 的偏差。

DNL[k] = (W[k] - 1 LSB) / 1 LSB

其中:
  W[k] = V[k+1] - V[k] (第 k 个码的实际宽度)
  V[k] = 第 k 个码的跳变点电压

理想情况: DNL[k] = 0  (每个码宽度恰好为 1 LSB)
实际情况: DNL[k] 在 -1 ~ +1 LSB 之间
DNL 值含义
DNL > 0该码的宽度大于 1 LSB（该码占更大电压范围）
DNL = 0该码宽度恰好为 1 LSB（理想）
DNL < 0该码宽度小于 1 LSB（该码占更小电压范围）
DNL < -0.9 LSB可能丢失码 (Missing Code)，该码宽度几乎为零

4.1.2 INL (积分非线性)

INL 表示 ADC 实际传输函数与理想传输函数之间的累积偏差，在所有码的 DNL 累积后得到。

INL[k] = Σ(i=0 to k) DNL[i]

或者使用端点拟合法:
  INL[k] = (V_actual[k] - V_ideal[k]) / 1 LSB

其中:
  V_actual[k]: 第 k 个码的实际跳变点电压
  V_ideal[k]:  第 k 个码的理想跳变点电压 (通过端点连线确定)

4.1.3 理想传输函数

数字输出码
  1111 ──┐
         │
  1110 ──┤  │
         │  │
  1101 ──┤    │
         │    │
  ...    │      │
         │      │
  0001 ──┤        │
         │        │
  0000 ──┤          │
         LSB
         └──┬──┬──┬──┬──┬──→ 模拟输入电压
            1  2  3  4  5  (LSB)

理想情况下，每个码的宽度均为 1 LSB，且跳变点均匀分布。

4.2 测试方法

4.2.1 直方图法 (Histogram Method)

原理：将已知分布的输入信号（如三角波 / 正弦波）输入 ADC，统计各码出现的频率。对于非线性度低的 ADC，各码出现的频率应与输入信号的 PDF（概率密度函数）匹配。

FT 应用: 对于低分辨率 ADC (8~12-bit)，使用三角波直方图法

测试设置:
  信号源: AWG (任意波形发生器)
  波形: 低失真三角波 (Triangular Wave)
  幅度: 略超过 ADC 满量程范围 (overdrive ~5%)
  频率: f_signal << f_sample (确保充分采样)
  采样数: 每码至少 10~100 次以上 (总采样数 = 2^N × 10)

测试步骤:
  Step 1: AWG 输出三角波到 HKADC 输入引脚
  Step 2: ADC 连续采样，存储所有码值
  Step 3: 统计各码出现的次数 H[k]
  Step 4: 计算各码的宽度 W[k] = H[k] / H_avg
  Step 5: 计算 DNL[k] = W[k] - 1 (归一化)
  Step 6: 计算 INL[k] = Σ(i=0 to k) DNL[i]
  Step 7: 报告 max(DNL) 和 max(INL)

4.2.2 伺服环路法 (Servo-Loop Method)

原理：使用反馈控制回路，使 ADC 输入端精确处于某两个码之间的跳变点。

适用: 高精度 ADC 测试 (12-bit 以上)，FT 中较少使用（速度慢）

测试电路:
  ┌─────────┐
  │  SMU /  │──── V_in ────→ DUT ADC
  │  AWG    │                    │
  │         │←── D_out ───────┘  │
  │         │                    │
  │ DAC ←── Comparator ←────── D_target
  └─────────┘

工作过程:
  1. 设置目标码 k, 以及比较方向 (V_in 从低到高)
  2. ADC 转换得到 D_out
  3. 比较 D_out 与目标码 k:
     - D_out < k: 增大 V_in
     - D_out = k: 保持 V_in 记录
     - D_out > k: 减小 V_in
  4. 反复逼近，找到 D_out 从 k-1 跳变到 k 的精确电压
  5. 记录该电压为 V_transition[k]
  6. 遍历所有 k = 1 到 2^N-1，获得完整传输函数

4.2.3 线性斜坡法 (Ramp Method)

FT 常用的折中方案：

测试设置:
  - 使用高线性度 SMU 或 AWG 输出缓慢线性斜坡电压
  - 斜坡变化率: dV/dt < 1 LSB / t_conv (确保每码至少一次采样)
  - 电压范围: 略超过 ADC 满量程

数据采集:
  - ADC 连续转换，记录 (V_force, D_out) 对
  - V_force 由 SMU 的精密 DAC 控制 (已知电压)
  - 同时用 DMM 监测实际 V_in 以提高精度

后处理:
  - 对每个码 k, 找到所有 D_out = k 对应的 V_force 范围
  - 码 k 的边界 = min(V_force) 和 max(V_force)
  - 码宽度 W[k] = V_max - V_min
  - DNL[k] = W[k] / W_ideal - 1
  - INL[k] = (V_center[k] - V_ideal_center[k]) / 1 LSB

4.3 判定标准 (Criteria)

参数8-bit ADC10-bit ADC12-bit ADC

INL±0.5 LSB±1 LSB±1~±2 LSB
Missing Code不允许不允许不允许
单调性必须必须必须

4.4 注意事项

  1. 噪声对 DNL 的影响：输入噪声会模糊码的边界，使 DNL 测量值偏小（表现比实际更好）。可在输入增加小振幅抖动 (Dither) 或使用大直方图统计消除。
  2. 测试时间：对于 12-bit ADC，完整的直方图法需要 2^12 × 10 = 40,960 次采样。FT 中通常简化（只测关键码点或分段测试）。
  3. 信号源线性度：斜坡/三角波的线性度必须优于被测 ADC 的线性度要求（至少 3~5x 更好），否则测量误差会叠加到 ADC 的 INL 结果中。
  4. 温度影响：INL 和 DNL 受温度影响，全温范围测试需要三温数据。
  5. 码密度直方图边界效应：在满量程边界 (code 0 和 code 2^N-1)，直方图统计可能不准确，需加入 overdrive 范围。

5. 上拉电阻测试 (HKADC Pull-Up Resistor Test)

5.1 原理

HKADC 的某些输入/输出引脚可能内置可配置的上拉电阻，用于：

  • 与外部漏极开路 (Open-Drain) 信号配合
  • 为外部无源传感器（如 NTC）提供偏置电流
  • 确保未使用的输入引脚处于确定电平

5.2 测试方法

5.2.1 电压分压法

测试电路:
  ┌──────────────┐
  │  DUT         │
  │              │
  │  Pin ──┬─────┤── Internal Pull-Up R_pu
  │        │     │      │
  │        │     │     VDD
  │        │     │
  │        │
  │     R_ext (已知精密电阻)
  │        │
  │       GND
  └──────────────┘

测试步骤:
  Step 1: 使能内部上拉电阻 (寄存器设置)
  Step 2: 外部连接精密电阻 R_ext 到 GND
  Step 3: 测量引脚电压 V_pin
  Step 4: 计算 R_pu:
         R_pu = R_ext × (VDD - V_pin) / V_pin
         (上拉电阻与 R_ext 形成分压)
  Step 5: 验证 R_pu 在规格范围内

5.2.2 电流测量法

直接测量法（更精确）:

测试步骤:
  Step 1: 使能内部上拉电阻
  Step 2: 使用 SMU 在引脚上 Force 电压 V_force = VDD × 0.5
  Step 3: 测量 SMU 输出的电流 I_meas (漏入上拉电阻的电流)
  Step 4: 计算 R_pu = (VDD - V_force) / I_meas
  Step 5: 切换 V_force 到不同电压值验证线性度

5.2.3 多档位测试

如果上拉电阻有多个可编程档位：

5.3 判定标准 (Criteria)

参数典型规格说明

上拉电阻精度 (Trim 后)±2%已执行修调

电源电压敏感度< 1%/V随 VDD 变化

5.4 注意事项

  1. 外部电阻精度：外接的精密电阻 R_ext 精度应优于 DUT 上拉电阻规格的 5 倍（如 ±2% 规格需 ≤ ±0.4% 外接电阻）。
  2. 引脚漏电校正：如果引脚自身有漏电（尤其是高温下），会在分压法中引入误差。建议先测量引脚背景漏电再做校正。
  3. 开关导通电阻：上拉电阻的内部开关 (MOS Switch) 导通电阻 Ron 会与 R_pu 串联，成为测量值的一部分。这通常是设计允许的。
  4. 双测试电压：建议在 V_pin = VDD × 0.3 和 V_pin = VDD × 0.7 两个点各测一次，验证上拉电阻的电压系数。

第二部分：XOADC (Crystal Oscillator ADC / 辅助 ADC)

6. XOADC 概述

XOADC (Crystal Oscillator ADC) 是 PMIC 中专用于辅助测量的低速率、高精度 ADC。与 HKADC 相比，XOADC 通常具有：

特性HKADCXOADC
典型分辨率10~12-bit14~16-bit
采样率1k~10ksps10~100sps
通道数6~16 通道2~4 通道
主要用途实时监测 (电压/电流/温度)精密测量 (电池内阻、阻抗)
精度1%~3%0.1%~0.5%
架构SAR / Sigma-DeltaSigma-Delta (过采样)

6.1 典型应用

  • 电池内阻精密测量 (辅助 SOH/EIS)
  • 高精度温度测量 (配合 NTC 热敏电阻)
  • 外部传感器信号采集
  • 关键电压的精确读取

7. 静态参数测试 (XOADC Static Parameter Test)

7.1 原理

XOADC 的静态参数测试覆盖以下关键指标：

  • 偏移误差 (Offset Error)：零输入时的 ADC 输出码偏移
  • 增益误差 (Gain Error)：ADC 传输函数斜率与理想值的偏差
  • 线性误差 (Linearity Error)：ADC 传输函数与最佳拟合直线的偏离
  • 噪声 (Noise)：ADC 在静态输入条件下的输出码标准偏差

7.2 测试方法

7.2.1 偏移误差测试

测试条件:
  - XOADC 正常工作模式
  - 输入通道连接到 GND (或输入短接到 VCM)
  - 过采样率 (OSR) 设置为典型值

测试步骤:
  Step 1: 短接 XOADC 差分输入 (V_in+ = V_in-)
  Step 2: 等待稳定时间 (≥ 100ms for Sigma-Delta)
  Step 3: 连续采样 N 次 (N ≥ 100)
  Step 4: 计算平均码值 D_avg
  Step 5: 计算偏移误差:
         Offset (LSB) = D_avg - 0
         Offset (mV) = D_avg × V_ref / 2^N

判定: Offset < ±3 LSB (典型)

7.2.2 增益误差测试

测试条件:
  - XOADC 正常工作模式
  - 输入通道连接精密电压源

测试步骤:
  Step 1: 施加低端校准电压 V_low (如 V_ref × 0.05)
  Step 2: 采样，得到 D_low
  Step 3: 施加高端校准电压 V_high (如 V_ref × 0.95)
  Step 4: 采样，得到 D_high
  Step 5: 计算实际增益:
         G_actual = (D_high - D_low) / (V_high - V_low)
         G_ideal = 2^N / V_ref
  Step 6: 计算增益误差:
         Gain_Error (%) = (G_actual / G_ideal - 1) × 100%

判定: Gain_Error < ±0.5% (典型)

7.2.3 线性误差测试

方法: 端点拟合法 (Endpoint Fit)

测试步骤:
  Step 1: 选择 M 个测试电压点 (M ≥ 8)，均匀分布在输入范围
  Step 2: 对每个点施加 V_in[k] 并记录 D_out[k]
  Step 3: 使用端点连线建立理想传输函数:
         D_ideal[k] = (V_in[k] - V_min) / (V_max - V_min) × 2^N
  Step 4: 计算各点偏差:
         INL[k] = D_out[k] - D_ideal[k]
  Step 5: 报告 max(|INL[k]|)

测试电压点 (14-bit, V_ref = 2.5V):
  | 点号 | V_in (V) | 理想码 |
  |:----:|:--------:|:------:|
  | 1 | 0.000 | 0 |
  | 2 | 0.3125 | 2048 |
  | 3 | 0.6250 | 4096 |
  | 4 | 0.9375 | 6144 |
  | 5 | 1.2500 | 8192 |
  | 6 | 1.5625 | 10240 |
  | 7 | 1.8750 | 12288 |
  | 8 | 2.1875 | 14336 |
  | 9 | 2.5000 | 16383 |

7.2.4 噪声测试

测试条件:
  - XOADC 差分输入短接到 VCM (共模电压)
  - 连续采样 N 次 (N ≥ 1000)

测试步骤:
  Step 1: 采集 N 个样本 D[0] ~ D[N-1]
  Step 2: 计算均值 μ = avg(D)
  Step 3: 计算标准偏差 σ = sqrt(Σ(D[i] - μ)² / (N-1))
  Step 4: 计算有效分辨率 (ENOB):
         ENOB = log2(FSR / (6.6 × σ × V_ref / 2^N))

判定:
  | 参数 | 典型值 |
  |------|:------:|
  | RMS 噪声 | < 50μV rms |
  | 峰峰值噪声 | < 300μV pp |
  | 有效位数 (ENOB) | ≥ 13-bit @ 10sps |

7.3 判定标准 (Criteria)

参数XOADC 典型规格测试条件
分辨率14~16-bit—
偏移误差±2 LSB零输入
增益误差±0.2% ~ ±0.5%全量程
积分非线性 (INL)±2 LSB端点拟合法
微分非线性 (DNL)±0.5 LSB—
RMS 噪声< 20~50μV短接输入, OSR=256
有效位数 (ENOB)≥ 13-bit @ 10sps—
电源抑制比 (PSRR)≥ 80dB @ DC—
共模抑制比 (CMRR)≥ 90dB @ DC—

7.4 注意事项

  1. 过采样率 (OSR) 设置：Sigma-Delta ADC 的精度与 OSR 成正比，但转换时间也随之增加。FT 测试需在精度与测试时间之间权衡。
  2. 建立时间 (Settling Time)：Sigma-Delta ADC 的数字滤波器在通道切换或输入跳变后需要数个转换周期才能稳定。在切换通道后应丢弃前 2~3 次转换结果。
  3. 参考电压去耦：XOADC 的高精度依赖于稳定的参考电压。PCB 布局中 V_ref 去耦电容必须靠近 DUT 引脚。
  4. 差分布线：差分输入对必须等长等距走线，避免引入额外的差分噪声。
  5. 时钟抖动：XOADC 的时钟质量直接影响 SNR。过大的时钟抖动会劣化高频输入的性能。

8. 上拉电阻测试 (XOADC Pull-Up Resistor Test)

8.1 原理

XOADC 的上拉电阻测试与 HKADC 类似，但由于 XOADC 通常用于精密测量，其上拉电阻的精度要求可能更高，测量方法也更严格。

8.2 测试方法

8.2.1 静态分压法

测试电路（与 HKADC 一致）:

     VDD
      │
      ├── Internal R_pu (待测)
      │
  DUT Pin ─── R_ext (精密) ─── GND

测量:
  1. 使能上拉
  2. 测量 V_pin
  3. R_pu = R_ext × (VDD - V_pin) / V_pin

8.2.2 精确电流注入法

适用于 XOADC 的高精度要求：

测试步骤:
  Step 1: 使能上拉电阻
  Step 2: 使用精密 SMU 在引脚注入已知电流 I_inject
  Step 3: 测量引脚电压 V_pin
  Step 4: 计算 R_pu = (VDD - V_pin) / (I_pu + I_inject)
  
  其中 I_pu 是上拉电阻本身的电流:
  I_pu = V_pin / R_ext (如果外接 R_ext 到 GND)
  或 I_pu = 0 (如果引脚悬空, 但悬空时电压会飘到 VDD)

8.2.3 差分测量法（消除误差）

方法: 测量两个不同外接电阻下的电压，计算 R_pu

测量点 1: R_ext1 → V_pin1 → I_total1 = V_pin1 / R_ext1
测量点 2: R_ext2 → V_pin2 → I_total2 = V_pin2 / R_ext2

方程组:
  I_total1 = (VDD - V_pin1) / R_pu + V_pin1 / R_ext1
  I_total2 = (VDD - V_pin2) / R_pu + V_pin2 / R_ext2

由于 R_ext1, R_ext2 已知，求解 R_pu:
  R_pu = ... (通过解方程消除 SMU 偏置误差)

8.3 判定标准 (Criteria)

参数XOADC 典型规格
上拉电阻精度±5%
上拉电阻精度 (Trim 后)±1%
温度系数 (TCR)< 200ppm/°C
电压系数 (VCR)< 100ppm/V

8.4 注意事项

  1. 高精度电阻要求：XOADC 的上拉电阻可能需要 ±1% 或更高精度，外接参考电阻的精度必须 < ±0.1%。
  2. 自热效应：上拉电阻的功耗虽然小，但在高精度测量中自热效应可能导致测量值漂移。测试时间应尽量短或等待热平衡。
  3. XOADC 内部采样：上拉电阻与 XOADC 输入采样电路共用引脚，采样时电容的瞬态充电会干扰电压测量。应在采样保持间隙进行上拉电阻测量。
