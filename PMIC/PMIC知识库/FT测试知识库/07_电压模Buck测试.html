电压模Buck测试 — PMIC 电压模式降压变换器 FT 测试（含多相）

本文档覆盖电压模式降压变换器（Voltage-Mode Buck Converter）在 FT（Final Test）阶段的所有测试项，涵盖单相与多相配置的完整测试方案，包括原理说明、测试方法、条件配置与判定标准。

一、电压模Buck变换器概述

1.1 电压模式控制基本原理

电压模式控制（Voltage-Mode Control）是 PWM 降压变换器中最经典的控制方式。其核心结构如下：

  • 误差放大器（EA, Error Amplifier）：将反馈电压 VFB 与参考电压 VREF 的误差放大
  • 补偿网络（Compensation Network）：Type-II 或 Type-III 补偿，保证环路稳定性和足够的相位裕度
  • PWM 比较器：将 EA 的输出（补偿后的误差信号）与周期性斜坡信号（Ramp）比较，生成 PWM 脉冲
  • 功率级：HS-FET 和 LS-FET 根据 PWM 占空比开关
VREF ---|+\
        |  >---[Compensation]---|+\
VFB ----|-/                     |  >--- PWM ---> Driver ---> Power Stage ---> L/C ---> VOUT
                           Ramp -|-/

电压模式控制的关键特征：

特征描述
控制方式电压环 EA + PWM 比较器
开关频率固定频率（由内部或外部时钟决定）
调制方式固定频率 PWM
补偿需求Type-II / Type-III 补偿（需外部或片上补偿）
瞬态响应中等（受 EA 带宽限制）
抗噪性较弱（PWM 比较器对噪声敏感）
多相扩展适合多相并联（同频率，相位交错）

1.2 三种工作模式

电压模Buck通常支持三种工作模式：

模式全称适用负载效率纹波
CCMContinuous Conduction Mode重载高（导通损耗为主）低
COTConstant-On-Time Mode中载中等中
ECOEfficiency Optimization Mode轻载极高（开关损耗极小）较高

1.3 多相Buck原理

多相Buck将 N 个相同的Buck功率级并联，各相的 PWM 时钟相位错开 360°/N，实现交错运行（Phase Interleaving）。

多相化的核心收益：

收益量化说明
纹波抵消输出纹波降低至单相的 ≈ 1/N（理想情况）
等效频率提高等效开关频率 = N × fsw
输出电容减少同纹波要求下，输出电容可减少 50%+
热分布每相承担 1/N 的电流，热分布均匀
瞬态响应等效频率提高，环路带宽可设计更高

二、多相LX频率测试

2.1 原理

多相Buck的 LX 频率测试需要验证两方面的指标：

  1. 各相开关频率：每相的 PWM 频率应等于系统时钟频率
  2. 相间相位关系：各相之间的相位差应为 360°/N

以 4 相Buck为例，相位关系为：

Phase 1:  ___|‾‾‾‾‾|___|‾‾‾‾‾|___  (0°)
Phase 2:  ___|‾‾‾‾‾|___|‾‾‾‾‾|___  (90°)
Phase 3:  ___|‾‾‾‾‾|___|‾‾‾‾‾|___  (180°)
Phase 4:  ___|‾‾‾‾‾|___|‾‾‾‾‾|___  (270°)

2.2 测试方法

参数条件
VIN标称值
VOUT目标输出电压
ILOAD重载（确保所有相均在 CCM 下工作）
测量节点每相的 LX 引脚
测量仪器多通道示波器 / 频率计

测试步骤：

  1. 使能多相Buck输出至目标 VOUT
  2. 施加足够的负载（确保所有相均处于 CCM，无相被关闭）
  3. 用多通道示波器同时探测每一相的 LX 引脚
  4. 测量每一相的开关频率 fsw_Pn
  5. 测量相邻相之间的相位差 Δφ
  6. 验证频率一致性：各相频率差异 < ±2%
  7. 验证相位差：Δφ ≈ 360°/N ± 允差

2.3 判定标准

参数典型限值
各相频率一致性±2%
相位差误差（2相）180° ± 10°
相位差误差（3相）120° ± 10°
相位差误差（4相）90° ± 10°

2.4 测试注意事项

  • 多相Buck在轻载时会自动关闭部分相（Phase Shedding），测试时需施加足够负载确保所有相工作
  • 探头需使用短接地弹簧，减少环路电感耦合引起的测量误差
  • 相位差测量需同时触发所有通道，避免使用滚动模式

三、多相Buck输出下拉电阻测试

3.1 原理

多相Buck中，每一相都包含一个输出下拉（Output Discharge）通路。当 Buck 被禁用时：

  • 每一相的下拉电阻 Rpd_n 并联连接在 VOUT 与 GND 之间
  • 总下拉电阻 Rpd_total = Rpd_1 || Rpd_2 || … || Rpd_N
  • N 相并联后，总下拉电阻是单相的 1/N

因此，测试多相Buck的下拉电阻时，需要结合相数来推断单相的下拉电阻值。

3.2 测试方法

参数条件
Buck 状态禁用（Disabled）
VOUT 施加电压如 1.0V
测量流出 VOUT 的电流
测量仪器SMU

测试步骤：

  1. 禁用所有相的 Buck 输出
  2. 在 VOUT 引脚施加测试电压 Vforce
  3. 测量流出 VOUT 的电流 Imeas
  4. 计算总下拉电阻：Rpd_total = Vforce / Imeas
  5. 若已知相数为 N，单相下拉电阻为：Rpd_single = Rpd_total × N

3.3 判定标准

参数典型值单位
单相下拉电阻100 ~ 500Ω
4 相总下拉电阻25 ~ 125Ω
允差±20%—

3.4 测试注意事项

  • 确保所有相的下拉开关都正常导通（某些设计在禁用时部分相的下拉不激活）
  • 施加的测试电压不应超过 Buck 的额定输出电压

四、硬线ECO一步调压

4.1 原理

ECO 模式（Efficiency Optimization Mode） 是电压模Buck在轻载时采用的节能模式。

硬线一步调压是指通过硬件引脚控制输出电压在 ECO 模式下快速跳变的机制：

  • 通过一个专用硬件引脚（如 VSEL、VID 等）的电平切换
  • 使 VOUT 直接从当前值跳变到另一个预设值
  • 该过程不依赖数字接口（I2C/SPI），响应速度更快
  • 需要在跳变过程中无输出扰动（Glitch-less Transition）

典型应用场景：

  • CPU 休眠/唤醒时的快速电压切换
  • 在 I2C/SPI 不可用时通过 GPIO 紧急调整电压

4.2 测试方法

参数条件
Buck 模式ECO 模式
控制引脚硬件调压引脚（如 VSEL）
VOUT 初始值VOUT_LOW
VOUT 目标值VOUT_HIGH
负载轻载（确保 ECO 模式工作）
测量仪器示波器 / 数字化仪

测试步骤：

  1. 使能 Buck 在 ECO 模式下工作，设置初始输出电压 VOUT_LOW
  2. 等待输出稳定
  3. 切换硬件调压引脚电平（如从低到高）
  4. 用示波器捕获 VOUT 从 VOUT_LOW 到 VOUT_HIGH 的跳变波形
  5. 检查以下指标：
    • 跳变幅度：ΔVOUT = VOUT_HIGH_MEAS - VOUT_LOW_MEAS
    • 跳变时间：从控制引脚变化到 VOUT 稳定的时间
    • 过冲/下冲：跳变过程中的最大/最小 VOUT
    • 稳定时间：VOUT 进入目标值 ± 1% 范围内的时间
  6. 反向再测一次（从 VOUT_HIGH 到 VOUT_LOW）

4.3 判定标准

参数限值
一步调压幅度精度±2%
跳变过程过冲< 50mV
跳变过程中下冲< 50mV
稳定时间< 20us
Glitch 检查不允许出现反向瞬态

4.4 测试注意事项

  • ECO 模式下 Buck 可能进入脉冲跳跃（Pulse Skipping），需确保跳变时 Buck 处于活跃开关状态
  • 控制引脚的上升/下降时间会影响测试结果，需使用特性良好的信号源驱动

五、Ramp 过程反向调压及中断

5.1 原理

电压模Buck支持 DVS（动态电压调节），通过寄存器顺序写入目标电压，实现 VOUT 的线性斜坡调节。

Ramp 反向调压及中断测试覆盖以下场景：

场景操作预期行为
正向 RampVOUT 从 Low → HighVOUT 线性上升
反向 RampVOUT 从 High → LowVOUT 线性下降
Ramp 中断在 ramp 中写入新的目标电压从当前值开始向新目标调节
Ramp 反向正向 ramp 中突然转为反向VOUT 停止上升开始下降

与迟滞Buck的区别：

  • 电压模Buck的 ramp 由 DAC 和寄存器控制，精度更高
  • 电压模Buck的 ramp 速率通常可配置（通过寄存器设置 slew rate）
  • 电压模Buck的闭环控制使 ramp 过程更平滑，但仍需验证极端条件

5.2 测试方法

参数条件
VIN标称值
Ramp 速率规格值（如 5/10/20mV/us）
负载空载 + 轻载 + 满载
测量仪器高速数字化仪

测试步骤（以 ramp 中断为例）：

  1. 设置 Buck 输出为 VOUT_LOW（如 0.6V）
  2. 发起正向 ramp，目标 VOUT_HIGH（如 1.2V）
  3. 在 ramp 进行到 30% ~ 50% 时，写入一个新的目标电压（如 1.0V 或 0.8V）
  4. 捕获完整的 VOUT 波形
  5. 分析 ramp 连续性、单调性、过冲/下冲

5.3 判定标准

参数限值
Ramp 过程过冲< 50mV
Ramp 过程中下冲< 50mV
最终电压精度±2%
Ramp 斜率偏差±20%
单调性强制单调

5.4 测试注意事项

  • 需覆盖多种负载组合（空载、轻载、满载），因为 EA 的驱动能力在不同负载下不同
  • 建议使用高分辨率数字化仪（16-bit 以上）来检测 ramp 过程中的微小台阶（ramp step）

六、Loadline 精度测试

6.1 原理

Loadline（负载线/下垂控制） 是电压模Buck中一种重要的电压定位技术：

  • 通过有意引入输出阻抗 Rdroop，使 VOUT 随负载电流增加而线性下降
  • VOUT(ILOAD) = VOUT_0 - ILOAD × Rdroop
  • 其中 VOUT_0 是空载输出电压，Rdroop 是 loadline 电阻

Loadline 的核心优势：

优势说明
改善瞬态响应VOUT 的 DC 电平随负载变化，减少了瞬态电压变化幅度
减少输出电容相同的瞬态电压容限下，所需输出电容更小
电压定位空载时 VOUT 较高（效率优），满载时 VOUT 较低（减少功耗）

Loadline 的实现方式：

  • 检测输出电流（通过电感 DCR 检测、下管 Rds(on) 检测或 Sense FET）
  • 将电流信号转换为电压偏移量，叠加到 EA 的参考电压或反馈电压上

6.2 测试方法

参数条件
VIN标称值
VOUT目标输出电压
ILOAD0mA → IMAX（逐步增加）
测量每个负载点下的 VOUT

测试步骤：

  1. 使能 Buck 输出至目标电压（空载）
  2. 测量空载输出电压 VOUT_0
  3. 逐步增加负载电流至 IMAX（建议 5~10 个步进点）
  4. 在每个负载点，等待 VOUT 稳定后测量
  5. 绘制 VOUT vs. ILOAD 曲线
  6. 计算 loadline 电阻：
    • Rdroop = (VOUT_0 - VOUT_IMAX) / (IMAX - 0)
    • 或通过线性拟合获取斜率
  7. 验证 loadline 精度
VOUT
  |← VOUT_0（空载）
  |  ↘
  |    ↘
  |      ↘    ← ΔVOUT = ILOAD × Rdroop
  |        ↘
  |         VOUT_IMAX（满载）
  |___________________________ ILOAD
              IMAX

6.3 判定标准

参数典型限值
Loadline 电阻精度±15% （目标值）
Loadline 线性度R² > 0.98
空载 VOUT 精度±2%

6.4 测试注意事项

  • 使用 4-Wire Kelvin 连接测量 VOUT，避免线阻压降影响 loadline 测量结果
  • 负载电流步进需足够慢，确保每个负载点 VOUT 已稳定
  • 热效应影响：大电流下 DUT 自热影响 Rds(on)，可能改变 loadline 特性
  • Loadline 测试需在常温（25°C）和高温（85°C 或 125°C）下分别验证

七、OVP 测试（开环）

7.1 原理

开环 OVP 测试是指在开环或输出高阻抗条件下测试过压保护功能。电压模Buck的 OVP 检测通过独立比较器实现：

  • 开环条件意味着 Buck 的反馈环路不参与控制（或输出被外部强制驱动）
  • 测试目的是验证 OVP 比较器本身的触发阈值精度
  • 开环测试可以消除环路调节对 OVP 阈值测量的影响

7.2 测试方法

参数条件
Buck 状态开环 / 输出高阻（Hi-Z）或禁用
VOUT 强制电压从 VOUT_TARGET 逐步升高
测量仪器SMU（Force V, Measure I）

测试步骤：

  1. 将 Buck 设置为开环状态或 Hi-Z 输出（禁用输出开关）
  2. 使用 SMU 在 VOUT 引脚强制施加电压
  3. 从 VOUT_TARGET 开始，缓慢升高电压
  4. 监测内部 OVP 标志位（寄存器读取）或 FAULT 引脚状态
  5. 记录 OVP 触发时的 VOUT 电压值
  6. 降低 VOUT 电压，记录 OVP 恢复阈值（如果存在迟滞）

7.3 判定标准

参数典型值单位
OVP 触发阈值VOUT_TARGET × 115% ~ 130%—
OVP 迟滞50 ~ 200mV

7.4 测试注意事项

  • 开环 OVP 测试中，SMU 应设置电流钳位（如 50mA）以避免过流损坏
  • 部分 OVP 比较器在开环测试时可能受内部偏置影响，需确认测试条件

八、SCP 测试（开环）

8.1 原理

开环 SCP 测试是在开环条件下测试短路电流限制能力。与闭环 SCP 测试的区别：

  • 开环条件下，EA 的输出可能被强制到某个固定值
  • 测试的是功率级在最大占空比或固定占空比下的短路电流能力
  • 更直接地评估功率管的电流限制机制

8.2 测试方法

参数条件
Buck 状态开环（EA 输出固定）
VOUT短接到 GND
测量短路电流（VIN 电流或输出电流）
测量仪器SMU + 电流探头

测试步骤：

  1. 设置 Buck 为开环状态（HS-FET 强制导通或固定占空比）
  2. 将 VOUT 引脚通过低阻抗路径短接到 GND
  3. 测量 VIN 电流或输出电流
  4. 记录短路电流峰值和稳态值
  5. 观察是否触发 OCP 保护（电流限制）
  6. 验证限流值在规格范围内

8.3 判定标准

参数典型值
短路电流峰值< OCP 阈值 × 120%
稳态短路电流< OCP 阈值 × 110%

8.4 测试注意事项

  • 开环 SCP 测试可能导致大电流损坏 DUT，测试时间必须严格控制
  • 建议使用高功率 SMU 或通过外部 MOSFET 控制短路开关
  • 必须在 DUT 工作温度范围内测试（高温下电流限制可能漂移）

九、缓起时间测试

9.1 原理

电压模Buck的软启动（Soft-Start）通过控制 EA 参考电压 VREF 的上升速率来限制启动电流。软启动电路的核心是：

  • 内部电流源对软启动电容充电，产生线性上升的 VREF
  • VREF = (ISS / CSS) × t，其中 ISS 为充电电流，CSS 为软启动电容
  • EA 通过反馈环路使 VOUT 跟随 VREF 上升

多软启动时间设计： 部分电压模Buck支持多个可选的软启动时间，以适应不同输出电容和负载要求：

配置适用场景
快速软启动（~100us）小输出电容、快速开关机
标准软启动（~500us）常规输出电容
慢速软启动（~1ms）大输出电容、预偏置启动

9.2 测试方法

参数条件
VIN标称值
VOUT目标输出电压
负载空载
测量仪器数字化仪 / 示波器

测试步骤：

  1. 确保 VOUT 已放电至接近 0V
  2. 发送使能命令
  3. 用数字化仪捕获 VOUT 从 0V 上升至目标值的完整波形
  4. 测量 10% 到 90% VOUT 的上升时间
  5. 如果支持多软启动时间配置，切换配置后重复测试

9.3 判定标准

参数典型值
软启动时间（快速）100us ± 30%
软启动时间（标准）500us ± 30%
软启动时间（慢速）1ms ± 30%
单调性强制单调上升
启动过冲< 3% VOUT

9.4 测试注意事项

  • 启动前务必确认 VOUT 已完全放电
  • 若存在输出预偏置（Pre-bias），软启动行为可能不同（VOUT 从预偏置电压继续上升）

十、空载静态电流测试

10.1 原理

静态电流（Quiescent Current, IQ） 是 Buck 变换器在空载（IOUT = 0）时从输入消耗的电流。

在电压模Buck中，IQ 由以下部分组成：

组成部分说明在不同模式下的行为
带隙参考 VREF内部基准始终存在
误差放大器 EA环路调节始终工作
PWM 比较器脉冲调制COT/CCM 模式下持续工作
振荡器时钟产生CCM 固定频率工作
驱动级损耗开关ECO 模式下开关频率极低
保护电路OVP/SCP/TSD 监测始终存在

三种不同模式下的 IQ 差异：

模式IQ 大小说明
ECO 模式最低（~10uA）大部分电路关闭，仅维持输出
COT 模式中等（~50uA）Ton 控制电路工作，频率随负载变化
CCM 模式最高（~几百 uA）所有电路持续工作

10.2 测试方法

参数条件
VIN标称值
VOUT目标输出电压
负载空载 (IOUT = 0mA)

十一、Delay-Loop On-Time 和 RC On-Time 测试

11.1 原理

11.1.1 Constant-On-Time（COT）控制原理

COT（恒定导通时间）控制是一种在电压模和迟滞Buck中广泛使用的控制方式，其特点为：

  • 上管导通时间（TON）由定时电路决定，基本恒定
  • 开关频率通过调节关断时间（TOFF）来调节
  • 负载变重时，TOFF 缩短，频率升高以提供更多能量

11.1.2 TON 产生方式

TON 的产生有两种常见方式：

方式原理精度工艺敏感性
Delay-Loop TON数字延迟链（Delay Chain）计数产生固定TON高低（数字逻辑）
RC TONRC 定时电路：TON = k × R × C中等高（R、C 随工艺变化）

Delay-Loop TON 原理：

EN ----> 延迟链（可调抽头）
         |→ D1 → D2 → ... → Dn →|
         |______ 比较器 ________|
                   |
                  TON 结束信号

延迟链由多个门延迟单元串联，总延迟 = TON。通常可以通过 trim 调整延迟链的抽头位置来校准 TON。

RC TON 原理：

VIN ----> R ----> C ----|+\
                        |  >---> TON 结束
VREF ----|-/

电流源给电容充电，电容电压达到阈值时触发 TON 结束。TON = (C × VTH) / ICHARGE。

11.2 测试方法

参数条件

VOUT目标值（影响占空比进而影响 TON）

测量节点LX 引脚

测试步骤：

  1. 使能 Buck 在 COT 模式下运行
  2. 设置 VOUT 为指定值
  3. 施加负载（确保工作在 COT 模式）
  4. 用示波器捕获 LX 波形
  5. 测量 HS-FET 导通时间（TON）
  6. 对于 Delay-Loop TON：
    • 在不同 VIN/VOUT/负载下验证 TON 的一致性
    • TON 基本不随工况变化
  7. 对于 RC TON：
    • 在不同 VIN 下验证 TON 变化
    • 验证 TON 是否符合 RC 时间常数

  • TON 时间通常很短（几十到几百 ns），需要高带宽示波器（≥ 500MHz）
  • 多次测量取平均以降低随机误差
  • 需区分 TON 是天然变化还是测试误差

十三、Ramp Step 幅度测试

13.1 原理

电压模Buck的 DVS（动态电压调节）通过离散电压台阶（Ramp Step） 实现：

  • 内部 VID DAC 在每个时钟周期递增/递减一个固定步长
  • 步长 = VSTEP（如 5mV、10mV）
  • 步进间隔 = TSTEP（如 1us、2us）
  • Ramp 速率 = VSTEP / TSTEP

Ramp Step 示意图：

VOUT
  |      _  _  _  _  _  _
  |    _| |_| |_| |_| |_| |_
  |  _|                   | |_
  |_|                        |_
  |_____________________________ t
     ↑ 每个台阶 = VSTEP
     ←→ 台阶间间隔 = TSTEP

13.2 测试方法

参数条件
VIN标称值
VOUT 起始VOUT_LOW
VOUT 目标VOUT_HIGH
负载空载
测量仪器高分辨率数字化仪

测试步骤：

  1. 设置 Buck 输出为 VOUT_LOW
  2. 发起正向 ramp 到 VOUT_HIGH
  3. 使用高分辨率数字化仪（≥ 16-bit）连续采样 VOUT
  4. 对 VOUT 波形进行差分处理，检测每个台阶
  5. 测量：
    • 台阶幅度：VSTEP（相邻台阶之间的电压差）
    • 台阶间隔：TSTEP
    • 台阶数量：NRAMP = (VOUT_HIGH - VOUT_LOW) / VSTEP
    • 单调性：每个台阶的电压方向是否一致
  6. 反向 ramp 重复测试

台阶检测算法：

对 VOUT 采样序列做微分：
  dV/dt = (V[n] - V[n-1]) / Ts

检测 dV/dt 的显著变化：
  |dV/dt| > 阈值 → 检测到台阶

台阶幅度 = 相邻稳态值之差

13.3 判定标准

参数典型值允差
台阶幅度5mV / 10mV±30%
台阶间隔1us / 2us±20%
台阶数量(VHIGH - VLOW) / VSTEP±1
单调性强制单调—
台阶间纹波< 5mV—

13.4 测试注意事项

  • 需要高分辨率数字化仪（推荐 16-bit 以上）以分辨小幅度台阶（5mV）
  • 台阶幅度越小，对噪声越敏感。建议使用平均功能降低随机噪声
  • 示波器的垂直分辨率通常为 8-bit，可能不足以分辨 5mV 台阶，优先使用高分辨率数字化仪

十四、EA Clamp 下钳位上升压测

14.1 原理

误差放大器（EA）的钳位电压（Clamp Voltage） 决定了 PWM 比较器输入的变化范围，进而控制占空比的极限。

EA Clamp 的作用：

钳位对应条件影响
上钳位（High Clamp）EA 输出最高电压对应最大占空比（DMAX）
下钳位（Low Clamp）EA 输出最低电压对应最小占空比（DMIN）

EA 输出与占空比的关系：

  • EA 输出与斜坡信号（Ramp）在 PWM 比较器比较
  • EA 输出越高 → 占空比越大
  • EA 输出被钳位至 VCLAMP_HIGH → 占空比达到 DMAX
  • EA 输出被钳位至 VCLAMP_LOW → 占空比达到 DMIN

下钳位上升压测（EEA Clamp Low-Side Clamp Rising Test） 测试：

  • 强制 EA 输出达到下钳位（通过设置 VOUT 远高于目标值）
  • 测量 EA 下钳位电压 VCLAMP_LOW
  • 验证钳位电压是否在预期范围内
  • 间接验证系统的最小占空比能力

14.2 测试方法

参数条件
VIN标称值（较高，如 5V）
VOUT设置远低于目标（使 EA 饱和为低）
负载空载或轻载
测量EA 输出引脚电压（如可引出）或间接推断

直接测量法（EA 输出可引出）：

  1. 设置 VIN 为高值，VOUT_TARGET 设置为低值（如 0.6V）
  2. 使能 Buck
  3. 由于 VOUT 远低于目标，EA 输出驱动到低电平
  4. 在 PWM 比较器输出处观察占空比是否达到 DMIN
  5. 直接测量 EA 输出引脚电压 = VCLAMP_LOW

间接推断法（EA 输出不可引出）：

  1. 逐步降低 VOUT_TARGET，同时监测 VOUT 实际值
  2. 当 VOUT 实际值不再随目标值降低而降低时
  3. 说明 EA 已经达到下钳位
  4. 此时的 VOUT_TARGET 可以推断钳位状态

14.3 判定标准

参数典型值单位
EA 下钳位电压0.3 ~ 0.6V

14.4 测试注意事项

  • 如果 EA 输出不是外部引脚，无法直接测量，需通过寄存器调试接口间接读回
  • EA 钳位电压和对应的占空比边界与 trim 相关，需结合 trim 文档分析
  • 温度变化会影响 EA 的钳位电压

十五、输出电压精度/纹波测试（三种模式：ECO/COT/CCM）

15.1 原理

电压模Buck在不同工作模式下具有不同的输出电压特性和纹波表现：

模式控制方式工作负载输出纹波效率
ECO 模式脉冲跳跃（Pulse Skipping），轻载时跳过多余开关周期轻载（< 50mA）最高（跳跃时电压恢复）最高
COT 模式恒定导通时间，TON 固定，TOFF 调节中载（50mA ~ 500mA）中等中等
CCM 模式固定频率 PWM重载（> 500mA）最低（连续导通）高

ECO 模式的高纹波原因：

  • 在 ECO 模式下，Buck 仅在 VOUT 下降到下限阈值时才开启一个开关周期
  • 开关周期之间间隔长（数十到数百个时钟周期），VOUT 在间隔期间自然下降
  • 这导致较大的输出电压波动（纹波）

CCM 模式低纹波原因：

  • 每个开关周期连续导通，电感电流连续
  • 输出电容持续充放电，电压变化幅度小
  • 纹波频率 = 开关频率（高），滤波效果好

  • CCM 模式纹波测量时，时基应设置为较短时间（us 级）

十六、BUCK 小占空比输出电压精度测试

16.1 原理

小占空比条件：当 VIN 远高于 VOUT 时，Buck 变换器工作在小占空比（Small Duty Cycle）条件下。

D = VOUT / VIN （理想情况，CCM 下）

VIN = 5V, VOUT = 0.6V → D = 12%
VIN = 12V, VOUT = 0.6V → D = 5%

最小导通时间限制（Minimum TON, TON_MIN）：

  • PWM 控制器能够产生的最窄导通脉冲宽度受限于电路内部延迟
  • 当占空比要求小于 DMIN = TON_MIN × fsw 时，Buck 无法准确调节
  • 表现为 Droop（电压跌落）——VOUT 实际值低于目标值

小占空比下的典型影响：

影响说明
输出电压偏低（Droop）无法精确输出所需占空比
多脉冲现象控制器跳过多个周期后输出一个脉冲
频率调制实际开关频率降低
纹波增大因为脉冲跳过/聚集导致输出波纹增大

16.2 测试方法

参数条件

VOUT最低值（如 0.6V 或 0.3V）

测试步骤：

  1. 设置 VIN 为最高值，VOUT_TARGET 为最低值
  2. 使能 Buck 输出
  3. 施加中载（CCM 条件）
  4. 使用 DMM 测量 VOUT 实际值
  5. 计算精度误差
  6. 若误差超出规格（如 > 3%），可能指示 TON_MIN 限制

  • 需在 ECO 模式的整个负载范围内测试，不同负载下精度可能不同
  • 若 ECO 精度超出规格，需检查 ECO 比较器的 trim 是否正常

十九、RampDown 过程输出异常筛选

19.1 原理

在电压模Buck的 RampDown（DVS 向下调节）过程中，VOUT 从高电压下降到低电压。可能出现的异常与迟滞Buck类似：

异常类型描述对负载（CPU/GPU）的影响
下冲（Undershoot）VOUT 跌至目标值以下可能导致逻辑电路时序违规
非单调（Non-Monotonic）VOUT 下降过程中出现局部上升可能导致核心电压异常升高
台阶异常某个 ramp step 缺失或重叠导致 VOUT 曲线异常
振铃下降过程后的振荡延长稳定时间

由于 CPU/GPU 核心电压对 ramp 质量要求极高，RampDown 异常筛选是 FT 中的关键质量筛选项。

19.2 测试方法

参数条件
VIN标称值
VOUT 起始VOUT_HIGH（如 1.2V）
VOUT 目标VOUT_LOW（如 0.6V）
Ramp 速率规格值
负载空载 + 满载
测量仪器高速高分辨率数字化仪

测试步骤：

  1. 设置 Buck 输出为 VOUT_HIGH，稳定运行

  2. 发起 ramp-down 命令（目标 VOUT_LOW）

  3. 使用数字化仪连续采样 VOUT（采样率 ≥ 10MS/s，分辨率 ≥ 16-bit）

  4. 捕获完整 ramp-down 过程波形

  5. 执行以下异常检测：

    下冲检测：

    • 计算 VOUT 与目标值的偏差
    • 标记 VOUT < VOUT_TARGET - VTH 的时段

    非单调检测：

    • 计算 VOUT 的微分（差分）：dV[n] = V[n] - V[n-1]
    • 在 ramp 期间，dV[n] 应为负值（下降）
    • 任何正值表示非单调行为

    台阶异常检测：

    • 识别 ramp 台阶
    • 检查台阶幅度和间隔的一致性

    振铃检测：

    • 在 ramp 完成后检查 VOUT 的波动幅度

检测算法伪代码：

// 下冲检测
for each sample V[n]:
    if V[n] < VOUT_TARGET - UNDERSHOOT_LIMIT:
        flag_undershoot = true

// 非单调检测
for each sample V[n] during ramp:
    if V[n] > V[n-1] + NOISE_TH:
        flag_non_monotonic = true

// 振铃检测
samples_after_ramp = V[n_settled ... n_end]
if peak_to_peak(samples_after_ramp) > RINGING_LIMIT:
    flag_ringing = true

19.3 判定标准

参数限值
下冲幅度< 目标 VOUT - 50mV
非单调检测零容忍（不允许）
稳定后振铃< 5mVp
Ramp 斜率偏差±25%
台阶缺失零容忍

19.4 测试注意事项

  • 数字化仪的采样率需要足够高，台阶间隔通常在 us 级，需要至少 10 倍过采样
  • 高分辨率（≥ 16-bit）是检测微小非单调异常的必要条件
  • 空载和满载下的 ramp-down 行为不同：空载时输出电容放电慢，可能更平缓；满载时负载协助放电，可能更快
  • RampDown 异常属于零容忍缺陷，任何异常的 DUT 必须标记为 Fail
