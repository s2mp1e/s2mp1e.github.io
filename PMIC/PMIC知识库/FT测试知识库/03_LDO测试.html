LDO测试 — PMIC 低压差线性稳压器 FT 测试

LDO（Low Dropout Regulator）是 PMIC 中为 SoC 各电压域提供稳定低压供电的核心模块。FT 阶段需全面验证 LDO 在 Normal 模式和 ECO 模式下的 DC/AC 性能、保护功能及时序特性，确保封装后器件满足数据手册规格。

与 LDO 修调知识库（侧重 CP Trim） 互补，本文聚焦于 FT 阶段的 LDO 完整功能验证与参数测试。

1. LDO 基础架构回顾

1.1 核心架构

一个典型的 PMIC 片上 LDO 包含以下关键模块：

VIN ----┬-------------------+----┬---- VOUT
         │                    │    │
         │               +---[Pass]---+
         │               |  FET      |
         │               +-----┬-----+
         │                     │
         │               +-----┴-----+
         │               |   Error   |
         │               | Amplifier |
         │               +-----┬-----+
         │                     │
         │               +-----┴-----+
         │               |   VREF    |
         │               +-----------+
         │                    R1
         │               +----===----+------------ VOUT
         │               │           │
         │               │    R2     │
         │               +----===----+---- GND
         │                     │
         │                     FB (Feedback Node)
         └─────────────────────┘

1.2 输出电压公式

VOUT = VREF × (1 + R1/R2)

1.3 Normal 模式 vs ECO 模式

特性Normal 模式ECO 模式
偏置电流高（几 μA ~ 几十 μA）低（几百 nA ~ 几 μA）
EA 增益高（60dB ~ 80dB）低（40dB ~ 60dB）
静态电流高低（为轻载优化）
负载调整率优（< 0.5%/A）一般（1%~2%/A）
瞬态响应快慢
应用场景性能敏感负载低功耗待机

2. LDO 输出带载调压测试

2.1 测试原理

LDO 输出带载调压测试（Load Regulation Test）验证 LDO 在不同的负载电流下输出电压的稳定性和精度。该测试覆盖 Normal 和 ECO 两种工作模式，并在多个输出电压设定点（如 0.6V / 1.0V / 1.5V）和多个负载电流（如 5mA / 10mA）下进行。

负载调整率的定义：

Load Regulation = ΔVOUT / ΔILOAD    [mV/mA 或 %/mA]

物理意义：负载电流每变化 1mA 时，输出电压的变化量。

理论背景：

LDO 输出电压随负载变化的原因包括：

  1. 有限环路增益：误差放大器（EA）的开环增益有限，负载变化导致环路增益变化，产生稳态误差。
  2. Pass FET 输出阻抗：PMOS 调整管的漏极-源极电阻 Rout 上的 IR Drop 随负载变化。
  3. 封装寄生电阻：bonding 线、引线框架和引脚上的电阻（Rbon + Rlead）会引入 IR Drop。
  4. EA 失调电压变化：负载变化可能改变 EA 输入对管的工作点，导致 Vos 变化。

2.2 测试方法

测试配置

项目配置说明
VINVOUT_target + VDO_margin（通常 +0.3V ~ +0.5V）保证 Pass FET 工作在线性区
VIN 上限不超过 LDO 绝对最大额定值防止过压损坏
电子负载有源电子负载或 ATE 板载负载模块CC（恒流）模式
测量仪器高精度 DMM 或 ATE 高精度 ADCKelvin 四线法
去耦电容VOUT 引脚接 Cout（按数据手册）维持环路稳定性

测试流程

Step 1: 配置 LDO 工作模式与输出电压
  ├── 写入寄存器选择 Normal 模式
  ├── 设置输出目标电压（如 0.6V/1.0V/1.5V）
  └── 使能 LDO

Step 2: 空载测量（ILOAD = 0mA）
  ├── 等待 VOUT 稳定（~100μs ~ 500μs）
  ├── 测量 VOUT_NL
  └── 记录空载输出电压

Step 3: 轻载测量（ILOAD = 5mA）
  ├── 施加 5mA 负载
  ├── 等待 VOUT 稳定（~200μs ~ 1ms）
  ├── 测量 VOUT_5mA
  └── 记录轻载输出电压

Step 4: 中载测量（ILOAD = 10mA）
  ├── 施加 10mA 负载
  ├── 等待 VOUT 稳定（~200μs ~ 1ms）
  ├── 测量 VOUT_10mA
  └── 记录中载输出电压

Step 5: 重复以上步骤测试 ECO 模式
  ├── 切换 LDO 至 ECO 模式
  └── 重复 Step 2 ~ Step 4

Step 6: 计算与判定
  ├── 负载调整率 = (VOUT_NL - VOUT_10mA) / 10mA
  ├── 输出电压精度 = (VOUT_meas - VOUT_target) / VOUT_target × 100%
  └── 各项是否在规格内

2.5 注意事项

  1. VIN 电压选择：VIN 需高于 VOUT + VDO_min 保证 LDO 正常稳压，但 VIN 过高会导致 Pass FET 上功耗增加，自热效应（Self-Heating）使结温升高，可能改变 VOUT。

  2. 负载电流的 IR Drop 补偿：大电流时 Force 路径上的 IR Drop 会影响 VIN 的实际值。需使用 Kelvin Sense 线确保测量的是 LDO 引脚端的真实电压。

  3. 输出电压稳定时间：改变负载后需等待足够时间让 LDO 环路重新稳定。ECO 模式的带宽更窄，稳定时间通常比 Normal 模式长 5~10 倍。

  4. Cout 影响：LDO 的输出电容 Cout 会影响环路的稳定性和瞬态响应。测试时必须使用数据手册指定的 ESR 和容值范围。

  5. 多电压点测试效率：如果 PMIC 有多个 LDO，需在测试时间与覆盖率之间平衡。可以在 Characterization 阶段全面测试，量产阶段只测试关键电压点。

3. LSW 直通阻抗测试

3.1 测试原理

LSW（Load Switch，负载开关）本质上是一个低导通电阻（Low Ron）的 PMOS/NMOS 传输管，用于将电源电压直接旁路到输出端，不经过 LDO 的稳压环路。LSW 导通时相当于一个低值电阻，其直流特性由 Ron 决定。

LSW 等效电路：

VIN ────────┬─────── [PMOS Pass FET] ────────┬─────── VOUT
            │              Ron                │
            │                                 │
          Control                           Load
          (ON/OFF)                          (Device)

测试原理：

LSW 阻抗测试（也称 Ron 测试）通过以下方式测量导通电阻：

Ron = (VOUT - VIN) / ILOAD   [当 LSW 导通时]

推导过程：

  1. Force 已知电流 ILOAD 流入 LSW 输出端（或流出，取决于电流方向）
  2. 测量 VIN 端与 VOUT 端之间的电压差 Vdrop = VIN - VOUT
  3. Ron = Vdrop / ILOAD

3.2 测试方法

测试配置

项目配置说明
VIN标称工作电压（如 1.8V / 3.3V）按数据手册选择
Force 电流100mA ~ 500mA（典型值）足够大以产生可测压降，但不超过额定电流
连接方式Kelvin 四线法（Force + Sense 分离）消除接触电阻和线阻的影响
测量仪器SMU 或 DMM + 精密电流源SMU 可同时 Force 和 Measure

测试流程

Step 1: 配置 LSW
  ├── 使能 LSW，使其进入导通状态（ON）
  ├── 确认 LSW 将 VIN 直通到 VOUT
  └── 等待 LSW 完全开启（~10μs ~ 100μs）

Step 2: Force 电流
  ├── 在 VOUT 端施加已知电流 I_force（如 200mA）
  ├── 电流方向：从 VOUT 流向外部负载（电流流出）
  └── 注意 LSW 是双向的还是单向的

Step 3: 测量电压差
  ├── 以 Kelvin 方式测量 VIN 引脚电压
  ├── 以 Kelvin 方式测量 VOUT 引脚电压
  ├── 计算 Vdrop = VIN - VOUT
  └── 注意 Vdrop 通常很小（几 mV ~ 几十 mV）

Step 4: 计算 Ron
  ├── Ron = Vdrop / I_force
  └── 记录 Ron 值

Step 5: 可选：在不同 VIN 和温度下重复
  ├── VIN 变化：验证 Ron 的 VGS 依赖性
  ├── 温度变化：验证 Ron 的温度系数（正 TCR for PMOS）
  └── 记录 Ron vs VIN / Temp 特性

电流方向注意事项

LSW 类型电流方向说明
单向 LSWVIN → VOUT电流只能从输入流向输出
双向 LSWVIN ↔ VOUT电流可双向流动，测试时通常从 VIN 向 VOUT 施加
带体二极管的 PMOS注意体二极管方向若电压极性反向，体二极管会导通干扰测量

参数典型条件说明
VIN标称值（如 1.8V / 3.3V / 5.0V）可在多个电压点测试

对比项LSW Ron 测试LDO Dropout 测试

3.6 注意事项

  1. Kelvin 连接绝对必要：Ron 测试中 Vdrop 通常只有几 mV 到几十 mV，Force 路径上的接触电阻（可能也是几 mΩ ~ 几十 mΩ）会引入显著误差。Force 和 Sense 必须分离。

  2. Force 电流选择：

    • 电流太小 → Vdrop 太小 → 信噪比低 → Ron 测量误差大
    • 电流太大 → 自热效应使 Ron 值漂移（PMOS 的 Ron 随结温升高而增大）
    • 建议在 Characterization 阶段做电流扫描，确定最优 Force 电流

  3. 温度敏感性：PMOS 的 Ron 具有显著的正温度系数，测量时应记录芯片温度，并将结果归一化到标准温度。

  4. LSW 控制时序：确保 LSW 在测量前已完全开启。某些 LSW 设计有缓起功能（Soft-Start），开启时间可能长达几十 μs。

  5. 体二极管效应：如果 LSW 使用 PMOS + 体二极管结构，当 VOUT > VIN 时体二极管会正向导通，测量的 Vdrop 会显著减小，导致 Ron 计算错误。测试时应确保 VIN > VOUT。

4. LDO Ramp 过程反向调压及中断测试

4.1 测试原理

LDO Ramp（动态电压调节，Dynamic Voltage Scaling）是指 LDO 在使能状态下通过寄存器改变输出电压目标值的过程。Ramp 过程中 LDO 的输出电压从当前值以可控的压摆率（Slew Rate）过渡到新的目标值。

Ramp 过程的时序：

VOUT
  ^
  |     ┌───────────────────── 新目标电压（如 1.0V）
  |    /
  |   /    Ramp 过程（Slew Rate 可控）
  |  /
  | └───────────────────────── 原目标电压（如 0.6V）
  |
  +──────────────────────────────────> 时间
       ^                          ^
       |                          |
  寄存器写入新目标             VOUT 到达新目标

反向调压（Reverse Regulation）测试：

反向调压测试验证在 Ramp 过程中（VOUT 正在变化时），若收到反向的调压指令（如从升压切换为降压，或从降压切换为升压），LDO 能否正确响应而不产生异常行为（如过冲、下冲、振荡或输出失效）。

中断测试：

中断测试验证在 Ramp 过程中收到中断信号（如 FAULT、OCP、OTP 事件），LDO 能否按预期行为响应（如停止 Ramp、回到安全电压、或关断）。

4.2 测试方法

测试配置

项目配置说明
VINVOUT_max + VDO_margin保证最高输出电压时仍有足够裕量
负载恒定负载（如 5mA）避免负载变化引入干扰
测量仪器高速示波器（≥ 100MHz 带宽）捕获 Ramp 过程中的瞬态波形
触发方式寄存器写入事件或电压变化沿精确捕获 Ramp 起始点

反向调压测试流程

Step 1: 初始配置
  ├── 使能 LDO，设置初始输出电压 VOUT_start
  ├── 施加恒定负载 ILOAD
  └── 等待 VOUT 稳定在 VOUT_start

Step 2: 启动 Ramp（升压方向）
  ├── 通过 I2C/SPI 写入寄存器，设置 VOUT_target > VOUT_start
  ├── LDO 开始以设定 Slew Rate 升压
  └── 示波器触发捕获 Ramp 波形

Step 3: 在 Ramp 过程中插入反向指令
  ├── 在 VOUT 尚未到达 VOUT_target 时（约半程）
  ├── 写入反向调压指令：设置新的 VOUT_target2 < 当前电压
  └── 示波器连续捕获波形

Step 4: 观察与分析
  ├── VOUT 是否平滑反向过渡？
  ├── 有无过冲（Overshoot）或下冲（Undershoot）？
  ├── 有无振荡或不稳定现象？
  ├── Ramp 方向切换是否及时？
  └── 是否在规定时间内到达新的目标电压？

Step 5: 重复 Step 2~4，测试降压 → 升压反向
  ├── 初始为高压，Ramp 降压过程中插入升压指令
  └── 观察反向切换行为

中断测试流程

Step 1: 初始配置
  ├── 使能 LDO，设置 VOUT_start
  └── 开始 Ramp 升压

Step 2: 在 Ramp 过程中触发中断事件
  ├── 方法 A：注入 OCP 事件（短暂过载）
  ├── 方法 B：注入 OTP 事件（加热）
  ├── 方法 C：通过寄存器模拟 FAULT 事件
  └── 在 Ramp 中途触发中断

Step 3: 观察 LDO 对中断的响应
  ├── LDO 是否按设计停止 Ramp？
  ├── 是否回到预设的安全电压？
  ├── 中断清除后是否能恢复 Ramp？
  └── 是否有异常波形（振荡、电压崩溃等）？

Step 4: 记录结果
  ├── 记录响应时间和行为模式
  └── 判定是否满足设计预期

VOUT_target最高设定值（如 1.5V）Ramp 的目标电压

ILOAD5mA（恒定）避免负载瞬态干扰

4.4 判定标准

检查项判定标准说明
反向切换连续性VOUT 波形无跳变/中断应平滑过渡

下冲幅度< VOUT_target × 5%切换时谷值不低于目标值 5%

4.5 注意事项

  1. I2C/SPI 通信时序：Ramp 过程中的寄存器写入需在 Ramp 窗口内精确控制。需要使用 ATE 的数字通道或 MCU 精确控制通信时序。

  2. 示波器触发设置：Ramp 过程可能持续几十到几百 μs，示波器触发应设置在 Ramp 起始点附近。可使用电压阈值触发或数字通道触发。

  3. 负载效应：恒定负载有助于分离 Ramp 行为与负载瞬态。但需注意，在某些设计下 Ramp 过程中负载电流可能发生变化（如负载随 VOUT 变化），建议在不同负载条件下重复测试。

  4. 安全考虑：Ramp 过程中如果出现失控（如输出超过绝对最大额定值），可能导致芯片损坏。测试时应在 VOUT 端设置过压保护限值。

  5. 寄存器配置确认：测试前需确认 Slew Rate 配置寄存器、Ramp 使能寄存器、方向控制寄存器的地址和默认值。

5. LDO ECO VOUT 检测

5.1 测试原理

ECO 模式（Efficiency Optimization Mode）是 LDO 在轻载条件下通过降低偏置电流来提高效率的工作模式。在 ECO 模式下，LDO 采用比较器（Comparator）而非线性误差放大器（Linear Error Amplifier）进行稳压，从而导致输出电压存在一定的纹波和偏移。

ECO 模式稳压原理：

             ┌─────────────┐
VREF ────────┤+ Comparator ├─────── Control Logic ──── Pass FET Gate
             │             │
FB ──────────┤-            │
             └─────────────┘
                  |
            VOUT 经过 R1/R2 分压到 FB

ECO 模式的特点：

  • 比较器式调节：当 FB 电压下降到低于 VREF 时，比较器触发，开启 Pass FET 对输出充电
  • 迟滞控制（Hysteresis）：比较器具有迟滞特性，避免在 VREF 附近频繁开关
  • 输出电压纹波：由于迟滞控制方式，VOUT 会在 VREF ± ΔV 范围内波动，产生锯齿波纹波
  • 平均电压偏移：由于比较器的响应延迟和迟滞，ECO 模式下的平均 VOUT 通常略低于 Normal 模式

  └── 测量纹波频率 Fripple

  ├── VOUT_DC_avg 是否在 ECO 模式精度规格内
  ├── Vripple_pp 是否在纹波规格内

5.5 注意事项

  1. DMM 平均测量 vs 示波器测量：

    • DMM 测量 DC 平均电压精度高，适合判定 VOUT 精度
    • 示波器适合捕捉纹波波形和瞬态特征，但 DC 精度较低
    • 建议同时使用两种仪器

  2. ECO 模式建立时间：ECO 模式环路带宽较窄，从 Normal 切换到 ECO 后需要较长时间才能进入稳态。测试时需耐心等待。

  3. 负负载电流：某些设计中，ECO 模式下 LDO 可能不支持负负载（电流从输出流入），测试时需确认负载电流方向。

  4. 与 OCP 的交互：ECO 模式下 OCP 的响应可能不同（由于偏置电流降低），如果测试中 VOUT 出现异常下降，需排除 OCP 误触发。建议在 ECO 测试后加测 Normal 模式确认 LDO 未受损。

6. LDO 缓起时间测试

6.1 测试原理

LDO 缓起（Soft-Start）是 LDO 在使能后控制输出电压以可控的压摆率上升至目标值的过程，主要目的是限制启动时的浪涌电流（Inrush Current）。

物理背景：

当 LDO 突然使能且输出端有大电容 Cout 时：

I_inrush = Cout × dVOUT/dt

若不控制 dVOUT/dt（缓起），则 I_inrush 可能非常大：
- 导致 VIN 电压跌落（VIN Drop）
- 触发 OCP（过流保护误动作）
- 产生电磁干扰（EMI）
- 对上游电源造成冲击

缓起实现方式：

方法一：参考电压缓起（最常见）
  在 EA 正端使用一个缓慢上升的参考电压：
  VREF(t) = VREF_final × (1 - e^(-t/τ))  或 VREF(t) = Slew_Rate × t

方法二：电流源对电容充电
  使用电流源对内部缓起电容 CSS 充电，产生缓起波形

方法三：数字 Ramp
  通过数字寄存器逐步增加输出电压目标值

6.2 测试方法

缓起时间的定义

缓起时间（Soft-Start Time, tSS）通常定义为：

  • 使能信号 → VOUT 达到 90% × VOUT_target 所需的时间
  • 或有定义为 VOUT 从 0V 上升到 VOUT_target 的时间（不同公司标准不同）
VOUT
  ^
  |                      ────────── VOUT_target
  |                    /
  |                  /
  |                /   ← 缓起过程（Slew Rate 控制）
  |              /
  |            /
  |          /
  |        /
  |      /
  |    /
  |   └─────────────────────────────> 时间
  |    ↑                         ↑
  |    |                         |
  |  使能信号                VOUT 到达 90% VOUT_target
  |  (EN 或 REG write)          tSS
  |

测试配置

项目配置说明
VINVOUT_target + VDO_margin标准供电
输出电容Cout（按数据手册推荐值）实际应用条件
负载空载 或 轻载（如 1mA）空载时缓起最慢
测量仪器示波器（2 通道以上）通道1: EN 信号，通道2: VOUT
探头10x 无源探头或差分探头带宽 ≥ 100MHz

测试流程

Step 1: 示波器配置
  ├── 通道1：连接 EN 使能信号（或 LDO 使能寄存器对应的 GPIO）
  ├── 通道2：连接 VOUT 引脚
  ├── 触发模式：上升沿触发（通道1）
  ├── 触发阈值：EN = VIN/2（或 0.7×VIN，视逻辑电平而定）
  ├── 时基：50μs/div ~ 200μs/div（视缓起时间而定）
  └── 垂直刻度：500mV/div（通道2）

Step 2: 使能 LDO
  ├── LDO 初始为关断状态（VOUT = 0V）
  ├── 写入寄存器使能 LDO（或拉高 EN 引脚）
  ├── LDO 开始缓起
  └── 示波器触发捕获波形

Step 3: 测量缓起时间
  ├── 光标测量：从使能信号 50% 点 → VOUT 达到 90% × VOUT_target 的点
  ├── 记录 tSS_rise
  └── 若有关断缓起（Soft-Down），测量下降时间

Step 4: 多条件重复
  ├── 不同 VOUT_target（0.6V / 1.0V / 1.5V）
  ├── 不同负载（空载 / 轻载 / 满载）
  ├── 不同温度（25°C / 85°C）
  └── 不同 Cout（若可配置）

Step 5: 判定
  ├── tSS_rise ∈ [tSS_min, tSS_max]
  └── 缓起波形无异常（无过冲、平台、振荡）

6.5 注意事项

  1. 使能信号触发的准确性：

    • 使用 LDO 的专用 EN 引脚触发比通过 I2C 写寄存器触发更准确（I2C 通信有不确定延迟）
    • 如果必须用 I2C 触发，可将示波器触发连接到 I2C 的 SCL 或 SDA 信号上

  2. 输出电容影响：

    • 缓起时间与输出电容成正比。测试条件必须明确指定 Cout，并与数据手册一致
    • 不同 ESR 的电容可能影响缓起波形的平滑度

  3. 轻载 vs 空载：

    • 空载时缓起最慢（负载不消耗电流，所有能量用于给 Cout 充电）
    • 满载时缓起最快（负载同时消耗电流）
    • 数据手册通常标注空载条件

  4. 缓起与 OCP 的交互：

    • 若缓起过程中浪涌电流超过 OCP 阈值，LDO 可能进入限流模式
    • 这会导致缓起时间变长、VOUT 上不去
    • 需确认 OCP 阈值高于启动浪涌电流

  5. Miller Plateau 效应：某些 LDO 设计中，缓起过程中的 Pass FET 栅极充电可能出现 Miller Plateau，导致 VOUT 上升出现一段平坦区。这不是故障，但需在判定时考虑。

7. LDO OCP 测试

7.1 测试原理

LDO OCP（Over-Current Protection，过流保护）是 LDO 的重要保护功能，在输出电流超过安全阈值时限制输出电流，防止 Pass FET 因过流而损坏。

OCP 电路架构：

VIN ───────┬──────────────────────── VOUT
           │
    +------+------+
    | Current     |      OCP 比较器
    | Sense       |         |
    | (Sense FET) │─────────+─── OCP_Flag
    +------+------+         |
           │             [VREF_OCP]
        I_sense
           │
    +------+------+
    |  Control    |
    |  Logic      |
    +------+------+
           │
       Gate Drive
           │
    +------+------+
    | Pass FET    |
    +------+------+
           │
          GND

工作原理：

  1. 电流检测（Current Sense）：使用 Sense FET 技术，通过一个小比例（如 1:1000）的镜像器件检测 Pass FET 的电流
  2. 比较器比较：将感测电流转换为电压后与参考电压 VREF_OCP 比较
  3. 限流动作：当 IOUT 超过 OCP 阈值时，控制电路减小 Pass FET 的栅极驱动，限制输出电流
  4. 恢复机制：OCP 触发后，LDO 可配置为自动恢复（Hiccup）或锁存（Latch-off）

OCP 的典型响应特性：

IOUT
  ^
  |     ┌──────────────────────────── OCP 限流值（ILIMIT）
  |    /
  |   /    正常负载范围
  |  /
  | /
  |/
  +─────────────────────────────────────> VOUT
  |                                     |
  |                                   VOUT 开始下降
  |                                   （输出进入恒流模式）

7.2 测试方法

OCP 阈值测试（ILIMIT 测试）

OCP 测试的核心是找到 LDO 输出电流的限流点（ILIMIT），即 VOUT 开始明显下降时的输出电流。

测试配置

项目配置说明
VINVOUT_target + VDO_margin充足裕量，避免 Dropout 干扰
负载有源电子负载（CC 模式）或 SMU可编程斜波增加电流
测量仪器示波器 + DMM捕获 VOUT 跌落曲线
ILOAD 扫描方式线性斜波或步进从 0 斜升至超过 OCP 阈值

测试流程

方法 A：斜波电流扫描法（推荐）

Step 1: 配置 LDO
  ├── 使能 LDO，设置 VOUT_target
  ├── 施加空载或极轻载
  └── 等待稳态

Step 2: 斜波增加负载电流
  ├── 电子负载以恒定斜率（如 1mA/μs）增加电流
  ├── 同时监测 VOUT
  └── VOUT 下降斜率 = dVOUT/dI（用于反应负载调整率）

Step 3: 检测 OCP 触发点
  ├── 定义 OCP 触发条件：VOUT 下降超过 ΔV（如 VOUT_target × 3%）
  ├── 记录触发点的电流值 ILIMIT
  └── 同时记录 OCP Flag 的状态（如果有 Flag 输出）

Step 4: 确认限流行为
  ├── 继续增加负载电流，确认 VOUT 下降但 IOUT 不再增加（恒流模式）
  └── 或者 IOUT 下降（Hiccup 模式）

Step 5: 恢复测试
  ├── 降低负载电流至正常范围
  ├── 确认 LDO 恢复正常稳压
  └── 记录恢复行为（自动恢复 / 需要复位）

方法 B：步进电流搜索法（ATE 常用）

Step 1: 设置初始负载 I = 0
Step 2: 步进增加负载 ΔI（如 5% × I_rated）
Step 3: 在每个步进点测量 VOUT
Step 4: 当 VOUT < VOUT_target - ΔV_threshold 时，
        记录当前 I 为 ILIMIT
Step 5: 继续增加 1~2 步确认恒流行为

判定参数

7.5 OCP 与 SCP 的区别

对比项OCP（过流保护）SCP（短路保护）
触发条件输出电流超过额定值 120%~150%输出对 GND 短路（VOUT ≈ 0V）

恢复方式自动恢复 / Hiccup / Foldback通常需要 POR 或重新使能

测试方法斜波电流扫描强制 VOUT 到 GND

7.6 注意事项

  1. 自热效应（Self-Heating）：OCP 测试中 LDO 功耗很大（Vdrop × ILIMIT），可能达到几百 mW 甚至几 W。长时间测试会导致芯片结温升高，ILIMIT 因温度系数漂移。

  2. 斜波速率选择：

    • 斜波太快：可能因 OCP 比较器响应延迟导致过冲，测得的 ILIMIT 偏高
    • 斜波太慢：自热效应导致 ILIMIT 漂移，测得的 ILIMIT 偏低
    • 建议在 Characterization 阶段扫描不同斜波速率，确定最优值

  3. Dropout 与 OCP 的区分：当 VIN 接近 VOUT 时，LDO 进入 Dropout 区域，VOUT 也会下降。OCP 测试时必须确保 VIN 有足够裕量，以区分 Dropout 和 OCP。

  4. Hiccup 模式测试：如果 LDO 采用 Hiccup 模式（触发 OCP 后周期性重启），需要捕获多个 Hiccup 周期来确认保护行为。建议使用示波器的长存储深度模式。

  5. 多次 OCP 测试的累积效应：重复触发 OCP 可能导致芯片热积累。建议在测试间加入冷却时间（Cooling Time），或通过温度监测确保结温在安全范围内。

8. LDO 静态电流测试

8.1 测试原理

LDO 静态电流（Quiescent Current, IQ）是 LDO 正常工作但输出空载时，从输入电源消耗的电流中除去输出负载电流的部分。IQ 主要用于 LDO 内部控制电路（误差放大器、基准电压源、偏置电路等）的供电。

IQ 的物理定义：

IQ = IIN - ILOAD

当 ILOAD = 0（空载）时：IQ = IIN

IQ 的构成：

组成部分来源典型值特性
EA 偏置电流误差放大器偏置1μA ~ 10μAVIN 决定，与 ILOAD 无关
VREF 缓冲器电流参考电压缓冲器0.5μA ~ 5μA通常恒定
反馈分压网络电流R1 + R2 分压电流1μA ~ 10μA通过 FB 电阻的电流
Pass FET 栅极驱动栅极驱动电路0.1μA ~ 1μA与 ILOAD 弱相关
保护电路偏置OCP、OTP 等0.1μA ~ 1μA通常恒定

IQ 与接地电流（Ground Current, IGND）的区别：

术语解释：

IQ（Quiescent Current）：
  = IIN - ILOAD
  理想情况：IQ = IIN（当 ILOAD = 0）
  
IGND（Ground Current）：
  = 通过 GND 引脚流出的电流
  对于 LDO：IGND = IIN - IOUT
  
在大多数 LDO 中，IQ ≈ IGND，因为 IIN 中未被 IOUT 使用的部分
主要从 GND 流出。但严格来说，IQ 是所有内部控制电路消耗的电流，
而 IGND 包括了 IQ 和任何从 GND 引脚流出的额外电流。

重要区分：
- IQ 是设计参数，衡量 LDO 自身的功耗效率
- IGND 是测量参数，在空载时 IGND = IQ（忽略微小差异）
- 某些 LDO 设计中 IQ 不等于 IGND（如 NMOS LDO 有额外的 VBIAS 供电）

8.2 测试方法

IQ 测试（空载条件）

IQ 的 FT 测试通常在空载条件下进行，测量 LDO 输入端的电流。

测试流程

Step 1: 配置 SMU
  ├── SMU 设置为 Force Voltage 模式
  ├── 输出电压 = VIN（LDO 输入电压）
  ├── 电流测量量程：自动或手动选择 μA 级量程
  └── 输出端：不接负载（或接高阻 > 1MΩ）

Step 2: LDO 关断状态测量（可选，用于背景校准）
  ├── LDO 处于 Disable 状态
  ├── 测量 IIN_shutdown
  └── 记录关机电流（可用作背景电流扣除）

Step 3: 使能 LDO
  ├── 通过寄存器使能 LDO
  ├── 设置输出电压到目标值
  └── 等待 VOUT 稳定（~100μs ~ 500μs）

Step 4: 测量 IQ
  ├── 在空载条件下测量 IIN
  ├── 等待电流稳定（~1ms ~ 10ms，因偏置电路建立时间）
  ├── 采样多次取平均
  ├── IQ = IIN_measured（因为 ILOAD = 0）
  └── 记录 IQ

Step 5: 多条件重复
  ├── 不同 VIN（标称值 ± 10%）
  ├── 不同模式（Normal / ECO）
  ├── 不同温度（25°C / 85°C）
  └── 不同 VOUT 设定（可选）

Step 6: 判定
  ├── IQ ∈ [IQ_min, IQ_max]
  └── 若超出规格，分析是否为工艺角偏差

8.5 小电流测量技术

FT 中测量微安级甚至纳安级 IQ 需要特殊的测试技术：

1. SMU 直接测量法（推荐）

配置 SMU → Force VIN, Measure IIN
  - 优点：简单直接，集成在 ATE 中
  - 缺点：SMU 在低电流量程时测量速度较慢
  - 建议：使用自动量程（Auto-Ranging）

2. 电阻法（不适合超低 IQ）

IIN ----[Rsense]---- LDO VIN
         |
       测量 Vsense = IIN × Rsense
  - 优点：低成本
  - 缺点：Rsense 上的压降会降低 LDO 实际 VIN
  - 适用：IQ > 10μA

3. 积分法（适合 nA 级 IQ）

IIN 对已知电容 C 充电 → 测量 dV/dt
IIN = C × dV/dt
  - 优点：可测极低电流
  - 缺点：测量时间长，受漏电影响

8.6 注意事项

  1. ATE 通道漏电流：ATE 接脚矩阵（Pin Electronics）的漏电流通常为几 nA 到几百 pA。对于 ECO 模式的 IQ（可能 < 1μA），ATE 的漏电流本身就可能成为显著的误差源。测量前需做漏电流校准。

  2. PCB 漏电流：测试板的表面污染（助焊剂残留、湿气）会在 VIN 和 GND 之间形成漏电路径。高阻测试（IQ < 1μA）时，建议使用 Guard Ring 保护。

  3. 去耦电容的漏电流：VIN 引脚上的去耦电容（MLCC）的绝缘电阻（IR）通常在 GΩ 级，但在高温下可能下降到 MΩ 级，引入额外的漏电。测试时需注意电容的选择。

  4. 温度效应：

    • 高温时漏电流增大（PN 结反向漏电每 10°C 翻倍）
    • MOS 管的亚阈值漏电（Isubthreshold）在高温下显著增加
    • 高温 IQ 通常比常温高 2~5 倍

  5. 模式切换后的稳定时间：从 Normal 切换到 ECO 模式后，内部偏置需要重新建立。ECO 模式的偏置电流更小，RC 时间常数更大，稳定时间可能长达几 ms 甚至几十 ms。

  6. 关机电流 vs IQ：关机电流（Shutdown Current）是 LDO 处于 Disable 状态时的输入电流，通常远小于 IQ（如 < 100nA）。如果 IQ 测试结果异常，可以对比关机电流来帮助定位问题。

9. 总结与测试顺序建议

9.1 LDO FT 测试执行顺序

Step 1: 系统基础检查
  ├── OS 测试（确保所有 LDO 引脚连接正常）
  ├── 漏电测试（确保无异常漏电路径）
  └── 关机电流测试（建立背景电流基线）

Step 2: LDO 输出电压精度测试（带载调压）
  ├── Normal 模式，多电压点，多负载点
  └── ECO 模式，轻载条件

Step 3: LDO ECO VOUT 检测
  ├── ECO 模式平均电压精度
  └── ECO 模式纹波测量

Step 4: LDO 缓起时间测试
  └── 多电压点，多负载，多温度

Step 5: LSW 直通阻抗测试
  └── Ron 测量

Step 6: LDO Ramp 反向调压及中断测试
  └── Ramp 过程中的反向切换和中断响应

Step 7: LDO OCP 测试
  ├── ILIMIT 阈值测量
  └── 限流行为验证

Step 8: LDO 静态电流测试
  ├── Normal 模式 IQ
  └── ECO 模式 IQ
