BuckBoost 测试 — PMIC 升降压变换器 FT 测试

Buck-Boost（升降压）变换器是 PMIC 中最重要的电源转换模块之一，能够在输入电压高于或低于输出电压时维持稳定的输出。FT 阶段需要对 Buck-Boost 的各项功能与性能参数进行全面验证，包括启动特性、静态功耗、保护功能、输出质量、模式切换等。

一、概述

1.1 Buck-Boost 变换器简介

Buck-Boost 变换器是一种 DC-DC 转换器，其输出电压可以低于、等于或高于输入电压。它结合了 Buck（降压）和 Boost（升压）两种拓扑结构，通过控制四个开关管的导通时序实现升降压功能。

典型四开关 Buck-Boost 拓扑：

                    ┌─── SW1 ──┬─── SW2 ───┐
                    │          L          │
    VIN ───────────┤          │          ├────────── VOUT
                    │       ┌──┴──┐       │
                    │       │    │       │
                    │       │    │       │
                    └─── SW3 ──┴─── SW4 ──┘
                              │
                             GND

四种工作模式：

模式输入 vs 输出工作方式
Buck 模式VIN >> VOUTSW1、SW3 为主开关，SW2 常开，SW4 常关
Buck-Boost 模式VIN ≈ VOUT四个开关管均参与开关转换
Boost 模式VIN << VOUTSW2、SW4 为主开关，SW1 常开，SW3 常关
直通模式 (Pass-Through)VIN ≈ VOUTSW1、SW2 常开，SW3、SW4 常关

1.2 FT 测试关注点

Buck-Boost FT 测试覆盖以下方面：

  1. 启动特性：软启动时间、浪涌电流限制
  2. 静态功耗：空载/轻载时的芯片自身功耗
  3. 保护功能：OVP、SCP 等保护电路是否正常触发
  4. 输出质量：直流精度、交流纹波、瞬态响应
  5. 模式切换：Buck/Boost/Buck-Boost 模式判断和切换
  6. 开关特性：开关频率、死区时间、占空比范围

二、软启动时间测试

2.1 原理 (Principle)

2.1.1 为什么要软启动

Buck-Boost 变换器在启动时，如果没有软启动 (Soft-Start) 电路，输出电容的充电电流将非常大，导致：

  • 输入电压跌落：瞬态大电流拉低输入电源，可能导致系统复位
  • 电感饱和：浪涌电流超过电感饱和电流，损坏电感或开关管
  • 输出过冲：启动瞬间输出电压可能大幅超过目标值
  • 系统供电不稳：同一电源轨上的其他电路受到干扰

2.1.2 软启动实现方式

方式一：内部电流限制法

在启动阶段限制开关管的峰值电流（逐周期限流），输出电压逐步上升：

I_peak_limit = I_limit_ss  (启动阶段)
I_peak_limit = I_limit_normal (正常运行)

方式二：参考电压斜坡法 (Voltage Ramp)

控制误差放大器的参考电压从 0V 线性上升到目标值，输出跟随参考电压：

VREF_ss(t) = VREF_target × (t / T_ss),  0 < t < T_ss
VOUT(t) ≈ VREF_ss(t) × (1 + R1/R2)

方式三：占空比渐进法

从最小占空比开始，逐步增加到稳态占空比，实现输出电压平滑上升。

常见混合方案：同时使用电流限制和电压斜坡，在限制浪涌电流的同时保证输出电压平滑上升。

2.2 测试方法 (Test Method)

2.2.1 基本测量方法

  1. 配置 Buck-Boost 为目标输出电压（如 3.3V）
  2. 使能变换器（通过 EN 管脚或 I2C 寄存器）
  3. 使用 Digitizer 或示波器捕获 VOUT 上升波形
  4. 测量 10% VOUT_target 到 90% VOUT_target 的时间

计算公式：

TSS​=T90%​−T10%​

其中：

  • T₁₀%：输出电压上升到目标值 10% 的时刻
  • T₉₀%：输出电压上升到目标值 90% 的时刻

2.2.2 精确测量技术

ATE 实现方案：

  • 使用 ATE 的 AWG (任意波形发生器) 产生使能信号
  • 使用 Digitizer（采样率 1 ~ 10 MS/s）捕获 VOUT 波形
  • 软件后处理计算 10%-90% 上升时间

2.2.3 浪涌电流测量

在测量软启动时间的同时，同步测量输入电流：

  1. 在输入路径串联精密采样电阻
  2. 使用差分 Digitizer 测量电阻两端电压
  3. 计算输入电流：I_IN = V_sense / R_sense

2.5 测试注意事项

  1. 负载影响：软启动时间与输出负载和电容密切相关，需在标准负载条件下测试
  2. 触发同步：Digitizer 触发信号需与使能信号同步，确保捕获完整的启动波形
  3. 软启动失败：若 VOUT 长时间达不到目标值，可能指示软启动电路异常或输出过载
  4. 重复性：建议多次启动取平均，排除单次启动的随机性

三、静态电流测试

3.1 原理 (Principle)

3.1.1 静态电流定义

静态电流 (Quiescent Current, IQ) 指变换器在空载或轻载条件下，控制电路（包括误差放大器、比较器、基准、驱动逻辑等）消耗的电流。它是评估电源芯片自身功耗的关键指标。

IQ​=IIN​−IOUT​

其中：

  • I_IN：输入电源提供的总电流
  • I_OUT：输出负载电流

在空载条件下（ILOAD = 0），I_Q ≈ I_IN（因为没有输出电流）。

3.1.2 PFM 模式 vs PWM 模式 IQ

模式工作原理IQ 典型值适用场景
PWM (Pulse Width Modulation)固定频率，调整占空比数百 μA ~ 数 mA中等~重载，低纹波
PFM (Pulse Frequency Modulation)固定导通时间，调整频率数 μA ~ 数十 μA轻载，高效率
Burst Mode / Skip Mode跳过部分开关周期数 μA ~ 数十 μA极轻载，最低功耗

3.1.3 IQ 的组成

IQ = I_bandgap + I_EA + I_comp + I_driver_loss + I_switch_loss + I_feedback
  • I_bandgap：带隙基准偏置电流（数 μA）
  • I_EA：误差放大器偏置电流（数 μA ~ 数十 μA）
  • I_comp：比较器偏置电流（数 μA）
  • I_driver_loss：栅极驱动损耗（与开关频率相关）
  • I_switch_loss：开关管栅极充放电损耗
  • I_feedback：反馈分压电阻上流过的电流（VOUT / (R1+R2)）

3.2 测试方法 (Test Method)

3.2.1 空载 IQ 测试

PWM 模式 IQ 测试：

  1. 使能变换器，设置为强制 PWM 模式
  2. 设置空载（ILOAD = 0）
  3. 等待输出稳定（典型 1 ~ 5ms）
  4. 测量输入电流 I_IN

PFM 模式 IQ 测试：

  1. 使能变换器，设置为 PFM/Auto 模式
  2. 设置空载或极小负载（如 1μA）
  3. 等待输出稳定
  4. 长时间积分测量输入电流（因 PFM 模式下电流呈脉冲状，需平均采样）

3.2.2 ATE 测量方案

方案一：精密 SMU 测量

使用源测量单元 (SMU) 直接测量输入电流：

  • 将 SMU 设置为 Force Voltage，Measure Current 模式
  • 设置合适量程（如 10μA 量程用于 PFM IQ，10mA 量程用于 PWM IQ）
  • 注意 SMU 的自动量程切换时间

方案二：串联采样电阻法

在输入路径串入精密采样电阻，用差动 Digitizer 测量电压降：

SMU ──→ R_sense (1Ω ~ 10KΩ) ──→ DUT VIN
                ↓
         Digitizer Diff Input
  • R_sense 选择：IQ 越小，R_sense 需越大，以产生可测量的电压降
    • PWM IQ (~1mA)：R_sense ≈ 1Ω → V_sense ≈ 1mV
    • PFM IQ (~1μA)：R_sense ≈ 1KΩ → V_sense ≈ 1mV

3.5 测试注意事项

  1. 漏电流补偿：测试板自身的漏电流可能达到数 μA，需在空板测量后做漏电流校准 (delta 测量)
  2. 测量稳定时间：PFM 模式下电流呈脉冲状，需足够长的积分时间（> 100ms）获得平均电流
  3. 温度影响：IQ 随温度升高而增加（偏置电流的温度系数为正），需全温度范围验证
  4. 输入滤波电容：DUT 输入端的去耦电容会吸收 SMU 的瞬态电流，需注意测量建立时间

四、下拉电阻测试

4.1 原理 (Principle)

4.1.1 下拉电阻的作用

Buck-Boost 变换器在关断 (Disable/Shutdown) 状态下，输出管脚 VOUT 需要被拉至 GND：

  1. 可控放电：确保关断时输出电容上的电荷快速泄放，VOUT 快速下降到 0V
  2. 防止浮空：避免输出管脚在关断时处于高阻态，受漏电流影响产生不确定电压
  3. 系统安全：确保下次启动时输出电容已完全放电，防止启动时序异常

典型电路结构：

VOUT ────┬─── SW_discharge ─── R_pd ──── GND
         │
         │    SW_discharge = NMOS 开关管
         │    R_pd = 片内多晶硅电阻，典型几十 Ω ~ 几百 Ω
         │
         └─── 输出电容 COUT (外部)

4.2 测试方法 (Test Method)

4.2.1 基本测量方法

方法一：电压-电流法

  1. 禁用 (Disable) Buck-Boost 变换器，使下拉电阻接入
  2. 在 VOUT 管脚施加一个测试电压 V_force（注意不超过最大允许电压）
  3. 测量流入 VOUT 管脚的电流 I_measure
  4. 计算下拉电阻：

RPD​=Imeasure​Vforce​​

方法二：两点法（消除接触电阻）

使用两个不同的测试电压，计算差分电阻：

  1. 施加 V1，测量 I1
  2. 施加 V2，测量 I2
  3. 计算：

RPD​=I2​−I1​V2​−V1​​

这种方法可以消除接触电阻和测试路径上的固定偏置电压误差。

4.2.2 ATE 实现

使用 PPMU (Per-Pin PMU) 或 SMU 进行 Force Voltage / Measure Current：

[ATE PPMU] Force V_force ──→ DUT VOUT Pin
           Measure I_measure ←── DUT VOUT Pin

4.2.3 关键注意事项

  1. 测试电压选择：V_force 不能过高，否则可能意外激活 Buck-Boost 的保护电路
  2. 开关管导通电阻：实际测量值包含放电开关管的导通电阻 Ron，规格书中通常给出 R_pd + Ron 的综合值
  3. 使能状态确认：必须确认 Buck-Boost 已被正确禁用，否则读取的电流包括变换器工作电流

4.3 测试条件

参数条件数值单位

五、OVP 过压保护测试

5.1 原理 (Principle)

5.1.1 OVP 的作用

过压保护 (Over Voltage Protection, OVP) 用于防止 Buck-Boost 输出电压超过安全阈值，保护下游负载电路。OVP 触发时，变换器会采取保护动作（关闭开关管、拉低输出等）。

OVP 触发场景：

  1. 反馈电阻开路：FB 分压电阻 R1 开路 → FB 电压 = 0 → EA 认为输出不足 → 占空比最大 → VOUT 飙升
  2. 上管短路：SW1 (Buck 上管) 或 SW2 (Boost 上管) 击穿短路 → 输入直通到输出
  3. 控制环路故障：EA 输出饱和、PWM 比较器失效等
  4. 输入电压异常升高：VIN 升高导致占空比异常

5.1.2 两类 OVP 实现

类型一：反馈环路 OVP (Feedback OVP)

  • 监控 FB 节点电压，当 VFB 超过 VREF 的某个百分比（如 115%）时触发
  • 覆盖反馈电阻开路的故障场景
  • 保护阈值：VFB_OVP = 115% ~ 130% × VREF

类型二：输出直接 OVP (Output OVP)

  • 通过独立的分压电阻网络直接监控 VOUT
  • 与反馈环路无关，即使反馈环路故障仍能保护
  • 保护阈值：VOUT_OVP = 110% ~ 130% × VOUT_nom

保护动作：

保护动作描述恢复方式
关断 (Shutdown)关闭所有开关管，变换器停止工作重新使能
强制 DCM禁止同步整流管导通，防止反向电流OVP 消失后自动恢复
下拉输出打开输出下拉电阻，快速放电需重新使能
Latch-off锁死，彻底关断需重新上电或 POR

5.2 测试方法 (Test Method)

5.2.1 反馈 OVP 测试

方法一：外部注入法

  1. 使能 Buck-Boost 正常工作（VOUT = VOUT_nom）
  2. 通过外部电源在 FB 管脚注入额外的电压，模拟 FB 电压异常
  3. 逐渐降低 FB 节点电压（模拟电阻开路故障），观察 OVP 是否触发
  4. 记录 OVP 触发时的 VOUT 实际值

注意：直接向 FB 注电压可能改变环路的反馈特性，需通过电阻隔离注入。

方法二：电阻模拟法

在反馈分压电阻 R1 上并联一个外部电阻，降低 R1 有效值：

  • R1 并联外部电阻 → 分压比降低 → VOUT 升高
  • 观察 OVP 触发时的 VOUT 值

5.2.2 输出 OVP 测试

  1. 使能 Buck-Boost 正常工作
  2. 使用外部电源通过隔离电阻向 VOUT 注入额外电压
  3. 逐步升高 VOUT，直到 OVP 保护触发
  4. 记录 OVP 触发阈值

ATE 实现：

[ATE DPS/SMU → VOUT] ──→ R_isolation (1KΩ) ──→ DUT VOUT
[DUT VOUT] ──→ ATE Digitizer (监控 OVP 触发)
[DUT FAULT_N/STATUS] ──→ ATE Digital (检测 OVP 标志)

5.5 测试注意事项

  1. 隔离电阻选择：注入路径的隔离电阻要足够大，避免影响正常输出
  2. 触发检测：OVP 触发后 VOUT 迅速下降，Digitizer 需足够快以捕获触发点
  3. 自恢复 vs 锁死：需区分 OVP 是自恢复型 (Hiccup) 还是锁死型 (Latch-off)
  4. 温度影响：OVP 阈值比较器的失调电压随温度变化，需验证全温度范围

六、SCP 短路保护测试

6.1 原理 (Principle)

6.1.1 SCP 的作用

短路保护 (Short Circuit Protection, SCP) 在 Buck-Boost 输出对地短路时保护芯片和系统：

  • 限制短路电流：防止过大的短路电流烧毁开关管、电感和 PCB 走线
  • 保护输入电源：防止短路导致输入电源电压崩溃
  • 热保护：防止芯片在短路状态下过热损坏

6.1.2 保护模式

模式一：Hiccup 模式（打嗝模式）

这是最常用的 Buck-Boost SCP 模式：

短路发生 → 检测到过流 → 关断变换器
    → 等待 T_hiccup_off (典型 1~10ms)
    → 尝试重启 (软启动)
    → 若短路仍存在 → 再次关断
    → 循环重复

平均短路电流：

ISC_avg​=Ilimit​×Ton​+Thiccup_off​Ton​​

其中：

  • I_limit：逐周期限流值
  • T_on：每个 hiccup 周期中变换器工作的时间
  • T_hiccup_off：每个 hiccup 周期中变换器关断的时间

由于 T_hiccup_off >> T_on，平均短路电流远小于限流值，芯片功耗可控：

PSC​≈ISC_avg​×VOUT_short​≈ISC_avg​×(0V∼0.2V)≈很低

优势：

  • 平均功耗低，芯片温度可控
  • 短路移除后自动恢复
  • 不需要外部复位

劣势：

  • 输出恢复时间取决于 hiccup 周期
  • 在短路状态下变换器仍在间歇工作

模式二：Latch-off 模式（锁断模式）

短路发生 → 检测到过流 → 关断变换器 → 锁死
    → 需要 POR (Power-On Reset) 或重新使能才能恢复

优势：

  • 短路状态下变换器完全停止工作
  • 最安全，功耗最低

劣势：

  • 短路移除后需要系统干预才能恢复
  • 不适用于热插拔等需要自动恢复的场景

八、状态寄存器 BB_STATE 测试

8.1 原理 (Principle)

8.1.1 BB_STATE 寄存器的作用

Buck-Boost 变换器内部有一个状态机，实时追踪当前的工作模式。BB_STATE 寄存器通过 I2C/SPI 接口将状态信息暴露给主机：

典型状态寄存器定义：

位域名称描述
[1:0]BB_MODE00 = Buck 模式, 01 = Boost 模式, 10 = Buck-Boost 模式, 11 = Pass-Through 模式
[2]BUCK_ACTIVEBuck 开关管是否在切换 (1=是)
[3]BOOST_ACTIVEBoost 开关管是否在切换 (1=是)
[4]PWM_MODE当前控制模式 (0=PFM, 1=PWM)
[5]OVP_FLAG过压保护标志
[6]SCP_FLAG短路保护标志
[7]READY变换器输出就绪

8.1.2 工作模式判断逻辑

Buck-Boost 变换器根据 VIN 和 VOUT 的比值自动选择工作模式：

VIN >> VOUT + V_hysteresis      → Buck 模式
VIN << VOUT - V_hysteresis      → Boost 模式
VOUT - V_hysteresis ≤ VIN ≤ VOUT + V_hysteresis  → Buck-Boost 模式

其中 V_hysteresis 是迟滞电压，防止 VIN 和 VOUT 接近时模式频繁切换。

8.2 测试方法 (Test Method)

8.2.1 模式验证

  1. 设置 VOUT 为目标值（如 3.3V）
  2. 调整 VIN，使其分别处于 Buck/Boost/Buck-Boost 区域
  3. 通过 I2C/SPI 读取 BB_STATE 寄存器
  4. 验证读取的模式与期望模式一致

测试序列：

VIN = 5.0V (VIN >> VOUT)    → 期望 Buck 模式
VIN = 3.3V (VIN ≈ VOUT)     → 期望 Buck-Boost 模式
VIN = 2.5V (VIN << VOUT)    → 期望 Boost 模式
VIN = 4.0V → 3.0V → 4.0V   → 验证模式切换迟滞

8.2.2 切换点精度

测量模式切换点的 VIN/VOUT 比值，验证是否符合设计值：

  1. 固定 VOUT，缓慢扫描 VIN
  2. 读取 BB_STATE，记录模式切换时刻的 VIN 值
  3. 计算切换阈值：

Buck → Buck-Boost 切换点: VIN_B_to_BB​=VOUT​+Vhys_B_to_BB​

Buck-Boost → Boost 切换点: VIN_BB_to_Boost​=VOUT​−Vhys_BB_to_Boost​

九、DCM/CCM 切换点测试

9.1 原理 (Principle)

9.1.1 DCM vs CCM

CCM (Continuous Conduction Mode)：

  • 电感电流在整个开关周期中始终 > 0
  • 负载较重时工作
  • 开关频率固定（PWM 模式）
  • 效率在中~重载时较高
  • 输出纹波较小

DCM (Discontinuous Conduction Mode)：

  • 电感电流在每个开关周期中降到 0 并保持一段时间
  • 负载较轻时工作
  • 开关频率可变（PFM 模式）或固定
  • 效率在轻载时较高（开关损耗降低）
  • 输出纹波较大

电感电流波形对比：

CCM:          DCM:
  IL            IL
  │             │
  │  /\         │  /\
  │ /  \        │ /  \
  │/    \       │/    \____
  └──────── t   └──────────── t
  始终 > 0       有 = 0 区间

9.1.2 DMD — DCM-CCM 切换点

DMD (DCM-CCM Transition Point) 定义为变换器从 DCM 切换到 CCM 的负载电流阈值。

理论计算：

DCM 和 CCM 边界发生在电感电流谷值刚好为 0 时：

IDMD​=2ΔIL​​×(1−D)

其中：

  • ΔI_L：电感电流峰峰值纹波
  • D：占空比

影响因素：

因素对 DMD 的影响说明
输入电压 VINVIN ↑ → DMD ↑VIN 升高 → 电感纹波增大
输出电压 VOUTVOUT ↑ → DMD ↑VOUT 升高 → 电感纹波增大
电感值 LL ↑ → DMD ↓电感增大 → 纹波减小
开关频率 f_SWf_SW ↑ → DMD ↓频率升高 → 纹波减小

9.2.2 频率变化法 (PFM 模式)

在 PFM 模式下，开关频率随负载变化：

  • 轻载 → 低频（跳过多个周期）
  • 负载增加 → 频率升高
  • DMD 点 → 频率达到最高并进入 CCM

  1. 扫描负载电流
  2. 测量 LX 开关频率
  3. 频率不再随负载增加的位置即为 DMD 点

9.2.3 效率拐点法

  • 绘制效率 η vs 负载电流 ILOAD 曲线
  • DCM 模式下效率随负载增加而升高
  • CCM 模式下效率随负载增加先升后降
  • 效率曲线的拐点通常对应 DMD 附近

十、LX 频率测试

10.1 原理 (Principle)

10.1.1 LX 开关频率

Buck-Boost 变换器的 LX 管脚是开关节点，其开关频率是变换器工作的基本参数：

  • PWM 模式：开关频率固定，由内部振荡器或 PLL 决定
  • PFM 模式：开关频率随负载变化
  • 频率范围：典型值 500KHz ~ 3MHz（消费类 PMIC），或低至 100KHz（汽车级）

频率决定因素：

fSW​=TON​+TOFF​1​

对于 PWM 模式，频率固定，但可能因以下原因偏离设计值：

  • 内部振荡器频率偏差（取决于 RC 振荡器精度）
  • 频率抖动 (Frequency Dithering) 用于 EMI 降低
  • 温度/电压导致振荡器频率漂移
  • 展频调制 (Spread Spectrum) 引入的频率变化

10.2 测试方法 (Test Method)

10.2.1 频率测量

方法一：LX 管脚直接测量

  2. 使用示波器探头连接 LX 管脚
  3. 测量 LX 波形的开关频率

方法二：ATE 频率计测量

通过测试 MUX 将 LX 信号路由到测试管脚，或直接测量 LX 管脚：

DUT LX ──→ 测试板缓冲器 (可选) ──→ ATE TMU / 频率计

方法三：从输出电压纹波推算

如果 LX 管脚不可接触，可通过测量 VOUT 纹波频率间接获得开关频率。

十一、VIN/VO 内部比较器翻转点测试

11.1 原理 (Principle)

11.1.1 比较器的作用

Buck-Boost 变换器内部使用比较器检测 VIN 和 VOUT 之间的关系，以确定变换器应工作在哪种模式（Buck / Boost / Buck-Boost）：

VIN ──┬──┐
       │  ├── 比较器 1 (VIN > VOUT + Vhys?)
       │  │
VOUT ──┴──┘
       │
       │  ┌── 比较器 2 (VIN < VOUT - Vhys?)
       │  │
       └──┘

比较器输出连接到状态机，控制四个开关管的导通模式：

比较器结果工作模式SW1SW2SW3SW4
VIN > VOUT + VhysBuckPWMONPWMOFF
VIN ≈ VOUTBuck-BoostPWMPWMPWMPWM
VIN < VOUT - VhysBoostONPWMOFFPWM

11.1.2 比较器的重要参数

  1. 翻转阈值 (Threshold)：VIN 相对于 VOUT 何时判断为 “高” 或 “低”
  2. 迟滞 (Hysteresis)：防止在阈值附近频繁翻转
  3. 延迟时间 (Propagation Delay)：从 VIN 变化到比较器输出的时间
  4. 失调电压 (Offset)：比较器输入对管的失配导致实际阈值偏离理想值

11.2 测试方法 (Test Method)

11.2.1 翻转点测量

方法一：寄存器读取法

  1. 固定 VOUT 为目标值
  2. 缓慢扫描 VIN（从高到低和从低到高）
  3. 在每个 VIN 点读取 BB_STATE 寄存器（或类似状态寄存器）
  4. 记录模式切换时的 VIN/VOUT 比值

方法二：LX 波形观察法

  1. 固定 VOUT，扫描 VIN
  2. 通过示波器观察 LX 节点波形
  3. 根据 LX 波形形态判断当前模式
  4. 记录切换点的 VIN 值

LX 波形模式识别：

Buck 模式 LX:         ┌──┐  ┌──┐  ┌──┐
               ──────┘  └──┘  └──┘  └──── VIN ~ VOUT (SW1 开关)

Buck-Boost LX:     ┌──┐  ┌──┐  ┌──┐
              ─────┘  └──┘  └──┘  └───── 四个开关均参与

Boost 模式 LX:     ┌─┐  ┌─┐  ┌─┐
              ─────┘ └──┘ └──┘ └─────── GND ~ VOUT (SW2 开关)

11.2.2 迟滞测量

  1. VIN 从高到低扫描 → 记录 Buck→Buck-Boost 切换点 V_B_to_BB_hi
  2. VIN 从低到高扫描 → 记录 Buck-Boost→Buck 切换点 V_BB_to_B_lo
  3. 迟滞 = V_B_to_BB_hi - V_BB_to_B_lo

类似地测量 Boost 侧的迟滞：

  1. VIN 从低到高扫描 → 记录 Boost→Buck-Boost 切换点 V_Boost_to_BB_lo
  2. VIN 从高到低扫描 → 记录 Buck-Boost→Boost 切换点 V_BB_to_Boost_hi
  3. 迟滞 = V_Boost_to_BB_lo - V_BB_to_Boost_hi

11.5 测试注意事项

  1. VIN 扫描速率：VIN 变化过快会导致比较器输出来不及稳定，测得翻转点不准
  2. 负载影响：负载电流变化会改变 VOUT 实际值，间接影响 VIN/VOUT 比较结果
  3. 噪声滤波：比较器输入端的小幅度噪声可能导致误翻转，建议进行多次测量取平均
  4. 温度效应：比较器失调电压随温度变化，全温度范围需重新验证翻转点

十二、总结

Buck-Boost 变换器 FT 测试涵盖了从启动特性到保护功能、从输出质量到模式切换的全面验证。以下是对各测试项的关键要点总结：

测试项测试重点主要风险/挑战
软启动时间10%-90% 上升时间，浪涌电流负载和电容条件标准化
静态电流 IQPWM/PFM/Shutdown 三种模式超低电流时测试板漏电流干扰
下拉电阻 R_pd关断状态下 VOUT 到 GND 电阻接触电阻消除
OVP反馈 OVP 和输出 OVP 阈值注入方法不当影响环路

VOUT 精度/纹波DC 精度 ±2%，纹波 < 20mV高频分量捕获、Kelvin 连接
BB_STATE模式寄存器正确性通信可靠性、模式切换点
DCM/CCM 切换DMD 负载电流阈值电感/频率/电压依赖性

核心工程经验：

  1. 测试顺序优化：保护功能测试（OVP/SCP）应在基础功能测试之后进行，避免因测试时序问题损坏芯片
  2. 条件组合管理：Buck-Boost 测试条件多（VIN × VOUT × ILOAD × Temp），需合理设计测试组以覆盖有效边界
  3. 保护测试安全：SCP 和 OVP 测试具有一定破坏性，建议在程序末尾执行，并设置超时保护
  4. 多 site 同测考虑：Buck-Boost 开关噪声可能通过电源/地耦合串扰到相邻 site，需注意测试板的隔离设计
  5. 失效分析：FT 失效需区分是芯片本身问题还是测试条件/测板导致的问题
