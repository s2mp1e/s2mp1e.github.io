# 时序测试方法 / Timing Measurement Methods

> PMIC ATE 中时序测量的原理、方法和注意事项。

---

## 一、时序测量在 PMIC 中的重要性

PMIC 本质上是**时间控制型**的功率芯片 (开关频率、占空比、延迟等)，时序参数直接决定系统性能：

| 场景 | 时序参数 | 影响 |
|------|---------|------|
| Buck 工作频率 | Fsw / Ton / Toff | 效率、纹波、EMI |
| 启动时序 | ACT TIME / SS Time | 系统上电顺序 |
| 保护响应 | OCP/OVP/UVLO Delay | 芯片安全性 |
| 通信时序 | I2C/SPI Setup/Hold | 通信可靠性 |
| 死区时间 | Dead Time | 直通风险、效率 |

## 二、ATE 时序测量原理

### 2.1 方法 1: Timing Measurement Unit (TMU)

ATE 内部的专用硬件，直接测量信号的时间参数：

```
DUT Signal ───┬─── TMU Input
               │
          ┌────┴───┐
          │  TMU    │ → Timer Start/Stop
          │  逻辑    │ → 时间测量结果
          └────────┘
```

**工作原理**：
1. 设定触发条件 (电压阈值、沿方向)
2. 信号穿越阈值时启动/停止 Timer
3. Timer 基于高精度参考时钟 (如 100ps 分辨率)
4. 返回时间值

### 2.2 方法 2: 数字捕获 (Digital Capture / Waveform Capture)

使用 ATE 的高速采样能力捕获波形，软件分析时间参数：

```
DUT Signal ───┬─── Digitizer Input
               │
          ┌────┴────────┐
          │ 高速ADC      │ → 采样波形数据
          │ (GSa/s级)    │ → 软件后处理分析
          └─────────────┘
```

**优点**：一次捕获可分析多个参数
**缺点**：需要大容量采样内存

### 2.3 方法 3: 频率计数器 (Frequency Counter)

```
DUT Signal ───┬─── Counter Input
               │
          ┌────┴────┐
          │ Counter  │ → 在固定 Gate Time 内计数
          │          │ → Fsw = Count / Gate Time
          └─────────┘
```

适合测量稳定频率，不适合单脉冲测量。

## 三、常见时序参数测量

### 3.1 脉冲宽度测量 (Ton / Toff)

```
SW 波形:

  VHIGH ──────┐      ┌─────
               │      │
               │      │
  VLOW ────────┘      └─────

               ↑      ↑
              Vt     Vt
           (上升沿)  (下降沿)

Ton = t_fall - t_rise
```

**ATE 设置关键点**:
- 电压阈值 Vt 的选择 — 通常 Vt = (VHIGH + VLOW) / 2
- 去毛刺滤波 — 避免噪声导致误触发
- 多次采样取平均 — 消除单周期抖动

### 3.2 频率测量 (Fsw)

**方法 A: 直接测周期**
```
For 多个周期:
  t_start = 第1个上升沿
  t_end   = 第N+1个上升沿
  Fsw = N / (t_end - t_start)
```

**方法 B: 测 Ton + 占空比**
```
Fsw = Ton / (Duty × Tsw)
但需要知道 Duty (可能来自反馈)
```

### 3.3 启动时间 (ACT TIME / Startup Time)

```
EN:
      ┌────────────────
──────┘
      ↑
    t_start

VOUT:
                  ┌──── VOUT_TARGET × 90%
                 /
                /
───────────────┘
                ↑
              t_stop

ACT TIME = t_stop - t_start
```

**ATE 实现方法**：
1. 启动 TMU 与 EN 上升沿同步
2. VOUT 通过比较器连接到 TMU
3. VOUT 达到阈值 → TMU 停止
4. 读取测量结果

### 3.4 死区时间 (Dead Time)

HS MOS 和 LS MOS 同时关断的时间，防止直通 (Shoot-through)：

```
HS Gate: ──┐      ┌────────
            │      │
            └──────┘
                 ↑ Dead Time
            ┌──────┐
LS Gate: ──┘      └────────
```

**测量方法**：
- 需要分别测量 HS Gate 和 LS Gate 波形
- PE (Pin Electronics) 电平检测
- Dead Time = LS Gate 上升沿 - HS Gate 下降沿

## 四、时序测量精度的影响因素

| 因素 | 影响 | 缓解措施 |
|------|------|---------|
| **ATE 时钟精度** | 系统性测量误差 | 校准 (Calibration) |
| **电压阈值精度** | 触发电平偏移 | 使用相对阈值 (Vt = 50%) |
| **信号噪声** | 沿抖动 → 测不准 | 多次平均、滤波 |
| **负载效应** | 探针/线缆寄生 | 主动探头、阻抗匹配 |
| **温度漂移** | ATE 和 DUT 双方漂移 | 温度补偿校准 |
| **DIB 走线延迟** | 信号传播延迟 | De-embedding / 校准 |

## 五、时序测量校准

### 5.1 为什么要校准？

ATE 内部的信号传播路径包含延迟：

```
DUT Pin → Socket → DIB走线 → Relay → Pin Electronics → TMU
            ↑                    ↑             ↑
         ~100ps              ~50ps          ~200ps
Total Propagation Delay: ~500ps ~ 1ns (典型值)
```

### 5.2 校准方法

```
Open/Short Calibration:
  1. 使用校准板 (Calibration Board) 代替 DUT
  2. 将 TMU 通道短路/开路
  3. 测量并记录路径延迟
  4. 测试时在软件中减去延迟

Deskew:
  1. 同一个信号通过不同通道测量
  2. 对齐各通道的时序差异
  3. 确保多通道测量的一致性
```

## 六、PMIC 时序测试最佳实践

1. **先确定参考点** — 电压阈值、沿选择、触发条件
2. **多次测量取统计** — 至少测 8~16 个周期
3. **注意负载影响** — 负载不同时 Ton/Fsw 可能变化
4. **AT Speed 测试** — 在所有输出同时工作时测量
5. **De-embedding** — 考虑 DIB 和 Socket 的延迟
6. **Spec Margin** — ATE 测量误差要在 Spec 中留余量
