# 其他模块测试 — PMIC LRA / GPIO / CODEC FT 测试

> **本文档详细阐述 PMIC 中 LRA（Linear Resonant Actuator，线性谐振马达驱动）、GPIO（General Purpose Input/Output，通用输入输出）和 CODEC（Audio Codec，音频编解码器）模块在 FT 阶段的测试原理与测试方法。**

---

## 1. LRA 测试 (Linear Resonant Actuator Driver Test)

### 1.1 概述

**LRA (Linear Resonant Actuator)** 是一种线性谐振马达，广泛应用于智能手机、可穿戴设备等消费电子产品中，用于提供触觉反馈（Haptic Feedback）。LRA 的核心特性是**需要在谐振频率下驱动**才能获得最大振动幅度和最佳效率。

PMIC 内部的 LRA 驱动器负责产生正弦波驱动信号，驱动 LRA 马达在最佳工作点振动。

### 1.2 工作原理

#### 1.2.1 LRA 的物理特性

```
LRA 等效模型:

              ┌──────────┐
              │          │
  Drive ──────┤  R_motor ├──────┬───── GND
  Signal      │          │      │
              └──────────┘      │
                              ┌─┴─┐
                              │ C │
                              │   │
                              └─┬─┘
                                │
                              ┌─┴─┐
                              │ L │
                              │   │
                              └─┬─┘
                                │
                              GND

  R: 线圈直流电阻 (典型 8~30Ω)
  L: 线圈电感 (典型 50~500μH)
  C: 弹簧等效电容 (由机械谐振决定)
```

| LRA 参数 | 典型范围 | 说明 |
|----------|---------|------|
| 谐振频率 (F_res) | 150~250Hz | 机械共振频率，在此频率下效率最高 |
| 线圈电阻 (R_coil) | 8~30Ω | 直流电阻 |
| 工作电压 | 1.0~3.0V rms | 典型驱动电压 |
| 最大驱动电流 | 100~300mA | 取决于 LRA 大小 |
| 起振时间 | 5~20ms | 从 0 到稳态的时间 |
| 制动时间 (Brake) | 5~15ms | 主动制动后的停止时间 |

#### 1.2.2 LRA 驱动器架构

PMIC 中 LRA 驱动器的典型结构：

```
                     VDD_BAT
                       │
  ┌──────────────┐    ┌┴┐
  │  Waveform    │    │ │  H-Bridge
  │  Generator   │    │ │
  │  (Sine PWM) │    │ │
  │              │    │ │
  │  Frequency   ├────┤ │──── LRA+
  │  Control     │    │ │
  │              │    │ │
  │  Amplitude   │    │ │──── LRA-
  │  Control     │    └─┘
  │              │     │
  │  Brake Ctrl  │    ┌─┴─┐
  │              │    │ │ │  Current
  │  Auto-       │    │ │ │  Sense
  │  Resonance   │    └─┬─┘
  │  Tracking    │      │
  └──────────────┘      │
                    Feedback (optional)
```

| 子模块 | 功能 | 说明 |
|--------|------|------|
| **波形发生器 (Waveform Gen)** | 生成正弦波 PWM 信号 | 基于 DDS (Direct Digital Synthesis) 或查表法 |
| **H-Bridge (全桥驱动)** | 将 PWM 转换为 LRA 两端驱动电压 | 差分输出，效率高 |
| **频率控制 (Freq Ctrl)** | 设置驱动频率 = LRA 谐振频率 | 通过寄存器设置 |
| **振幅控制 (Amp Ctrl)** | 调节驱动电压幅度 | 通过 PWM 占空比或电源电压调节 |
| **制动控制 (Brake Ctrl)** | 快速停止 LRA 振动 | 主动短路或反向驱动 |
| **自动谐振跟踪 (Auto-Resonance)** | 自动追踪 LRA 谐振频率 | 通过监测反电动势 (BEMF) 实现 |

#### 1.2.3 开环 vs 闭环驱动

| 驱动方式 | 原理 | 优点 | 缺点 |
|---------|------|------|------|
| **开环驱动** | 直接设置固定频率驱动 | 实现简单 | 无法补偿谐振频率偏移（老化/温度） |
| **闭环驱动** | 监测 BEMF 相位，自动调整频率 | 效率高，可自动跟踪 | 需要额外检测电路 |

**闭环谐振跟踪原理：**

```
1. 驱动器输出电压 V_drive @ 设定频率
2. LRA 两端产生电流 I_drive
3. 电流波形中的相位信息反映 LRA 是否在谐振点:
   - 驱动频率 < F_res: 电流相位超前电压 (感性)
   - 驱动频率 = F_res: 电流与电压同相 (纯阻性)
   - 驱动频率 > F_res: 电流相位滞后电压 (容性)
4. 检测 I_drive 与 V_drive 的相位差
5. 调整驱动频率使相位差 → 0
6. 锁定谐振频率
```

### 1.3 测试方法

#### 1.3.1 输出波形测试 (Output Waveform Verification)

**目的**：验证 LRA 驱动器输出正弦波的频率和幅度是否在规格内。

```
测试条件:
  - PMIC 正常供电 (VDD_BAT = 3.8V, VDD_IO = 1.8V)
  - 使能 LRA 驱动器
  - 设置驱动频率 = F_res (如 200Hz)
  - 设置驱动幅度 = V_target (如 2.0Vpp)
  - LRA 输出端接等效负载 R_LRA (如 15Ω)

测试连接:
  LRA+ ────┤ 示波器 CH1 (差分)
  LRA- ────┤
             │
            R_L (模拟 LRA 线圈电阻)
             │
            GND

测试步骤:
  Step 1: 使能 LRA 驱动器
  Step 2: 等待输出稳定 (t_wait > 20ms)
  Step 3: 捕获输出波形 (至少 10 个周期)
  Step 4: 测量波形频率 F_meas
  Step 5: 测量波形峰峰值 V_pp
  Step 6: 计算 THD (总谐波失真)
  Step 7: 验证所有参数在规格内

判定标准:
  | 参数 | 典型规格 | 说明 |
  |------|:--------:|------|
  | 频率偏差 | ±5% | 相对于设定频率 |
  | 幅度偏差 | ±10% | 相对于设定幅度 |
  | 波形 THD | < 5% | 正弦波纯度 |
  | 占空比对称性 | ±2% | 正负半周对称 |
```

#### 1.3.2 驱动电流/电压能力测试

**目的**：验证 LRA 驱动器的最大输出能力。

```
测试条件:
  - 设置最大驱动幅度
  - 连接不同阻值的负载电阻

测试步骤:
  Step 1: 设置最大幅度寄存器 (0xFF 或最大值)
  Step 2: 接入负载 R_load = R_min (如 8Ω)
  Step 3: 测量输出电流 I_out = V_LRA / R_load
  Step 4: 计算输出功率 P_out = I_out² × R_load
  Step 5: 验证是否满足电流/功率规格
  Step 6: 切换负载到 R_max (如 30Ω) 重复测试

判定标准:
  | 参数 | 规格 | 测试条件 |
  |------|:----:|---------|
  | 最大输出电流 | ≥ Imax_spec | R_load = R_min |
  | 最大输出电压 | ≥ Vmax_spec | R_load = R_max |
  | 输出功率 | ≥ Pmax_spec | — |
```

#### 1.3.3 自动谐振跟踪测试 (Auto-Resonance Tracking)

```
测试条件:
  - 需要模拟实际 LRA 的谐振特性
  - 或使用可调 LC 负载模拟器

测试步骤:
  Step 1: 使能闭环自动谐振跟踪模式
  Step 2: 设置初始驱动频率 (如偏离谐振点 +10%)
  Step 3: 监测频率调整过程
  Step 4: 验证驱动器在 t_lock 时间内锁定到谐振频率
  Step 5: 验证锁定后频率 F_locked 与目标 F_res 的偏差
  Step 6: 模拟频率漂移 (改变负载参数)，确认跟踪能力

判定标准:
  | 参数 | 规格 |
  |------|:----:|
  | 锁定时间 | < 100ms |
  | 锁定频率精度 | ±2% (相对于目标 F_res) |
  | 跟踪范围 | F_res × (80%~120%) |
  | 失锁检测 | 能在 100ms 内上报失锁状态 |
```

#### 1.3.4 主动制动功能测试 (Active Brake Test)

**目的**：验证 LRA 驱动器的主动制动功能，确保在停止驱动后 LRA 能快速停止振动。

```
测试条件:
  - LRA 驱动器输出稳定正弦波
  - 使能制动功能

制动方式:
  1. 短路制动: 将 LRA 两端短路，利用反电动势消耗能量
  2. 反向驱动制动: 施加反相电压/电流强制停止
  3. 智能制动: 根据 BEMF 相位动态调整制动信号

测试步骤:
  Step 1: 使能 LRA 驱动并输出稳定波形
  Step 2: 触发制动命令 (写制动寄存器)
  Step 3: 测量从制动触发到 V_LRA < V_threshold (如 50mV) 的时间
  Step 4: 验证制动时间 < T_brake_spec
  Step 5: 验证制动后无残余振荡

判定标准:
  | 制动方式 | 制动时间 | 说明 |
  |---------|:--------:|------|
  | 短路制动 | < 15ms | 无残余振荡 |
  | 主动制动 | < 8ms | 需要更复杂电路 |
  | 无制动 (自然衰减) | ~40~60ms | 作为对比参考 |
```

### 1.4 判定标准总表 (Criteria)

| 测试项 | 典型规格 | 备注 |
|-------|:--------:|------|
| **频率精度** | ±5% (开环) / ±2% (闭环) | 全驱动范围 |
| **幅度精度** | ±10% | 含负载变化 |
| **波形 THD** | < 5% | 正弦波质量 |
| **最大输出电流** | ≥ 200mA | 视具体设计 |
| **最大输出电压** | ≥ 3.0Vpp | 视具体设计 |
| **自动谐振锁定时间** | < 100ms | 闭环模式 |
| **自动谐振跟踪范围** | ±20% F_res | — |
| **制动时间 (短路制动)** | < 15ms | — |
| **制动时间 (主动制动)** | < 8ms | — |
| **静态漏电流** | < 1μA | 禁用状态 |

### 1.5 注意事项

1. **LRA 模拟负载**：FT 测试中无法连接真实 LRA 马达（机械部件），必须使用等效 RL 负载模型。推荐使用精密电阻 (R) 串联电感 (L) 的等效电路。
2. **自谐振频率识别**：LRA 的谐振频率存在个体差异和温度漂移，FT 中应测试驱动器的频率调节能力而非绝对频率值。
3. **启动冲击电流**：LRA 启动瞬间存在较大的冲击电流，测试时需确保 ATE 电源的瞬态响应能力。
4. **制动能量回收**：主动制动会将 LRA 的机械能转换为电能回馈到电源线，需确保测试板有足够的吸收能力。
5. **EMI 考量**：LRA 驱动器的 PWM 开关频率可能辐射噪声，测试时应注意屏蔽和去耦。

## 2. GPIO 功能测试 (GPIO Function Test)

### 2.1 概述

**GPIO (General Purpose Input/Output, 通用输入输出)** 是 PMIC 中最基本的数字接口引脚。在 FT 测试中，需要验证每个 GPIO 引脚的所有可配置功能和电特性。

### 2.2 GPIO 功能模块

#### 2.2.1 GPIO 引脚典型结构

```
                        VDD_IO
                         │
                    ┌────┴────┐
                    │  Pull-  │
                    │   Up    │
                    │ (可选)  │
                    └────┬────┘
                         │
  ┌───────┐             ├─────────── 输出数据 (DOUT)
  │ Output│             │            (来自寄存器)
  │ En    ├── Enable ───┤
  │ Ctrl  │             │
  └───────┘            ┌┴┐
  ┌───────┐           │ │
  │ Input │           │ │
  │ En    ├── Enable  │ │
  │ Ctrl  │           │ │
  └───────┘           │ │
                      │ │
                      └┬┘
                       │
                    ┌──┴──┐
              ┌─────┤ MUX │←─── IOMUX (功能复用选择)
              │     └─────┘
              │        │
              │    ┌───┴──── GPIO Pad
              │    │
              ├── 输入数据 (DIN → 寄存器)
              │
              ├── 中断检测 (上升/下降/双边沿)
              │
              └── 替代功能 (如: I2C, SPI, PWM_out...)
```

#### 2.2.2 GPIO 可配置特性

| 特性 | 可选配置 | 说明 |
|------|---------|------|
| **方向** | 输入 / 输出 / 开漏 / 高阻 | 基本引脚方向控制 |
| **输出类型** | Push-Pull / Open-Drain | 输出驱动模式 |
| **输出驱动强度** | 2mA / 4mA / 8mA / 12mA | 驱动电流能力 |
| **内部上拉** | 使能 / 禁用 | 可选内部上拉电阻 |
| **内部下拉** | 使能 / 禁用 | 可选内部下拉电阻 |
| **中断触发** | 上升沿 / 下降沿 / 双边沿 / 电平 | 中断检测配置 |
| **功能复用** | GPIO / 专用功能 n | IOMUX 选择 |

### 2.3 测试方法

#### 2.3.1 输出功能测试 (Output Test)

**目的**：验证 GPIO 配置为输出模式时，能正确输出 0 和 1 电平。

```
测试步骤:
  Step 1: 将 GPIO 配置为输出模式 (Push-Pull)
  Step 2: 写寄存器输出 0 (GPIO_DOUT = 0)
  Step 3: 用 ATE 数字通道测量引脚电压
  Step 4: 验证 V_pin < V_OL_max (如 0.4V)
  Step 5: 写寄存器输出 1 (GPIO_DOUT = 1)
  Step 6: 用 ATE 数字通道测量引脚电压
  Step 7: 验证 V_pin > V_OH_min (如 VDD_IO - 0.4V)

判定标准:
  | 参数 | 规格 | 条件 |
  |------|:----:|------|
  | V_OL (输出低电平) | < 0.4V | I_sink = 2~8mA |
  | V_OH (输出高电平) | > VDD_IO - 0.4V | I_source = 2~8mA |
```

#### 2.3.2 输入功能测试 (Input Test)

**目的**：验证 GPIO 配置为输入模式时，能正确读取外部输入电平。

```
测试步骤:
  Step 1: 将 GPIO 配置为输入模式 (高阻)
  Step 2: 用 ATE 数字通道 Force 低电平 (0V)
  Step 3: 读取 GPIO 输入寄存器 DIN
  Step 4: 验证 DIN = 0
  Step 5: 用 ATE 数字通道 Force 高电平 (VDD_IO)
  Step 6: 读取 GPIO 输入寄存器 DIN
  Step 7: 验证 DIN = 1

判定标准:
  | 参数 | 规格 | 说明 |
  |------|:----:|------|
  | V_IL (输入低电平最大) | < 0.3 × VDD_IO | 保证识别为 0 |
  | V_IH (输入高电平最小) | > 0.7 × VDD_IO | 保证识别为 1 |
  | 输入漏电流 | < ±1μA | 高阻态下 |
```

#### 2.3.3 开漏 / 开集输出测试 (Open-Drain Output Test)

**目的**：验证 GPIO 配置为开漏输出时的功能。

```
测试步骤:
  Step 1: 将 GPIO 配置为 Open-Drain 输出模式
  Step 2: 使能内部上拉（或在外部连接上拉电阻）
  Step 3: 写输出 0:
         - 测量 V_pin < V_OL (应为低电平)
  Step 4: 写输出 1 (高阻):
         - 测量 V_pin ≈ V_pullup (上拉电压)
  Step 5: 验证开漏功能正确

判定:
  - 输出 0 时: V_pin < 0.4V (N-MOS 导通)
  - 输出 1 时: V_pin = V_pullup (N-MOS 关断, 高阻)
```

#### 2.3.4 上拉 / 下拉电阻测试 (Pull-Up/Pull-Down Test)

**目的**：验证 GPIO 内部上拉/下拉电阻的阻值在规格范围内。

```
测试方法 (以上拉为例):

  Step 1: GPIO 配置为输入模式
  Step 2: 使能内部上拉 (设置寄存器)
  Step 3: GPIO 引脚保持悬空 (高阻)
  Step 4: 测量引脚电压 V_pin
  Step 5: V_pin ≈ VDD_IO (上拉到电源)
  
  如果需要精确测量电阻值:
  Step 4': 外部连接精密电阻 R_ext 到 GND
  Step 5': 测量 V_pin
  Step 6': 计算 R_pu = R_ext × (VDD_IO - V_pin) / V_pin
  
  下拉电阻测试类似:
  - 使能内部下拉
  - 引脚悬空时 V_pin ≈ GND
  - 外接 R_ext 到 VDD_IO 测量分压

判定标准:
  | 上拉/下拉类型 | 典型值 | 精度 |
  |--------------|:------:|:----:|
  | 弱上拉 | 50~100kΩ | ±20% |
  | 强上拉 | 4.7~10kΩ | ±10% |
  | 弱下拉 | 50~100kΩ | ±20% |
  | 强下拉 | 4.7~10kΩ | ±10% |
```

#### 2.3.5 中断功能测试 (Interrupt Test)

**目的**：验证 GPIO 的中断检测功能。

```
测试步骤:
  Step 1: GPIO 配置为输入模式
  Step 2: 配置中断触发方式 (上升沿/下降沿/双边沿/电平)
  Step 3: 清除中断标志寄存器
  Step 4: 施加触发条件:
         - 上升沿: Force 低 → 高跳变
         - 下降沿: Force 高 → 低跳变
         - 电平: Force 并保持指定电平
  Step 5: 读取中断状态寄存器，验证中断标志被置位
  Step 6: 清除中断标志
  Step 7: 验证中断清除后状态寄存器复位

判定标准:
  - 中断标志位在触发条件发生后正确置位
  - 中断标志位在清除操作后正确复位
  - 无虚假中断 (无触发时无标志)
  - 中断触发去抖时间 (如有) 符合规格
```

#### 2.3.6 驱动强度测试 (Drive Strength Test)

**目的**：验证 GPIO 在不同驱动强度下的输出电流能力。

```
测试步骤:
  Step 1: GPIO 配置为输出 Push-Pull 模式
  Step 2: 设置输出为高电平
  Step 3: GPIO 引脚连接 SMU (Force Low)
  Step 4: SMU 从引脚抽取电流 I_load
  Step 5: 测量 V_pin 随 I_load 的变化
  Step 6: 找到 V_OH 降至 VDD_IO - 0.4V 时的电流 I_source_max
  Step 7: 切换驱动强度设置，重复 Step 2~6

测试条件:
  | 驱动强度设置 | 预期 I_source_max | 测试 I_load |
  |:-----------:|:-----------------:|:----------:|
  | 2mA | ≥ 2mA | 2mA |
  | 4mA | ≥ 4mA | 4mA |
  | 8mA | ≥ 8mA | 8mA |
  | 12mA | ≥ 12mA | 12mA |
```

#### 2.3.7 功能复用 (IOMUX) 测试

**目的**：验证 GPIO 引脚在不同功能复用下的正确性。

```
测试方法:
  - 对每个 GPIO 的备用功能进行验证
  - 方法取决于备用功能类型:
    * 若备用功能为通信接口 (I2C/SPI): 运行对应通信协议测试
    * 若备用功能为 PWM 输出: 使用示波器/频率计验证波形
    * 若备用功能为外部中断: 触发并验证中断响应
    * 若备用功能为时钟输出: 测量频率和幅度

  - 测试后必须恢复 GPIO 模式并确认功能正常
```

### 2.4 判定标准总表 (Criteria)

| 测试项 | 典型规格 | 备注 |
|-------|:--------:|------|
| **V_OH (高电平输出)** | > VDD_IO - 0.4V | @ 额定驱动电流 |
| **V_OL (低电平输出)** | < 0.4V | @ 额定驱动电流 |
| **V_IH (输入高电平)** | > 0.7 × VDD_IO | — |
| **V_IL (输入低电平)** | < 0.3 × VDD_IO | — |
| **输入漏电流** | < ±1μA | 高阻态 |
| **输出驱动强度** | ±2mA / ±4mA / ±8mA | 可配置 |
| **上拉电阻** | 4.7k~100kΩ ±20% | 按配置 |
| **下拉电阻** | 4.7k~100kΩ ±20% | 按配置 |
| **中断响应时间** | < 1μs (硬件) | 从引脚跳变到标志置位 |
| **IOMUX 切换时间** | < 1μs | 功能切换延迟 |

### 2.6 注意事项

1. **上电初始状态**：GPIO 在上电瞬间应处于高阻态，避免与外部电路冲突。FT 测试需验证上电后寄存器默认值正确。
2. **测试顺序**：在多 GPIO 芯片上测试时，未被测试的引脚应保持在确定的电平（高阻 + 上拉/下拉或固定输出），防止悬浮导致不确定结果。
3. **IO 环回测试**：当两个 GPIO 可连通时（通过 PCB 走线），可进行环回测试（一个输出，另一个输入），验证内部数字路径的完整性。
4. **静电放电 (ESD) 保护**：GPIO 引脚上的 ESD 保护结构可能引入额外的漏电路径。在漏电测试中应注意区分正常 ESD 漏电和异常缺陷。
5. **负载电容**：GPIO 输出的上升/下降时间受负载电容影响。FT 测试应使用已知负载电容 (如 20pF / 50pF) 以获得可重复的测试结果。

## 3. CODEC 测试 (Audio Codec Test)

### 3.1 概述

**CODEC (Coder-Decoder, 音频编解码器)** 是 PMIC 中负责音频信号输入/输出的模块。它包含 **ADC（录音路径）** 和 **DAC（播放路径）**，可能还包括麦克风偏置、功放、混音器等辅助功能。

### 3.2 工作原理

#### 3.2.1 CODEC 系统架构

```
播放路径 (Playback / DAC Path):

  数字音频输入 ──→ 数字滤波器 ──→ DAC ──→ 低通滤波 ──→ 功放 ──→ 耳机/喇叭
  (I2S/PDM)     (SRC/FIR/IIR)                    (LPF)     (PA)

录音路径 (Record / ADC Path):

  麦克风 ──→ 前置放大 ──→ 抗混叠滤波 ──→ ADC ──→ 数字滤波器 ──→ 数字音频输出
           (PGA)          (AAF)                  (DEC/HPF)
```

| 子模块 | 功能 | 关键参数 |
|--------|------|---------|
| **DAC (数模转换器)** | 将数字音频信号转换为模拟电压 | SNR, THD+N, 动态范围 |
| **ADC (模数转换器)** | 将模拟音频信号转换为数字信号 | SNR, THD+N, 动态范围 |
| **PGA (可编程增益放大器)** | 麦克风/线路输入增益控制 | 增益范围, 步进, 噪声 |
| **PA (功率放大器)** | 驱动耳机/喇叭 | 输出功率, THD+N, 效率 |
| **数字滤波器** | 采样率转换, 滤波, 均衡 | 通带纹波, 阻带衰减 |
| **麦克风偏置 (Mic Bias)** | 为驻极体麦克风提供偏置电压 | 电压精度, 噪声 |

#### 3.2.2 关键性能指标

| 指标 | 英文 | 定义 | 典型消费级 | 典型高保真级 |
|------|------|------|:----------:|:------------:|
| **信噪比** | SNR | (信号功率 / 噪声功率) 的对数比 | 90~100dB | > 110dB |
| **总谐波失真+噪声** | THD+N | (谐波+噪声) / (总信号) 的比例 | < 0.01% | < 0.001% |
| **动态范围** | DR | 最大不失真信号与最小可辨信号之比 | 90~100dB | > 110dB |
| **通道串扰** | Crosstalk | 一个通道对另一通道的泄漏 | < -80dB | < -100dB |
| **频率响应** | Freq Resp | 通带内幅度平坦度 | ±1dB (20Hz~20kHz) | ±0.1dB |
| **采样率** | Sample Rate | 每秒采集的样本数 | 48kHz / 96kHz | 192kHz / 384kHz |

### 3.3 测试方法

#### 3.3.1 DAC 测试 (DAC Path Test)

**目的**：验证数字音频到模拟音频的转换质量。

```
测试条件:
  - 数字测试信号: 1kHz/20Hz/20kHz 正弦波 (0dBFS 或 -3dBFS)
  - 输出负载: 标准负载 (如 32Ω 耳机 / 10kΩ 线路)
  - 采样率: 48kHz (典型)
  - 位深: 16-bit / 24-bit

测试步骤:
  Step 1: 配置 CODEC 播放路径 (DAC 使能, 输出通道选择)
  Step 2: 向 DAC 发送数字测试信号 (I2S 数据)
  Step 3: 等待输出稳定 (t_settle > 100ms)
  Step 4: 使用 Audio Analyzer 或 ATE Digitizer 捕获模拟输出
  Step 5: 对捕获信号进行 FFT 分析
  Step 6: 计算 SNR, THD+N, 频率响应等指标
  Step 7: 与规格比较判定 PASS/FAIL
```

##### 3.3.1.1 THD+N 测试

```
输入: 1kHz 正弦波, -3dBFS (或 -1dBFS)
输出负载: 32Ω (耳机) / 10kΩ (线路)
FFT 设置:
  - 采样率: 192kHz (≥ 4x)
  - FFT 点数: 65536 (64k)
  - 窗口: 汉宁窗 (Hanning)
  - 平均次数: ≥ 16

分析:
  THD+N (%) = sqrt(Σ(harmonic_power) + noise_power) / signal_power × 100
  THD+N (dB) = 10 × log10(THD+N)

判定:
  | 等级 | THD+N | SNR |
  |:----:|:-----:|:---:|
  | 消费级 | < 0.05% | > 85dB |
  | 中端 | < 0.01% | > 95dB |
  | 高端 | < 0.002% | > 105dB |
```

##### 3.3.1.2 SNR 测试

```
测试方法 (带权/无加权):

方法 A (无加权):
  1. 播放 1kHz, -60dBFS 信号
  2. 捕获输出，FFT 分析
  3. SNR = 信号幅度 (dB) - 噪声底噪 (dB) + 60dB

方法 B (A-加权, 常用):
  1. 播放 1kHz, -60dBFS 信号
  2. 通过 A-Weighting 滤波器
  3. 计算加权 SNR
  
判定: SNR > 90dB (A-weighted) @ 1kHz
```

##### 3.3.1.3 频率响应测试

```
测试步骤:
  Step 1: 播放多频点正弦波 (20Hz, 100Hz, 1kHz, 5kHz, 10kHz, 20kHz)
  Step 2: 对每个频点测量输出幅度
  Step 3: 以 1kHz 为参考 (0dB)
  Step 4: 计算各频率点的相对增益:
         Gain(f) = 20 × log10(V_out(f) / V_out(1kHz))

判定标准:
  | 频率范围 | 允许偏差 | 说明 |
  |:--------:|:--------:|------|
  | 20Hz ~ 100Hz | ±1.5dB | 低频延伸 |
  | 100Hz ~ 10kHz | ±0.5dB | 中频平坦度 |
  | 10kHz ~ 20kHz | ±1.0dB | 高频滚降 |
```

##### 3.3.1.4 通道串扰测试

```
测试步骤:
  Step 1: 左声道播放 1kHz 正弦波 (0dBFS)
  Step 2: 右声道静音 (输出 0)
  Step 3: 测量左声道输出 V_L 和右声道输出 V_R
  Step 4: 串扰 = 20 × log10(V_R / V_L) [dB]
  Step 5: 交换左右声道，重复 Step 1~4
  Step 6: 取两个方向的串扰值

判定: 通道串扰 < -80dB (典型)
```

#### 3.3.2 ADC 测试 (ADC Path Test)

**目的**：验证模拟音频到数字音频的转换质量。

```
测试条件:
  - 模拟输入信号: 1kHz 正弦波, 幅度在满量程附近
  - 使用低失真信号源 (THD < -100dB)
  - 采样率: 48kHz

测试步骤:
  Step 1: 配置 CODEC 录音路径 (ADC 使能, PGA 增益设置)
  Step 2: Audio Analyzer 或低失真信号源输出测试信号
  Step 3: 注入到 CODEC 模拟输入引脚
  Step 4: 通过 I2S 或数字接口捕获 ADC 输出数字信号
  Step 5: 对捕获的音频数据进行 FFT 分析
  Step 6: 计算 SNR, THD+N 等指标
  Step 7: 与规格比较判定 PASS/FAIL

与 DAC 测试的区别:
  - ADC 需要外部低失真信号源
  - ADC 输出是数字量，需要通过数字接口捕获
  - 噪声源不同（量化噪声 vs 模拟噪声）
```

#### 3.3.3 输出功率 / 负载驱动能力测试

**目的**：验证音频功放在不同负载下的输出功率。

```
测试条件:
  - 负载类型: 16Ω / 32Ω / 600Ω (视应用)
  - 电源电压: VDD_IO (如 1.8V) 或功放专用电源 (如 5V)

测试步骤:
  Step 1: 播放 1kHz 正弦波, 逐步增大数字增益
  Step 2: 监测输出波形, 直到 THD 达到 1% (或 10% 视规格)
  Step 3: 记录此时的输出功率:
         P_out = V_rms² / R_load
  Step 4: 验证 P_out > P_out_spec (规格值)
  Step 5: 切换负载并重复

判定:
  | 负载 | 最小输出功率 | 测试条件 |
  |:----:|:-----------:|---------|
  | 16Ω  | 25mW | THD < 1%, VDD=1.8V |
  | 32Ω  | 25mW | THD < 1%, VDD=1.8V |
  | 600Ω | 10mW | THD < 1%, VDD=1.8V |
```

#### 3.3.4 输入灵敏度测试

**目的**：验证 ADC 录音路径在不同输入电平下的响应。

```
测试条件:
  - PGA 增益设置为最小值 (如 0dB)
  - 输入信号频率: 1kHz

测试步骤:
  Step 1: 从极小幅度开始, 逐步增大输入信号
  Step 2: 记录 ADC 输出数字量
  Step 3: 找到输入灵敏度点 (输出达到 -3dBFS 时的输入电平)
  Step 4: 调节 PGA 增益, 验证输入灵敏度的变化
  Step 5: 测量本底噪声 (无输入时的 ADC 输出噪声)

判定:
  | 参数 | 典型值 |
  |------|:------:|
  | 最小输入灵敏度 | < 10mV rms (PGA=0dB) |
  | 最大输入电平 | > 1V rms (PGA=0dB) |
  | PGA 增益范围 | 0dB ~ 60dB |
  | PGA 步进 | 1dB / 2dB |
  | 等效输入噪声 | < -110dBV (A-weighted) |
```

### 3.4 CODEC 测试规范汇总

| 测试项 | 测试方法 | 典型规格 |
|-------|---------|:--------:|

### 3.6 注意事项

1. **信号源纯度**：THD+N 测试中，信号源的失真必须远低于被测 CODEC 的预期 THD+N（至少低 10dB 以上）。建议使用 Audio Precision APx555 等专用音频分析仪。
2. **接地与屏蔽**：音频测试对地回路噪声和电磁干扰极为敏感。测试板应采用星型接地，音频信号路径应使用屏蔽线。
3. **数字域 vs 模拟域**：DAC 测试是数字域注入、模拟域分析；ADC 测试是模拟域注入、数字域分析。两者需要不同的测试设备和连接。
4. **Pop/Click 噪声**：CODEC 上电/下电时的瞬态噪声可能被人耳感知为 "噗" 声 (Pop/Click)。FT 中需要验证启停过程的瞬态噪声。
5. **时钟抖动**：I2S 时钟的抖动会直接影响 DAC/ADC 的 SNR。测试过程中应使用低抖动时钟源。
6. **多采样率**：CODEC 可能支持多种采样率 (8/16/32/44.1/48/96kHz)。FT 应验证所有支持采样率下的基本性能（至少测 48kHz 和 96kHz）。
7. **测试负载一致性**：不同测试工位间的负载电阻偏差会导致输出功率测量值差异。使用精密电阻 (< ±0.1%) 作为负载。

## 5. 常见问题与排查

| 问题模块 | 问题现象 | 可能原因 | 排查方向 |
|---------|---------|---------|---------|
| **LRA** | 输出幅度偏低 | H-Bridge Ron 偏大 / 电源电压不足 | 检查 H-Bridge 导通电阻和 VDD |
| **LRA** | 频率偏差大 | 波形发生器时钟偏差 | 检查内部振荡器精度 |
| **LRA** | 自动谐振无法锁定 | 反馈路径故障 / 相位检测异常 | 检查 BEMF 检测电路 |
| **LRA** | 制动时间过长 | 制动 MOSFET 导通不良 | 检查制动控制逻辑 |
| **GPIO** | V_OH 偏低 | 驱动强度设置不足 / 输出阻抗大 | 检查驱动强度配置 |

| **GPIO** | 中断丢失 | 去抖过滤 / 中断寄存器配置 | 检查中断配置时序 |
| **CODEC** | THD+N 超标 | 时钟抖动 / 电源噪声 / 信号源失真 | 检查时钟源和电源滤波 |
| **CODEC** | SNR 偏低 | 底噪过大 / 数字路径噪声耦合 | 检查 PCB 布线和接地 |
