# SOH / EIS / 库仑计测试 — PMIC 电池管理 FT 测试

> **本文档详细阐述 PMIC 电池管理（Battery Management）子系统在 FT 阶段的测试原理与测试方法，包括 SOH（State of Health，健康状态）、EIS（Electrochemical Impedance Spectroscopy，电化学阻抗谱）和库仑计（Coulomb Counter，电量计）三大核心测试模块。**

---

## 1. SOH 测试 (State of Health Test)

### 1.1 概述

**SOH（State of Health，健康状态）** 是衡量电池老化程度的关键指标。随着电池使用次数的增加和时间的推移，电池内部会发生不可逆的化学变化，导致内阻增加和可用容量衰减。SOH 测试用于量化这种老化程度，为系统提供电池健康状态的准确评估。

### 1.2 工作原理

#### 1.2.1 SOH 的定义

SOH 通常以百分比表示，100% 表示全新电池，0% 表示电池寿命终止（End of Life, EOL）。典型定义方式有两种：

| 定义方式 | 公式 | 说明 |
|---------|------|------|
| **基于容量衰减 (Capacity Fade)** | SOH = (C_aged / C_new) x 100% | 当前最大可用容量与初始容量之比 |
| **基于内阻增加 (Resistance Increase)** | SOH = (R_EOL - R_current) / (R_EOL - R_new) x 100% | 内阻从初始值到寿命终值的相对位置 |

在 PMIC FT 生产中，**基于内阻的方法**更常见，因为内阻测量可在短时间内完成，适合量产测试的 throughput 要求。

#### 1.2.2 电池内阻与 SOH 的关系

电池内阻由以下部分组成：

```
R_battery = R_ohmic + R_activation + R_diffusion
```

| 内阻分量 | 物理来源 | 随老化变化趋势 |
|----------|---------|--------------|
| **R_ohmic（欧姆内阻）** | 电解液电阻、隔膜电阻、极耳接触电阻 | 显著增加（电解液分解、SEI 膜增厚） |
| **R_activation（活化极化内阻）** | 电荷转移过程 | 增加（活性物质损失） |
| **R_diffusion（扩散内阻）** | Li+ 在电极中的扩散 | 增加（结构退化） |

老化过程中，内阻可增加 **1.5~3 倍**，是判断 SOH 的重要依据。

### 1.3 测试方法

#### 1.3.1 内阻测量法（FT 量产方法）

```
方法: 直流脉冲法 (DC Pulse / HPPC Method)
```

**测试步骤：**

```
Step 1: 将电池充电/放电至指定 SOC（如 50% SOC）
Step 2: 静置一段时间（如 30s），记录开路电压 Voc
Step 3: 施加已知大小的放电/充电电流脉冲 I_pulse（如 1C 或 0.5C）
Step 4: 测量脉冲施加瞬间的电压变化 ΔV
Step 5: 计算内阻 R = ΔV / I_pulse
Step 6: 将 R 与参考值比较，计算 SOH
```

**电压响应曲线示意：**

```
V(t)
│
│  Voc ────────────┐
│                  │   ΔV_ohmic (瞬间压降)
│                  ▼──┐
│                     │
│                     │── ΔV_polarization (极化建立)
│                     │
│                     │── 持续放电阶段
│                     │
│                     └──────────→  t
                   脉冲开始
```

**关键测量点：**

| 测量点 | 时间 | 含义 |
|--------|------|------|
| Voc | 脉冲前 | 开路电压（平衡状态） |
| V1 | 脉冲开始后 ~100μs | 欧姆内阻压降（R_ohmic） |
| V2 | 脉冲结束前 | 总内阻压降（R_ohmic + R_polarization） |
| V3 | 脉冲结束后瞬间 | 欧姆内阻恢复 |
| V4 | 恢复结束后 | 回滞电压 |

#### 1.3.2 交流阻抗法 (AC Impedance)

在 FT 中较少用于完整 SOH 评估，但可作为快速筛选：

```
测量条件：
  频率: 1kHz（单频点快速测量）
  激励: 小信号 AC 电流（如 10mA rms）
  测量: 交流电压响应 → 计算阻抗模值 |Z|@1kHz

判断: |Z|@1kHz > 阈值 → 内阻过大 → SOH 不良
```

### 1.4 SOH 计算与判定

#### 1.4.1 SOH 计算模型

```
模型 A（线性模型）:
  SOH = (R_EOL - R_meas) / (R_EOL - R_new) x 100%
  其中 R_new 和 R_EOL 从电池规格书获取

模型 B（查表模型）:
  SOH = LookupTable(R_meas, Temp, SOC)
  需提前建立 R vs. SOH 的对应关系表
```

#### 1.4.2 测试条件规范

| 参数 | 典型值 | 备注 |
|------|--------|------|
| 测试温度 | 25°C ± 2°C | 温度对内阻影响大，必须严格控制 |
| SOC 状态 | 50% ± 2% | SOC 不同内阻不同 |
| 脉冲电流 | 0.5C ~ 1C | 视电池容量而定 |
| 脉冲宽度 | 1s ~ 10s | 区分欧姆内阻和极化内阻 |
| 静置时间 | ≥ 30s | 脉冲前后均需静置 |
| 测量精度 | 电压: ±0.1mV, 电流: ±0.1% | 直接影响 SOH 精度 |

### 1.5 判定标准 (Criteria)

| 项目 | 规格 | 说明 |
|------|------|------|
| **SOH 报告精度** | ±3% (典型) | PMIC 报告的 SOH 与实际 SOH 的偏差 |
| **内阻测量精度** | ±2% | 内部电阻测量模块的精度要求 |
| **内阻分辨率** | < 100μΩ | 最小可检测的内阻变化 |
| **SOH 初值** | 100% ± 2% | 新电池的 SOH 报告值 |
| **内阻参考值偏差** | < ±5% @ 25°C | 与出厂标称内阻的偏差 |

### 1.6 注意事项

1. **温度敏感性**：电池内阻温度系数约为 -2%/°C（温度升高内阻降低），FT 测试必须严格控制温度。
2. **SOC 依赖性**：低 SOC 时内阻显著增加，测试需在指定 SOC 点进行。
3. **脉冲宽度选择**：过短的脉冲无法反映极化内阻，过长的脉冲会导致 SOC 变化。
4. **接触电阻校正**：Socket 接触电阻会叠加到测量结果中，需使用 Kelvin 测量或预先扣除。
5. **老化趋势验证**：SOH 算法需在使用中持续验证，FT 只保证初始精度。

## 2. EIS 测试 (Electrochemical Impedance Spectroscopy Test)

### 2.1 概述

**EIS（Electrochemical Impedance Spectroscopy，电化学阻抗谱）** 是一种通过在宽频率范围内测量电池的交流阻抗响应，来表征电池电化学特性（欧姆阻抗、电荷转移阻抗、扩散阻抗）的技术。

在 PMIC 中，EIS 功能用于：
- **电池建模**：建立电池的等效电路模型（ECM）参数
- **状态估计**：辅助 SOH 和 SOC 的精确估算
- **老化诊断**：区分不同类型的电池老化机制
- **安全监测**：检测微短路、析锂等异常状态

### 2.2 工作原理

#### 2.2.1 基本原理

EIS 通过向电池注入小幅度 AC 激励信号（电流或电压），测量电池的电压/电流响应，从而计算复阻抗：

```
Z(ω) = V_ac(ω) / I_ac(ω) = |Z|·e^(jθ) = Z' + jZ''
```

其中：
- |Z|：阻抗模值 (Impedance Magnitude)
- θ：阻抗相位角 (Phase Angle)
- Z'：实部 (Real Part) = |Z|·cos(θ)
- Z''：虚部 (Imaginary Part) = |Z|·sin(θ)

#### 2.2.2 AC 注入法

PMIC 中的 EIS 通常采用 **AC 电流注入法**：

```
┌─────────────────────────────────────────────────┐
│  PMIC EIS 模块                                   │
│                                                    │
│  AC Current Source ──→ Battery ──→ Voltage Sense   │
│       │                              │              │
│   Frequency Sweep                Magnitude & Phase  │
│   (0.1Hz ~ 10kHz)                Demodulation       │
│                                                    │
└─────────────────────────────────────────────────────┘
```

**测量流程：**

```
1. 设置激励频率 f (从高频到低频扫描)
2. 生成 AC 电流 I_ac = I_m · sin(2πft)
3. 注入电池
4. 测量电池端电压 V_ac = V_m · sin(2πft + θ)
5. 使用锁相放大 (Lock-in Amplifier) 解调出 V_m 和 θ
6. 计算 Z(ω) = V_m / I_m, θ = θ_v - θ_i
7. 切换下一频率，重复 1~6
```

#### 2.2.3 奈奎斯特图 (Nyquist Plot)

EIS 测量结果通常以奈奎斯特图表示：

```
-Z'' (Ω)
   │
   │    高频区         中频区          低频区
   │    (欧姆阻抗)    (电荷转移)      (扩散阻抗)
   │
   │      ··· ──→ semicircle ──→ 45° tail
   │    ·   ·
   │   ·     ·
   │  ·       ·
   │ ·         ·
   │·           ·
   │             ────────────────→ Z' (Ω)
   │R_ohmic     R_ohmic + R_ct
```

| 频率范围 | 对应阻抗分量 | 典型频率 |
|----------|-------------|---------|
| **高频区 (> 1kHz)** | 欧姆内阻 R_ohmic | 电解液、隔膜、极耳 |
| **中频区 (1Hz ~ 1kHz)** | 电荷转移阻抗 R_ct + C_dl | 电极/电解液界面 |
| **低频区 (< 1Hz)** | 扩散阻抗 Warburg | Li+ 在电极中的扩散 |

#### 2.2.4 等效电路模型 (ECM)

常用等效电路模型来拟合 EIS 数据：

```
Model: R_ohmic + (R_ct // CPE) + W
```

其中：
- R_ohmic：欧姆内阻（串联电阻）
- R_ct：电荷转移电阻
- CPE：恒定相位元件（代替理想电容，反映非理想行为）
- W：Warburg 扩散阻抗

### 2.3 测试方法

#### 2.3.1 FT 量产测试方案

FT 中 EIS 测试通常**不扫描全频段**（测试时间过长），而是采用以下简化方案：

| 方案 | 测试内容 | 测试时间 | 适用场景 |
|------|---------|:--------:|---------|
| **单频点** | 仅测 1kHz 阻抗 | < 10ms | 快速筛选 |
| **三点法** | 高/中/低各 1 个频点 | ~50ms | 常规量产 |
| **简化扫描** | 每 decade 3~5 点 | ~200ms | 高精度需求 |
| **全扫描** | 全频段 0.1Hz~10kHz | > 1s | 实验室/QA |

#### 2.3.2 典型 FT 测试流程 (三点法)

```
Step 1: 初始化 EIS 模块
  - 使能 EIS 电流源
  - 设置校准模式（连接校准电阻）

Step 2: 校准测量
  - 将 EIS 模块切换到精密校准电阻（如 10mΩ/100mΩ）
  - 测量校准电阻的阻抗和相位
  - 记录系统偏移用于补偿

Step 3: 切换到电池测量
  - EIS 模块连接到电池
  - 确认电池静止（无充放电电流）

Step 4: 高频点测量 (1kHz)
  - 频率: 1kHz
  - 激励电流: I_ac = 50mA rms
  - 测量: |Z|_1kHz, θ_1kHz
  - 计算: R_ohmic ≈ |Z|_1kHz · cos(θ_1kHz)

Step 5: 中频点测量 (10Hz)
  - 频率: 10Hz
  - 激励电流: I_ac = 25mA rms
  - 测量: |Z|_10Hz, θ_10Hz

Step 6: 低频点测量 (0.5Hz)
  - 频率: 0.5Hz
  - 激励电流: I_ac = 10mA rms
  - 测量: |Z|_0.5Hz, θ_0.5Hz

Step 7: 参数验证
  - 与规格限值比较
  - 判定 PASS/FAIL
```

#### 2.3.3 解调原理（锁相放大）

PMIC 内部使用数字锁相放大器 (Digital Lock-in Amplifier) 解调阻抗信号：

```
V_ac(t) = V_m · sin(ωt + θ)

混频:
  I = V_ac(t) · sin(ωt)     → 低通滤波 → V_m · cos(θ) / 2
  Q = V_ac(t) · cos(ωt)     → 低通滤波 → V_m · sin(θ) / 2

计算:
  V_m = 2 · sqrt(I² + Q²)
  θ = arctan(Q / I)
  |Z| = V_m / I_m
```

### 2.4 校准方法

#### 2.4.1 外部校准电阻

EIS 模块需要外部精密电阻进行增益和相位校准：

```
┌───────────────┐
│   PMIC EIS    │
│               │         ┌──────────────┐
│   I_out ──────┼─────────┤              │
│               │         │  校准电阻     │
│   V_sense ────┼─────────┤  (精密 ±0.1%) │
│               │         │              │
│               │         └──────────────┘
│   Cal_SW ─────┤ 控制 Relay
└───────────────┘
```

| 校准电阻值 | 用途 | 对应阻抗范围 |
|-----------|------|-------------|
| 10mΩ | 低阻抗校准（动力电池） | 5~50mΩ |
| 100mΩ | 中阻抗校准（消费电池） | 50~500mΩ |
| 1Ω | 高阻抗校准（小型电池） | 0.5~5Ω |

#### 2.4.2 校准流程

```
1. 断开电池连接，导通校准 Relay
2. 接入标准电阻 R_cal
3. 在标准频率点测量：
   - 幅度增益校正因子 G_cal = R_cal / |Z_measured|
   - 相位偏移校正因子 θ_offset = 0 - θ_measured
4. 存储校正因子到寄存器
5. 切换到电池测量模式
6. 实际测量值 = 原始测量值 × G_cal，相位值 = θ_raw + θ_offset
```

### 2.5 判定标准 (Criteria)

| 参数 | 规格 | 备注 |
|------|------|------|
| **阻抗模值精度** | ±2% (典型) | 全频段 |
| **相位精度** | ±2° (典型) | > 1Hz 时 |
| **相位精度 (低频)** | ±5° | < 1Hz 时（噪声大） |
| **激励电流精度** | ±1% | AC 电流源精度 |
| **频率精度** | ±0.5% | 激励频率精度 |
| **阻抗测量范围** | 1mΩ ~ 10Ω | 覆盖常见电池 |
| **最大 DC 偏置容差** | ±100mV | 电池端 DC 电压波动 |
| **校准电阻精度要求** | ±0.1% (外部) | 参考标准 |

### 2.6 注意事项

1. **电池平衡状态**：EIS 测量必须在不充电/不放电的静止状态下进行，DC 电流会导致测量失真。
2. **激励幅度选择**：激励电流必须足够小以确保系统线性响应（通常 < 10mV 电压响应），但又要足够大以获得良好 SNR。
3. **频率响应时间**：低频测量（如 0.1Hz）需要至少 10 个周期的稳定时间（即 100s），FT 中通常避免极低频测量。
4. **噪声抑制**：EIS 测量易受开关电源噪声和工频 (50/60Hz) 干扰，需使用平均滤波和屏蔽。
5. **温度影响**：电池阻抗随温度显著变化，全温范围测试需建立温度补偿表。
6. **校准频率依赖性**：校准因子可能随频率变化，宽频段测试应在多个频率点校准。

## 3. 库仑计测试 (Coulomb Counter Test)

### 3.1 概述

**库仑计 (Coulomb Counter)** 是 PMIC 电池管理系统中的核心电量监测模块。它通过连续测量电池的充放电电流并对其时间积分，实时跟踪电池的荷电状态 (State of Charge, SOC)。

库仑计的基本原理：

```
SOC(t) = SOC(0) + (1 / C_nom) · ∫₀ᵗ (I_bat - I_loss) · dt

其中:
  SOC(t):  当前荷电状态 (%)
  SOC(0):  初始荷电状态 (%)
  C_nom:   电池标称容量 (Ah / mAh)
  I_bat:   电池电流 (正 = 放电, 负 = 充电)
  I_loss:  自放电等损耗电流
```

### 3.2 工作原理

#### 3.2.1 系统架构

PMIC 库仑计模块的典型架构：

```
                     ┌──────────┐
Battery ───┬─────────┤ Shunt    ├─────── System Load
           │         │ Resistor │          │
           │         │ (Rsense) │          │
           │         └────┬─────┘          │
           │              │                 │
           │         ┌────▼─────┐          │
           │         │ Current  │          │
           └─────────┤ Sense    │          │
                     │ Amplifier│          │
                     └────┬─────┘          │
                          │                 │
                     ┌────▼─────┐          │
                     │   ADC    │          │
                     └────┬─────┘          │
                          │                 │
                     ┌────▼─────┐          │
                     │ Digital  │          │
                     │Integrator│          │
                     └────┬─────┘          │
                          │                 │
                     ┌────▼─────┐          │
                     │   Fuel   │          │
                     │  Gauge   │          │
                     │  Registers│          │
                     └──────────┘          │
```

| 模块 | 功能 | 关键参数 |
|------|------|---------|
| **Shunt Resistor (Rsense)** | 电流采样电阻 | 典型值 1~10mΩ，精度 ±0.5%~1% |
| **Current Sense Amplifier (CSA)** | 放大 Shunt 两端差分电压 | 增益 50~200，失调 < ±50μV |
| **ADC** | 将模拟电压转换为数字量 | 分辨率 16~24bit，采样率 1~100Hz |
| **Digital Integrator** | 累加电流采样值，计算累积电荷 | 位数 ≥ 32bit |
| **Fuel Gauge Registers** | 存储 SOC、累积容量、标志位 | 含 OTP/RAM 存储 |

#### 3.2.2 电流测量路径

```
电流 → Shunt 电阻 → V_sense = I_bat × Rsense
         ↓
   CSA 放大 → V_out = V_sense × Gain
         ↓
   ADC 采样 → D_out = V_out / V_ref × 2^N
         ↓
   数字积分 → Q_acc = Σ(D_out × Gain_cal × Tsample)
```

### 3.3 测试方法

#### 3.3.1 增益误差测试 (Gain Error Test)

**目的**：测量库仑计的电流测量增益精度。

```
测试条件:
  - 通过精密电流源施加已知 DC 电流到电池端
  - 选择多个电流点（正/负方向）

测试步骤:
  Step 1: 设置电源/电子负载输出 I_target
  Step 2: 通过库仑计 ADC 读取测量值 I_meas
  Step 3: 计算增益误差 Gain_Error = (I_meas / I_target - 1) × 100%

测试点:
  | # | I_target | 方向 | 预期增益误差 |
  |---|----------|------|-------------|
  | 1 | +Imax    | 放电 | < ±1% |
  | 2 | +0.5·Imax| 放电 | < ±1% |
  | 3 | +0.1·Imax| 放电 | < ±2% |
  | 4 | -0.1·Imax| 充电 | < ±2% |
  | 5 | -0.5·Imax| 充电 | < ±1% |
  | 6 | -Imax    | 充电 | < ±1% |
```

#### 3.3.2 失调误差测试 (Offset Error Test)

**目的**：测量库仑计的零输入电流偏差。

```
测试条件:
  - 电池端开路（无电流）
  - 分别测量有偏置和无偏置情况

测试步骤:
  Step 1: 断开负载，确保电池端无电流
  Step 2: 在 shunt 两端短接（V_sense = 0）
  Step 3: 读取 ADC 输出，记录 Offset_Digital
  Step 4: 计算等效输入失调 Offset_uV = Offset_Digital × V_ref / 2^N / Gain
  Step 5: 等效电流失调 Offset_A = Offset_uV / Rsense

判定标准:
  | 测试项 | 典型规格 | 说明 |
  |-------|---------|------|
  | CSA 输入失调 | < ±50μV | 折合到输入端 |
  | ADC 失调 | < ±5 LSB | 数字域 |
  | 等效电流失调 | < ±5mA | 取决于 Rsense 和 Gain |
```

#### 3.3.3 积分精度测试 (Integration Accuracy Test)

**核心测试**：验证库仑计在指定时间内的累积电荷精度。

```
测试条件:
  - 施加已知 I 和已知持续时间 t
  - 理论累积电荷 Q_target = I × t
  - 库仑计报告 Q_meas

测试步骤:
  Step 1: 复位库仑计累积寄存器
  Step 2: 开启恒流源 I_charge (+1A 充电)
  Step 3: 持续 t = 60s
  Step 4: 关闭电流源
  Step 5: 读取库仑计累积电荷 Q_meas
  Step 6: 计算误差 Error = (Q_meas - Q_target) / Q_target × 100%

测试组合:
  | 测试组合 | 电流 | 时间 | 理论电荷 | 预期精度 |
  |---------|------|:----:|:--------:|:--------:|
  | 小电荷 | +100mA | 10s | 1000mAs | ±2% |
  | 中电荷 | +500mA | 60s | 30000mAs | ±1% |
  | 大电荷 | +2A | 120s | 240000mAs | ±1% |
  | 反向 | -1A | 30s | -30000mAs | ±1% |
  | 零电荷 | 0mA | 60s | 0mAs | < ±10mAs |
  | 变电流 | 100mA→1A 步进 | 60s | 计算 | ±1.5% |
```

#### 3.3.4 自放电补偿测试 (Self-Discharge Compensation)

**目的**：验证库仑计在开路状态下的漏电跟踪能力。

```
测试条件:
  - 电池静置（开路）
  - PMIC 处于低功耗模式
  - 持续监测 60min（或可接受的 FT 时间）

测试:
  1. 记录初始累积电荷 Q_start
  2. 等待指定时间 t_standby
  3. 记录最终累积电荷 Q_end
  4. 等效自放电电流 I_self_discharge = (Q_end - Q_start) / t_standby
  5. 验证 I_self_discharge 在规格内

注意: FT 中通常不进行长时间测试，改为验证自放电补偿
      寄存器的配置值是否正确。
```

### 3.4 校准与修调

#### 3.4.1 增益校准 (Gain Calibration)

库仑计的增益误差主要通过修调补偿：

```
校准流程:
  1. 施加已知电流 I_cal（如 1A）
  2. 读取库仑计原始值 D_raw
  3. 计算理论值 D_theory = I_cal × Rsense × Gain / V_ref × 2^N
  4. 计算校准因子 K_cal = D_theory / D_raw
  5. 将校准因子写入库仑计校准寄存器
  6. 施加验证电流 I_verify，确认误差在规格内
```

#### 3.4.2 失调校准 (Offset Calibration)

```
失调校准流程:
  1. 零电流条件下读取残余偏移 D_offset
  2. 写入失调补偿寄存器
  3. 周期性（如每 10 次测量）自动归零

方法:
  - 前台校准: 测量前短接输入，记录偏移
  - 后台校准: 周期性插入校准周期
```

### 3.5 判定标准 (Criteria)

| 参数 | 规格 | 测试条件 |
|------|------|---------|
| **库仑计数精度** | ±1% (典型) | I > 0.1·Imax，25°C |
| **库仑计数精度 (小电流)** | ±3% | I < 0.1·Imax |
| **增益误差** | ±0.5% (Trim 后) | 全温度范围 |
| **失调误差** | < ±0.1% FSR | 折合到输入 |
| **积分非线性** | < ±0.1% | ADC 线性度 |
| **分辨率** | ≥ 16-bit | 有效分辨率 |
| **采样率** | ≥ 10Hz | 典型值 |
| **累积电荷寄存器宽度** | ≥ 32-bit | 防止溢出 |
| **温度漂移** | < ±50ppm/°C | 跨 -20°C~85°C |

### 3.6 测试电路配置

```
                  SMU1 (电源/充电模拟)
                     │
                  ┌──┴──┐
                  │     │
               [Rsense] │
                  │     │
  DMM1 ─── V_sense ─┘     │
                  │       │
             DUT 电池端 ──┤
               │         │
              ┌┤         │
              ││         │
              └┤         │
               │         │
              GND       GND
                  │
                  SMU2 / 电子负载 (放电模拟)

控制信号:
  I2C/SPI ──── DUT (PMIC) ──── 库仑计寄存器读取
```

### 3.7 注意事项

1. **Shunt 电阻的选择**：Rsense 值的选择需权衡功耗 (I²R) 和信噪比 (V_sense)。典型值 1~10mΩ，大电流应用需降至 0.5mΩ 以下。
2. **Kelvin 连接**：Shunt 电阻两端的采样线必须使用 Kelvin 4 线连接，排除走线电阻引入的误差。
3. **共模电压范围**：CSA 需处理电池端的共模电压（最高可达 ~4.5V/cell × 串数），超出范围会导致饱和。
4. **温度影响**：Shunt 电阻的 TCR（典型 ±50~±100ppm/°C）会引入增益漂移，高精度应用需使用 TCR < 20ppm/°C 的精密电阻。
5. **积分清零同步**：累积电荷寄存器归零需与已知 SOC 点同步（如充满电时），FT 中需验证清零功能。
6. **ADC 采样率 vs 电流变化**：采样率不足会导致高频电流分量被混叠到积分结果中。建议采样率 ≥ 10× 最高电流变化频率。
7. **自热效应**：大电流长时间测试会导致 PMIC 和 Shunt 电阻自热，影响测量精度。测试时间应尽量短。

## 5. 常见问题与排查

| 问题 | 可能原因 | 排查方向 |
|------|---------|---------|
| SOH 偏差过大 | 温度未平衡 / SOC 不准 | 检查 soak time 和充电电路 |
| EIS 相位角异常 | 校准失效 / Relay 接触不良 | 重新校准，检查 Relay 导通电阻 |
| 库仑计积分误差大 | Shunt 焊点不良 / 增益校准失效 | 检查 Kelvin 连接，重做增益校准 |
| 零电流读数偏大 | CSA 失调未校准 / PCB 漏电 | 检查 PCB 清洁度，重做失调校准 |
| EIS 低频噪声大 | 工频干扰 / 电池不平衡 | 增加平均次数，检查电池状态 |
| 库仑计满量程偏差 | Rsense 焊接偏差 / ADC 基准漂移 | 检查 Rsense 实际阻值，验证 Vref |
