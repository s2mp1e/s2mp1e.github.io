# 迟滞Buck测试 — PMIC 迟滞型降压变换器 FT 测试

> 本文档覆盖迟滞型降压变换器（Hysteretic Buck Converter）在 FT（Final Test）阶段的所有测试项，包括原理说明、测试方法、条件配置与判定标准。

---

## 一、迟滞Buck变换器概述

### 1.1 迟滞控制基本原理

迟滞Buck变换器采用**基于比较器的控制方式**，而非传统的误差放大器（EA）加补偿网络。其核心控制环路如下：

- **电压反馈**：输出电压 VOUT 通过反馈分压电阻网络产生反馈电压 VFB
- **纹波注入（Ripple Injection）**：由于迟滞比较器需要一定的纹波才能稳定工作，在 VFB 上叠加一个注入纹波信号（通常来自 LX 节点通过 RC 网络耦合）
- **迟滞比较器**：比较 VFB + 注入纹波与内部参考电压 VREF。当 VFB 低于下限阈值时，开启上管（HS-FET）；当 VFB 高于上限阈值时，关闭上管
- **天然稳定性**：无需外部 RC 补偿网络，迟滞比较器本身提供稳定的滞环控制

```
VREF ----|+\
         |  >-----> HS-FET Gate Drive
VFB+RI --|-/
```

**迟滞Buck的关键特征：**

| 特征 | 描述 |
|------|------|
| 控制方式 | 比较器直接控制，无误差放大器 |
| 开关频率 | 变频工作（Variable Frequency），随 VIN、VOUT、负载变化 |
| 瞬态响应 | 极快，比较器直接响应 VOUT 变化 |
| 稳定性 | 天然稳定，无需外部补偿 |
| 输出纹波 | 固有存在（迟滞比较器工作需要），通常较大 |
| 轻载效率 | 高（自然进入 DCM，无开关损耗浪费） |

### 1.2 FT 测试项总览

| 编号 | 测试项 | 关键参数 |
|------|--------|----------|
| 1 | 静态电流/效率/DMD测试 | IQ, Efficiency, DCM-CCM transition |
| 2 | Buck Ramp 反向调压及中断 | DVS ramp reverse, interrupt response |
| 3 | 缓起时间测试 | Soft-start time (10%-90%) |
| 4 | 下拉电阻测试 | Output discharge resistance |
| 5 | OVP 测试 | Over-voltage protection threshold |
| 6 | SCP 测试 | Short-circuit current limit |
| 7 | 输出电压精度/纹波测试 | DC accuracy, ripple Vpp |
| 8 | LX 频率测试 | Switching frequency at specified load |
| 9 | DCM 检测 | Discontinuous conduction detection |
| 10 | RampDown 异常筛选 | Ramp-down undershoot, glitch screening |

## 二、静态电流/效率/DMD测试

### 2.1 原理

#### 2.1.1 迟滞Buck的效率特性

迟滞Buck的效率由以下损耗分量决定：

- **导通损耗（Conduction Loss）**：Pcond = ILOAD² × (Rds_on_HS × D + Rds_on_LS × (1-D))
- **开关损耗（Switching Loss）**：Psw = fsw × (Qgate_HS + Qgate_LS) × VDRV
- **静态损耗（Quiescent Loss）**：PQ = VIN × IQ
- **电感损耗（Inductor Loss）**：Pind = ILOAD² × DCR（直流铜损）+ 磁芯损耗

效率计算公式：
```
η = POUT / PIN = (VOUT × IOUT) / (VIN × IIN)
```

#### 2.1.2 DMD 原理

**DMD（Duty Mode Detection）** 是迟滞Buck中用于检测 DCM（断续导通模式）与 CCM（连续导通模式）之间切换点的电路模块。

- 轻载时，迟滞Buck自然进入 DCM：电感电流在开关周期结束前下降到零，下管关闭后 LX 节点出现振铃
- 重载时，迟滞Buck进入 CCM：电感电流始终大于零，LX 持续开关无断续
- DMD 通过检测下管电流（或 LX 节点电压）来判断电流过零点，从而确定工作模式

**DMD Trim 的重要性：**

| 修调方向 | 影响 |
|----------|------|
| DMD 点过高 | 过早进入 CCM，轻载效率下降 |
| DMD 点过低 | 过晚进入 CCM，重载时纹波增大且可能引起音频噪声 |
| 最佳点 | 在轻载效率与输出纹波之间取得最优权衡 |

### 2.2 测试方法

#### 2.2.1 静态电流（IQ）测试

| 参数 | 条件 |
|------|------|
| DUT 状态 | 输出使能，空载（IOUT = 0mA） |
| VIN | 标称值（如 3.7V） |
| VOUT | 目标输出电压 |
| 测量节点 | VIN 输入电流 |
| 测量仪器 | SMU 或 高精度 DMM（串入电流测量路径） |

测试步骤：
1. 使能 Buck 输出，空载运行
2. 等待输出稳定（软启动完成后）
3. 测量 VIN 输入电流 IIN
4. 记录 IQ = IIN（在空载时，输出电流 = 0，所有输入电流视为静态电流）

#### 2.2.2 效率测试

| 参数 | 条件 |
|------|------|
| VIN | 标称值（如 3.7V） |
| VOUT | 目标输出电压 |
| IOUT 扫描范围 | 如 1mA, 10mA, 50mA, 100mA, 200mA, 500mA, 1A |
| 测量量 | VIN, IIN, VOUT, IOUT |

测试步骤：
1. 设定负载电流 IOUT
2. 待 DUT 稳定后，同时测量 VIN, IIN, VOUT, IOUT
3. 计算 PIN = VIN × IIN，POUT = VOUT × IOUT
4. 计算 η = POUT / PIN × 100%
5. 逐点扫描负载电流，绘制效率曲线

**判定标准示例：**

| 负载条件 | 效率下限 |
|----------|----------|
| 轻载（1mA） | > 70% |
| 中载（100mA） | > 85% |
| 满载（1A） | > 80% |

#### 2.2.3 DMD 测试

| 参数 | 条件 |
|------|------|
| VIN | 标称值 |
| VOUT | 目标输出电压 |
| 负载扫描 | 从轻载（1mA）逐渐增大，或从重载逐渐减小 |
| 检测方法 | LX 波形观察 / 内部 DMD 标志位 |

测试步骤：
1. 设置 VIN 和 VOUT
2. 将负载从轻载开始，逐步增加负载电流
3. 在每个负载点，观察 LX 波形：
   - DCM：LX 波形在关断期间出现振铃（ring），开关频率较低
   - CCM：LX 持续开关，无振铃间隙
4. 记录 DCM→CCM 的翻转电流值
5. 验证翻转点是否在目标值 ± 允差内（如 50mA ± 10mA）

```
LX 波形示意：

DCM（轻载）:
HS on   LS on   Ringing         HS on
__      __                     __
  |____|  |________________|    |____|
       振铃 → 指示电感电流到零

CCM（重载）:
HS on   LS on   HS on   LS on
__      __      __      __
  |____|  |____|  |____|  |____|
       连续开关，无振铃
```

### 2.3 测试注意事项

- 效率测试建议使用 4-Wire Kelvin 连接，消除接触电阻和线阻的影响
- DMD 翻转点可能存在迟滞（DCM→CCM 与 CCM→DCM 阈值不同），需明确测试方向
- 大电流测试时需注意 PCB 走线载流能力和散热条件
- IQ 测试时 PMIC 可能处于非开关状态（空载时的低功耗模式），需确认测试条件符合规格定义

## 三、Buck Ramp 过程反向调压及中断

### 3.1 原理

迟滞Buck支持 **DVS（Dynamic Voltage Scaling，动态电压调节）**：通过寄存器或硬件引脚改变目标输出电压。

Ramp 过程反向调压及中断测试验证以下场景：

- **正向 ramp**：VOUT 从低向高调节
- **反向 ramp**：VOUT 从高向低调节
- **ramp 中断**：在 ramp 过程中突然改变目标电压
- **ramp 反向**：在 ramp 过程中反向调节（如升压中突然改为降压）

迟滞Buck在这些场景下的关键行为：

| 场景 | 预期行为 | 风险 |
|------|----------|------|
| 正向 ramp | VOUT 线性上升至新目标 | 过冲（overshoot） |
| 反向 ramp | VOUT 线性下降至新目标 | 下冲（undershoot） |
| ramp 中断后继续 | 平滑过渡到新目标 | 电压突变 |
| ramp 反向 | VOUT 反向追踪新目标 | 电压凹陷或尖峰 |

### 3.2 测试方法

| 参数 | 条件 |
|------|------|
| VIN | 标称值 |
| VOUT 起始值 | VOUT_LOW（如 0.6V） |
| VOUT 目标值 | VOUT_HIGH（如 1.2V） |
| Ramp 速率 | 如 10mV/us |
| 负载条件 | 空载 + 轻载（如 10mA） |
| 测量仪器 | 高速数字化仪 / 示波器 |

测试步骤（正向 ramp 中断为例）：
1. 设置 Buck 输出为 VOUT_LOW
2. 发起 ramp 命令，目标为 VOUT_HIGH
3. 在 ramp 进行到约 50% 时，写入新的目标电压（高于或低于当前值）
4. 使用数字化仪连续采样 VOUT
5. 分析 VOUT 波形：
   - 检查是否有异常的过冲/下冲
   - 检查 ramp 斜率是否连续
   - 检查是否平滑过渡到最终目标
6. 验证 VOUT 最终建立值在精度范围内

典型判定标准：

| 参数 | 限值 |
|------|------|
| Ramp 过程过冲 | < 50mV |
| Ramp 过程中下冲 | < 50mV |
| 最终电压精度 | ±2% |
| Ramp 速率偏差 | ±20% |

### 3.3 测试注意事项

- 数字化仪的采样率需足够高（建议 > 10MS/s）以捕获瞬态细节
- 需覆盖空载和带载两种条件，因为负载会影响迟滞Buck的响应速度
- Ramp 中断测试对时序要求严格，需精确控制寄存器写入时机

## 四、缓起时间测试

### 4.1 原理

**软启动（Soft-Start）** 用于限制 Buck 变换器启动时的涌入电流（Inrush Current），防止：

- 输出电压过冲
- 输入电压跌落
- 电感饱和
- 输出电容充电电流过大触发过流保护

迟滞Buck的内部软启动电路工作时，内部参考电压 VREF 从 0 逐渐上升至目标值，使 VOUT 跟随上升，从而限制了占空比和峰值电流。

### 4.2 测试方法

| 参数 | 条件 |
|------|------|
| VIN | 标称值 |
| VOUT | 目标输出电压 |
| 负载 | 空载 |
| 测量节点 | VOUT |
| 测量仪器 | 数字化仪 / 示波器 |

测试步骤：
1. 确保 VOUT 已放电至接近 0V
2. 发送使能命令启动 Buck
3. 用数字化仪捕获 VOUT 从 0V 上升至目标值的完整波形
4. 测量 10% VOUT 到 90% VOUT 的时间间隔
5. 记录软启动时间 Tss

```
VOUT
  |
  |              ____目标 VOUT (100%)
  |            /
  |          /  ← 90% VOUT
  |        /
  |      /  ← 10% VOUT
  |    /
  |  /
  |_________________________________ t
      |←   Tss (软启动时间)  →|
```

### 4.3 判定标准

| 参数 | 典型值 | 单位 |
|------|--------|------|
| 软启动时间 | 100 ~ 500 | us |
| 启动过冲 | < 3% VOUT | — |
| 单调性 | 必须单调上升 | — |

### 4.4 测试注意事项

- 启动前务必确认 VOUT 已完全放电（否则 Tss 测量不准确）
- 有些设计在输出预偏置（Pre-bias）情况下软启动行为不同，需单独测试
- 需在多个温度点测试（高温下软启动时间可能增大）

## 五、下拉电阻测试

### 5.1 原理

**输出下拉电阻（Output Discharge Resistor）** 是在 Buck 关闭时，将输出电容上的残余电荷快速泄放的路径。其作用是：

- 确保下次启动时 VOUT 从 0V 开始
- 防止输出端在断电后仍保持高电平，避免对负载产生危害
- 在快速开关机序列中保证输出完全放电

下拉电阻通常是一个连接在 VOUT 与 GND 之间的 MOSFET 开关串联一个小电阻，在 Buck 被禁用时自动导通。

### 5.2 测试方法

| 参数 | 条件 |
|------|------|
| Buck 状态 | 禁用（Disabled） |
| VOUT 施加电压 | 如 1.0V |
| 测量 | 流出 VOUT 的电流 |
| 测量仪器 | SMU（Force Voltage, Measure Current） |

测试步骤：
1. 禁用 Buck 输出（确保下拉开关已导通）
2. 在 VOUT 引脚施加测试电压 Vforce
3. 测量从 VOUT 流出的电流 Imeas
4. 计算下拉电阻：Rpd = Vforce / Imeas

### 5.3 判定标准

| 参数 | 典型值 | 单位 |
|------|--------|------|
| 下拉电阻 | 50 ~ 500 | Ω |
| 允差 | ±20% | — |

### 5.4 测试注意事项

- 施加的测试电压不应高于 Buck 的额定输出电压，否则可能损坏内部电路
- 需确保 Buck 确实处于禁用状态（下拉开关应导通）
- 若下拉电阻过大（开路），可能导致关机后 VOUT 残留电压

## 六、OVP 测试

### 6.1 原理

**过压保护（OVP, Over-Voltage Protection）** 用于检测 VOUT 是否超过安全阈值。迟滞Buck的 OVP 通过一个独立的比较器实现：

- OVP 比较器监测 VOUT（或 VFB）电压
- 当 VOUT 超过 OVP 阈值时，触发保护动作
- 保护动作可以是：**锁存关断（Latch-Off）** 或 **自动恢复（Auto-Recovery / Hiccup）**

迟滞Buck的 OVP 触发原因可能包括：
- 反馈电阻开路（FB float）
- 上管短路
- 输入电压突变

### 6.2 测试方法

| 参数 | 条件 |
|------|------|
| Buck 状态 | 使能，空载或轻载 |
| 测试方法 | 强制 VOUT 超过阈值 |
| OVP 阈值 | 如 VOUT_TARGET × 120% |

测试步骤：
1. 使能 Buck 输出至目标电压
2. 通过外部 SMU 向 VOUT 强制施加电压，逐步升高直至超过 OVP 阈值
3. 监测以下信号：
   - VOUT 波形（是否出现关断或 hiccup 行为）
   - 保护标志位（如 OVP_INT, FAULT 等寄存器状态）
4. 记录 OVP 触发阈值（VOUT 首次触发保护时的电压值）
5. 若为 latch-off 型：确认关断后需要重新使能才能恢复
6. 若为 auto-recovery 型：确认 VOUT 恢复正常后自动恢复输出

### 6.3 判定标准

| 参数 | 典型值 | 单位 |
|------|--------|------|
| OVP 触发阈值 | VOUT_TARGET × 115% ~ 130% | — |
| 响应时间 | < 10 | us |

### 6.4 测试注意事项

- OVP 测试可能损坏 DUT，需设置电流钳位限制（如 100mA）
- 若 OVP 为 latch-off 类型，每次触发保护后需要复位才能继续测试

## 七、SCP 测试

### 7.1 原理

**短路保护（SCP, Short Circuit Protection）** 在 VOUT 被短路到 GND 时保护变换器和负载。迟滞Buck的 SCP 通常采用 **打嗝模式（Hiccup Mode）**：

- 当检测到过流或短路时，变换器关闭输出
- 等待一段冷却时间后，尝试重新启动
- 若短路仍在，再次触发保护，进入循环打嗝
- 直到短路解除，变换器恢复正常输出

**Hiccup Mode 示意图：**
```
VOUT
  |      ___                   ___
  |     |   |                 |   |
  |     |   |                 |   |
  |_____|   |_________________|   |____
       关断   尝试重启   关断   尝试重启
          ↑ 短路      ↑ 短路     ↑ 短路解除 → 正常输出
```

Hiccup 模式的优点：
- 短路期间平均电流小，降低热损耗
- 不会损坏变换器或负载
- 自动恢复，无需外部干预

### 7.2 测试方法

| 参数 | 条件 |
|------|------|
| Buck 状态 | 使能，正常输出 |
| 短路条件 | VOUT 短接到 GND（通过开关管或继电器） |
| 测量 | VOUT 波形、VIN 电流 |

测试步骤：
1. 使能 Buck 输出至目标电压，带额定负载
2. 将 VOUT 短路到 GND
3. 观察 VOUT 波形：
   - 记录 VOUT 跌落速度
   - 观察是否进入 hiccup 模式
   - 记录 hiccup 周期（关断时间 + 尝试重启时间）
4. 测量短路时的峰值电流（可通过 VIN 电流或输出电流推算）
5. 解除短路（打开短路开关）
6. 观察 DUT 是否能自动恢复正常输出
7. 重复多次，验证保护的一致性

### 7.3 判定标准

| 参数 | 典型值 |
|------|--------|
| 短路峰值电流 | < OCP 阈值 × 110% |
| Hiccup 关断时间 | 1 ~ 10 ms |
| Hiccup 尝试重启时间 | 100 ~ 500 us |
| 短路解除后恢复 | 自动恢复至目标电压 |

### 7.4 测试注意事项

- 使用低阻抗短路开关（如 MOSFET 开关或继电器）
- 测试时间不宜过长，避免 DUT 过热
- 注意 PCB 短路路径的载流能力
- 对于 latch-off 类型 SCP，解除短路后需重新使能

## 八、输出电压精度与纹波测试

### 8.1 原理

#### 8.1.1 迟滞Buck的固有纹波

迟滞Buck与其他拓扑的关键区别之一是其固有的输出纹波特性：

- 迟滞比较器需要一定的纹波幅度才能正常工作
- 如果没有纹波注入（Ripple Injection），迟滞比较器在低 ESR 输出电容下可能无法稳定触发
- 因此，迟滞Buck的纹波是**功能性要求**（而非纯寄生效应）

#### 8.1.2 纹波注入技术（Ripple Injection）

为在低 ESR 陶瓷输出电容下正常工作，迟滞Buck引入了**纹波注入**：

- 从 LX 节点通过 RC 网络（Rinj + Cinj）耦合一个与电感电流纹波成比例的电压信号
- 该信号叠加到 VFB 上，提供足够的纹波幅度驱动迟滞比较器
- 注入的纹波代表电感电流信息（包含 DC 偏移和 AC 纹波）

```
VOUT ----[Rinj]----+---- VFB （到比较器）
                   |
                  Cinj
                   |
                  GND

LX ----[可选路径]----+ （另一种注入方式）
```

#### 8.1.3 不同负载下的纹波特性

| 负载条件 | 模式 | 纹波特性 |
|----------|------|----------|
| 轻载 | DCM | 纹波较大（电感电流到零后 LX 振铃耦合） |
| 中载 | 临界 DCM/CCM | 纹波中等 |
| 重载 | CCM | 纹波最小（连续导通，电感电流纹波稳定） |

### 8.2 测试方法

| 参数 | 条件 |
|------|------|
| VIN | 标称值 |
| VOUT | 目标输出电压 |
| 负载 | 空载、轻载、中载、满载 |
| 测量 | DC 平均值 + AC 纹波 Vpp |
| 测量仪器 | DMM（DC 精度）+ 示波器/数字化仪（AC 纹波）|

测试步骤（DC 精度）：
1. 使能 Buck 输出至目标 VOUT
2. 带载至指定负载电流
3. 使用 DMM 测量 VOUT 的 DC 平均值（建议多次采样取平均）
4. 计算精度误差：Error = (VOUT_MEAS - VOUT_TARGET) / VOUT_TARGET × 100%

测试步骤（AC 纹波）：
1. 使能 Buck 输出至目标 VOUT
2. 带载至指定负载电流
3. 使用示波器/数字化仪在 AC 耦合模式下测量 VOUT 纹波
4. 记录峰峰值 Vpp
5. 如需频谱分析，测量主导纹波频率

### 8.3 判定标准

| 参数 | 条件 | 典型限值 |
|------|------|----------|
| DC 精度 | 所有负载 | ±2% |
| 纹波 Vpp | 轻载（DCM） | < 30 mV |
| 纹波 Vpp | 重载（CCM） | < 15 mV |

### 8.4 测试注意事项

- DC 精度测量建议使用 4-Wire Kelvin 连接到 DUT 的远端 sense 点
- AC 纹波测量需使用短接地弹簧（短地线），避免噪声耦合
- 示波器带宽建议限制在 20MHz，避免高频噪声干扰纹波读数
- 测量纹波时示波器设置为 AC 耦合，20mV/div，20MHz 带宽限制

## 九、LX 频率测试

### 9.1 原理

迟滞Buck的一个重要特征是其**开关频率随工况变化**：

- 开关频率 fsw = f(VIN, VOUT, ILOAD, 迟滞窗口，TON/OFF 时间)
- 轻载时频率降低（DCM 模式，开关周期之间有空闲时间）
- 重载时频率升高（CCM 模式，连续开关）
- 高 VIN 时频率变化更大

| 影响因素 | 对频率的影响 |
|----------|-------------|
| VIN 升高 | 频率升高（TON 时间一定，VIN 升高电流上升更快） |
| ILOAD 增大 | 频率升高（CCM 下需要更多开关周期传输能量） |
| VOUT 升高 | 频率降低（TON 时间不变，VOUT 高导致电流纹波小，周期长） |
| 迟滞窗口增大 | 频率降低（纹波需更大幅度才能翻转） |

### 9.2 测试方法

| 参数 | 条件 |
|------|------|
| VIN | 标称值和边值（如 Min, Typ, Max） |
| VOUT | 目标输出电压 |
| 负载 | 指定负载电流（如轻载和重载） |
| 测量节点 | LX 引脚 |
| 测量仪器 | 频率计 / 示波器 |

测试步骤：
1. 使能 Buck 输出至目标 VOUT
2. 设置指定负载电流
3. 用示波器探头连接 LX 引脚
4. 测量一个完整开关周期的频率（或占空比）
5. 对于 DCM 模式，需测量开关频率（振荡频率）和脉冲频率（包络频率）

### 9.3 判定标准

| 参数 | 条件 | 典型范围 |
|------|------|----------|
| 最小频率 | 轻载 DCM | > 100 kHz |
| 典型频率 | 中载 | 1 ~ 3 MHz |
| 最大频率 | 重载 CCM | < 6 MHz |

### 9.4 测试注意事项

- LX 引脚电压摆幅大（0V ~ VIN），使用示波器探头时需确保探头耐压足够
- 探头应使用短接地弹簧以减小测试回路电感
- 迟滞Buck频率存在一定随机性，建议多次测量取平均

## 十、DCM 检测

### 10.1 原理

**DCM（Discontinuous Conduction Mode，断续导通模式）** 检测是迟滞Buck在轻载下高效运行的关键：

- 在轻载条件下，迟滞Buck的上管导通时间很短（仅为传递足够的能量维持 VOUT）
- 当电感电流下降到零时，下管关断，LX 节点变为高阻态
- 此时 LX 节点与输出电感、寄生电容形成谐振回路，产生**振铃（Ringing）**

**DCM 检测的两种方法：**

| 方法 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| 零电流检测（ZCD） | 通过检测下管 Vds 判断电感电流过零 | 精确，可精确控制 DCM 深度 | 需修调下管 Rds(on) |
| LX 振铃检测 | 检测 LX 节点的振铃来判断 DCM | 无需额外比较器 | 阈值需精确设置 |

迟滞Buck通过 DCM 检测可以实现：

- **零电流关断（Zero-Current Switching）**：减少下管关断损耗
- **轻载效率优化**：避免负向电感电流导致的能量回馈
- **模式平滑切换**：在 DCM 和 CCM 之间平滑过渡

### 10.2 测试方法

| 参数 | 条件 |
|------|------|
| VIN | 标称值 |
| VOUT | 目标输出电压 |
| 负载 | 轻载（如 1mA, 5mA, 10mA） |
| 测量节点 | LX 引脚 |
| 测量仪器 | 示波器 |

测试步骤：
1. 使能 Buck 输出至目标 VOUT
2. 设置负载为轻载（确保预期工作在 DCM）
3. 观察 LX 波形：
   - 确认在开关周期中存在高阻振铃阶段
   - 振铃频率 ≈ 1 / (2π√(L × Cparasitic) )
4. 逐步增大负载，观察 DCM→CCM 的过渡
5. 记录在哪个负载电流下 DCM 消失（进入 CCM）
6. 与设计预期值比较

DCM 下的 LX 波形特征：

```
LX 节点电压（DCM 轻载）:

VIN ────┐
        |   ← HS FET 导通，电感充电
   GND ─┼──┐
        |  |  ← LS FET 导通，电感续流
        |  |   振铃 ← 电感电流到零，LX 高阻
  -VIN ─┘  └──┬──┬──┬──┬──┬────
              ↓  ↓  ↓  ↓  ↓
            振铃频率 = 1/(2π√(L×C))
```

### 10.3 判定标准

| 参数 | 条件 | 典型限值 |
|------|------|----------|
| DCM 存在性 | 轻载（< DMD 阈值） | 必须检测到 DCM |
| 振铃幅度 | DCM 期间 | < 1Vp |
| 模式切换 | 负载增大至 DMD 阈值 | 平滑切换至 CCM |

### 10.4 测试注意事项

- 示波器探头寄生电容可能影响振铃频率，需使用低电容探头
- DCM 检测与 DMD 修调密切相关，测试前需确认 DMD trim 已正确烧录
- 在极轻载下（如 100uA），迟滞Buck可能进入跳跃模式（Skip Mode），需区分与正常 DCM 的区别

## 十一、RampDown 过程输出异常筛选测试

### 11.1 原理

迟滞Buck的 **RampDown（输出电压斜坡下降）** 过程在 DVS 向下调节时发生。对于 CPU/GPU 核心供电轨：

- 输出电压需从高电压（如 1.2V）下降至低电压（如 0.6V）
- 控制电路通过降低内部参考电压，使 VOUT 跟随下降
- 迟滞Buck通过下管导通来释放输出电容上的储能

**可能出现的异常情况：**

| 异常类型 | 描述 | 风险 |
|----------|------|------|
| 下冲（Undershoot） | VOUT 低于目标值，甚至出现负电压 | 可能导致负载逻辑错误 |
| 非单调（Non-Monotonic） | VOUT 下降过程中出现上升台阶 | 违反 DVS 单调性要求 |
| 过度振铃 | VOUT 下降后在稳定点附近振荡 | 稳定时间长 |
| 下降过快 | ramp 速率超出规格 | 可能引起 EMI 或负过冲 |

### 11.2 测试方法

| 参数 | 条件 |
|------|------|
| VIN | 标称值 |
| VOUT 起始值 | VOUT_HIGH（如 1.2V） |
| VOUT 目标值 | VOUT_LOW（如 0.6V） |
| Ramp 速率 | 规格值（如 10mV/us）|
| 负载条件 | 空载 + 满载 |
| 测量仪器 | 高速数字化仪 |

测试步骤：
1. 设置 Buck 输出为 VOUT_HIGH
2. 发起 ramp-down 命令（目标为 VOUT_LOW）
3. 使用高速数字化仪连续采样 VOUT 波形（采样率 > 10MS/s）
4. 分析波形：
   - **下冲检测**：测量 VOUT 是否跌落到低于目标值超过规定值
   - **非单调检测**：检查 VOUT 是否出现局部上升（微分 dVOUT/dt 极性翻转）
   - **振铃检测**：测量达到稳定后的纹波幅度
   - **斜率检测**：测量 ramp-down 的平均斜率
5. 记录异常事件的数量和幅度

**异常检测算法示例：**

```
下冲检测：
  ∀ t, VOUT(t) ≥ VOUT_TARGET - VUNDERSHOOT_MAX

非单调检测：
  ∀ t, dVOUT/dt ≤ 0 （在 ramp-down 期间）

振铃检测：
  在 ramp 完成后，VOUT 在 ±VRINGING_MAX 以内稳定
```

### 11.3 判定标准

| 参数 | 限值 |
|------|------|
| Ramp-down 下冲 | < VOUT_TARGET - 50mV |
| Ramp-down 非单调 | 不允许（零容忍） |
| 稳定后振铃 Vpp | < 5mV @ 稳定后 10us |
| Ramp 斜率偏差 | ±25% |
| 单调性 | 强制单调下降 |

### 11.4 测试注意事项

- 数字化仪的采样率必须足够高以捕获快速瞬态（建议 > 20MS/s）
- 建议使用高分辨率数字化仪（16-bit 以上）以检测微小异常
- 需在多个负载条件下测试（空载时 ramp-down 可能更快，满载时可能稳定）
- RampDown 异常可能导致负载（CPU/GPU）逻辑错误，属于严重质量缺陷，需零容忍

## 十三、常见失效模式与排查

| 失效现象 | 可能原因 | 排查方法 |
|----------|----------|----------|
| IQ 过高 | 内部电路漏电、trim 异常 | 检查 DUT 是否正常开关 |
| 效率偏低 | Rds(on) 偏大、TON 异常 | 检查 trim code |
| DMD 点偏移 | DMD 比较器失调 | 检查 DMD trim |
| OVP 误触发 | 反馈电阻开路、纹波过大 | 检查 VFB 电压波形 |
| SCP 不恢复 | Latch-off 型未复位 | 确认复位时序 |
| 输出电压偏低 | 反馈电阻偏大、VREF 偏低 | 检查 VREF 和 trim |
| 纹波过大 | 纹波注入过大、输出电容偏小 | 检查注入网络 RC |
| Ramp-down 下冲过大 | 负载电流过大、ramp 速率过快 | 检查负载和 ramp 设置 |
| LX 频率异常 | TON/T OFF trim 异常 | 检查 RC TON trim |
