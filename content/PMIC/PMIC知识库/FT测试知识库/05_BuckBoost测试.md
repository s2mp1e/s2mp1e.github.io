## 一、概述

### 1.1 Buck-Boost 变换器简介

Buck-Boost 变换器是一种 DC-DC 转换器，其输出电压可以低于、等于或高于输入电压。它结合了 Buck（降压）和 Boost（升压）两种拓扑结构，通过控制四个开关管的导通时序实现升降压功能。

**典型四开关 Buck-Boost 拓扑**：

```
                    ┌─── SW1 ──┬─── SW2 ───┐
                    │          L          │
    VIN ───────────┤          │          ├────────── VOUT
                    │       ┌──┴──┐       │
                    │       │    │       │
                    │       │    │       │
                    └─── SW3 ──┴─── SW4 ──┘
                              │
                             GND
```

**四种工作模式**：

| 模式 | 输入 vs 输出 | 工作方式 |
|------|-------------|---------|
| Buck 模式 | VIN >> VOUT | SW1、SW3 为主开关，SW2 常开，SW4 常关 |
| Buck-Boost 模式 | VIN ≈ VOUT | 四个开关管均参与开关转换 |
| Boost 模式 | VIN << VOUT | SW2、SW4 为主开关，SW1 常开，SW3 常关 |
| 直通模式 (Pass-Through) | VIN ≈ VOUT | SW1、SW2 常开，SW3、SW4 常关 |

### 1.2 FT 测试关注点

Buck-Boost FT 测试覆盖以下方面：

1. **启动特性**：软启动时间、浪涌电流限制
2. **静态功耗**：空载/轻载时的芯片自身功耗
3. **保护功能**：OVP、SCP 等保护电路是否正常触发
4. **输出质量**：直流精度、交流纹波、瞬态响应
5. **模式切换**：Buck/Boost/Buck-Boost 模式判断和切换
6. **开关特性**：开关频率、死区时间、占空比范围

## 二、软启动时间测试

### 2.1 原理 (Principle)

#### 2.1.1 为什么要软启动

Buck-Boost 变换器在启动时，如果没有软启动 (Soft-Start) 电路，输出电容的充电电流将非常大，导致：

- **输入电压跌落**：瞬态大电流拉低输入电源，可能导致系统复位
- **电感饱和**：浪涌电流超过电感饱和电流，损坏电感或开关管
- **输出过冲**：启动瞬间输出电压可能大幅超过目标值
- **系统供电不稳**：同一电源轨上的其他电路受到干扰

#### 2.1.2 软启动实现方式

**方式一：内部电流限制法**

在启动阶段限制开关管的峰值电流（逐周期限流），输出电压逐步上升：

```
I_peak_limit = I_limit_ss  (启动阶段)
I_peak_limit = I_limit_normal (正常运行)
```

**方式二：参考电压斜坡法 (Voltage Ramp)**

控制误差放大器的参考电压从 0V 线性上升到目标值，输出跟随参考电压：

```
VREF_ss(t) = VREF_target × (t / T_ss),  0 < t < T_ss
VOUT(t) ≈ VREF_ss(t) × (1 + R1/R2)
```

**方式三：占空比渐进法**

从最小占空比开始，逐步增加到稳态占空比，实现输出电压平滑上升。

**常见混合方案**：同时使用电流限制和电压斜坡，在限制浪涌电流的同时保证输出电压平滑上升。

### 2.2 测试方法 (Test Method)

#### 2.2.1 基本测量方法

1. 配置 Buck-Boost 为目标输出电压（如 3.3V）
2. 使能变换器（通过 EN 管脚或 I2C 寄存器）
3. 使用 Digitizer 或示波器捕获 VOUT 上升波形
4. 测量 10% VOUT_target 到 90% VOUT_target 的时间

```
VOUT
│
│         ┌──── 100%
│       ┌─┘────  90%
│      │
│      │   T_ss (10%-90%)
│      │
│     ┌┘────  10%
│  ┌──┘
│  │
─┴────────────────────────── t
  使能
```

**计算公式**：

$$T_{SS} = T_{90\%} - T_{10\%}$$

其中：
- **T₁₀%**：输出电压上升到目标值 10% 的时刻
- **T₉₀%**：输出电压上升到目标值 90% 的时刻

#### 2.2.2 精确测量技术

**ATE 实现方案**：

- 使用 ATE 的 AWG (任意波形发生器) 产生使能信号
- 使用 Digitizer（采样率 1 ~ 10 MS/s）捕获 VOUT 波形
- 软件后处理计算 10%-90% 上升时间

```
[ATE AWG] ──使能信号──→ [DUT EN]
                       [DUT VOUT] ──→ [ATE Digitizer]
```

#### 2.2.3 浪涌电流测量

在测量软启动时间的同时，同步测量输入电流：

1. 在输入路径串联精密采样电阻
2. 使用差分 Digitizer 测量电阻两端电压
3. 计算输入电流：I_IN = V_sense / R_sense

### 2.3 测试条件

| 参数 | 条件 1 (轻载) | 条件 2 (满载) | 单位 |
|------|--------------|--------------|------|
| 输入电压 VIN | VIN_min / typ / max | VIN_min / typ / max | V |
| 输出电压 VOUT | VOUT_nom | VOUT_nom | V |
| 输出负载 ILOAD | 0 (空载) | ILOAD_max | A |
| 输出电容 COUT | COUT_nom | COUT_nom | μF |
| 温度 | 25°C / hot / cold | 25°C / hot / cold | °C |

### 2.4 判定标准

| 测试项 | 条件 | 最小值 | 典型值 | 最大值 | 单位 |
|-------|------|-------|-------|-------|------|
| 软启动时间 (10%-90%) | 空载 | 50 | 200 | 500 | μs |
| 软启动时间 (10%-90%) | 满载 | 100 | 400 | 1000 | μs |
| 浪涌电流峰值 | 所有条件 | — | — | I_limit_ss | A |
| 启动过冲 | 所有条件 | — | — | VOUT_nom + 3% | V |

### 2.5 测试注意事项

1. **负载影响**：软启动时间与输出负载和电容密切相关，需在标准负载条件下测试
2. **触发同步**：Digitizer 触发信号需与使能信号同步，确保捕获完整的启动波形
3. **软启动失败**：若 VOUT 长时间达不到目标值，可能指示软启动电路异常或输出过载
4. **重复性**：建议多次启动取平均，排除单次启动的随机性

## 三、静态电流测试

### 3.1 原理 (Principle)

#### 3.1.1 静态电流定义

静态电流 (Quiescent Current, IQ) 指变换器在空载或轻载条件下，控制电路（包括误差放大器、比较器、基准、驱动逻辑等）消耗的电流。它是评估电源芯片自身功耗的关键指标。

$$I_Q = I_{IN} - I_{OUT}$$

其中：
- **I_IN**：输入电源提供的总电流
- **I_OUT**：输出负载电流

在空载条件下（ILOAD = 0），I_Q ≈ I_IN（因为没有输出电流）。

#### 3.1.2 PFM 模式 vs PWM 模式 IQ

| 模式 | 工作原理 | IQ 典型值 | 适用场景 |
|------|---------|----------|---------|
| **PWM (Pulse Width Modulation)** | 固定频率，调整占空比 | 数百 μA ~ 数 mA | 中等~重载，低纹波 |
| **PFM (Pulse Frequency Modulation)** | 固定导通时间，调整频率 | 数 μA ~ 数十 μA | 轻载，高效率 |
| **Burst Mode / Skip Mode** | 跳过部分开关周期 | 数 μA ~ 数十 μA | 极轻载，最低功耗 |

#### 3.1.3 IQ 的组成

```
IQ = I_bandgap + I_EA + I_comp + I_driver_loss + I_switch_loss + I_feedback
```

- **I_bandgap**：带隙基准偏置电流（数 μA）
- **I_EA**：误差放大器偏置电流（数 μA ~ 数十 μA）
- **I_comp**：比较器偏置电流（数 μA）
- **I_driver_loss**：栅极驱动损耗（与开关频率相关）
- **I_switch_loss**：开关管栅极充放电损耗
- **I_feedback**：反馈分压电阻上流过的电流（VOUT / (R1+R2)）

### 3.2 测试方法 (Test Method)

#### 3.2.1 空载 IQ 测试

**PWM 模式 IQ 测试**：

1. 使能变换器，设置为强制 PWM 模式
2. 设置空载（ILOAD = 0）
3. 等待输出稳定（典型 1 ~ 5ms）
4. 测量输入电流 I_IN

**PFM 模式 IQ 测试**：

1. 使能变换器，设置为 PFM/Auto 模式
2. 设置空载或极小负载（如 1μA）
3. 等待输出稳定
4. 长时间积分测量输入电流（因 PFM 模式下电流呈脉冲状，需平均采样）

#### 3.2.2 ATE 测量方案

**方案一：精密 SMU 测量**

使用源测量单元 (SMU) 直接测量输入电流：

- 将 SMU 设置为 Force Voltage，Measure Current 模式
- 设置合适量程（如 10μA 量程用于 PFM IQ，10mA 量程用于 PWM IQ）
- 注意 SMU 的自动量程切换时间

**方案二：串联采样电阻法**

在输入路径串入精密采样电阻，用差动 Digitizer 测量电压降：

```
SMU ──→ R_sense (1Ω ~ 10KΩ) ──→ DUT VIN
                ↓
         Digitizer Diff Input
```

- **R_sense 选择**：IQ 越小，R_sense 需越大，以产生可测量的电压降
  - PWM IQ (~1mA)：R_sense ≈ 1Ω → V_sense ≈ 1mV
  - PFM IQ (~1μA)：R_sense ≈ 1KΩ → V_sense ≈ 1mV

### 3.3 测试条件

| 参数 | PWM 模式 | PFM 模式 | 单位 |
|------|---------|---------|------|
| VIN | VIN_nom | VIN_nom | V |
| VOUT | VOUT_nom | VOUT_nom | V |
| ILOAD | 0 | 0 (或 1μA) | A |
| 温度 | 25°C | 25°C | °C |
| 开关频率 | f_sw_nom | PFM (自动) | Hz |

### 3.4 判定标准

| 测试项 | 模式 | 最小值 | 典型值 | 最大值 | 单位 |
|-------|------|-------|-------|-------|------|
| 静态电流 IQ | PWM | — | 800 | 1500 | μA |
| 静态电流 IQ | PFM / Auto | — | 15 | 50 | μA |
| 静态电流 IQ | 关断 (Shutdown) | — | 0.1 | 1 | μA |

### 3.5 测试注意事项

1. **漏电流补偿**：测试板自身的漏电流可能达到数 μA，需在空板测量后做漏电流校准 (delta 测量)
2. **测量稳定时间**：PFM 模式下电流呈脉冲状，需足够长的积分时间（> 100ms）获得平均电流
3. **温度影响**：IQ 随温度升高而增加（偏置电流的温度系数为正），需全温度范围验证
4. **输入滤波电容**：DUT 输入端的去耦电容会吸收 SMU 的瞬态电流，需注意测量建立时间

## 四、下拉电阻测试

### 4.1 原理 (Principle)

#### 4.1.1 下拉电阻的作用

Buck-Boost 变换器在关断 (Disable/Shutdown) 状态下，输出管脚 VOUT 需要被拉至 GND：

1. **可控放电**：确保关断时输出电容上的电荷快速泄放，VOUT 快速下降到 0V
2. **防止浮空**：避免输出管脚在关断时处于高阻态，受漏电流影响产生不确定电压
3. **系统安全**：确保下次启动时输出电容已完全放电，防止启动时序异常

**典型电路结构**：

```
VOUT ────┬─── SW_discharge ─── R_pd ──── GND
         │
         │    SW_discharge = NMOS 开关管
         │    R_pd = 片内多晶硅电阻，典型几十 Ω ~ 几百 Ω
         │
         └─── 输出电容 COUT (外部)
```

### 4.2 测试方法 (Test Method)

#### 4.2.1 基本测量方法

**方法一：电压-电流法**

1. 禁用 (Disable) Buck-Boost 变换器，使下拉电阻接入
2. 在 VOUT 管脚施加一个测试电压 V_force（注意不超过最大允许电压）
3. 测量流入 VOUT 管脚的电流 I_measure
4. 计算下拉电阻：

$$R_{PD} = \frac{V_{force}}{I_{measure}}$$

**方法二：两点法（消除接触电阻）**

使用两个不同的测试电压，计算差分电阻：

1. 施加 V1，测量 I1
2. 施加 V2，测量 I2
3. 计算：

$$R_{PD} = \frac{V_2 - V_1}{I_2 - I_1}$$

这种方法可以消除接触电阻和测试路径上的固定偏置电压误差。

#### 4.2.2 ATE 实现

使用 PPMU (Per-Pin PMU) 或 SMU 进行 Force Voltage / Measure Current：

```
[ATE PPMU] Force V_force ──→ DUT VOUT Pin
           Measure I_measure ←── DUT VOUT Pin
```

#### 4.2.3 关键注意事项

1. **测试电压选择**：V_force 不能过高，否则可能意外激活 Buck-Boost 的保护电路
2. **开关管导通电阻**：实际测量值包含放电开关管的导通电阻 Ron，规格书中通常给出 R_pd + Ron 的综合值
3. **使能状态确认**：必须确认 Buck-Boost 已被正确禁用，否则读取的电流包括变换器工作电流

### 4.3 测试条件

| 参数 | 条件 | 数值 | 单位 |
|------|------|------|------|
| VIN | 任意 | 0 或 VIN_nom | V |
| EN (使能) | 禁用 | 0 | V |
| V_force (测试电压) | — | 0.1 ~ VOUT_nom (如 1.0V) | V |
| 温度 | 常温 | 25 | °C |

### 4.4 判定标准

| 测试项 | 最小值 | 典型值 | 最大值 | 单位 |
|-------|-------|-------|-------|------|
| 下拉电阻 R_pd | 30 | 50 | 80 | Ω |
| 或 R_pd (不同设计) | 100 | 200 | 300 | Ω |

> **注意**：不同 Buck-Boost 设计的下拉电阻值不同，需按具体芯片规格判定。大电流变换器通常使用更小的下拉电阻以加速放电。

## 五、OVP 过压保护测试

### 5.1 原理 (Principle)

#### 5.1.1 OVP 的作用

过压保护 (Over Voltage Protection, OVP) 用于防止 Buck-Boost 输出电压超过安全阈值，保护下游负载电路。OVP 触发时，变换器会采取保护动作（关闭开关管、拉低输出等）。

**OVP 触发场景**：

1. **反馈电阻开路**：FB 分压电阻 R1 开路 → FB 电压 = 0 → EA 认为输出不足 → 占空比最大 → VOUT 飙升
2. **上管短路**：SW1 (Buck 上管) 或 SW2 (Boost 上管) 击穿短路 → 输入直通到输出
3. **控制环路故障**：EA 输出饱和、PWM 比较器失效等
4. **输入电压异常升高**：VIN 升高导致占空比异常

#### 5.1.2 两类 OVP 实现

**类型一：反馈环路 OVP (Feedback OVP)**

- 监控 FB 节点电压，当 VFB 超过 VREF 的某个百分比（如 115%）时触发
- 覆盖反馈电阻开路的故障场景
- 保护阈值：VFB_OVP = 115% ~ 130% × VREF

**类型二：输出直接 OVP (Output OVP)**

- 通过独立的分压电阻网络直接监控 VOUT
- 与反馈环路无关，即使反馈环路故障仍能保护
- 保护阈值：VOUT_OVP = 110% ~ 130% × VOUT_nom

**保护动作**：

| 保护动作 | 描述 | 恢复方式 |
|---------|------|---------|
| 关断 (Shutdown) | 关闭所有开关管，变换器停止工作 | 重新使能 |
| 强制 DCM | 禁止同步整流管导通，防止反向电流 | OVP 消失后自动恢复 |
| 下拉输出 | 打开输出下拉电阻，快速放电 | 需重新使能 |
| Latch-off | 锁死，彻底关断 | 需重新上电或 POR |

### 5.2 测试方法 (Test Method)

#### 5.2.1 反馈 OVP 测试

**方法一：外部注入法**

1. 使能 Buck-Boost 正常工作（VOUT = VOUT_nom）
2. 通过外部电源在 FB 管脚注入额外的电压，模拟 FB 电压异常
3. 逐渐降低 FB 节点电压（模拟电阻开路故障），观察 OVP 是否触发
4. 记录 OVP 触发时的 VOUT 实际值

> **注意**：直接向 FB 注电压可能改变环路的反馈特性，需通过电阻隔离注入。

**方法二：电阻模拟法**

在反馈分压电阻 R1 上并联一个外部电阻，降低 R1 有效值：

- R1 并联外部电阻 → 分压比降低 → VOUT 升高
- 观察 OVP 触发时的 VOUT 值

#### 5.2.2 输出 OVP 测试

1. 使能 Buck-Boost 正常工作
2. 使用外部电源通过隔离电阻向 VOUT 注入额外电压
3. 逐步升高 VOUT，直到 OVP 保护触发
4. 记录 OVP 触发阈值

**ATE 实现**：

```
[ATE DPS/SMU → VOUT] ──→ R_isolation (1KΩ) ──→ DUT VOUT
[DUT VOUT] ──→ ATE Digitizer (监控 OVP 触发)
[DUT FAULT_N/STATUS] ──→ ATE Digital (检测 OVP 标志)
```

### 5.3 测试条件

| 参数 | 条件 | 数值 | 单位 |

## 六、SCP 短路保护测试

### 6.1 原理 (Principle)

#### 6.1.1 SCP 的作用

短路保护 (Short Circuit Protection, SCP) 在 Buck-Boost 输出对地短路时保护芯片和系统：

- **限制短路电流**：防止过大的短路电流烧毁开关管、电感和 PCB 走线
- **保护输入电源**：防止短路导致输入电源电压崩溃
- **热保护**：防止芯片在短路状态下过热损坏

#### 6.1.2 保护模式

**模式一：Hiccup 模式（打嗝模式）**

这是最常用的 Buck-Boost SCP 模式：

```
短路发生 → 检测到过流 → 关断变换器
    → 等待 T_hiccup_off (典型 1~10ms)
    → 尝试重启 (软启动)
    → 若短路仍存在 → 再次关断
    → 循环重复
```

**平均短路电流**：

$$I_{SC\_avg} = I_{limit} \times \frac{T_{on}}{T_{on} + T_{hiccup\_off}}$$

其中：
- **I_limit**：逐周期限流值
- **T_on**：每个 hiccup 周期中变换器工作的时间
- **T_hiccup_off**：每个 hiccup 周期中变换器关断的时间

由于 T_hiccup_off >> T_on，平均短路电流远小于限流值，芯片功耗可控：

$$P_{SC} \approx I_{SC\_avg} \times V_{OUT\_short} \approx I_{SC\_avg} \times (0V \sim 0.2V) \approx 很低$$

**优势**：
- 平均功耗低，芯片温度可控
- 短路移除后自动恢复
- 不需要外部复位

**劣势**：
- 输出恢复时间取决于 hiccup 周期
- 在短路状态下变换器仍在间歇工作

**模式二：Latch-off 模式（锁断模式）**

```
短路发生 → 检测到过流 → 关断变换器 → 锁死
    → 需要 POR (Power-On Reset) 或重新使能才能恢复
```

**优势**：
- 短路状态下变换器完全停止工作
- 最安全，功耗最低

**劣势**：
- 短路移除后需要系统干预才能恢复
- 不适用于热插拔等需要自动恢复的场景

### 6.2 测试方法 (Test Method)

#### 6.2.1 基本 SCP 测试

**方法一：电子负载短路法**

1. 使能 Buck-Boost 带载正常工作
2. 使用电子负载或继电器将 VOUT 短路到 GND
3. 监控 VOUT 电压和输入电流
4. 观察保护行为（Hiccup 或 Latch-off）
5. 测量短路电流

**方法二：开关管短路法**

在测试板上预装一个 MOSFET 开关管连接 VOUT 和 GND：

```
VOUT ────┬──── DUT VOUT
         │
         └─── D (MOSFET) ──── GND
                 G (控制信号) ←── ATE Digital
                 S (GND)
```

1. Buck-Boost 正常工作
2. ATE 控制 MOSFET 导通，将 VOUT 短接到 GND
3. 监控测试结果

#### 6.2.2 限流值测量

在短路状态下，测量变换器的限流值：

- 在电感支路串联精密采样电阻，测量电感峰值电流
- 或测量输入电流结合效率推算电感电流

## 七、输出电压精度与纹波测试

### 7.1 原理 (Principle)

#### 7.1.1 输出电压精度

Buck-Boost 变换器的输出电压由以下公式决定：

$$V_{OUT} = V_{REF} \times \left(1 + \frac{R_1}{R_2}\right)$$

**误差来源**：

| 误差源 | 典型影响 | 说明 |
|-------|---------|------|
| VREF 精度 | ±1% ~ ±2% | Bandgap 基准电压的工艺偏差 |
| R1/R2 精度 | ±0.5% ~ ±2% | 片上反馈分压电阻的匹配精度 |
| EA 失调电压 | ±1% ~ ±3% | 误差放大器输入失调 Vos |
| 负载调整率 (Load Reg) | ±0.5% ~ ±1% | 负载变化导致的输出偏移 |
| 线性调整率 (Line Reg) | ±0.1% ~ ±0.5% | 输入电压变化导致的输出偏移 |
| 温度漂移 | ±1% ~ ±2% | VREF 和电阻的温漂 |

**总精度**（均方根叠加）：

$$V_{OUT\_accuracy} = \pm\sqrt{V_{REF\_err}^2 + R_{ratio\_err}^2 + V_{os\_err}^2 + LoadReg^2 + LineReg^2 + TempDrift^2}$$

典型总精度：±2% ~ ±5%（取决于芯片设计和修调与否）。

#### 7.1.2 输出纹波

纹波 (Ripple) 是 Buck-Boost 输出上的交流分量，主要由以下因素决定：

**电感电流纹波** (ΔI_L) 在输出电容 ESR 上产生的电压纹波：

$$\Delta I_L = \frac{V_{IN} - V_{OUT}}{L} \times D \times T_{SW}$$

$$V_{ripple} = \Delta I_L \times ESR_{COUT} + \frac{\Delta I_L}{8 \times C_{OUT} \times f_{SW}}$$

其中：
- **D**：占空比
- **T_SW**：开关周期
- **ESR_COUT**：输出电容等效串联电阻
- **C_OUT**：输出电容值

**纹波组成**：

| 纹波分量 | 产生原因 | 频率特性 | 典型幅值 |
|---------|---------|---------|---------|
| 开关纹波 (Switching Ripple) | 电感电流纹波在 ESR 上产生 | f_SW | 数 mV ~ 数十 mV |
| 谐振噪声 | LC 谐振 | f_LC | 数 mV |
| 高频尖峰 (Spike) | 开关管切换时的振铃 | 数十 ~ 数百 MHz | 数十 mV ~ 数百 mV |
| 低频噪声 | 环路控制、参考噪声 | < 100 KHz | 数 mV |

### 7.2 测试方法 (Test Method)

#### 7.2.1 直流精度测量

使用高精度 DVM (数字万用表) 或 ATE 精密测量板卡：

1. 使能 Buck-Boost，设置目标 VOUT 和负载电流
2. 等待输出稳定
3. 用 Kelvin (4-wire) 连接测量 VOUT
4. 计算误差：

$$\text{Error (\%)} = \frac{V_{OUT\_meas} - V_{OUT\_target}}{V_{OUT\_target}} \times 100\%$$

**多条件组合测试**：

| VIN | VOUT | ILOAD | 温度 |
|-----|------|-------|------|
| VIN_min | VOUT_min | ILOAD_min | 25°C |
| VIN_typ | VOUT_typ | ILOAD_typ | 85°C |
| VIN_max | VOUT_max | ILOAD_max | -40°C |
| VIN_min | VOUT_max | ILOAD_typ | 25°C |
| VIN_max | VOUT_min | ILOAD_typ | 25°C |

#### 7.2.2 纹波测量

**示波器/Digitizer 测量法**：

1. 使用 AC 耦合方式（滤除直流分量）
2. 设置适当的垂直分辨率（mV/div）和时基（μs/div）
3. 测量纹波的峰峰值 (Vpp) 和有效值 (Vrms)
4. 建议采样率 > 10 × f_SW，采样深度 > 1000 个开关周期

**ATE 高速 Digitizer 实现**：

```
DUT VOUT ──→ AC Coupling (电容, 如 10μF) ──→ ATE Digitizer
                                                │
                                           高采样率 (10~100 MS/s)
                                           高分辨率 (12~16 bit)
```

**纹波参数计算**：

- **Vpp (峰峰值)**：Vmax - Vmin
- **Vrms (有效值)**：$$\sqrt{\frac{1}{N}\sum_{i=1}^{N}(V_i - \bar{V})^2}$$
- **纹波频率**：FFT 分析确定主要纹波频率成分

| 参数 | 条件 1 | 条件 2 | 条件 3 | 单位 |
|------|--------|--------|--------|------|
| VIN | VIN_min | VIN_typ | VIN_max | V |
| VOUT | VOUT_min / typ / max | 同左 | 同左 | V |

| 温度 | 25°C | 85°C | -40°C | °C |
| COUT | COUT_min | COUT_nom | COUT_max | μF |

| 测试项 | 条件 | 最小值 | 典型值 | 最大值 | 单位 |
|-------|------|-------|-------|-------|------|
| VOUT DC 精度 | 所有条件 | -2 | — | +2 | % |
| VOUT DC 精度 | 含全温度范围 | -3 | — | +3 | % |
| 输出纹波 (Vpp) | f_SW 处，ILOAD_typ | — | 5 | 20 | mV |
| 输出纹波 (Vpp) | 含高频尖峰 | — | 10 | 50 | mV |
| 负载调整率 | 0 → ILOAD_max | — | 0.5 | 2 | % |
| 线性调整率 | VIN_min → VIN_max | — | 0.2 | 1 | % |

### 7.5 测试注意事项

1. **Kelvin 连接**：直流精度测量必须使用 4-wire Kelvin 连接，消除接触电阻和测试导线压降
2. **探头带宽**：纹波测量探头带宽需 > 500 MHz，以捕获高频尖峰
3. **接地回路**：探头接地线尽量短，减少接地回路引入的噪声
4. **AC 耦合 vs DC 耦合**：小纹波测量建议 AC 耦合，充分利用 Digitizer 的动态范围
5. **测试点位置**：纹波测量点应在 VOUT 电容两端，而非芯片管脚处（管脚处的寄生电感会引入额外噪声）

## 八、状态寄存器 BB_STATE 测试

### 8.1 原理 (Principle)

#### 8.1.1 BB_STATE 寄存器的作用

Buck-Boost 变换器内部有一个状态机，实时追踪当前的工作模式。BB_STATE 寄存器通过 I2C/SPI 接口将状态信息暴露给主机：

**典型状态寄存器定义**：

| 位域 | 名称 | 描述 |
|------|------|------|
| [1:0] | BB_MODE | 00 = Buck 模式, 01 = Boost 模式, 10 = Buck-Boost 模式, 11 = Pass-Through 模式 |
| [2] | BUCK_ACTIVE | Buck 开关管是否在切换 (1=是) |
| [3] | BOOST_ACTIVE | Boost 开关管是否在切换 (1=是) |
| [4] | PWM_MODE | 当前控制模式 (0=PFM, 1=PWM) |
| [5] | OVP_FLAG | 过压保护标志 |
| [6] | SCP_FLAG | 短路保护标志 |
| [7] | READY | 变换器输出就绪 |

#### 8.1.2 工作模式判断逻辑

Buck-Boost 变换器根据 VIN 和 VOUT 的比值自动选择工作模式：

```
VIN >> VOUT + V_hysteresis      → Buck 模式
VIN << VOUT - V_hysteresis      → Boost 模式
VOUT - V_hysteresis ≤ VIN ≤ VOUT + V_hysteresis  → Buck-Boost 模式
```

其中 **V_hysteresis** 是迟滞电压，防止 VIN 和 VOUT 接近时模式频繁切换。

### 8.2 测试方法 (Test Method)

#### 8.2.1 模式验证

1. 设置 VOUT 为目标值（如 3.3V）
2. 调整 VIN，使其分别处于 Buck/Boost/Buck-Boost 区域
3. 通过 I2C/SPI 读取 BB_STATE 寄存器
4. 验证读取的模式与期望模式一致

**测试序列**：

```
VIN = 5.0V (VIN >> VOUT)    → 期望 Buck 模式
VIN = 3.3V (VIN ≈ VOUT)     → 期望 Buck-Boost 模式
VIN = 2.5V (VIN << VOUT)    → 期望 Boost 模式
VIN = 4.0V → 3.0V → 4.0V   → 验证模式切换迟滞
```

#### 8.2.2 切换点精度

测量模式切换点的 VIN/VOUT 比值，验证是否符合设计值：

1. 固定 VOUT，缓慢扫描 VIN
2. 读取 BB_STATE，记录模式切换时刻的 VIN 值
3. 计算切换阈值：

$$\text{Buck → Buck-Boost 切换点: } V_{IN\_B\_to\_BB} = V_{OUT} + V_{hys\_B\_to\_BB}$$

$$\text{Buck-Boost → Boost 切换点: } V_{IN\_BB\_to\_Boost} = V_{OUT} - V_{hys\_BB\_to\_Boost}$$

### 8.3 测试条件

| 参数 | Buck 模式 | Buck-Boost 模式 | Boost 模式 | 单位 |
|------|----------|----------------|-----------|------|
| VOUT | VOUT_nom | VOUT_nom | VOUT_nom | V |
| VIN | VOUT_nom + 1.0 | VOUT_nom ± 0.2 | VOUT_nom - 1.0 | V |
| ILOAD | ILOAD_typ | ILOAD_typ | ILOAD_typ | A |
| 温度 | 25°C | 25°C | 25°C | °C |

### 8.4 判定标准

| 测试项 | 最小值 | 典型值 | 最大值 | 单位 |
|-------|-------|-------|-------|------|
| Buck → Buck-Boost 切换点 | VOUT + 0.3 | VOUT + 0.5 | VOUT + 0.7 | V |
| Buck-Boost → Boost 切换点 | VOUT - 0.7 | VOUT - 0.5 | VOUT - 0.3 | V |
| 模式切换迟滞 | 0.2 | 0.4 | 0.6 | V |
| BB_STATE 读取正确性 | 100 | 100 | — | % |

### 8.5 测试注意事项

1. **通信稳定性**：多次读取 BB_STATE，确认读取结果一致，排除 I2C/SPI 通信错误
2. **缓慢扫描**：VIN 变化速率不宜过快（建议 < 0.1 V/ms），确保状态机有足够时间响应
3. **迟滞验证**：双向扫描（VIN 上升和下降），确认迟滞窗口正确
4. **寄存器描述确认**：不同芯片的 BB_STATE 寄存器位定义可能不同，需仔细核对数据手册

## 九、DCM/CCM 切换点测试

### 9.1 原理 (Principle)

#### 9.1.1 DCM vs CCM

**CCM (Continuous Conduction Mode)**：

- 电感电流在整个开关周期中始终 > 0
- 负载较重时工作
- 开关频率固定（PWM 模式）
- 效率在中~重载时较高
- 输出纹波较小

**DCM (Discontinuous Conduction Mode)**：

- 电感电流在每个开关周期中降到 0 并保持一段时间
- 负载较轻时工作
- 开关频率可变（PFM 模式）或固定
- 效率在轻载时较高（开关损耗降低）
- 输出纹波较大

**电感电流波形对比**：

```
CCM:          DCM:
  IL            IL
  │             │
  │  /\         │  /\
  │ /  \        │ /  \
  │/    \       │/    \____
  └──────── t   └──────────── t
  始终 > 0       有 = 0 区间
```

#### 9.1.2 DMD — DCM-CCM 切换点

**DMD (DCM-CCM Transition Point)** 定义为变换器从 DCM 切换到 CCM 的负载电流阈值。

**理论计算**：

DCM 和 CCM 边界发生在电感电流谷值刚好为 0 时：

$$I_{DMD} = \frac{\Delta I_L}{2} \times (1 - D)$$

其中：
- **ΔI_L**：电感电流峰峰值纹波
- **D**：占空比

**影响因素**：

| 因素 | 对 DMD 的影响 | 说明 |
|------|-------------|------|
| 输入电压 VIN | VIN ↑ → DMD ↑ | VIN 升高 → 电感纹波增大 |
| 输出电压 VOUT | VOUT ↑ → DMD ↑ | VOUT 升高 → 电感纹波增大 |
| 电感值 L | L ↑ → DMD ↓ | 电感增大 → 纹波减小 |
| 开关频率 f_SW | f_SW ↑ → DMD ↓ | 频率升高 → 纹波减小 |

### 9.2 测试方法 (Test Method)

#### 9.2.1 波形观察法

1. 使能变换器，设置目标 VOUT
2. 设置 ILOAD = 0（空载）
3. 使用示波器探头测量 LX 节点电压或通过电流探头测量电感电流
4. 从空载开始逐渐增加负载电流
5. 观察电感电流波形：当电感电流谷值刚好达到 0A 时为 DCM/CCM 边界
6. 记录此时的负载电流 I_DMD

```
空载 (DCM):                 加重到 DMD 点:
LX波形:                      LX波形:
  ││  ││  ││  ││               ││  ││  ││  ││
  ││  ││  ││  ││               ││  ││  ││  ││
  └┘  └┘  └┘  └┘               └──┘──┴──┘──┘
  有死区 (不连续)            谷值刚好到 0
```

#### 9.2.2 频率变化法 (PFM 模式)

在 PFM 模式下，开关频率随负载变化：

- 轻载 → 低频（跳过多个周期）
- 负载增加 → 频率升高
- DMD 点 → 频率达到最高并进入 CCM

测量方法：
1. 扫描负载电流
2. 测量 LX 开关频率
3. 频率不再随负载增加的位置即为 DMD 点

#### 9.2.3 效率拐点法

- 绘制效率 η vs 负载电流 ILOAD 曲线
- DCM 模式下效率随负载增加而升高
- CCM 模式下效率随负载增加先升后降
- 效率曲线的拐点通常对应 DMD 附近

### 9.3 测试条件

| 参数 | 条件 | 数值 | 单位 |
|------|------|------|------|
| VIN | 典型值 | VIN_nom | V |
| VOUT | 目标值 | VOUT_nom | V |
| ILOAD 扫描范围 | 0 → ILOAD_rated | — | A |
| 负载步进 | 扫描步长 | 10 ~ 50 | mA |
| 温度 | 常温 | 25 | °C |

### 9.4 判定标准

| 测试项 | 最小值 | 典型值 | 最大值 | 单位 |
|-------|-------|-------|-------|------|
| DMD (DCM/CCM 切换点) | 50 | 100 | 200 | mA |
| DCM 频率 @ 空载 | 10 | 50 | 200 | KHz |
| 模式切换平滑程度 | 无明显跳变 | — | — | — |

> **注意**：DMD 值设计上要确保在轻载时进入 DCM（提高效率），同时 DMD 不能过低以避免在中等负载时频繁模式切换。

## 十、LX 频率测试

### 10.1 原理 (Principle)

#### 10.1.1 LX 开关频率

Buck-Boost 变换器的 LX 管脚是开关节点，其开关频率是变换器工作的基本参数：

- **PWM 模式**：开关频率固定，由内部振荡器或 PLL 决定
- **PFM 模式**：开关频率随负载变化
- **频率范围**：典型值 500KHz ~ 3MHz（消费类 PMIC），或低至 100KHz（汽车级）

**频率决定因素**：

$$f_{SW} = \frac{1}{T_{ON} + T_{OFF}}$$

对于 PWM 模式，频率固定，但可能因以下原因偏离设计值：
- 内部振荡器频率偏差（取决于 RC 振荡器精度）
- 频率抖动 (Frequency Dithering) 用于 EMI 降低
- 温度/电压导致振荡器频率漂移
- 展频调制 (Spread Spectrum) 引入的频率变化

### 10.2 测试方法 (Test Method)

#### 10.2.1 频率测量

**方法一：LX 管脚直接测量**

1. 使能变换器，设置目标 VOUT 和负载条件
2. 使用示波器探头连接 LX 管脚
3. 测量 LX 波形的开关频率

**方法二：ATE 频率计测量**

通过测试 MUX 将 LX 信号路由到测试管脚，或直接测量 LX 管脚：

```
DUT LX ──→ 测试板缓冲器 (可选) ──→ ATE TMU / 频率计
```

**方法三：从输出电压纹波推算**

如果 LX 管脚不可接触，可通过测量 VOUT 纹波频率间接获得开关频率。

#### 10.2.2 多条件测试

| 条件 | VIN | VOUT | ILOAD | 期望行为 |
|------|-----|------|-------|---------|
| PWM, 轻载 | VIN_nom | VOUT_nom | ILOAD_min | f_SW = f_nom |
| PWM, 重载 | VIN_nom | VOUT_nom | ILOAD_max | f_SW = f_nom |
| PFM, 轻载 | VIN_nom | VOUT_nom | ILOAD_min | f_SW < f_nom (PFM) |
| 全电压范围 | VIN_min/max | VOUT_nom | ILOAD_typ | f_SW 偏差在规格内 |

### 10.3 判定标准

| 测试项 | 模式 | 最小值 | 典型值 | 最大值 | 单位 |
|-------|------|-------|-------|-------|------|
| PWM 开关频率 | VIN_typ, VOUT_typ, ILOAD_typ | -10% | f_nom | +10% | Hz |
| PWM 开关频率 | 全电压/全温度 | -15% | f_nom | +15% | Hz |
| PFM 频率 @ 空载 | — | — | — | f_nom/10 | Hz |
| 频率稳定性 (短期) | PWM 模式 | — | — | ±2 | % |

### 10.4 测试注意事项

1. **探头加载**：LX 管脚的高频信号（含振铃）可能受探头寄生电容影响，建议使用 10:1 或 100:1 衰减探头
2. **频率平均**：建议测量 100 个以上周期的平均频率，排除单周期抖动的影响
3. **频率抖动**：如果芯片使用了展频技术，频率测量需取足够长时间的统计值

## 十一、VIN/VO 内部比较器翻转点测试

### 11.1 原理 (Principle)

#### 11.1.1 比较器的作用

Buck-Boost 变换器内部使用比较器检测 VIN 和 VOUT 之间的关系，以确定变换器应工作在哪种模式（Buck / Boost / Buck-Boost）：

```
VIN ──┬──┐
       │  ├── 比较器 1 (VIN > VOUT + Vhys?)
       │  │
VOUT ──┴──┘
       │
       │  ┌── 比较器 2 (VIN < VOUT - Vhys?)
       │  │
       └──┘
```

比较器输出连接到状态机，控制四个开关管的导通模式：

| 比较器结果 | 工作模式 | SW1 | SW2 | SW3 | SW4 |
|-----------|---------|-----|-----|-----|-----|
| VIN > VOUT + Vhys | Buck | PWM | ON | PWM | OFF |
| VIN ≈ VOUT | Buck-Boost | PWM | PWM | PWM | PWM |
| VIN < VOUT - Vhys | Boost | ON | PWM | OFF | PWM |

#### 11.1.2 比较器的重要参数

1. **翻转阈值 (Threshold)**：VIN 相对于 VOUT 何时判断为 "高" 或 "低"
2. **迟滞 (Hysteresis)**：防止在阈值附近频繁翻转
3. **延迟时间 (Propagation Delay)**：从 VIN 变化到比较器输出的时间
4. **失调电压 (Offset)**：比较器输入对管的失配导致实际阈值偏离理想值

### 11.2 测试方法 (Test Method)

#### 11.2.1 翻转点测量

**方法一：寄存器读取法**

1. 固定 VOUT 为目标值
2. 缓慢扫描 VIN（从高到低和从低到高）
3. 在每个 VIN 点读取 BB_STATE 寄存器（或类似状态寄存器）
4. 记录模式切换时的 VIN/VOUT 比值

**方法二：LX 波形观察法**

1. 固定 VOUT，扫描 VIN
2. 通过示波器观察 LX 节点波形
3. 根据 LX 波形形态判断当前模式
4. 记录切换点的 VIN 值

**LX 波形模式识别**：

```
Buck 模式 LX:         ┌──┐  ┌──┐  ┌──┐
               ──────┘  └──┘  └──┘  └──── VIN ~ VOUT (SW1 开关)

Buck-Boost LX:     ┌──┐  ┌──┐  ┌──┐
              ─────┘  └──┘  └──┘  └───── 四个开关均参与

Boost 模式 LX:     ┌─┐  ┌─┐  ┌─┐
              ─────┘ └──┘ └──┘ └─────── GND ~ VOUT (SW2 开关)
```

#### 11.2.2 迟滞测量

1. VIN 从高到低扫描 → 记录 Buck→Buck-Boost 切换点 V_B_to_BB_hi
2. VIN 从低到高扫描 → 记录 Buck-Boost→Buck 切换点 V_BB_to_B_lo
3. 迟滞 = V_B_to_BB_hi - V_BB_to_B_lo

类似地测量 Boost 侧的迟滞：

1. VIN 从低到高扫描 → 记录 Boost→Buck-Boost 切换点 V_Boost_to_BB_lo
2. VIN 从高到低扫描 → 记录 Buck-Boost→Boost 切换点 V_BB_to_Boost_hi
3. 迟滞 = V_Boost_to_BB_lo - V_BB_to_Boost_hi

### 11.3 测试条件

| 参数 | 条件 | 数值 | 单位 |
|------|------|------|------|
| VOUT | 固定值 | VOUT_nom (如 3.3V) | V |
| VIN 扫描范围 | 从 VIN_min 到 VIN_max | 2.5 ~ 5.5 | V |
| VIN 扫描步长 | 精细扫描 | 10 ~ 50 | mV |
| VIN 扫描速率 | 缓慢，避免比较器响应不及 | < 10 | mV/ms |
| ILOAD | 轻载 | 10 | mA |
| 温度 | 常温 | 25 | °C |

### 11.4 判定标准

| 测试项 | 最小值 | 典型值 | 最大值 | 单位 |
|-------|-------|-------|-------|------|
| Buck → Buck-Boost 翻转点 (VIN 下降) | VOUT + 0.2 | VOUT + 0.4 | VOUT + 0.6 | V |
| Buck-Boost → Buck 翻转点 (VIN 上升) | VOUT + 0.1 | VOUT + 0.3 | VOUT + 0.5 | V |
| Buck 侧迟滞 | 0.05 | 0.1 | 0.2 | V |
| Boost → Buck-Boost 翻转点 (VIN 上升) | VOUT - 0.6 | VOUT - 0.4 | VOUT - 0.2 | V |
| Buck-Boost → Boost 翻转点 (VIN 下降) | VOUT - 0.5 | VOUT - 0.3 | VOUT - 0.1 | V |
| Boost 侧迟滞 | 0.05 | 0.1 | 0.2 | V |

### 11.5 测试注意事项

1. **VIN 扫描速率**：VIN 变化过快会导致比较器输出来不及稳定，测得翻转点不准
2. **负载影响**：负载电流变化会改变 VOUT 实际值，间接影响 VIN/VOUT 比较结果
3. **噪声滤波**：比较器输入端的小幅度噪声可能导致误翻转，建议进行多次测量取平均
4. **温度效应**：比较器失调电压随温度变化，全温度范围需重新验证翻转点

## 十二、总结

Buck-Boost 变换器 FT 测试涵盖了从启动特性到保护功能、从输出质量到模式切换的全面验证。以下是对各测试项的关键要点总结：

| 测试项 | 测试重点 | 主要风险/挑战 |
|-------|---------|-------------|
| **软启动时间** | 10%-90% 上升时间，浪涌电流 | 负载和电容条件标准化 |
| **静态电流 IQ** | PWM/PFM/Shutdown 三种模式 | 超低电流时测试板漏电流干扰 |
| **下拉电阻 R_pd** | 关断状态下 VOUT 到 GND 电阻 | 接触电阻消除 |
| **OVP** | 反馈 OVP 和输出 OVP 阈值 | 注入方法不当影响环路 |
| **SCP** | Hiccup/Latch-off 行为验证 | 热管理、限流值精度 |
| **VOUT 精度/纹波** | DC 精度 ±2%，纹波 < 20mV | 高频分量捕获、Kelvin 连接 |
| **BB_STATE** | 模式寄存器正确性 | 通信可靠性、模式切换点 |
| **DCM/CCM 切换** | DMD 负载电流阈值 | 电感/频率/电压依赖性 |
| **LX 频率** | PWM 固定频率精度 | 展频模式下的测量方法 |
| **VIN/VO 比较器** | 翻转点阈值和迟滞 | VIN 扫描速率、温度效应 |

**核心工程经验**：

1. **测试顺序优化**：保护功能测试（OVP/SCP）应在基础功能测试之后进行，避免因测试时序问题损坏芯片
2. **条件组合管理**：Buck-Boost 测试条件多（VIN × VOUT × ILOAD × Temp），需合理设计测试组以覆盖有效边界
3. **保护测试安全**：SCP 和 OVP 测试具有一定破坏性，建议在程序末尾执行，并设置超时保护
4. **多 site 同测考虑**：Buck-Boost 开关噪声可能通过电源/地耦合串扰到相邻 site，需注意测试板的隔离设计
5. **失效分析**：FT 失效需区分是芯片本身问题还是测试条件/测板导致的问题
