# 时钟测试 — PMIC 时钟与振荡器 FT 测试

> 时钟与振荡器是 PMIC 的"心跳"，为数字控制逻辑、开关电源开关频率、RTC 计时、通信接口等提供精确的时间基准。FT 阶段需要验证时钟频率的准确性、占空比、抖动以及在不同电压和温度条件下的稳定性。

## 一、概述

### 1.1 PMIC 中的时钟源类型

PMIC 芯片内部通常集成多种时钟源，以满足不同模块对时钟精度和功耗的要求：

| 时钟源 | 典型频率 | 精度等级 | 功耗 | 典型用途 |
|--------|---------|---------|------|---------|
| RC 振荡器 | 1024 KHz ~ 数 MHz | ±1% ~ ±5% | 低 | 开关电源开关频率、数字逻辑时钟、状态机时钟 |
| 晶体振荡器 (XOSC) | 38.4 MHz / 32.768 KHz | ±10 ~ ±100 ppm | 中~高 | 高精度计时、RF 参考时钟、通信接口 |
| PLL 倍频时钟 | 数 MHz ~ 数百 MHz | 取决于参考源 | 高 | 高速数字接口、音频采样率、PWM 发生器 |
| 内部低频振荡器 | 32 KHz | ±10% ~ ±30% | 极低 | 低功耗模式、唤醒定时器、看门狗 |

### 1.2 FT 测试关注点

在 FT 阶段，时钟测试主要关注以下几个方面：

1. **频率精度 (Frequency Accuracy)**：时钟频率是否在规格要求范围内
2. **占空比 (Duty Cycle)**：时钟高电平与低电平时间的比例，通常要求 45% ~ 55%
3. **抖动 (Jitter)**：时钟周期的短期随机波动，影响时序裕量
4. **温度/电压稳定性**：时钟频率随温度和电源电压的漂移程度
5. **启动特性**：振荡器启动时间、稳定时间

## 二、1024KHz 时钟测试

### 2.1 原理 (Principle)

#### 2.1.1 RC 振荡器基本架构

1024KHz（1.024 MHz）时钟通常由片上 **RC 振荡器 (Resistor-Capacitor Oscillator)** 产生。其基本原理是利用 RC 网络的充放电时间常数决定振荡频率。典型架构为 **比较器 + RC 网络** 的多谐振荡器：

```
                    ┌─────────────┐
VDD ──┬─── R ──────┤ 比较器 (+)   │
       │            │             │
       │     ┌──────┤ 比较器 (-)───┼───┐
       │     │      └─────────────┘   │
       │     │              │         │
       │     C             ┌┴┐        │
       │     │            GND         │
       │     │          (参考电压)     │
       │     │                        │
       └─────┴────────────────────────┘
```

**工作原理**：

1. 电流源通过电阻 R 对电容 C 充电，电容电压 Vc 呈指数上升
2. 当 Vc 达到比较器阈值电压 Vref 时，比较器翻转
3. 翻转后放电通路开启，电容快速放电至低阈值
4. 电容再次充电，重复以上过程，在输出端产生方波时钟信号

**频率公式**：

$$f \approx \frac{1}{2 \cdot R \cdot C \cdot \ln\left(\frac{V_{DD} - V_{L}}{V_{DD} - V_{H}}\right)}$$

简化情况下（假设比较器阈值对称）：

$$f \approx \frac{1}{2.2 \cdot R \cdot C}$$

其中：
- **R**：片上多晶硅电阻 (Poly Resistor)，sheet resistance 随工艺角变化约 ±20%
- **C**：片上 MIM 电容或 MOS 电容，单位电容密度随工艺角变化约 ±10%
- **Vref**：比较器参考电压，通常由 Bandgap 产生

#### 2.1.2 频率偏差来源

未修调的 RC 振荡器频率偏差主要来自：

1. **电阻工艺偏差**：Poly 电阻 sheet resistance 随工艺角变化 ±15% ~ ±25%
2. **电容工艺偏差**：MOS 电容单位电容密度变化 ±5% ~ ±15%
3. **比较器延迟**：比较器的传播延迟随 PVT 变化，引入额外频率误差
4. **温度漂移**：电阻和电容的温度系数 (TCR, TCC) 导致频率随温度变化
5. **电源电压敏感度**：比较器阈值和充放电电流随 VDD 变化

**修调机制**：在 CP 阶段通过 Trim Code 调整 RC 网络的有效 R 或 C 值，将频率校准到目标值。典型修调范围为 ±20%，步长 ~2%。

#### 2.1.3 为何选择 1024KHz

- **1024K = 2^20 / 1024**：便于数字电路分频得到精确的定时
- 可用于生成开关电源的开关频率（或经 PLL 倍频/分频）
- 在数字逻辑中提供 1μs 级的时间分辨率（1 周期 ≈ 0.977 μs）

### 2.2 测试方法 (Test Method)

#### 2.2.1 频率测量方法

**方法一：通过测试管脚直接测量**

如果芯片将 1024KHz 时钟输出到专用测试管脚（或通过 MUX 复用到 GPIO），可直接用频率计测量：

```
DUT 时钟输出 ──→ 测试板通道 ──→ 频率计 (Frequency Counter) / TMU
```

**方法二：通过芯片内部 MUX 输出**

许多 PMIC 设计有 **测试 MUX (Test Mux)**，通过 I2C/SPI 配置寄存器选择将内部时钟信号路由到测试管脚：

```
寄存器配置 (0xXX) → 选择 CLK_1024K → MUX → Test Pin → 频率计
```

**方法三：ATE 数字通道捕获**

使用 ATE 数字通道板卡捕获时钟信号，通过 ATE 的 TMU (Time Measurement Unit) 或 FC (Frequency Counter) 板卡测量频率：

- TMU 测量单个周期：精度高，但受噪声影响
- FC 测量多个周期取平均：精度高，抗噪声能力强

#### 2.2.2 占空比测量

占空比通过测量高电平时间 (Th) 和低电平时间 (Tl) 计算：

$$\text{Duty Cycle (\%)} = \frac{T_h}{T_h + T_l} \times 100\%$$

ATE 实现方式：
- 使用 TMU 分别测量上升沿到下降沿的时间 (Th) 和下降沿到上升沿的时间 (Tl)
- 或使用数字通道的 time set 功能进行采样

### 2.3 测试条件 (Test Conditions)

| 参数 | 最小值 | 典型值 | 最大值 | 单位 |
|------|-------|-------|-------|------|
| 电源电压 VDD | VDD_min (如 2.7V) | VDD_typ (如 3.7V) | VDD_max (如 5.5V) | V |
| 环境温度 | T_cold (-40°C / 0°C) | 25°C | T_hot (85°C / 125°C) | °C |
| 测试负载 | — | 15 pF (测试板寄生) | — | pF |

### 2.4 判定标准 (Criteria)

| 测试项 | 条件 | 最小值 | 典型值 | 最大值 | 单位 |
|-------|------|-------|-------|-------|------|
| 频率精度 (已修调) | 25°C, VDD_typ | 1008 | 1024 | 1040 | KHz |
| 频率精度 (已修调) | 全温度/全电压 | 990 | 1024 | 1058 | KHz |
| 频率误差 (未修调) | 25°C, VDD_typ | — | — | ±5% | — |
| 占空比 | 所有条件 | 45 | 50 | 55 | % |

> **注意**：1024KHz 通常是 CP 阶段的重点修调项（Trim Target）。FT 阶段主要验证修调后的频率是否仍在规格范围内。若 FT 发现频率超差，可能指示封装应力导致修调值偏移，或者芯片存在物理损伤。

### 2.5 测试流程

```
1. 配置寄存器使能 1024KHz 振荡器
2. 等待振荡器稳定（典型等待时间 100μs ~ 1ms）
3. 配置测试 MUX，将 CLK_1024K 路由到测试管脚
4. 使用频率计/TMU 测量频率
5. 使用 TMU 测量占空比
6. 与上下限比较，判断 Pass/Fail
7. 若失败，记录失败 bin 码并标记
```

## 三、38.4MHz 时钟测试

### 3.1 原理 (Principle)

#### 3.1.1 晶体振荡器架构

38.4MHz 高频时钟通常由 **晶体振荡器 (Crystal Oscillator, XOSC)** 产生。与 RC 振荡器不同，晶体振荡器利用石英晶体的压电效应实现极高的频率稳定性。

**典型 Pierce 振荡器架构**：

```
                    ┌──────────────┐
                    │   Inverter   │
                    │   (AMP)      │
                    │              │
                    │   IN    OUT  │
                    └──┬──────────┘
                       │          │
                    ┌──┴──┐    ┌──┴──┐
                    │ C1  │    │ C2  │
                    │ 18pF│    │ 18pF│
                    └──┬──┘    └──┬──┘
                       │          │
                       └──────────┘
                           Crystal
                          (38.4MHz)
                            │
                           GND
```

**核心组件**：

1. **石英晶体 (Quartz Crystal)**：38.4MHz 基频 (Fundamental) 或 3 次泛音 (3rd Overtone) 模式
   - 等效为一个 RLC 串联谐振回路并联一个寄生电容
   - 极高的 Q 值 (>10,000)，频率稳定性远优于 RC 振荡器
   - 温度稳定性典型值 ±10 ~ ±50 ppm（取决于晶体切割方式和等级）
2. **反相放大器 (Inverting Amplifier)**：提供增益以维持振荡
3. **负载电容 (Load Capacitors C1, C2)**：决定振荡频率的精确值
4. **反馈电阻 Rf**：使放大器偏置在放大区
5. **限流电阻 Rs**：限制驱动功率，保护晶体

#### 3.1.2 频率稳定性

晶体振荡器的频率精度主要取决于：

- **晶体的切割角精度**：AT-cut 晶体在 -20°C ~ +70°C 范围内典型温漂 ±20 ppm
- **负载电容匹配精度**：外部电容 C1/C2 的精度直接影响振荡频率
- **老化效应 (Aging)**：晶体老化典型值 ±3 ~ ±5 ppm/年
- **电路板寄生电容**：PCB 走线寄生电容会改变有效负载电容

#### 3.1.3 启动与稳定

晶体振荡器启动过程：

```
启动阶段:
1. 加电 → 放大器增益 → 热噪声被放大
2. 晶体滤波 → 仅在谐振频率附近有正反馈
3. 振幅指数增长 → 进入非线性区 → 振幅稳定

稳定时间: 典型值 1ms ~ 10ms (取决于晶体 Q 值和放大器驱动能力)
```

### 3.2 测试方法 (Test Method)

#### 3.2.1 频率测量

**方法一：外部晶体法**

在 FT 测试板上安装 38.4MHz 晶体或使用晶体振荡器模块作为时钟源：

1. 将外部晶体连接到 DUT 的 XO_IN / XO_OUT 管脚
2. 使能芯片内部振荡器电路
3. 测量 XO_OUT 管脚的输出频率（使用频率计或示波器）

```
外部晶体 ──→ DUT XO_IN ──→ 内部 XOSC ──→ XO_OUT ──→ 频率计
```

**方法二：内部时钟输出法**

如果芯片内部有 PLL 或时钟分频器，可将 38.4MHz 时钟经分频后输出到测试管脚：

```
XOSC → 38.4MHz → 分频 (÷38) → ~1MHz → MUX → Test Pin → 频率计
```

分频测量可降低对 ATE 数字通道带宽的要求。

**方法三：PLL 锁定检测法**

通过 PLL 锁定指示位 (Lock Detect) 间接判断时钟是否正常。但此方法无法测量精确频率值。

#### 3.2.2 抖动测量

抖动 (Jitter) 是时钟信号在时间轴上的短期波动：

**周期抖动 (Period Jitter)**：实际周期与理想周期的偏差

$$J_{period} = \max|T_n - T_{ideal}|$$

**周期间抖动 (Cycle-to-Cycle Jitter)**：相邻两个周期的差值

$$J_{cc} = \max|T_{n+1} - T_n|$$

**ATE 测量方法**：

- 使用高速采样板卡（如 1GS/s 以上 Digitizer）捕获时钟波形
- 或多个周期重复测量，统计 TIE (Time Interval Error)
- 使用 ATE 的专用抖动分析模块

### 3.3 测试条件

| 参数 | 条件 | 数值 |
|------|------|------|
| 电源电压 | VDD_min / typ / max | 2.7V / 3.7V / 5.5V |
| 温度 | 常温 / 高温 / 低温 | 25°C / 85°C / -40°C |
| 外部晶体负载电容 | 按规格书 | 18 pF ±5% |
| 晶体等效串联电阻 (ESR) | 按晶体规格 | < 50 Ω |

### 3.4 判定标准

| 测试项 | 条件 | 规格 | 单位 |
|-------|------|------|------|
| 频率精度（晶体模式） | 25°C | ±50 | ppm |
| 频率精度（晶体模式） | 全温度 | ±100 | ppm |
| 频率精度（内部振荡器模式） | 25°C | ±1 | % |
| 周期抖动 (RMS) | 所有条件 | < 50 | ps |
| 周期抖动 (Peak-to-Peak) | 所有条件 | < 300 | ps |
| 周期间抖动 (RMS) | 所有条件 | < 30 | ps |
| 振荡器启动时间 | VDD_typ, 25°C | < 5 | ms |

> **关键区别**：晶体振荡器（带外部晶体）的频率精度可达 ppm 级，远高于 RC 振荡器的 % 级。若芯片使用内部 LC 振荡器替代外部晶体，则精度介于 RC 和晶体之间，典型 ±0.5% ~ ±1%。

### 3.5 测试注意事项

1. **PCB 布局**：38.4MHz 为高频信号，测试板走线需控制阻抗，避免信号反射
2. **寄生电容**：测试板探针和走线的寄生电容会改变振荡频率，需在测板设计时做补偿
3. **晶体选择**：FT 用晶体需选择与芯片设计匹配的负载电容和 ESR
4. **EMI 考虑**：高频时钟信号可能辐射电磁干扰，测试板需做好屏蔽

## 四、32KHz RTC 时钟测试

### 4.1 原理 (Principle)

#### 4.1.1 为什么是 32.768KHz

32.768KHz = 2^15 Hz，这个数字的意义在于：

- 经过 15 级二进制分频器 (二分频 15 次) 可精确得到 1Hz（1 秒定时）
- 32.768KHz ÷ 2^15 = 1 Hz
- 这使得 RTC (Real-Time Clock) 可以最小硬件开销实现精确的秒计时

#### 4.1.2 两种实现方式

**方式一：RC 振荡器实现**

- 使用片上 RC 网络产生 ~32KHz 时钟
- **优点**：无需外部元件，成本低，功耗极低（典型 < 1μA）
- **缺点**：频率精度差，典型 ±5% ~ ±30%
- **应用场景**：对时间精度要求不高的场合（如唤醒定时器、看门狗）

**方式二：晶体振荡器实现 (32.768KHz 音叉晶体)**

- 使用外接 32.768KHz 音叉晶体 (Tuning Fork Crystal)
- **优点**：极高的频率精度，典型 ±5 ~ ±100 ppm
- **缺点**：需要外部晶体和负载电容，增加 BOM 成本和面积
- **应用场景**：需要精确计时的场合（RTC 日历时钟、闹钟）

#### 4.1.3 音叉晶体特性

32.768KHz 音叉晶体与高频 AT-cut 晶体不同：

| 特性 | 音叉晶体 (Tuning Fork) | AT-cut 晶体 |
|------|----------------------|-------------|
| 典型频率 | 32.768 KHz | 数 MHz ~ 数百 MHz |
| 切割方式 | X+2° ~ X+5° | AT-cut |
| 温度特性 | 抛物线型，25°C 附近最平坦 | S 形曲线 |
| 温度系数 | -0.04 ppm/°C² (二次) | -0.3 ppm/°C (线性) |
| 典型精度 | ±20 ppm @ 25°C | ±10 ~ ±50 ppm |
| 等效串联电阻 (ESR) | 30 ~ 70 KΩ | 10 ~ 100 Ω |
| Q 值 | ~50,000 | > 100,000 |

**温度特性曲线**：

音叉晶体的频率随温度呈抛物线变化：

$$\frac{\Delta f}{f} = B \times (T - T_0)^2$$

其中：
- **B** ≈ -0.04 ppm/°C²
- **T₀** = 25°C (拐点温度)
- 在 -40°C ~ +85°C 范围内，最大频率偏差约 -160 ppm

### 4.2 测试方法 (Test Method)

#### 4.2.1 频率测量

与 1024KHz 测量方法类似，32KHz 时钟可通过以下方式测量：

1. **直接管脚输出**：将 32KHz 时钟通过测试 MUX 输出到测试管脚
2. **分频后输出**：将 32KHz 经分频后输出（如 ÷32 → 1KHz），降低对 ATE 测量能力的要求
3. **RTC 计数器验证**：通过 I2C 读取 RTC 计数器值，在经过固定时间后再次读取，计算实际经过时间与理论时间的偏差

**RTC 计数器验证方法**：

```
1. 初始化 RTC 计数器为 0
2. 使能 32KHz 时钟
3. 等待精确的 ATE 定时（如 1 秒）
4. 读取 RTC 计数器值，应为 32768 ± 误差
5. 计算实际频率：f = counter_value / elapsed_time
```

这种方法不需要将时钟输出到管脚，适用于测试管脚受限的情况。

#### 4.2.2 功耗测量

32KHz 时钟通常用于低功耗模式，FT 需要测量其工作电流：

- **RC 模式**：典型 < 1μA
- **晶体模式**：典型 1 ~ 5μA（包括振荡器驱动电流）

### 4.3 测试条件

| 参数 | 条件 | RC 模式 | 晶体模式 | 单位 |
|------|------|---------|---------|------|
| VDD_RTC | 最小值 | 1.8 | 1.8 | V |
| VDD_RTC | 典型值 | 3.0 | 3.0 | V |
| VDD_RTC | 最大值 | 5.5 | 5.5 | V |
| 温度 | 范围 | -40 ~ +85 | -40 ~ +85 | °C |

### 4.4 判定标准

| 测试项 | 模式 | 条件 | 最小值 | 典型值 | 最大值 | 单位 |
|-------|------|------|-------|-------|-------|------|
| 频率 | RC | 25°C, 已修调 | 31.0 | 32.768 | 34.5 | KHz |
| 频率 | RC | 全温度 | 29.0 | 32.768 | 36.5 | KHz |
| 频率 | 晶体 | 25°C | 32767.3 | 32768 | 32768.7 | Hz |
| 频率 | 晶体 | 全温度 | 32762 | 32768 | 32774 | Hz |
| 频率误差 | RC (未修调) | 25°C | -30 | — | +30 | % |
| 频率误差 | 晶体 | 25°C | -20 | — | +20 | ppm |
| 工作电流 | RC | 无负载 | — | 0.5 | 2 | μA |
| 工作电流 | 晶体 | 无负载 | — | 2 | 5 | μA |

### 4.5 测试注意事项

1. **低功耗测量**：32KHz 工作电流极低，需注意测试板漏电流对测量结果的影响
2. **晶体起振**：音叉晶体起振时间较长（典型 0.5 ~ 2 秒），测试需预留足够等待时间
3. **负载电容匹配**：晶体模式需选用与芯片内部电容匹配的外部负载电容
4. **修调处理**：32K RC 模式通常在 CP 阶段进行修调，FT 仅做验证

## 五、其他时钟测试

### 5.1 PLL 时钟生成测试

#### 5.1.1 原理

PLL (Phase-Locked Loop) 用于将低频参考时钟倍频到高频，为高速模块提供时钟：

```
参考时钟 ──→ 鉴频鉴相器(PFD) ──→ 环路滤波器(LF) ──→ VCO ──→ 输出时钟
                  ↑                                        │
                  └──── 分频器 (÷N) ←──────────────────────┘
```

**关键参数**：
- **倍频比 N**：输出频率 = 参考频率 × N
- **锁定时间 (Lock Time)**：从使能到频率稳定的时间
- **锁定范围 (Lock Range)**：PLL 能锁定和跟踪的输入频率范围
- **相位噪声 (Phase Noise)**：PLL 输出的短期频率稳定度

#### 5.1.2 测试方法

1. **PLL 锁定检测**：读取 Lock Detect 寄存器位
2. **频率测量**：将 PLL 输出通过分频器后测量
3. **锁定时间测量**：使能 PLL，监控频率变化，测量达到稳定所需时间

#### 5.1.3 判定标准

| 测试项 | 典型值 | 单位 |
|-------|-------|------|
| 锁定时间 | < 100 | μs |
| 锁定范围 | ±5 ~ ±10 | % |
| 输出频率精度 | ±100 ~ ±500 | ppm |
| RMS 抖动 | < 10 | ps |

### 5.2 时钟分频精度测试

#### 5.2.1 原理

芯片内部常通过分频器从主时钟产生多个派生时钟。分频精度的误差源包括：

- **分频器本身的整数比误差**（理论上无误差，整数分频）
- **主时钟的频率误差**直接影响派生时钟
- **异步时钟域同步**可能引入 ±1 周期的同步不确定性

#### 5.2.2 测试方法

1. 测量主时钟频率 f_main
2. 测量分频后时钟频率 f_div
3. 计算分频比：N = f_main / f_div
4. 验证 N 是否等于预期分频比

### 5.3 时钟展频测试 (Spread Spectrum)

#### 5.3.1 原理

展频时钟 (SSC, Spread Spectrum Clocking) 通过周期性调制时钟频率，将能量分散到更宽的频带上，降低 EMI (电磁干扰) 峰值：

```
原始时钟：能量集中在单一频率 → 高 EMI 峰值
展频时钟：能量分布在 f_center ± Δf 范围内 → EMI 峰值降低 3~12 dB
```

**展频参数**：
- **调制率 (Modulation Rate)**：频率调制的周期，典型 30 ~ 60 KHz
- **展频幅度 (Spread Amount)**：频率变化范围，典型 ±0.5% ~ ±2%
- **调制波形**：通常为三角波 (Triangular)，也有 Hersey 波

#### 5.3.2 测试方法

1. 使用频谱分析仪测量时钟频谱
2. 测量展频后的 -3dB 带宽
3. 计算 EMI 峰值降低量
4. 验证调制波形和频率

### 5.4 时钟抖动测试 (Jitter Test)

#### 5.4.1 抖动类型

| 抖动类型 | 定义 | 典型值 | 对系统的影响 |
|---------|------|-------|------------|
| 周期抖动 (Period Jitter) | 实际周期与理想周期的偏差 | 数十 ~ 数百 ps | 影响建立/保持时间裕量 |
| 周期间抖动 (Cycle-to-Cycle Jitter) | 相邻周期之差 | 数十 ~ 数百 ps | 影响高速接口时序 |
| TIE (Time Interval Error) | 实际沿位置与理想沿位置的偏差 | 数百 ps ~ ns | 影响同步通信 |
| 确定性抖动 (DJ) | 由串扰、SSN 等确定因素引起 | 取决于电路设计 | 可预测，可消除 |
| 随机抖动 (RJ) | 由热噪声等随机因素引起 | RMS 值 | 高斯分布，不可消除 |

#### 5.4.2 测量方法

**ATE 抖动测量方案**：

1. **长周期采样法**：
   - 使用高速 Digitizer 连续采集 M 个时钟周期
   - 计算每个周期的宽度
   - 统计周期均值和标准差

2. **时间间隔测量法**：
   - TMU 重复测量 N 个周期的时间
   - 计算平均周期，与单周期测量值比较

3. **眼图法 (ATE 数字通道)**：
   - 使用 ATE 数字通道进行 shmoo 扫描
   - 生成眼图，从眼图张开度判断抖动

#### 5.4.3 判定标准

| 时钟源 | 周期抖动 (RMS) | 周期抖动 (Pk-Pk) | 测量条件 |
|-------|---------------|-----------------|---------|
| 1024K RC | < 0.1% of period | < 0.5% of period | VDD_typ, 25°C |
| 38.4M XOSC | < 50 ps | < 300 ps | VDD_typ, 25°C |
| 32K RC | < 1% of period | < 5% of period | VDD_typ, 25°C |
| 32K 晶体 | < 1 μs | < 5 μs | VDD_typ, 25°C |

### 6.1 频率测量仪器

| 仪器/板卡 | 频率范围 | 精度 | 适用测试项 |
|----------|---------|------|-----------|

| ATE 频率计板卡 (FC) | 1 Hz ~ 500 MHz | ±1 ppm | 高精度频率测量 |

### 6.2 测试板配置要点

| 考虑因素 | 建议 |
|---------|------|

## 七、总结

PMIC 时钟与振荡器 FT 测试是确保芯片正常工作的关键环节：

| 时钟源 | 测试重点 | 主要挑战 |
|-------|---------|---------|
| 1024K RC Osc | 修调后频率精度、占空比 | 工艺偏差、温度漂移 |
| 38.4M XOSC | ppm 级频率精度、抖动 | 高频测量精度、寄生效应 |
| 32K RTC | 频率精度、低功耗电流 | 超低功耗测量、晶体起振 |
| PLL | 锁定时间、相位噪声 | 高速测量、精确计时 |
| 展频时钟 | EMI 降低量、调制参数 | 频谱测量、时间-频率域转换 |

**核心经验**：

1. **修调验证**：1024K RC 和 32K RC 通常在 CP 修调，FT 需验证修调效果
2. **温度影响**：RC 振荡器频率随温度变化显著，需全温度范围覆盖
3. **寄生补偿**：高频晶体测试需考虑测试板寄生电容，必要时做 de-embedding
4. **低功耗精度**：32K 晶体测试需平衡功耗和精度要求
5. **测试时间优化**：时钟稳定等待时间是 FT 测试时间的主要消耗之一，需优化等待策略
