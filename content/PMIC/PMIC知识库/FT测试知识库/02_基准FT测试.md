## 1. VREF1P0 电压测试

### 1.1 测试原理

VREF1P0 是 PMIC 内部 1.0V 参考电压输出，通常由 Bandgap 产生的 VBG（约 1.2V）经过电阻分压网络和缓冲器（Buffer）后生成。典型架构如下：

```
VBG (1.2V) --> Resistor Divider --> Buffer (OPA) --> VREF1P0 Output
                     |
              Trim Code Control
```

**核心电路机制**：

- **Bandgap 基准源**：产生与温度无关的稳定电压 VBG（约 1.2V），为整个 PMIC 提供参考基准。
- **电阻分压网络**：将 VBG 按分压比 R2/(R1+R2) 降到 1.0V 附近。分压电阻通常采用高匹配度的多晶硅电阻（Poly Resistor）。
- **缓冲器（Buffer Amplifier）**：轨到轨（Rail-to-Rail）运放，提供足够的驱动能力（通常 >1mA）并隔离负载对分压网络的影响。Buffer 的输入失调电压（Vos）会直接叠加到输出端。
- **修调机制**：在分压电阻串上并联/串联可开关的修调电阻 Bank，通过 CP 阶段确定的 Trim Code 微调分压比，使输出精确校准到 1.000V。

**VT 测试的目的**：FT 阶段不重新修调 VREF1P0（除非设计支持 FT 补充修调），而是验证：

1. CP 阶段写入 OTP 的 Trim Code 是否已正确加载并生效
2. 封装应力（Package Stress）是否导致 VREF1P0 偏移超出规格
3. 全温度范围（25°C / 高温 / 低温）下 VREF1P0 是否仍满足精度要求

### 1.2 测试方法

#### 测试配置

| 项目 | 配置 | 说明 |
|------|------|------|
| 测量仪器 | 高精度 DMM（如 Keysight 3458A，8.5位）或 ATE 板载高精度 ADC | 精度需优于 0.1mV |
| 连接方式 | 开尔文四线法（Kelvin / 4-Wire） | Force 线与 Sense 线分离，消除接触电阻和线阻压降 |
| 采样方式 | 平均采样 16~64 次 | 降低随机噪声，使测量精度达到 μV 级 |
| 加载条件 | 空载 或 轻载（如 100μA） | FT 阶段通常使用轻载验证，避免自热效应 |

#### 测试流程

```
Step 1: 系统上电
  ├── 施加 VDD 与 VBAT（按 SPEC 标称值）
  └── 等待系统电源就绪（POR 完成）

Step 2: 使能 VREF1P0 模块
  ├── 写入寄存器使能 VREF1P0 Buffer 输出
  └── 等待输出稳定（500μs ~ 1ms）

Step 3: 加载 Trim Code
  ├── 确认 OTP 已自动加载至 Shadow Register
  ├── 可选：回读 Trim Code 验证加载正确
  └── 等待 Trim 生效（~100μs）

Step 4: 测量 VREF1P0 电压
  ├── 在 VREF1P0 引脚以 Kelvin 方式测量
  ├── 采样 N 次取平均
  └── 记录测量值 VREF1P0_meas

Step 5: 判定
  ├── VREF1P0_meas ∈ [VREF1P0_target - tolerance, VREF1P0_target + tolerance]
  └── 若超规格，记录 Fail 并进入分析流程
```

### 1.3 测试条件

| 参数 | 25°C（常温） | 高温（Hot） | 低温（Cold） | 说明 |
|------|-------------|------------|-------------|------|
| 环境温度 | 25°C ± 2°C | 85°C / 125°C | -40°C / 0°C | 视产品等级而定（消费/工业/汽车） |
| VDD | 标称值 ± 5% | 标称值 ± 5% | 标称值 ± 5% | 可在多个 VDD 点测试线调整率 |
| VBAT | 标称值 | 标称值 | 标称值 | 若 VREF1P0 使用 VBAT 供电 |
| 负载电流 | 0 / 100μA | 0 / 100μA | 0 / 100μA | 验证负载调整率 |
| 热平衡时间 | 无需 | ≥ 2 分钟 | ≥ 3 分钟 | 大温差需保证结温稳定 |
| 测量精度 | ±0.05% | ±0.05% | ±0.05% | 测量系统需优于 DUT 精度 10 倍 |

### 1.4 判定标准

| 参数 | 典型规格 | 说明 |
|------|---------|------|
| VREF1P0 目标值 | 1.000 V | 设计标称值 |
| 精度要求 | ±1.0% ~ ±2.0%（即 ±10mV ~ ±20mV） | 视具体产品 SPEC 而定 |
| 负载调整率 | < 0.5% / mA | 从空载到满载的 VOUT 变化 |
| 线调整率 | < 0.1% / V | VDD 变化时的 VOUT 变化 |
| 全温漂移 | < ±0.5% | 25°C → 125°C / -40°C 的 VOUT 变化 |

### 1.5 与 CP Trim 的关系

| 阶段 | 测试温度 | 主要目标 | 是否修调 |
|------|---------|---------|---------|
| CP | 25°C（常温） | 确定最佳 Trim Code 并写入 OTP | 是 |
| FT | 25°C / Hot / Cold | 验证 Trim Code 生效，检查封装应力影响 | 否（仅验证） |

**关键关注点**：若 FT 测试中 VREF1P0 偏离 CP 测量值超过预期（如 > 0.5%），可能原因包括：

- 封装塑封应力改变了片上电阻值（Package Shift）
- OTP 存储单元数据丢失或加载失败（Data Retention Issue）
- 测试条件差异（如负载不同、VDD 不同）
- ATE 与 CP 探针台之间的系统偏差

### 1.6 注意事项

1. **Kelvin 连接必需**：VREF1P0 测试中任何接触电阻引入的压降都会直接叠加到测量结果中，必须使用四线法。
2. **去耦电容**：VREF1P0 引脚在测试板上需加适当的去耦电容（通常 0.1μF || 1μF），防止 ATE 电源噪声耦合。
3. **负载效应**：测量时需注意 ATE 通道的输入漏电流。高精度 DMM 的输入阻抗通常在 >10GΩ，影响可忽略，但 ATE 板载 ADC 的输入阻抗可能较低。
4. **温度均衡**：高温/低温测试时，芯片与测试座（Socket）之间需要充分的温度平衡时间，避免因热梯度导致测量不准确。
5. **Trim Code 回读**：建议在测量 VREF1P0 之前先回读 Trim Code 寄存器，确认 CP 修调码已正确加载。

## 2. VBG 电压测试

### 2.1 测试原理

VBG（Bandgap Voltage）是 PMIC 中最核心的基准电压源，一般为 1.200V（典型值，视设计而定）。经典 BJT 型 Bandgap 利用以下原理产生与温度无关的电压：

**核心公式**：

```
VBG = VBE + m × ΔVBE
```

- **VBE**：BJT 基极-发射极电压，具有负温度系数（CTAT），约 -2 mV/°C
- **ΔVBE**：两个不同电流密度下 BJT 的 VBE 之差，具有正温度系数（PTAT），约为 (kT/q) × ln(N)
- **m**：增益系数（由电阻比 R2/R1 决定），用于放大 PTAT 分量以恰好补偿 CTAT 分量

**标准电路架构（Brokaw Cell）**：

```
                        VDD
                         |
                     +---------+
                     |   OPA   |
                     +----+----+
                          |
            +-------------+-------------+
            |                           |
           [R1]                        [R2]
            |                           |
       +----+----+                +----+----+
       |   Q1    |                |   Q2    |
       |  (1x)   |                |  (Nx)   |
       +----+----+                +----+----+
            |                           |
            +-------------+-------------+
                          |
                        [R3]
                          |
                         GND
```

- Q1 与 Q2 的发射极面积比为 1:N
- OPA 迫使 Q1 与 Q2 集电极电压相等
- ΔVBE = VBE1 - VBE2 = (kT/q) × ln(N)
- PTAT 电流 I = ΔVBE / R1
- VBG = VBE1 + (R2/R1) × ΔVBE

**温度补偿**：通过调整 R2/R1 的比例 m，使 VBG 在室温附近呈现零温度系数（ZTC, Zero Temperature Coefficient）。

### 2.2 测试方法

#### 温度系数（TC）验证原理

VBG 的 FT 测试与其他参数不同，核心在于**验证温度漂移特性**——即在不同温度下测量 VBG 的变化量，计算温度系数（Temperature Coefficient，单位为 ppm/°C）：

```
TC (ppm/°C) = (VBG_max - VBG_min) / (VBG_nom × ΔT) × 10^6
```

其中：
- VBG_max：全温范围内的最大 VBG 值
- VBG_min：全温范围内的最小 VBG 值
- VBG_nom：标称 VBG 值（如 1.200V）
- ΔT：温度范围（如 165°C，从 -40°C 到 125°C）

#### 测试流程

```
Step 1: 常温测量（25°C）
  ├── 上电并开启 Bandgap 模块
  ├── 等待 Bandgap 稳定（~500μs）
  ├── 在 VBG 引脚（或通过内部测试 MUX 路由）测量电压
  ├── 记录 VBG_25C
  └── 确认与 CP 修调目标值的偏差 < 预期

Step 2: 高温测量（85°C / 125°C）
  ├── 升温至目标温度
  ├── 等待热平衡（Soak Time：2~5 分钟）
  ├── 测量 VBG_Hot
  └── 记录 VBG_Hot

Step 3: 低温测量（-40°C / 0°C）
  ├── 降温至目标温度
  ├── 等待热平衡（Soak Time：3~5 分钟）
  ├── 测量 VBG_Cold
  └── 记录 VBG_Cold

Step 4: 计算与分析
  ├── 计算 ΔVBG_hot = VBG_Hot - VBG_25C
  ├── 计算 ΔVBG_cold = VBG_Cold - VBG_25C
  ├── 计算 TC (ppm/°C)
  └── 判断是否满足规格
```

#### 测量方式

由于 VBG 节点通常在芯片内部，FT 阶段测量 VBG 有以下几种方式：

| 测量方式 | 实现方法 | 优点 | 缺点 |
|---------|---------|------|------|
| **专用 VBG 引脚** | 芯片设计时直接将 VBG 节点引出 | 直接、准确 | 占用封装引脚 |
| **测试模式路由** | 通过 DFT 电路将 VBG 路由到 GPIO 或测试引脚 | 不占用额外引脚 | 需 DFT 支持，可能引入额外误差 |
| **内部 ADC 测量** | 使用片上 HKADC 测量 VBG 并读取数字结果 | 无需测试引脚 | 精度受限于 ADC 精度 |
| **间接法** | 测量 VREF1P0 等已知比例的输出，反推 VBG | 无需特殊路由 | 精度低，不推荐 FT 使用 |

### 2.3 测试条件

| 参数 | 常温 | 高温 | 低温 | 说明 |
|------|------|------|------|------|
| 温度 | 25°C ± 2°C | 85°C ~ 125°C | -40°C ~ 0°C | 视产品等级确定 |
| VDD | 标称值 ± 5% | 标称值 ± 5% | 标称值 ± 5% | 可选做 VDD sweep |
| 负载 | 空载（高阻） | 空载（高阻） | 空载（高阻） | VBG 节点驱动能力弱 |
| Soak Time | N/A | ≥ 2 min | ≥ 3 min | 大温差需更长时间 |
| 测量精度 | ±0.05% | ±0.05% | ±0.05% | 测量系统要求高 |

### 2.4 判定标准

| 参数 | 典型规格 | 说明 |
|------|---------|------|
| VBG 标称值 | 1.200 V | 视具体设计而定，常见 1.20V / 1.25V |
| VBG 精度（25°C） | ±0.5% ~ ±1.0%（即 ±6mV ~ ±12mV） | 修调后的残余误差 |
| 温度系数（TC） | ±20 ~ ±50 ppm/°C | 一阶补偿典型值 |
| 高阶补偿 TC | ±5 ~ ±15 ppm/°C | 带曲率补偿的设计 |
| 全温范围漂移 | < ±0.5% | 对应 -40°C ~ 125°C |

### 2.5 注意事项

1. **高阻抗节点**：VBG 节点的输出阻抗通常很高，ATE 通道的漏电流（如 pA ~ nA 级）可能造成可观的电压误差。必须使用高输入阻抗的测量设备。
2. **热梯度（Thermal Gradient）**：芯片内部功率耗散可能造成局部温度梯度，影响 VBG 的准确性。尤其当邻近的大电流模块（如 Buck、LDO）工作时，自热效应会扭曲 VBG 读数。
3. **应力效应**：封装塑封应力会改变 BJT 的 VBE 特性和片上电阻值，导致 FT 的 VBG 测量值与 CP 值存在系统偏移（Package Shift）。高精度设计需要在 CP 修调中预留补偿量。
4. **启动验证**：Bandgap 可能存在简并偏置点（Degenerate Bias Point），导致 VBG = 0 或 VBG = VDD。测试时需确认 VBG 已正常启动。
5. **多温度测试顺序**：建议按 25°C → Hot → Cold 的顺序进行，避免直接从高温跳到低温造成热冲击。

## 3. IREF 电流测试

### 3.1 测试原理

IREF（Reference Current）是 PMIC 中用于偏置所有模块（LDO、Buck、Buckboost、ADC、OSC 等）的基准电流。其精度直接影响整个芯片的功耗、速度和噪声性能。

**典型产生电路**：

```
        VDD
         |
    +----+-----+
    |   PMOS    |   <- 电流镜
    +----+-----+
         |
         +----------- IREF 输出（给各模块镜像）
         |
     +---+---+
     |  OPA  |   <- VREF 加在 Rref 两端
     +---+---+
         |
         +---+---+
             |
        +---+---+
        |  Rref  |   <- 参考电阻
        +---+---+
             |
            GND
```

**工作原理**：

```
IREF = VREF / Rref
```

1. OPA 以负反馈方式将 VREF（或 VBG）精确施加在参考电阻 Rref 两端
2. 产生电流 IREF = VREF / Rref
3. PMOS 电流镜将此基准电流按比例复制（Mirror）给各下游模块

**电流镜分配示例**：

```
IREF (Master)
    +---> I_LDO（偏置电流，比例 1x）
    +---> I_BUCK（偏置电流，比例 4x）
    +---> I_OSC（充电电流，比例 2x）
    +---> I_ADC（偏置电流，比例 0.5x）
    +---> I_BIAS（全局偏置，比例 0.25x）
```

### 3.2 测试方法

#### 测试原理

FT 阶段测量 IREF 有两种主要方法：

**方法 A：直接测量法（有专用 IREF 引脚）**

直接将 ATE 的电流表（pA 级精度）接入 IREF 引脚，或使用 ATE 的 PPMU 在 Force Voltage / Measure Current 模式下测量。

**方法 B：电阻法（推荐）**

```
IREF pin ---[Rext（精密 0.1%）]--- GND
              |
            测量 V = IREF × Rext
```

选择合适的 Rext，使 V 在 50mV ~ 500mV 范围内，用 Kelvin 方式测量电压，再换算为电流。

| 预期 IREF | 推荐 Rext | 预期 Vdrop |
|-----------|----------|-----------|
| 1 μA | 100 kΩ | 100 mV |
| 2 μA | 50 kΩ | 100 mV |
| 5 μA | 20 kΩ | 100 mV |
| 10 μA | 10 kΩ | 100 mV |

#### 测试流程

```
Step 1: 连接测量路径
  ├── 将精密电阻 Rext 连接到 IREF 引脚与 GND 之间
  └── 以 Kelvin 方式连接电压测量线

Step 2: 使能 IREF 模块
  ├── 写入寄存器开启 IREF 输出
  └── 等待电流稳定（~500μs）

Step 3: 测量 IREF
  ├── 测量 Rext 两端电压 Vmeas
  ├── 计算 IREF = Vmeas / Rext
  ├── 或使用 ATE 电流表直接测量
  └── 记录 IREF_meas

Step 4: 判定
  ├── IREF_meas ∈ [IREF_target - tolerance, IREF_target + tolerance]
  └── 超规格则记录 Fail
```

### 3.3 测试条件

| 参数 | 典型条件 | 说明 |
|------|---------|------|
| VDD | 标称值 ± 5% | 验证电流的电源敏感性（PSRR） |
| 温度 | 25°C / 85°C / -40°C | IREF 的温度系数取决于电阻 TCR |
| Rext 精度 | 0.1% 或更高 | 外部精密电阻，温度系数 < 25 ppm/°C |
| 测量精度 | ±0.5% ~ ±1% | 综合电压测量精度 + 电阻精度 |
| 输出端电压 | 固定（如 0.5V） | 电流镜输出阻抗有限，需固定电压 |

### 3.4 判定标准

| 参数 | 典型规格 | 说明 |
|------|---------|------|
| IREF 标称值 | 1 μA ~ 10 μA | 视设计而定 |
| 修调后精度 | ±2% ~ ±5% | 取决于修调位数和电阻精度 |
| 温度漂移 | ±5% ~ ±10%（全温） | 电阻 TCR 主导 |
| 线调整率 | < 1% / V | VDD 变化 1V 时的电流变化 |

### 3.5 注意事项

1. **小电流测量注意事项**：
   - 测量路径需使用 Guard 线（有源屏蔽），减少漏电流
   - 测试前需进行漏电流校准（减去背景漏电流）
   - 避免在 IREF 路径上使用多路复用器（MUX），其漏电流会引入显著误差

2. **电流镜输出阻抗**：IREF 电流源的输出阻抗有限，当 IREF 引脚电压变化时，沟道长度调制效应会导致电流变化。测试时应固定 IREF 引脚电压（Force Voltage）。

3. **温度影响**：片上参考电阻 Rref 的 TCR 直接决定 IREF 的温度系数。多晶硅电阻（Poly Resistor）的 TCR 通常为 100~300 ppm/°C，扩散电阻可达 1000+ ppm/°C。

4. **与其他模块的耦合**：IREF 修调改变后，所有依赖 IREF 的模块（OSC、LDO bias、Buck 控制电路）的行为都会变化。在 FT 验证中，若 IREF 超出规格，需要评估其对后续测试项的影响。

## 4. VPTAT 电压测试

### 4.1 测试原理

VPTAT（Proportional To Absolute Temperature）电压是一个与绝对温度成正比的参考电压，广泛用于 PMIC 的温度监测和热管理。

**物理原理**：

VPTAT 基于双极型晶体管（BJT）的 VBE 差值与温度的关系：

```
ΔVBE = VBE1 - VBE2 = (kT/q) × ln(N)
```

其中：
- k = 1.38 × 10^(-23) J/K（玻尔兹曼常数）
- q = 1.602 × 10^(-19) C（电子电荷量）
- T = 绝对温度（单位：K）
- N = 两个 BJT 的电流密度比（或发射极面积比）

**电路实现**：

```
                   VDD
                    |
               +----+----+
               |   OPA   |
               +----+----+
                    |
       +------------+------------+
       |                         |
     [R1]                       [R2]
       |                         |
  +----+----+              +----+----+
  |   Q1    |              |   Q2    |
  |  (1x)   |              |  (Nx)   |
  +----+----+              +----+----+
       |                         |
       +------------+------------+
                    |
               VPTAT 输出节点 ---> [Buffer] ---> VPTAT_PIN
                    |
                   GND
```

**电压-温度关系**：

```
VPTAT = (R2/R1) × (kT/q) × ln(N)
```

VPTAT 呈线性正温度系数，典型斜率约 1~5 mV/°C（视 R2/R1 比值和 N 值而定）。

### 4.2 测试方法

#### 核心原理：利用已知温度标定 VPTAT 特性

FT 中 VPTAT 的测试利用外部已知温度（温箱控制）来验证芯片内部 VPTAT 电压的线性度和斜率。

#### 测试流程

```
Step 1: 在已知温度 T1（如 25°C）下测量 VPTAT
  ├── 上电，使能 VPTAT 模块
  ├── 等待温度稳定（Soak）
  ├── 测量 VPTAT 电压，记录 V1 @ T1
  └── 系统记录 (T1, V1) 数据点

Step 2: 在已知温度 T2（如 85°C）下测量 VPTAT
  ├── 升温至 T2，等待热平衡
  ├── 测量 VPTAT 电压，记录 V2 @ T2
  └── 系统记录 (T2, V2) 数据点

Step 3: 在已知温度 T3（如 -40°C）下测量 VPTAT
  ├── 降温至 T3，等待热平衡
  ├── 测量 VPTAT 电压，记录 V3 @ T3
  └── 系统记录 (T3, V3) 数据点

Step 4: 线性度与斜率计算
  ├── 斜率 S = (V2 - V1) / (T2 - T1)    [mV/°C]
  ├── 偏移量 V0 = V1 - S × T1           [mV]
  ├── 非线性误差 = max|V_meas - (S × T + V0)|
  └── 判断斜率、偏移量、非线性是否在规格内
```

#### 测量方式

| 方式 | 描述 | 适用场景 |
|------|------|---------|
| 直接引脚测量 | VPTAT 有专用输出引脚，外部 DMM 直接测量 | 精度最高，FT 首选 |
| 测试模式路由 | 通过 DFT 将 VPTAT 路由到 GPIO | 节省引脚，需 DFT 支持 |
| 内部 ADC 读取 | 通过片上 HKADC 转换 VPTAT 并数字读出 | 适合系统级测试 |

### 4.3 测试条件

| 参数 | 条件 | 说明 |
|------|------|------|
| 温度点 T1 | 25°C ± 1°C | 常温参考点 |
| 温度点 T2 | 85°C / 125°C | 高温点 |
| 温度点 T3 | -40°C / 0°C | 低温点 |
| VDD | 标称值 ± 5% | 可验证电源抑制能力 |
| Soak Time | 2~5 分钟/温度点 | 确保结温与温箱一致 |
| 测量精度 | ±0.1°C（等效温度） | 电压测量精度需换算为温度精度 |

### 4.4 判定标准

| 参数 | 典型规格 | 说明 |
|------|---------|------|
| VPTAT @ 25°C | 设计值（如 0.5V ~ 0.8V） | 随设计而异 |
| 斜率 | 1 ~ 5 mV/°C | 由 R2/R1 和 N 决定 |
| 斜率容差 | ±5% ~ ±10% | 工艺偏差导致的斜率变化 |
| 非线性误差 | < ±0.5% FS | VPTAT 的理想线性度 |
| 电压精度 | ±2% ~ ±5% | 绝对电压精度（未修调时） |

### 4.5 注意事项

1. **温度均衡**：VPTAT 测试对温度精度非常敏感。芯片结温与温箱设置温度之间可能存在差异（特别是大电流测试时），需要足够的 Soak Time 确保温度平衡。

2. **自热效应**：当芯片内部其他模块（如 Buck、LDO）工作时，芯片结温会显著高于环境温度。VPTAT 测试应尽量在空载或轻载条件下进行。

3. **斜率偏差的根源**：VPTAT 斜率主要由 R2/R1 比值决定。片上电阻的匹配度通常很好（< 0.5%），但绝对值的工艺角变化会影响电路工作点，间接影响斜率。

4. **与温度传感器的配合**：VPTAT 电压通常作为温度传感器（VPTAT SENSOR）的原始输入，传感器将其转换为数字温度读数。VPTAT 的精度直接影响温度传感器的精度。

## 5. VPTAT SENSOR 电压测试

### 5.1 测试原理

VPTAT SENSOR（Temperature Sensor）是利用 VPTAT 原理实现片上温度检测的传感器模块。它将 VPTAT 电压通过 ADC 转换为数字温度值，或通过 Buffer 输出与温度成比例的模拟电压。

**传感器架构**：

```
VPTAT Core -----> [Buffer] -----> [MUX] -----> [ADC] -----> Digital Code
      |                |              |
   (BJT pair)   (驱动/隔离)   (多通道选择)  (HKADC/XOADC)
```

**核心关系**：

VPTAT SENSOR 的输出（模拟或数字）与温度呈线性关系：

```
DOUT = Gain × VPTAT + Offset
     = Gain × (S × T + V0) + Offset
     = K × T + B
```

其中：
- K = 温度灵敏度（LSB/°C 或 mV/°C）
- B = 零点偏移（对应 0°C 或 25°C 时的输出值）

### 5.2 测试方法

FT 阶段对温度传感器的测试采用**两点或多点校准验证法**：

#### 测试流程

```
Step 1: 传感器输出读取
  ├── 使能温度传感器模块
  ├── 配置 ADC 为温度传感器测量模式
  └── 读取数字温度值或测量模拟输出电压

Step 2: 常温校准点验证（25°C）
  ├── 温箱设置为 25°C，等待热平衡
  ├── 读取传感器输出 Tsen_25C
  ├── 计算误差：Error = Tsen_25C - 25°C
  └── 记录常温偏差

Step 3: 高温验证（85°C / 125°C）
  ├── 温箱升温至目标温度，等待热平衡
  ├── 读取传感器输出 Tsen_Hot
  ├── 计算误差：Error = Tsen_Hot - T_Hot
  └── 记录高温偏差

Step 4: 低温验证（-40°C / 0°C）
  ├── 温箱降温至目标温度，等待热平衡
  ├── 读取传感器输出 Tsen_Cold
  ├── 计算误差：Error = Tsen_Cold - T_Cold
  └── 记录低温偏差

Step 5: 综合判定
  ├── 最大温度误差 = max(|Error_25C|, |Error_Hot|, |Error_Cold|)
  ├── 线性度评估（如有多于 2 个温度点）
  └── 判断是否满足温度精度规格
```

#### 温度精度换算

| 传感器输出类型 | 测量方式 | 精度换算 |
|---------------|---------|---------|
| 数字输出（℃） | 直接读取寄存器 | 无需换算，直接比较 |
| 模拟电压输出 | DMM 测电压，查表/公式转温度 | V → T 换算公式需已知 |
| ADC Code 输出 | 读取 ADC 数字码 | Code → V → T 两步换算 |

### 5.3 测试条件

| 参数 | 条件 | 说明 |
|------|------|------|
| 校准温度点 | 25°C ± 1°C | 常温参考点，通常在此做单点校准 |
| 高温验证点 | 85°C / 125°C | 视产品等级确定 |
| 低温验证点 | -40°C / 0°C | 视产品等级确定 |
| VDD | 标称值 ± 5% | 电源影响传感器精度 |
| Soak Time | 3~5 分钟/温度点 | 温度传感器对 Soak Time 要求较高 |
| 温度梯度 | < 5°C/min | 避免热冲击和温度过冲 |

### 5.4 判定标准

| 参数 | 消费级规格 | 工业级规格 | 汽车级规格 |
|------|-----------|-----------|-----------|
| 温度精度（25°C） | ±2°C | ±1.5°C | ±1°C |
| 温度精度（全温） | ±5°C | ±3°C | ±2°C |
| 分辨率 | 1°C（8 位） | 0.5°C（9 位） | 0.25°C（10 位） |
| 长期稳定性 | ±1°C/年 | ±0.5°C/年 | ±0.3°C/年 |

### 5.5 VPTAT 与 VPTAT SENSOR 的关系

| 对比项 | VPTAT | VPTAT SENSOR |
|--------|-------|-------------|
| 输出类型 | 原始模拟电压 | 经 ADC 转换的数字温度值或缓冲后的模拟电压 |
| 测试内容 | 电压精度、斜率、线性度 | 温度读数精度、全温范围误差 |
| 测试温度点 | 2~3 个 | 2~3 个（多点更优） |
| 判定依据 | mV/°C 斜率偏差 | °C 温度误差 |
| 校准方式 | 通常不校准 | CP 中可做单点/两点校准 |
| FT 重点 | 验证 CP 后参数稳定 | 验证实际温度测量精度 |

### 5.6 温度传感器误差分析

温度传感器的总误差可分解为：

| 误差来源 | 典型量值 | 说明 |
|---------|---------|------|
| VPTAT 核心误差 | ±1°C ~ ±2°C | BJT 对匹配、工艺角偏差 |
| ADC 量化误差 | ±0.5 LSB | 对应 ±0.5°C ~ ±1°C |
| ADC 偏移误差 | ±1 LSB ~ ±2 LSB | ADC 输入失调 |
| ADC 增益误差 | ±1% ~ ±2% | ADC 参考电压偏差 |
| 封装应力 | ±0.5°C ~ ±1°C | 塑封应力影响 BJT 特性 |
| 总误差（RSS） | ±2°C ~ ±5°C | 各分量平方和开根号 |

### 5.7 注意事项

1. **单点校准的有效性**：许多 PMIC 仅在常温（25°C）做单点校准，利用 VPTAT 的固有线性度保证全温精度。但若 VPTAT 斜率偏离设计值，单点校准无法修正高温/低温偏差。

2. **ADC 精度瓶颈**：温度传感器的最终精度受限于 ADC 的转换精度。如果 ADC 的有效位数（ENOB）不足，即使 VPTAT 核心非常精确，最终温度读数也可能有较大误差。

3. **温度梯度影响**：芯片内部存在温度梯度时，BJT 传感器所在位置的温度可能与芯片外壳温度不一致。这在 FT 测试中需要关注：温箱控制的是环境温度，而传感器测量的是结温。

4. **数字滤波**：片上温度传感器通常包含数字滤波（如滑动平均、中值滤波），用于抑制噪声。测试时需注意滤波器建立时间，避免过早读数。

## 6. 总结与基准测试顺序

### 6.1 FT 基准测试顺序建议

在 FT 测试中，基准模块的测试建议按以下顺序执行：

```
Step 1: VREF1P0 电压测试
  ├── 最先测试，验证系统基本参考电压是否正常
  ├── 若 VREF1P0 异常，后续所有依赖参考电压的测试项均可能失效
  └── 可及早停止测试，节省时间

Step 2: VBG 电压测试
  ├── 验证 Bandgap 基准源正常
  └── 全温范围测试需在温度箱中进行

Step 3: IREF 电流测试
  ├── 验证全局偏置电流正常
  └── IREF 偏差会影响后续模块测试（TC 等）

Step 4: VPTAT 电压测试
  ├── 验证温度传感前端正常
  └── 需在多个温度点测量

Step 5: VPTAT SENSOR 测试
  ├── 最后测试，依赖 VPTAT 前端和 ADC 均正常
  └── 全温范围综合验证
```

### 6.2 各测试项关键规格汇总

| 测试项 | 关键参数 | 典型精度要求 | 温度依赖性 | 测试时间 |
|--------|---------|-------------|-----------|---------|
| VREF1P0 | 1.000V 电压精度 | ±1% ~ ±2% | 低 | 短（~10ms） |
| VBG | 1.200V + TC | ±0.5% ~ ±1%, TC < 50 ppm/°C | 高（需多温度点） | 长（~数分钟含 Soak） |
| IREF | 参考电流值 | ±2% ~ ±5% | 中（TCR 影响） | 短（~20ms） |
| VPTAT | 斜率 mV/°C + 线性度 | ±5% 斜率, ±0.5% 线性度 | 高（需多温度点） | 长（~数分钟含 Soak） |
| VPTAT SENSOR | 温度读数精度 | ±2°C ~ ±5°C | 高（需多温度点） | 长（~数分钟含 Soak） |

### 6.3 CP Trim 与 FT 验证的对应关系

| CP Trim 项 | FT 验证项 | 验证目标 |
|-----------|----------|---------|
| VREF1P0 Trim | VREF1P0 电压测试 | Trim 码生效，封装后未偏移 |
| VBG Trim | VBG 电压测试 + TC | Trim 码生效，温漂在规格内 |
| IREF Trim | IREF 电流测试 | Trim 码生效，电流值准确 |
| 无（VPTAT 通常不 Trim） | VPTAT + VPTAT SENSOR | 原始精度满足规格 |

### 6.4 失效模式分析

| 测试项 | 典型失效模式 | 可能原因 | 后续处理 |
|--------|------------|---------|---------|
| VREF1P0 | 电压偏低/偏高 | OTP 加载失败、封装应力、Trim 码偏移 | 回读 Trim 寄存器、尝试重载 |
| VREF1P0 | 电压不稳定 | Buffer 振荡、去耦不足 | 检查测试板去耦、负载条件 |
| VBG | 全温漂移过大 | 温度补偿失效、电阻 TCR 异常 | 分析 TC Trim 是否需要补充 |
| VBG | 常温偏差大 | OTP 加载失败、封装应力 | 回读 Trim 寄存器、与 CP 数据对比 |
| IREF | 电流偏差大 | 电阻 Rref 偏差、VREF 偏差 | 检查 IREF Trim 寄存器 |
| IREF | 温度依赖性异常 | 电阻类型错误、TCR 异常 | 分析晶圆工艺角 |
| VPTAT | 斜率偏差 | R2/R1 比例偏差 | 非 Trim 项，判断是否在 Accept 范围 |
| VPTAT SENSOR | 温度读数不准 | ADC 偏差、VPTAT 核心偏差 | 综合判断是否需补充校准 |
