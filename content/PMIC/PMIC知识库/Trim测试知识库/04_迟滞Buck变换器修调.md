# 迟滞Buck变换器修调

## 一、迟滞Buck变换器概述

### 1.1 什么是迟滞Buck变换器

迟滞Buck变换器（Hysteretic Buck Converter）是一种**电压模式（Voltage-Mode）** 的降压变换器，其核心控制方式如下：

- **纹波注入（Ripple Injection）**：输出纹波通过注入网络耦合到比较器输入端，作为反馈信号的一部分参与调制。
- **基于比较器的控制（Comparator-Based Control）**：使用迟滞比较器（Hysteretic Comparator）而非传统的误差放大器（EA）+ 补偿网络来控制开关动作。当反馈电压低于下限阈值时开启上管，高于上限阈值时关闭上管。
- **无需外部补偿（No External Compensation）**：由于采用迟滞比较器直接控制，系统天然稳定，不需要外部的RC补偿网络。
- **变频工作（Variable Frequency Operation，VFO）**：开关频率随输入电压、输出电压和负载电流变化，而非固定频率PWM。
- **快速瞬态响应（Fast Transient Response）**：迟滞结构比较器直接响应输出电压变化，几乎无延迟，瞬态响应速度远快于传统的电压模式或电流模式PWM变换器。

### 1.2 迟滞Buck的典型修调项概览

由于工艺偏差（PVT Variation），迟滞Buck的内部电路参数需要经过修调（Trim）来保证最终产品的各项指标在规格书范围内。主要修调项如下：

| 编号 | 修调项 | 英文描述 | 核心目的 |
|------|--------|----------|----------|
| 1 | LX电阻修调 | LX Rds(on) Trim | DCM检测精度、效率优化 |
| 2 | VO_R电阻精度修调 | Output Voltage Feedback Resistor Trim | 输出电压精度 |
| 3 | Vref_R电阻精度修调 | Reference Resistor Trim | 内部参考电流/时序精度 |
| 4 | RC Ton时间修调 | RC Turn-On Time Trim | Ton时间精度 |
| 5 | 输出电压带载修调 | VOUT Trim under Load | 带载输出电压精度 |
| 6 | POCP修调 | Peak Over-Current Protection Trim | 过流保护点精度 |
| 7 | 负DMD修调 | Negative Current Detection Trim | DCM/CCM切换精度 |

## 二、迟滞Buck的LX电阻修调

### 2.1 原理（Principle）

迟滞Buck变换器的功率管（Power FET）导通电阻（Rds(on)）在制造过程中会随**工艺角（Process Corner）** 发生显著变化。LX节点是指功率管（上管Source/下管Drain）与电感之间的连接点。

LX电阻修调的核心目的包括：

- **DCM检测**：迟滞Buck在轻载时进入非连续导通模式（DCM），需要精确检测电感电流过零点（Zero-Cross）。过零检测电路通常通过检测LX节点电压（即下管Vds）来推断电感电流方向。若Rds(on)不准确，过零检测点会偏移，导致DCM/CCM边界控制不精确。
- **效率优化**：Rds(on)直接影响导通损耗。修调Rds(on)感知值（Sensed Resistance）确保检测电路正确评估功耗和电流状态。
- **OCP精度基础**：部分OCP检测也依赖于下管Rds(on)的 sensing 值。

修调的本质是**调整检测通路中用于补偿Rds(on)工艺漂移的可调电阻或电流源**，使检测电路"认为"的Rds(on)值与实际值匹配。

### 2.2 测试方法（Test Method）

**基本思路**：在LX节点注入已知电流，测量电压降，计算实际的Rds(on)，然后调整修调码使检测电路匹配该值。

**步骤**：

1. **上管（High-Side FET）Rds(on)测量**：
   - 将Buck设置为强制PWM模式（FPWM），使其在CCM下工作。
   - 让Buck输出额定负载电流（I_LOAD）。
   - 在上管导通期间，测量LX节点的电压（相对于VIN或PGND）。
   - 已知电流 = I_LOAD（上管导通时电流近似等于负载电流），计算 Rds(on)_HS = (VIN - VLX) / I_LOAD。
   - 依次扫描修调码（Trim Code），找到使检测值与目标值最接近的码值。

2. **下管（Low-Side FET）Rds(on)测量**：
   - Buck工作在CCM下，在下管导通期间测量LX节点电压（相对于PGND）。
   - Rds(on)_LS = VLX / I_LOAD（下管导通时LX到GND的压降）。
   - 同样扫描修调码，找到最优码值。

3. **零负载/小电流交叉验证**：
   - 在轻载（DCM）条件下，观察过零检测点的LX波形，确认DCM检测是否正常。

### 2.3 注意事项（Considerations）

- 测量Rds(on)时需要准确知道通过功率管的电流。当电感纹波电流较大时，需要在导通时间的中点采样以得到平均电流值。
- LX节点的高速开关特性会产生振铃（Ringing），采样窗口应避开开关切换瞬态。
- 温度和电压条件：Rds(on)随温度升高而增大（正温度系数），修调应在常温下完成，但要考虑高温工况下的余量。
- 死区时间（Dead Time）的影响：在上下管切换的死区时间内，体二极管导通会产生额外压降，需要避开此窗口采样。
- 对于多相Buck，各相的Rds(on)需独立修调并分别存储修调码。
- **外部连接确认**：确保LX节点到外部测试点的连接路径引入的额外阻抗已被考虑（de-embedding），特别是使用长导线或探针卡时。

## 三、迟滞Buck的VO_R电阻精度修调

### 3.1 原理（Principle）

迟滞Buck的输出电压由**内部反馈电阻分压网络（Feedback Resistor Divider）** 决定：

$$V_{OUT} = V_{REF} \times \left(1 + \frac{R_{TOP}}{R_{BOTTOM}}\right)$$

其中：
- VREF是内部参考电压（通常由带隙基准产生）
- R_TOP是上端反馈电阻（接VOUT到反馈节点）
- R_BOTTOM是下端反馈电阻（接反馈节点到GND）

电阻分压网络通常由**多晶硅电阻（Poly Resistor）** 或**扩散电阻（Diffusion Resistor）** 组成，其绝对值在工艺角下可能偏差±15%~±30%，但电阻比率（Ratio）的匹配精度相对较好（1%~3%）。然而对于高精度输出电压要求（如±1%），仍需通过修调来补偿：

- 电阻比率偏差（Mask/Etch 导致的微小失配）
- VREF电压本身的偏差（由BG修调项补偿）
- 反馈节点的漏电流影响

修调方式通常为**修调电阻阵列（Trimmable Resistor Ladder）**：通过熔丝（EFuse/One-Time Programmable, OTP）或寄存器控制开关，在R_TOP或R_BOTTOM上并联/串联修调电阻步进（Trim Step），从而微调分压比。

### 3.2 测试方法（Test Method）

**基本思路**：在特定负载条件下（通常为轻载或空载）测量VOUT，与目标值比较，迭代修调码。

**步骤**：

1. **准备条件**：
   - 设置输入电压VIN为典型值（如3.7V）。
   - 设置输出电压目标值（如1.8V）。
   - 负载电流设置为轻载（如10mA或空载），以排除IR Drop对测量的干扰（注意：空载时可能进入DCM模式，纹波较大，建议使用10~50mA轻载CCM模式）。

2. **测量VOUT**：
   - 使用高精度万用表（DMM）或采样系统在输出电容后端（即测试板上的sense点）测量VOUT。
   - 确保测量点尽量靠近芯片反馈回路，而非负载端，避免PCB走线IR Drop引入误差。

3. **扫描修调码**：
   - 依次遍历所有的VO_R trim code。
   - 记录每个码值对应的VOUT读数。
   - 选择最接近目标电压的码值。

4. **验证**：
   - 写入最优码并重新测量VOUT，确认在误差范围内。
   - 如有需要，在不同VIN和温度条件下验证修调效果。

### 3.3 注意事项（Considerations）

- VO_R修调通常在**空载或轻载**下进行，重载下的VOUT偏差由后续的"输出电压带载修调"补偿。
- 务必确认芯片内部反馈回路的状态。有些芯片在测试模式下可以通过寄存器直接读取反馈节点电压，从而将VREF偏差和电阻偏差分离开来。
- 电阻的**温度系数（TCR）**：修调只能在某一温度点校准电阻比率，但TCR失配会导致不同温度下的比率变化。需要评估TCR mismatch的影响是否在规格范围内。
- 并联和串联修调的区别：并联修调（在现有电阻上并联小电阻）会使总阻值变小（VOUT变低），串联修调则相反。测试前需确认修调方向和步进精度。
- **输出纹波影响**：滞回Buck的输出纹波较大，测量时建议使用平均值（Average）或多点采样取平均，避免纹波峰值影响修调判断。

## 四、迟滞Buck的Vref_R电阻精度修调

### 4.1 原理（Principle）

Vref_R是指**内部参考电阻（Reference Resistor）**，通常是一颗经过设计的高精度多晶硅电阻（如RNWELL/Poly Resistor），用于：

- **电流参考（Current Reference）**：与内部带隙基准电压（VBG或IREF）配合，生成精确的偏置电流（如：I = VREF / R_REF）。
- **时序参考**：用于产生开关控制时序（如TON/TOFF定时器的Cap充电电流）。
- **过流检测参考**：部分OCP方案中，过流阈值由IREF流过Vref_R产生的压降决定。

由于工艺偏差，Vref_R的绝对值可能偏离设计值±20%~±30%。通过修调，可以：

- 调整参考电阻的有效阻值，使IREF等关键电流源恢复到设计值。
- 间接补偿整个Buck电流回路的精度。

**与VO_R的区别**：
- VO_R修调的是**反馈分压电阻比率**，直接影响VOUT直流值。
- Vref_R修调的是**单一电阻的绝对值**，影响电流/时序，间接影响频率和效率。

### 4.2 测试方法（Test Method）

**基本思路**：让一已知的精确电流流过Vref_R，测量其上的电压降，计算实际电阻值，然后调整修调码。

**方法一（直接法）**：

1. 将芯片置于测试模式，使Vref_R的一端连接到外部测试引脚（或通过测试多路复用器MUX引出）。
2. 从外部施加精确的已知电流（如10uA）流过Vref_R。
3. 用高精度DMM测量Vref_R两端的电压。
4. 计算R_actual = V_measured / I_forced。
5. 比较R_actual与R_target，选择修调码。

**方法二（间接法——通过IREF测试）**：

1. 不使用芯片时，通过外部电源可测量芯片的IREF输出电流。
2. 如果IREF = VREF / Vref_R，已知VREF（通过BG修调已校准），则可以通过IREF反算R值：

   $$R_{VREF\_R} = \frac{V_{REF}}{I_{REF}}$$

3. 调整Vref_R修调码直到IREF达到目标值。

### 4.3 注意事项（Considerations）

- Vref_R修调应在VREF电压已经过BG修调且稳定的前提下进行（如果VREF本身不准，则Vref_R修调失去了基准）。
- 直接法测量时，注意测试通路上的额外串联电阻（开关导通电阻、引脚寄生电阻），必要时使用**Kelvin连接（四线法）** 或通过已知电阻进行 de-embedding。
- 间接法（通过IREF反算）时，注意IREF输出端口是否还有其他负载路径导致电流分流。
- Vref_R的温度特性和电压系数（Voltage Coefficient）应在修调后进行评估，确保全温度范围和全电压范围内精度达标。
- **IR Drop影响**：芯片内部走线也有寄生电阻，尤其当Vref_R阻值较小（如几十kΩ）时，走线电阻可能占据可观的百分比。

## 五、迟滞Buck的RC Ton时间修调

### 5.1 原理（Principle）

迟滞Buck的导通时间（Turn-On Time, Ton）由**RC定时网络**或**电流源+电容**结构决定：

**RC型（RC Type）**：
$$T_{ON} = k \times R_{TON} \times C_{TON}$$

**电流源型（Current-Source Type）**：
$$T_{ON} = \frac{C_{TON} \times V_{TH}}{I_{TON}}$$

其中：
- R_TON / C_TON 是片内RC元件
- k是常数（取决于比较器阈值比例）
- V_TH是比较器翻转阈值
- I_TON是由IREF产生的充电电流

Ton的精度直接影响：

- **开关频率（Switching Frequency）**：Ton + Toff 决定周期，Ton偏差直接影响频率。
- **电感电流纹波**：ΔI_L = (VIN - VOUT) × TON / L，纹波过大或过小影响效率和稳定性。
- **输出电压纹波**：与Ton正相关。
- **DCM/CCM切换点**：Ton决定了最小能量传递周期。

由于片内RC和电流源均受PVT影响（电阻±20%，电容±10%，电流±15%），Ton偏差可达±30%以上，必须通过修调补偿。

### 5.2 测试方法（Test Method）

**基本思路**：测量Buck LX引脚上的脉冲宽度（Pulse Width）作为Ton，扫描修调码使其匹配目标值。

**步骤**：

1. **波形获取**：
   - 设置Buck工作在稳态CCM模式（或特定VIN/VOUT条件下）。
   - 使用示波器（Oscilloscope）高带宽探头（建议>100MHz）连接LX引脚。
   - 触发模式设为上升沿（Rising Edge）触发，采集稳定的LX开关波形。

2. **Ton测量**：
   - 使用示波器的脉冲宽度测量功能（Pulse Width Measurement）。
   - 测量50%幅度处的Ton脉宽（High-Side FET导通时间）。
   - 读取多个周期并取平均，以减小单周期抖动的影响。

3. **阈值测量**（若示波器不支持PWM分析）：
   - 也可用Frequency Counter或Time Interval Analyzer测量Ton。
   - 或者通过数字采集系统（如ATE的数字通道板卡）采样LX波形并软件计算。

4. **修调码扫描**：
   - 遍历所有RC Ton修调码（通常为二进制或温度计编码）。
   - 记录每个码值对应的Ton。
   - 构建Ton vs Trim Code 曲线，选择最接近目标Ton的码值。
   - 注意修调方向：增加RC值会使Ton增大，反之减小。

5. **交叉验证**：
   - 在多个VIN/VOUT条件下验证Ton修调效果。
   - 测量对应条件下的开关频率，确认频率在规格范围内。

### 5.3 注意事项（Considerations）

- **Ton测量条件**：Ton与VIN、VOUT有直接关系，修调条件应严格参考数据手册指定的测试条件（如VIN=3.7V, VOUT=1.8V, ILOAD=200mA）。
- **示波器精度**：Ton通常在几十ns到几百ns量级，需要示波器具有足够的采样率（至少≥2GSa/s）和时间分辨率。
- **探头带宽**：LX节点的switching node有快速上升/下降沿（纳秒级），使用10x无源探头时注意其带宽是否足够（最好使用差分探头或有源探头）。
- **死区时间和振铃**：LX波形在Ton的开始和结束处有振铃和死区时间。测量时应以50% VIN幅度点作为Ton的起止点，而非过零或峰值点。
- **修调码的单调性**：确保修调码的变化对Ton的影响是单调的（Monotonic）。如果存在非单调性，说明修调网络存在设计缺陷。
- **频率抖动（Frequency Jitter）**：迟滞Buck本身存在频率抖动，多次测量取平均是必要的。
- **同步基准**：如果使用ATE系统测试，数字通道的时序校准至关重要，特别是当Ton < 100ns时。
- **不同模式下的差异**：DCM和CCM下的Ton可能有差异（由于负载和电感的能量状态不同），建议在修调时统一在CCM下进行。

## 六、迟滞Buck的输出电压修调（带载）

### 6.1 原理（Principle）

前文的VO_R修调是在轻载条件下进行的，主要校准了反馈电阻分压网络的精度。然而，在**重载（Heavy Load）** 条件下，实际VOUT会偏离轻载值，原因包括：

- **IR Drop（压降）**：从芯片输出引脚到反馈采样点之间的PCB走线和封装引线（Bond Wire）存在电阻，重载电流下产生显著压降。
- **DC Regulation Offset（直流调节偏移）**：迟滞比较器的输入失调电压（Input Offset Voltage）在不同负载下可能有变化（受共模输入范围影响）。
- **纹波中心偏移（Ripple Center Shift）**：重载时电感纹波电流增大，加上比较器迟滞窗口和传输延迟，可能使输出电压平均值（Average）偏移。
- **地弹（Ground Bounce）**：大电流瞬态在地线上产生的电压偏移影响输出电压传感。

因此，**带载输出电压修调（VOUT Trim under Load）** 是在实际的负载条件下对输出电压进行最终校准，补偿IR Drop和调节偏移。

### 6.2 测试方法（Test Method）

**基本思路**：在额定负载电流下测量VOUT，调整输出电压修调码（可能是一个独立的VOUT Trim码，或调整VREF/反馈电阻），使VOUT符合目标值。

**步骤**：

1. **测试条件建立**：
   - VIN设为额定值（如3.7V）。
   - 电子负载（Electronic Load）连接到VOUT，设置为额定负载电流（如1A或数据手册指定值）。
   - 测量点选择：在芯片输出电容的两端（Force和Sense采用Kelvin连接）。
   - 让Buck在目标模式下工作（如FPWM/CCM）。

2. **基准测量**：
   - 写入VO_R轻载修调码（已在前一步完成）。
   - 读取带载VOUT（VOUT_LOAD）。
   - 计算偏差：ΔV = VOUT_LOAD - VOUT_TARGET。

3. **修调码扫描**：
   - 遍历带载VOUT修调码，每个码值测量并记录VOUT。
   - 选择使VOUT最接近VOUT_TARGET的码值。
   - 一些设计将VOUT修调实现为调整VREF（VREF微调DAC）或调整R_TOP（额外电阻串）。

4. **IR Drop测量（辅助分析）**：
   - 如果芯片有独立的输出电压Sense引脚（Remote Sense），比较VOUT_SENSE和VOUT_FORCE的差值可以得到IR Drop。
   - 若没有Remote Sense，可通过在不同负载电流下测量VOUT的变化斜率来估算IR Drop。

5. **交叉验证**：
   - 在修调码确定后，检查轻载VOUT是否仍在规格范围内（因为带载修调可能影响轻载VOUT，需要trade-off）。
   - 检查全负载范围内的VOUT精度是否满足规格要求。

### 6.3 注意事项（Considerations）

- **测量点选择至关重要**：Force/Sense必须分开。Sense线要连接到芯片VOUT引脚最靠近封装的位置（Kelvin检测），Force线连接到电子负载。这是带载修调中最大的误差来源。
- **负载瞬态**：如果负载有动态变化（Pulse Load），需要在负载稳定后（稳态窗口内）测量。
- **线损补偿**：如果测试系统使用继电器矩阵或长导线，需要对Force/Sense进行校准（Short/Open校准）。
- **散热/自热效应**：重载下芯片温度会上升，VOUT会随温度漂移。测量应在热平衡后进行（通常等待数十秒至数分钟）。
- **耦合到反馈路径**：注意大电流回路和反馈回路不应共享同一地路径，否则共阻抗耦合（Ground Loop）会引入测量误差。
- **修调顺序依赖性**：带载VOUT修调通常是在VO_R轻载修调之后执行。如果带载修调的方式是调整VREF，注意VREF本身还有其他用途，确保不会影响到其他模块。
- **Ripple Averaging**：由于迟滞Buck的纹波在重载下变大（尤其在陶瓷输出电容上ESR很小时），测量平均值时要确保DMM的积分时间（Integration Time）覆盖至少几个开关周期（PLC ≥ 10 或 NPLC ≥ 1）。

## 七、迟滞Buck的POCP修调

POCP（Peak Over-Current Protection，峰值过流保护）是迟滞Buck的关键保护功能。当电感电流峰值超过设定的OCP阈值时，控制逻辑会关闭上管或触发逐周期限流（Cycle-by-Cycle Current Limit）。POCP修调包含三个子项。

### 7.1 Buck的OCP比较器失调电压修调

#### 7.1.1 原理（Principle）

OCP检测的核心是一个**电流检测比较器（Current Sense Comparator）**。该比较器将检测到的电感电流信号（通常是通过Sense FET采样得到的电压信号）与一个参考阈值电压进行比较。

比较器本身存在**输入失调电压（Input Offset Voltage, VOS）**，这会导致：
- OCP触发点偏移：实际OCP阈值 = 理想阈值 ± VOS
- 随共模输入电压变化的VOS变化（CMRR）
- 随温度变化的VOS漂移

VOS修调的目的是**校准比较器的失调电压到接近零**，使OCP触发点准确。

#### 7.1.2 测试方法（Test Method）

**基本思路**：找到比较器的翻转点（Trip Point），计算出实际失调电压，然后通过修调DAC补偿。

**方法——电压扫描法（Voltage Ramp Method）**：

1. **进入测试模式**：
   - 将芯片置于特殊测试模式，使得比较器的两个输入引脚可以直接或间接访问。
   - 通常需要禁用功率管开关操作（Power Stage Disabled），使检测电流为零。

2. **差分电压扫描**：
   - 在比较器的正输入端（Sense+）和负输入端（Sense- / Reference）之间施加可变的差分电压。
   - 从低于预期VOS的值开始线性扫描（或二进制搜索），直到比较器输出翻转。
   - 记录翻转点的差分电压，该值即为VOS。

3. **修调码选择**：
   - 根据VOS的极性和幅度，选择对应的Trim Code。
   - 修调DAC通常可提供 ±VOS_RANGE 的调节范围，步进为 LSB。
   - 每个码值写入后重新测量VOS，直到VOS在目标范围内（如 ±0.5mV）。

4. **多通道/多模式**：
   - 如果芯片有多个Buck通道，每个通道的OCP比较器需独立修调。
   - 部分设计有不同OCP模式（如低速/高速模式），可能需要分别修调。

#### 7.1.3 注意事项（Considerations）

- **测试模式入口**：进入测试模式的方法因芯片而异，可能涉及特殊寄存器写入序列或特定的引脚电压条件。确保测试程序正确且完整地执行了进入序列。
- **比较器速度与建立时间**：比较器在测试模式下可能被配置为低速低功耗模式，其翻转响应时间较长。扫描电压时的步进速度需要足够慢，以便比较器有充分时间响应。
- **迟滞的影响**：部分OCP比较器设计有少量的迟滞（Hysteresis，通常0.5~2mV）以防止噪声误触发。测量VOS时需要明确是上升沿翻转还是下降沿翻转（或取两者的平均值）。
- **多路复用通路寄生**：如果比较器的输入通过MUX连接到测试引脚，通路上的开关电阻和漏电流会增加测量误差。需要注意MUX的Ron压降。
- **温度系数**：VOS随温度漂移，常温修调后需要在高温和低温下验证效果。部分高精度芯片提供温度补偿修调（TC Trim）。

---

### 7.2 Buck POCP Sense修调

#### 7.2.1 原理（Principle）

POCP Sense修调校准的是**电流检测通路（Current Sense Path）** 的总增益和偏移。典型结构如下：

- **Sense FET（感测功率管）**：一个小尺寸的MOSFET（通常为功率管的1/N比例）与功率管并联，通过Mirror结构复制电感电流。
- **Sense Amplifier（感测放大器）**：钳位Sense FET的漏极电压与功率管漏极电压相等（VDS匹配），使Sense电流精确比例于功率管电流。
- **Sense Resistor（感测电阻）**：Sense电流流过检测电阻，产生电压信号 VSENSE = ISENSE × RSENSE = (ILOAD / N) × RSENSE。

工艺偏差导致：
- Sense FET的W/L比例失配
- Sense Amplifier的失调电压（影响VDS匹配精度）
- Sense Resistor的绝对值偏差

POCP Sense修调即**调整感测通路的总增益**，使得VSENSE准确反映ILOAD。

#### 7.2.2 测试方法（Test Method）

**基本思路**：注入已知的负载电流，测量或推断sense amplifier的输出电压（或OCP触发点），调整sense校准码。

**方法——V-I Transfer校准**：

1. **测试条件**：
   - 强制Buck输出一个已知的电流（I_LOAD_FORCE）。
   - 确保Buck工作在FPWM模式下（避免DCM干扰）。

2. **测量Sense电压**：
   - 如果芯片测试模式允许，直接从Sense Amplifier输出引脚测量VSENSE。
   - 如果无法直接测量，则通过读取OCP触发点来间接推算：
     a. 缓慢增加负载电流（或强制拉载），直到OCP触发（通过状态寄存器读取或LX波形确认）。
     b. 记录OCP触发时的电流I_TRIP。
     c. 计算I_TRIP与理论OCP阈值的比值。

3. **修调码扫描**：
   - 遍历POCP Sense Trim Code。
   - 在每个码值下测量I_TRIP。
   - 选择使I_TRIP最接近目标OCP阈值的码值。

4. **增益线性度检查**：
   - 在多个电流点（如50% OCP, 80% OCP, 100% OCP）下测量Sense输出，确认增益的线性度（Linearity）在规格内。

#### 7.2.3 注意事项（Considerations）

- **大电流测试的安全性**：POCP测试涉及接近或过流条件，可能触发OCP导致Buck关闭或进入Hiccup模式。测试序列需要设计为快速扫描并设定好恢复机制。
- **自热效应**：大电流下功率管结温迅速上升，使Rds(on)增大，可能影响Sense FET的匹配。建议采用脉冲式测试（Pulsed Test）来避免自热。
- **Sense Amplifier带宽**：瞬时过流检测需要在每个开关周期内完成，Sense通路带宽不足会影响POCP响应时间。修调验证时也要确认响应时间。
- **区分静态增益校准和动态失调**：POCP Sense修调主要调整的是DC增益，但与OCP比较器VOS修调可能相互影响（系统级校准）。建议先做VOS Trim再做Sense Trim，或两者迭代进行。
- **Trim Code的冗余设计**：如果POCP Sense修调码是非易失性存储（EFuse/OTP）中存储的，务必在烧录前验证所有码值的有效性，避免烧录后发现非单调或跳码问题。

### 7.3 Buck OCP自修调

#### 7.3.1 原理（Principle）

OCP自修调（Self-Calibration / Self-Trim）是芯片内部集成的**自动校准序列**，可以在上电时或由主机触发启动，自动完成OCP修调而不需要外部ATE介入。

**典型流程**：

1. **上电序列触发**：芯片上电复位（POR）后，自动开始自修调序列。
2. **内部电流注入**：芯片内部产生一个精确的参考电流（基于已修调的IREF和VREF），施加到Sense通路上。
3. **自比较**：内部逻辑自动调整校准DAC（比较器失调DAC 或 Sense增益DAC），直到Sense比较器在预设的参考点翻转。
4. **码值锁定**：将得到的校准码值存入内部寄存器（RAM-based，每次上电后需要重做）或烧录到非易失性存储器（EFuse/OTP）。

自修调的优势：

- **降低ATE测试成本**：减少外部测试时间和仪器需求。
- **实时补偿**：可以补偿温度漂移和环境变化（若每次上电执行）。
- **简化量产流程**：ATE仅需验证自修调结果是否正确，而非逐项修调。

#### 7.3.2 测试方法（Test Method）

**基本思路**：触发芯片自修调序列，然后通过外部测量验证自修调后的OCP阈值是否落在规格范围内。

**步骤**：

1. **触发自修调**：
   - 如果是上电自动触发：芯片上电后等待自修调完成（通常几毫秒到几百毫秒，可通过状态寄存器读取完成标志）。
   - 如果是命令触发：通过I2C/SPI等接口发送特定的自修调启动命令。

2. **读取校准码**：
   - 通过寄存器读取自修调后的DAC码值。
   - 确认码值在合理范围内（没有饱和在最大或最小值，否则说明器件可能异常）。

3. **外部验证**：
   - 如7.2节所述，将Buck加载到接近OCP阈值的电流。
   - 验证OCP触发点是否在规格范围内。
   - 如果有多颗芯片，统计自修调码的分布情况（Process Distribution），一致性好说明自修调算法稳定。

4. **温度验证**：
   - 在常温下完成自修调后，在高温（如85°C）和低温（如-40°C）下重新验证OCP阈值。
   - 确认自修调具有足够的温度补偿能力。
   - 如果自修调仅在上电时执行一次（非实时Tracking），高温下的OCP精度取决于校准电路的温漂特性。

#### 7.3.3 注意事项（Considerations）

- **自修调的启动条件**：某些芯片要求VIN和VOUT稳定后才能启动自修调。如果启动条件不满足，自修调结果可能无效。测试程序需检查相关的Power Good或Ready标志。
- **自修调与外部修调的优先级**：如果既设计有外部修调（ATE Trim）又有自修调（Self-Cal），需要明确两者的关系：
  - 自修调是替代外部修调（采用后无需ATE修调）？
  - 还是自修调是在外部修调基础上的 Fine-Tune？
  - 不同方案的测试策略完全不同。
- **自修调失败处理**：芯片自修调可能因内部参考尚未稳定、时钟异常等因素失败。ATE需有能力检测自修调完成标志或校验码有效性，失败时标记为Fail或进行重试。
- **测试覆盖**：自修调减少了ATE测试项，但ATE仍需覆盖自修调功能的验证——即验证"自修调确实工作并产生了正确结果"，而不是完全跳过。
- **自修调码的上电保持**：如果自修调码仅保存在易失性寄存器中，ATE断电后丢失，需要在每次ATE测试的初始化序列中触发自修调。如果一次ATE测试涉及多次下电（如多工位并行测试），需注意时序。
- **诊断模式**：自修调通常不提供外部干预的接口。当自修调结果异常时，ATE应能回退到手动修调模式进行故障分析（Failure Analysis）。

## 八、Buck的负DMD修调

### 8.1 原理（Principle）

负DMD（Negative Current Detection，或称为负电流检测 / Zero-Cross Detection）用于检测**电感电流过零点**，是迟滞Buck在DCM（断续导通模式）和CCM（连续导通模式）之间切换的关键控制信号。

**物理含义**：

在Buck变换器中：
- **CCM模式**：电感电流在整个周期内始终大于零（上管导通时上升，下管导通时下降但仍大于零）。
- **DCM模式**：电感电流在下管导通期间下降到零后，下管关闭，进入断续状态。体二极管不导通（或只在死区时间短暂导通）。

负DMD检测即检测电感电流何时下降到零（或接近零），此时关闭下管以防止：

1. **反向电流（Reverse Inductor Current）**：如果下管在电流过零后继续导通，电流反向流动（从输出端流向输入端），会增加损耗、降低轻载效率。
2. **输出电压泵升**：反向电流可能给输出电容充电，使VOUT异常升高。
3. **系统效率劣化**：反向电流会产生额外的导通损耗和磁芯损耗。

**检测方法**：
- 负DMD比较器（Zero-Cross Comparator）检测下管导通时LX节点的电压：
  - 当电感电流正向（下管到输出）时，LX电压 = IL × Rds(on)_LS，为正（相对于PGND）。
  - 当电感电流降到零并开始反向时，LX电压变为负（电流从输出流入LX再经下管到GND，实际上VDS反向）。
  - 比较器检测LX电压与PGND（或一个小的负参考电压）的差值，当LX电压越过零/负参考值时触发翻转。

由于Rds(on)的工艺偏差直接影响VDS = IL × Rds(on)，负DMD比较器的翻转点与Rds(on)有关，这也是为什么负DMD修调和LX Rds(on)修调密切相关。

### 8.2 测试方法（Test Method）

**基本思路**：将负载电流从正（输出电流）逐渐减小到零并过零（注入电流到输出），观察DMD比较器何时触发，调整修调码使得过零检测点在目标电流范围内。

**步骤**：

1. **测试条件**：
   - Buck设置为DCM使能模式（即允许进入DCM）。
   - 初始负载电流设置在DCM边界以上（如CCM区域），例如100mA。
   - VIN和VOUT设为典型值。
   - 使用电子负载在CC（Constant Current）模式下工作。

2. **正向扫描（通过零到负）**：
   - 缓慢减少电子负载电流（或增加Source电流），速率建议 < 10mA/s 或步进足够小（如1mA/步），以给DMD比较器和控制环路足够响应时间。
   - 如果使用ATE，可以通过DAC控制负载/源电流的连续扫描。

3. **检测DCM标志**：
   - 读取芯片内部的状态寄存器（如 DCM_FLAG、ZCD_FLAG、MODE_INDICATOR）。
   - 如果没有寄存器标志，观测LX波形：进入DCM后LX会出现一段时间的High-Z（高阻状态，由体二极管导通或寄生振荡指示）。
   - 记录DCM_FALG置位（或DCM/CCM状态切换）时的电流值I_DMD。

4. **确定DMD点**：
   - I_DMD即为负DMD检测点。
   - 典型目标值：0mA（理想零电流检测）附近，允许一定的负值范围（如-5mA ~ +5mA）。
   - 如果I_DMD在目标范围内，则不需要修调。

5. **修调码扫描**：
   - 如果I_DMD不在目标范围内，遍历负DMD修调码。
   - 每个码值重新扫描负载电流并测量I_DMD。
   - 选择使I_DMD最接近目标值的码值。

6. **验证**：
   - 在修调码写入后，在DCM模式下检查轻载（如1mA~20mA）的效率是否有异常提升（说明负电流得到了有效防止）。
   - 同时验证在CCM模式下（负载增加到200mA以上）是否能正常工作且不失步。

### 8.3 注意事项（Considerations）

- **扫描速度的影响**：如果电流扫描速度过快，电感电流和芯片内部控制环路可能跟不上，导致DMD检测滞后。建议低速扫描并加入稳定等待时间。
- **正弦波特性**：DCM边界处LX波形会出现由电感和寄生电容谐振引起的阻尼振荡（Damped Sinusoidal Ringing）。这属于正常的DCM行为，但在判断DCM/CCM状态时需要鉴别。
- **温度影响**：Rds(on)随温度升高而增大，这意味着负DMD点在热态下会偏移（电流检测值偏大/偏小取决于具体实现）。评估高温/低温下的DMD点漂移量。
- **LX Rds(on) Trim vs 负DMD Trim**：
  - LX Rds(on)修调解决的是Rds(on)绝对值（用于电流感知的物理量）。
  - 负DMD修调解决的是比较器阈值。
  - 两者有交集，建议修调顺序：先LX Rds(on) Trim，再负DMD Trim。
- **负载电流方向的重要性**：测试负DMD时需要**能从输出吸取电流即可逆电流源/主动负载（Active Load / Bidirectional Supply）**，普通电子负载只能消耗电流无法注入电流。如果芯片要求检测负电流到一定的负值范围（如-50mA），需要双向电源/源表（SMU）支持。
- **AC耦合干扰**：当负载电流接近于零时，Buck的输出纹波本身可能引起负载电流的微小幅值波动。测量时需使用平均电流，而非瞬时值。
- **与POCP的互斥性**：当OCP触发时，芯片会关闭上管并可能进入Hiccup模式，这与DCM检测无关。在测试负DMD时需要确保不会误触发OCP（特别是当电流从零变为负时）。
- **死区时间影响**：在死区时间内，体二极管导通导致LX电压为负（-0.7V 到 -1V），这是正常情况，不被视为负DMD的触发条件。比较器需要有一个Blanking Time（消隐时间）来避开死区。
- **效率验证**：修调结束后，建议对比修调前和修调后在轻载（1mA, 10mA, 50mA）下的效率数据。负DMD修调不当导致的负电流会显著降低轻载效率。

## 九、修调顺序总结

为确保各修调项互不干扰，建议在ATE测试程序中遵循以下执行顺序：

```
1. 基准修调
   ├── VBG基准电压修调 (Bandgap Reference Trim)
   ├── VREF1P0电压修调 (1.0V Reference Trim)
   └── IREF基准电流修调 (Current Reference Trim)
   
2. 迟滞Buck修调
   ├── [1] Vref_R电阻精度修调 (参考电阻 Trim)
   ├── [2] VO_R电阻精度修调 (反馈分压电阻 Trim — 轻载)
   ├── [3] RC Ton时间修调 (导通时间 Trim)
   ├── [4] LX电阻修调 (Rdson Trim)
   ├── [5] 负DMD修调 (零电流检测 Trim)
   ├── [6] OCP比较器失调电压修调 (Vos Trim)
   ├── [7] POCP Sense修调 (感测通路 Trim)
   ├── [8] 自修调验证 (Self-Cal Validation)
   └── [9] 输出电压带载修调 (VOUT Trim under Load)
```

**说明**：
- VBG/VREF/IREF等基准修调在任何其他修调之前完成，它们是后续所有修调的基础。
- Vref_R电阻精度修调影响电流源精度，应在RC Ton和POCP Sense修调之前。
- VO_R修调应在轻载条件下先完成，带载VOUT修调在最后执行（因为它的补偿效果最接近最终使用条件，且不会影响其他修调项）。
- LX Rds(on)修调在负DMD修调和OCP修调之前，因为两者都依赖于Rds(on)精度。
- 如果芯片支持OCP自修调（Self-Cal），ATE的主要任务变为验证自修调结果，但仍建议先完成基准和电阻类的校准修调。

## 十、常用仪器与设备建议

| 修调项 | 推荐仪器 | 关键指标要求 |
|--------|----------|-------------|
| LX电阻修调 | SMU (Source Measure Unit) / DMM + 电流源 | 电流精度±0.1%，电压测量分辨率≥10uV |
| VO_R修调 | DMM (6.5位或更高) | 电压测量精度±0.01% |
| Vref_R修调 | SMU (四线Kelvin) | 四线测量能力，分辨率≥1uV |

| 带载VOUT修调 | DMM + 电子负载 | DMM高精度，电子负载CC模式稳定 |
| OCP修调 | SMU (双向/源能力) / 电子负载 + 示波器 | 电流范围覆盖1.5×OCP阈值 |
| 负DMD修调 | 双向SMU / 源表 | 电流源/吸收双向能力，mA级分辨率 |

## 十一、常见问题与排查（FAQ）

### Q1: 为什么迟滞Buck的VOUT修调必须在轻载和带载下分别进行？
因为轻载下主要校准的是反馈电阻分压比率和VREF精度（芯片自身精度），而重载下额外引入了IR Drop和调节偏移（系统级偏差）。分别校准可以得到最优的全负载范围VOUT精度。

### Q2: 负DMD修调后，为什么轻载效率反而下降了？
可能的原因：负DMD修调导致过零检测点偏正（即电感电流还未到零就关闭了下管），或偏负（允许了较多负电流）。前者导致能量传递减少（效率损失），后者导致负电流损耗。需要重新校准到接近零的位置。

### Q3: OCP自修调和ATE手动修调应该如何选择？
取决于成本和精度要求。自修调降低测试成本但芯片面积增加（内置修调DAC和逻辑），ATE手动修调精度可控但测试时间长。常见方案：自修调作为粗调（Coarse Trim），ATE做精调（Fine Trim）；或完全依赖自修调，ATE仅做Go/No-Go验证。

### Q4: RC Ton修调为何要在多个VIN/VOUT条件下验证？
因为Ton不仅取决于RC，还与VIN和VOUT有一定耦合关系（通过比较器阈值和传输延迟）。某些工艺角下VIN/VOUT影响更大，单一条件下的修调可能无法覆盖全工作范围。

### Q5: LX电阻修调时，死区时间为什么需要避开？
在死区时间内，上下管都关闭，LX节点处于高阻状态，体二极管导通产生约0.7V的压降，该压降不反映Rds(on)而是二极管正向压降。在此窗口内测量会得到错误的Rds(on)值。测量窗口应选在MOSFET完全导通且电流稳定的区间内。
