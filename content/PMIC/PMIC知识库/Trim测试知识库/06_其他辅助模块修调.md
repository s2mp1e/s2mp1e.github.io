# 其他辅助模块修调

本文档涵盖 PMIC 中除电源转换核心模块（BUCK、BOOST、LDO）之外的**辅助模块**修调（trim）与校准（calibration）内容，包括 EIS 电流修调、XOADC/HKADC 内部上拉电阻修调、库仑计修调以及 BATID 检测。

---

## 1. EIS 电流修调（Electrochemical Impedance Spectroscopy Current Trim）

### 1.1 原理

**EIS（电化学阻抗谱）** 是一种通过向电池注入小振幅 AC 电流激励并测量其电压响应，从而计算电池阻抗的技术。EIS 广泛应用于电池健康状态（SOH，State of Health）和电荷状态（SOC，State of Charge）评估。

**基本原理：**

- PMIC 内部的 EIS 模块向电池通路注入一个已知频率和幅度的**正弦电流激励**。
- 测量电池两端的**电压响应**（包括幅度衰减和相位偏移）。
- 通过比较激励信号与响应信号，计算电池的**复阻抗** $Z = |Z| \angle \theta = \frac{V_{response}}{I_{stimulus}}$。
- 扫描多个频率点，构建 Nyquist 图或 Bode 图，拟合等效电路模型（如 Randles 模型）。

**为什么需要修调：**

EIS 测量的准确性直接取决于**注入电流的精度**。片上电流 DAC（IDAC）存在工艺偏差（PVT variation），导致实际注入电流偏离目标值。若不修调，阻抗计算会产生系统性误差。因此需要通过 trim 将激励电流校准到目标值。

### 1.2 测试方法

**目标：** 将 EIS 激励电流修调到标称值（例如 10mA、20mA、50mA 等），保证幅度误差在 spec 范围内（通常 < ±5%）。

**测试步骤：**

1. **连接已知负载：** 在电池路径上串联/并联一个已知精度的电阻 $R_{load}$（例如 10mΩ ~ 100mΩ 精密功率电阻）。
2. **配置 EIS 模块：** 使能 EIS 电流源，设置目标电流 $I_{target}$ 和目标频率 $f_0$。
3. **测量电压：** 使用精密电压表（DMM）或差分探头测量负载电阻两端的电压 $V_{meas}$。
4. **计算实际电流：** $I_{actual} = V_{meas} / R_{load}$。
5. **计算误差：** $\Delta I = I_{actual} - I_{target}$。
6. **遍历 trim code：** 逐一写入 EIS trim 寄存器中的不同 code，重复测量，找到使 $|I_{actual} - I_{target}|$ 最小的 code。
7. **多频点验证（可选）：** 对多个频率点（如 1Hz, 10Hz, 100Hz, 1kHz）重复测试，验证带宽内电流幅度平坦度。

**测试条件建议：**

| 参数 | 建议值 |
|------|--------|
| 负载电阻精度 | 至少 0.1% |
| 电流范围 | 根据 PMIC spec（通常 1mA ~ 100mA） |
| 频率范围 | 0.1Hz ~ 10kHz |
| 温度 | 室温（25°C），必要时做三温（-40°C / 25°C / 85°C） |

### 1.3 注意事项

1. **开尔文连接（Kelvin sensing）：** 测量负载电阻电压时务必使用四线开尔文连接，消除走线电阻和接触电阻的影响。
2. **DC bias 电流：** EIS 通常在电池 DC 偏置之上叠加 AC 激励，需确认 DC bias 电流不与 AC 激励冲突，且 DMM 需能正确测量 AC+DC 信号。
3. **频率效应：** 在高频时（>1kHz），PCB 寄生电容和电感会影响电流测量，建议使用高频电流探头或降低频率点 trim。
4. **负载电阻功率：** 确保电阻额定功率足够，避免大电流下电阻发热导致阻值漂移。
5. **环境噪声：** EIS 测量易受 50/60Hz 工频干扰，建议使用屏蔽电缆和差分测量。
6. **trim code 单调性验证：** trim code 增大时，电流应单调递增，若存在非单调性需要标记不良品。

## 2. XOADC 修调（内部上拉电阻修调）

### 2.1 原理

**XOADC（Crystal Oscillator ADC）** 是 PMIC 内部用于高精度电压测量的 ADC，通常负责测量电池电压（VBAT）、GPIO 电压等关键模拟量。

**ADC 架构：**

XOADC 多采用 **逐次逼近型（SAR，Successive Approximation Register）ADC**。其工作原理为：

- 使用一个比较器和一个 DAC（电容阵列或电阻阵列）逐位逼近输入电压。
- 从 MSB 开始，依次比较 $V_{in}$ 与 DAC 输出，每位决定后更新 DAC 值，最终输出数字码。
- 分辨率为 10~12 bit，采样率通常在几十 kSPS 到几百 kSPS。

**比例测量（Ratiometric Measurement）原理：**

XOADC 在测量外部电压时，通常使用**内部上拉电阻 $R_{pullup}$** 与外部下拉电阻（或电池内阻）形成分压：

$$V_{meas} = V_{ref} \times \frac{R_{external}}{R_{pullup} + R_{external}}$$

ADC 测量得到的是分压后的电压，再反推外部电阻或电池电压。由此可知，**$R_{pullup}$ 的绝对值直接影响测量精度**。

由于片上电阻存在工艺偏差（通常 ±20% ~ ±30%），必须通过修调将 $R_{pullup}$ 调整到目标值（例如 10kΩ、100kΩ 等）。

### 2.2 测试方法

**目标：** 将 XOADC 内部上拉电阻修调到标称值（如 10kΩ），误差在 spec 范围内（通常 ±1% ~ ±2%）。

**测试步骤（已知电阻分压法）：**

1. **连接外部精密电阻：** 在 XOADC 测量引脚与 GND 之间连接已知精度的外部电阻 $R_{ext}$（例如 10kΩ，精度 0.1%）。
2. **使能 XOADC 内部上拉：** 配置寄存器使能 XOADC 的内部上拉电阻 $R_{pullup}$，形成分压。
3. **测量分压电压：** 使用精密 ADC 或 DMM 测量引脚电压 $V_{pin}$。
4. **计算实际 $R_{pullup}$：**
   $$R_{pullup\_actual} = R_{ext} \times \frac{V_{ref} - V_{pin}}{V_{pin}}$$
   其中 $V_{ref}$ 为内部参考电压（如 1.0V 或 1.8V）。
5. **计算误差：**
   $$\Delta R = \frac{R_{pullup\_actual} - R_{target}}{R_{target}} \times 100\%$$
6. **遍历 trim code：** 修改 XOADC 上拉电阻 trim 寄存器中的 code，使误差最小。
7. **最终验证：** 使用不同阻值的 $R_{ext}$（例如 5kΩ、10kΩ、20kΩ）验证修调后的精度。

**ING/DNL 测试方法：**

- **INL（积分非线性，Integral Nonlinearity）：** 对 ADC 输入施加斜坡电压（ramp），记录每个 code 对应的输入电压，计算实际转换曲线与理想直线之间的最大偏差。
- **DNL（微分非线性，Differential Nonlinearity）：** 测量相邻两个 code 之间的实际步进与理想步进（1 LSB）的偏差，DNL 应满足 ±0.5 LSB 以内（无失码）。
- **Offset/Gain 校准：**
  - **Offset trim：** 输入短路（$V_{in} = 0$），测量 ADC 输出码，调整 offset 寄存器使输出为 0。
  - **Gain trim：** 输入满量程参考电压（$V_{in} = V_{ref}$），调整 gain 寄存器使输出为满码（如 1023 对于 10-bit ADC）。

### 2.3 注意事项

1. **外部电阻精度：** $R_{ext}$ 的精度直接影响修调结果，建议使用 0.1% 或更高精度的电阻。
2. **参考电压稳定性：** XOADC 的参考电压 $V_{ref}$ 本身也需要修调（参见基准修调章节），$V_{ref}$ 的误差会传递到 $R_{pullup}$ 的计算中。
3. **引脚漏电：** 测量前需确认 XOADC 引脚无异常漏电（leakage current），否则分压计算会产生偏差。
4. **缓冲时间（settling time）：** 使能上拉电阻后，需要等待 RC 充放电稳定后再进行测量，通常等待 3~5 个时间常数 $\tau = R_{pullup} \times C_{pin}$。
5. **ESD 保护电路影响：** ESD 二极管在极端电压下可能导通，需确保测试电压在正常工作范围内。
6. **多温度点修调：** 上拉电阻的 TCR（温度系数）会导致不同温度下的阻值漂移，建议在常温 trim 后验证高低温精度，必要时分段 trim。

## 3. HKADC 修调（内部上拉电阻修调）

### 3.1 原理

**HKADC（Housekeeping ADC）** 是 PMIC 中用于**通用系统监控**的 ADC，负责监测以下参数：

- 系统电压（VBUS、VSYS、VBAT 等）
- 芯片温度（die temperature）
- 外部 NTC 热敏电阻电压
- 充电电流（charging current）
- GPIO 状态电压

**与 XOADC 的主要区别：**

| 特性 | XOADC | HKADC |
|------|-------|-------|
| 精度要求 | 高（±1%~ ±2%） | 中等（±2%~ ±5%） |
| 分辨率 | 10~12 bit | 8~12 bit |
| 采样率 | 较低 | 较高 |
| 主要用途 | 电池电压、精密测量 | 系统监控、温度检测 |
| 通道数 | 少（1~2 路） | 多（8~16 路） |
| 内部上拉电阻 | 用于电池检测 | 用于 NTC/GPIO 检测 |

**比例测量原理：**

与 XOADC 类似，HKADC 也使用内部上拉电阻 $R_{pullup}$ 进行**比例测量（ratiometric measurement）**。典型应用场景：

- **NTC 温度检测：** 内部上拉电阻与外部 NTC 热敏电阻形成分压，ADC 测量分压点的电压，查表得到温度。
- **GPIO 电压识别：** 通过分压比计算外部输入电压。

由于片上电阻工艺偏差，$R_{pullup}$ 的绝对值不准确，必须通过修调校准，否则温度检测和电压识别都会出现系统性偏差。

**ADC 架构：**

HKADC 通常使用 **逐次逼近型（SAR）** 或 **Sigma-Delta（Σ-Δ）** ADC：

- **SAR ADC：** 速度较快，功耗适中，适合多通道轮询。
- **Sigma-Delta ADC：** 精度更高，但采样率较低，适合低频信号的高精度测量。

### 3.2 测试方法

#### 3.2.1 内部上拉电阻修调

方法与 XOADC 相同（已知电阻分压法）：

1. 在 HKADC 测量通道与 GND 之间连接精密电阻 $R_{ext}$（如 10kΩ, 0.1%）。
2. 使能对应通道的内部上拉电阻。
3. 测量该通道的 ADC 转码值，换算为电压 $V_{meas}$。
4. 计算实际 $R_{pullup}$：
   $$R_{pullup\_actual} = R_{ext} \times \frac{V_{ref} - V_{meas}}{V_{meas}}$$
5. 调整 trim code 使 $R_{pullup\_actual}$ 趋近于 $R_{target}$。
6. 对每个需要 trim 的通道重复（不同通道可能共享同一上拉电阻，也可能独立）。

#### 3.2.2 引脚漏电测试（Pin Leakage Test）

**目的：** 验证 HKADC 输入引脚的漏电流是否在 spec 范围内，避免漏电影响测量精度。

**方法：**
1. 将所有 HKADC 引脚置于 Hi-Z 状态。
2. 使用 SMU（Source Measure Unit）在引脚上施加电压（如 $V_{ref}$）。
3. 测量流入/流出引脚的电流，典型 spec 为 < 100nA ~ 1μA。

#### 3.2.3 ADC 转码精度测试（Transfer Code Accuracy Test）

**方法：**
1. 使用精密电压源向 HKADC 输入已知电压（如 0V, 0.25×Vref, 0.5×Vref, 0.75×Vref, Vref）。
2. 读取 ADC 输出数字码。
3. 计算误差：
   - **Offset error：** 输入 0V 时的输出码（理想应为 0）。
   - **Gain error：** 输入 Vref 时的输出码与满码值的偏差。
   - **Linearity error：** 中间点的输出码与理想直线的偏差。

#### 3.2.4 INL/DNL 测试

- 与 XOADC 测试方法一致：施加斜坡电压，记录逐码跳变点。
- 对 HKADC 可以使用更高效的**直方图法（histogram method）**：施加正弦波或三角波，统计输出码分布，反推 INL/DNL。

### 3.3 注意事项

1. **多通道串扰（crosstalk）：** HKADC 有多路输入通道，需验证通道间隔离度，确保一路的大信号不干扰相邻通道。
2. **输入阻抗：** HKADC 在采样瞬间会从源端抽取电流，需确保外部驱动电路有足够的驱动能力（或使用 buffer）。
3. **采样时间（sampling time）：** 上拉电阻与外部电容构成 RC 低通滤波器，需设置足够的采样时间（acquisition time）让电压稳定。
4. **温度传感器校准：** NTC 测量通道的上拉电阻 trim 后，还需要配合温度查表（LUT）验证温度精度。
5. **电源抑制比（PSRR）：** HKADC 的电源噪声抑制能力有限，测量时需确保电源干净，必要时加 RC 滤波。
6. **trim code 共享 vs 独立：** 确认每个通道的 trim code 是独立的还是共享的，若共享则以优先级最高的通道为准。

## 4. 库仑计修调（Coulomb Counter / Fuel Gauge Trim）

### 4.1 原理

**库仑计（Coulomb Counter / Fuel Gauge）** 用于精确测量电池的充放电电荷量，是实现剩余电量（SOC，State of Charge）估算的核心模块。

**基本原理：**

库仑计通过测量**流入/流出电池的电流对时间的积分**来计算电荷变化：

$$Q(t) = Q(0) + \int_{0}^{t} I_{batt}(\tau) \, d\tau$$

其中 $Q$ 为电荷量（单位：Coulomb 或 mAh），$I_{batt}$ 为电池电流（正为充电，负为放电）。

**硬件实现：**

1. **电流检测电阻（Sense Resistor $R_{sense}$）：** 串联在电池通路中，将电流转换为差分电压 $V_{sense} = I \times R_{sense}$。
2. **差分 ADC / 电流检测放大器（Current Sense Amplifier, CSA）：** 放大 $V_{sense}$ 并转换为数字信号。
3. **积分器 / 累加器：** 对 ADC 输出做累加，得到总电荷量。
4. **Sigma-Delta 调制器：** 许多 PMIC 使用 Σ-Δ 调制器对电流信号进行连续采样，实现高精度、低噪声的电流测量。

**为什么需要修调：**

- **Offset trim：** CSA 和 ADC 存在输入失调电压（offset voltage），在零电流条件下会误报有电流流动，导致 SOC 漂移。
- **Gain trim：** $R_{sense}$ 的绝对值偏差和 CSA 的增益偏差会导致电流测量比例误差，需做增益校准。
- **温度影响：** $R_{sense}$ 的 TCR 和 CSA 的温漂会导致不同温度下精度不一致。

### 4.2 测试方法

#### 4.2.1 Offset Trim（零电流失调修调）

**目标：** 使零电流输入时库仑计输出为零。

**方法：**
1. **断开电池/负载：** 确保电池通路无电流流动（$I = 0$）。
2. **使能库仑计：** 开始 ADC 转换和累加。
3. **读取测量值：** 记录一段时间内（如 1 秒）的累计电荷量或平均电流值。
4. **计算 offset：** 若读取值非零，则将其作为 offset 存入寄存器。
5. **调整 offset trim code：** 修调 DAC 或寄存器抵消 offset。
6. **验证：** 确认零电流下读取值 < spec（例如 < 1mA）。

**注意事项：**
- 需确保测试系统本身无漏电回路（漏电 < offset spec）。
- 多次测量取平均以消除随机噪声影响。

#### 4.2.2 Gain Trim（增益修调）

**目标：** 校准电流测量比例系数，使测量值与实际值一致。

**方法：**
1. **连接精密电流源：** 在电池通路中注入已知电流 $I_{force}$（如 500mA、1A、2A 等）。
2. **测量库仑计输出：** 读取 ADC 输出的电流数字码 $Code_{meas}$。
3. **计算增益误差：**
   $$Gain_{error} = \frac{Code_{meas}}{I_{force} \times R_{sense} \times CSA_{gain}} - 1$$
4. **调整 gain trim code：** 修调 CSA 增益或 ADC 参考，使 $Code_{meas}$ 与预期值匹配。
5. **多点验证：** 使用多个电流点（如 10mA、100mA、1A、2A）验证线性度。

**测试条件建议：**

| 参数 | 建议值 |
|------|--------|
| 电流范围 | 10mA ~ 最大充放电电流 |
| 电流源精度 | ±0.1% |
| $R_{sense}$ | 根据 spec（通常 5mΩ ~ 20mΩ） |
| 测量时间 | 每个点至少 100ms |

#### 4.2.3 温度补偿（Temperature Compensation）

**原理：** $R_{sense}$ 的电阻温度系数（TCR）和 CSA 的温漂会导致不同温度下的增益变化。温度补偿通过以下方法实现：

1. 在多个温度点（-40°C、25°C、85°C）测量 gain error。
2. 建立温度与 gain error 的关系曲线或分段线性模型。
3. 在运行时根据 die temperature 查表调整 gain。

**测试方法：**
1. 将 DUT 置于温度 chamber 中。
2. 在每个温度点重复 gain trim 方法。
3. 记录 trim code 与温度的关系。
4. 生成温度补偿查找表（LUT）或拟合多项式系数。

### 4.3 注意事项

1. **测试系统漏电流：** 库仑计 offset trim 对测试系统本身的漏电非常敏感。确认测试板（DIB / loadboard）上的漏电 < offset spec 的 1/10。
2. **接触电阻：** 大电流测试时，接触电阻和连接器电阻的发热会影响 $R_{sense}$ 的有效值。使用开尔文连接（Kelvin connection）进行电流感测。
3. **积分时间选择：** 库仑计测量需要一定的积分时间，较长时间的积分可以降低噪声，但会增加测试时间。需要根据 spec 的噪声要求选择合适的积分时间。
4. **电流方向：** 确认充/放电两个方向都有足够的精度，必要的话分别做双向 trim（bidirectional trim）。
5. **睡眠模式电流：** 超低功耗睡眠模式下库仑计的 offset 可能会变化，需单独验证。
6. **长期漂移：** 部分 PMIC 支持定期自校准（auto-calibration），在测试时需确认自校准功能是否正常工作。
7. **分辨率与 LSB 权重：** 确认库仑计的分辨率（如 1mA·h LSB 或 1μV LSB 对应 $R_{sense}$ 换算）。

## 5. BATID（Battery ID 检测）

### 5.1 原理

**BATID（Battery Identification）** 用于识别插入的电池类型或模组型号，以便 PMIC 自动配置充电参数（恒流值、恒压值、终止电流等）。

**工作原理：**

- 电池包内部通常包含一个 **ID 电阻（BATID resistor）** 或 EEPROM 芯片，连接到 BATID 引脚。
- PMIC 内部有一个 BATID 检测模块，通常由**内部上拉电阻** 或**内部电流源** 和 **比较器 / ADC** 组成。
- 当电池插入时，BATID 引脚上的电压由内部上拉电阻 $R_{pullup}$ 和电池 ID 电阻 $R_{BATID}$ 分压决定：
  $$V_{BATID} = V_{ref} \times \frac{R_{BATID}}{R_{pullup} + R_{BATID}}$$
- PMIC 通过 ADC 测量 $V_{BATID}$ 或使用比较器与参考电压比较，从而判断 $R_{BATID}$ 的阻值范围，确定电池类型。
- 不同阻值的 $R_{BATID}$ 对应不同电池型号（例如 10kΩ = 标准电池，20kΩ = 高容量电池，47kΩ = 快充电池等）。

**为什么需要修调：**

BATID 检测的准确性直接取决于：
- **内部上拉电阻 $R_{pullup}$ 的精度**（需修调，方法同 XOADC/HKADC）
- **ADC 或比较器的参考电压精度**
- **比较器的 offset 电压**

如果 $R_{pullup}$ 偏差过大，$V_{BATID}$ 会偏离理论值，可能导致电池类型误判（如将标准电池识别为快充电池，存在安全隐患）。

### 5.2 测试方法

#### 5.2.1 上拉电阻修调（如独立于 XOADC/HKADC）

若 BATID 模块有独立的上拉电阻，修调方法与 XOADC/HKADC 相同（已知电阻分压法）：

1. 在 BATID 引脚与 GND 之间连接精密电阻 $R_{ext}$。
2. 使能 BATID 内部上拉，测量 $V_{BATID}$。
3. 计算实际 $R_{pullup}$，调整 trim code。

#### 5.2.2 BATID 识别验证

**目标：** 验证 PMIC 能否正确识别各种电池类型的 ID 电阻。

**方法：**

1. **准备校准电阻：** 准备一组精密电阻，覆盖所有电池类型的 ID 电阻标称值（包括阻值上限和下限）。
2. **连接每个电阻进行测试：**
   - 将电阻连接到 BATID 引脚与 GND 之间。
   - 触发 BATID 检测流程（通常为 power-up 或插入检测中断后）。
   - 读取 BATID 寄存器中的检测结果（电池类型编码）。
3. **结果判定：**
   - 确认检测结果是否与预期电池类型一致。
   - 对电阻容差边缘值（标称值 ± tolerance）也需测试，确认检测窗口（detection window）的正确性。
4. **容差边界测试（guard band test）：**
   - 对每种电池类型的检测阈值附近进行步进扫描（如以 1kΩ 步进），找到翻转点（transition point）。
   - 确认翻转点留有余量（guard band），避免因电阻容差导致误判。
5. **短路/开路检测：**
   - BATID 引脚对 GND 短路：应检测为"无电池"或"未知电池"。
   - BATID 引脚开路（悬空）：应检测为"无电池"或触发报警。

**测试矩阵示例：**

| 外部电阻 | 预期电池类型 | PASS/FAIL 条件 |
|----------|-------------|----------------|
| GND (短路) | NO_BAT / SHORT | > |
| 10kΩ ±1% | BAT_TYPE_A | ADC code 在 A 区间 |
| 20kΩ ±1% | BAT_TYPE_B | ADC code 在 B 区间 |
| 47kΩ ±1% | BAT_TYPE_C | ADC code 在 C 区间 |
| 开路 (Open) | NO_BAT / OPEN | > |

### 5.3 注意事项

1. **安全风险：** BATID 误判（如将标准电池判为大电流快充电池）可能导致充电电流过大，引发安全风险。修调后需严格验证各检测区间的边界。
2. **去抖动（debounce）：** 电池插入瞬间可能存在接触抖动，BATID 检测通常需要去抖动滤波（debounce time）。验证时需考虑 debounce 时间对测试时间的影响。
3. **ESD 和浪涌：** BATID 引脚可能暴露在外部，需注意 ESD 保护。测试时避免超过引脚耐压值。
4. **电池 EEPROM 方案：** 部分高端电池包使用 EEPROM（如 HDQ / 1-Wire 协议）而非 ID 电阻。此类方案需测试通信时序和数据读取的正确性。
5. **上拉电阻复用：** 确认 BATID 的上拉电阻是否与 XOADC/HKADC 共享。若共享，修调时需同步影响。
6. **电阻精度 vs 检测窗口：** ID 电阻的容差（通常 ±1% ~ ±5%）必须小于检测窗口（相邻电池类型的电压区间），否则可能误判。建议检测窗口至少为 3σ 以上。
7. **系统级验证：** 建议在系统级（接实际电池）验证 BATID 功能，因为实际电池包的 BATID 引脚可能还包含并联电容（滤波用），影响 ADC 建立时间。

---

## 总结

PMIC 辅助模块的修调虽然不像 BUCK/BOOST 功率修调那样直接影响电源输出质量，但对于系统的**可靠性、安全性和用户体验**至关重要。以下是各模块修调的关键要点对比：

| 模块 | 修调对象 | 核心方法 | 关键指标 | 优先级 |
|------|---------|---------|----------|--------|
| EIS | 激励电流 | 已知负载电阻 + 电压测量 | 电流幅度误差 < ±5% | 高（SOH 精度） |
| XOADC | 上拉电阻 + ADC 校准 | 已知电阻分压法 | $R_{pullup}$ 精度 < ±2% | 高（电池电压精度） |
| HKADC | 上拉电阻 + ADC 校准 | 已知电阻分压法 | $R_{pullup}$ 精度 < ±5% | 中（系统监控） |
| 库仑计 | Offset / Gain | 零电流/已知电流法 | Offset < ±1mA, Gain < ±1% | 高（SOC 精度） |
| BATID | 上拉电阻 + 检测窗口 | 已知 ID 电阻模拟 | 检测区间无重叠误判 | 高（安全相关） |

修调完成后，建议进行**最终验证（final verification）**，确保所有参数在 spec 范围内，并记录 trim code 用于后续良率分析（yield analysis）。
