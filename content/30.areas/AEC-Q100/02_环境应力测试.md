# 环境应力测试 / Environmental Stress Tests (Group A)

---

## 一、测试项目一览

| 缩写 | 测试名称 | 应力条件 (典型) | 时长 |
|------|---------|----------------|------|
| **PC** | Preconditioning | 回流焊 + 湿度敏感预处理 | — |
| **TC** | Temperature Cycling | -55°C ↔ +150°C | 500/1000 循环 |
| **PTC** | Power Temperature Cycling | -40°C ↔ +125°C + 通电 | 1000 循环 |
| **HTSL** | High Temp Storage Life | 150°C (Grade 0: 175°C) | 1000h |
| **THB** | Temp Humidity Bias | 85°C/85%RH + 偏压 | 1000h |
| **HAST** | Highly Accelerated Stress | 130°C/85%RH + 偏压 | 96h |
| **AC** | Autoclave (无偏压 HAST) | 121°C/100%RH/2atm | 96h |
| **UHST** | Unbiased HAST | 130°C/85%RH | 96h |

---

## 二、PC (Preconditioning / 预处理)

### 目的

模拟 SMT 贴片回流焊对封装的影响，是**所有其他测试的前提**。

### 流程

```
① 初始电气测试 (记录基准数据)
② 烘烤 (125°C × 24h, 去湿)
③ 湿度浸泡 (MSL 等级决定, 如 MSL3: 30°C/60%RH × 192h)
④ 回流焊 × 3 次 (峰值 260°C, 模拟贴片)
⑤ 电气测试 (验证无损伤)
⑥ 外观检查 (C-SAM 检查分层)
```

### 关键测试设备

```
回流焊炉 (Reflow Oven):
  温度曲线: 预热 → 保温 → 回流 (峰值 260°C) → 冷却
  3 次循环

C-SAM (超声扫描):
  检测封装分层 (Delamination)
  芯片裂纹 (Die Crack)
```

---

## 三、TC (Temperature Cycling / 温度循环)

### 目的

验证封装在极端温度交替下的结构完整性 (热膨胀系数失配)。

### 条件

```
Grade 0/1: -55°C ↔ +150°C (或 -65°C ↔ +150°C)
Grade 2/3: -50°C ↔ +125°C

循环数: 500 (Qual) / 1000 (Grade 0/1)
单循环: 高温保持 15min → 低温保持 15min (空气-空气)
```

### 测试流程

```
① 初始电测
② 温循 500/1000 循环 (每循环 ~1h)
③ 中途检查 (250/500 循环后电测)
④ 完成 → 最终电测
⑤ C-SAM + 外观检查

判定: 电参数在规格内 + 无分层/裂纹
```

---

## 四、HTSL (High Temp Storage Life / 高温存储)

### 目的

验证芯片在高温下长期存储的可靠性 (金属间化合物生长、电荷损失等)。

### 条件

```
温度: 150°C (Grade 0: 175°C)
时间: 1000 小时

无偏压 (纯存储)
```

### 关键失效模式

| 失效 | 机理 |
|------|------|
| Flash 数据丢失 | 浮栅电荷泄漏 |
| 键合退化 | 金属间化合物 (Au-Al) 生长 |
| 参数漂移 | 界面态变化 |
| OTP 数据错误 | 抗熔丝退化 |

---

## 五、THB (Temperature Humidity Bias / 温湿度偏压)

### 目的

验证封装在湿热+通电条件下的抗腐蚀/抗漏电能力。

### 条件

```
温度: 85°C
湿度: 85%RH
偏压: 最大工作电压 (加在引脚间)
时间: 1000 小时
```

### 测试要点

```
① 偏压配置: 相邻引脚加反向电压 (最大电场)
② 周期监测: 每 168h 检查漏电
③ 判定: 漏电流不超规 + 无电迁移/腐蚀

ATE 角色: 提供测试板 + 定期电测
```

---

## 六、HAST / AC / UHST (加速湿热)

### 6.1 三种测试的区别

| 测试 | 偏压 | 条件 | 时间 | 加速因子 |
|------|------|------|------|---------|
| **HAST** | 有 | 130°C/85%RH | 96h | ~THB×10 |
| **UHST** | 无 | 130°C/85%RH | 96h | 高 |
| **AC** | 无 | 121°C/100%RH/2atm | 96h | 高 |

### 6.2 HAST 测试流程

```
① 初始电测
② 装板 (偏压板) + 放入 HAST 腔体
③ 130°C/85%RH × 96h + 偏压
④ 取出 → 电测 (24h 内完成)
⑤ 判定

HAST 设备: 专用压力腔 (蒸汽 + 压力 + 温度)
```

## 七、Group A 测试流程整合

```
所有 Group A 测试的通用流程:

┌──────────────────────────────────────┐
│ ① 初始电测 (Full Parametric Test)     │
│    ↓                                 │
│ ② PC 预处理 (回流焊模拟)               │
│    ↓                                 │
│ ③ 分配样本到各测试                     │
│    ├── TC (温循)                      │
│    ├── HTSL (高温存储)                │
│    ├── THB (温湿偏压)                 │
│    └── HAST (加速湿热)                │
│    ↓                                 │
│ ④ 应力测试 (各条件)                    │
│    ↓                                 │
│ ⑤ 最终电测 (Full Parametric Test)     │
│    ↓                                 │
│ ⑥ 外观/C-SAM 检查                     │
│    ↓                                 │
│ ⑦ 数据判读 → 报告                     │
└──────────────────────────────────────┘
```
