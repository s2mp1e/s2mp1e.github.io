# 封装完整性测试 / Package Assembly Integrity (Group C)

---

## 一、测试项目一览

| 缩写 | 测试名称 | 测试内容 |
|------|---------|---------|
| **WBS** | Wire Bond Shear | 键合球剪切力测试 |
| **WBP** | Wire Bond Pull | 键合线拉力测试 |
| **SD** | Solder Ball Shear | 锡球剪切力测试 |
| **PD** | Physical Dimensions | 外形尺寸验证 |
| **SBS** | Solder Ball Shear | 焊球剪切 (BGA) |
| **LI** | Lead Integrity | 引脚完整性 |
| **DS** | Die Shear | 芯片剪切力 |

---

## 二、WBS (Wire Bond Shear / 键合球剪切)

### 目的

验证金线/铜线键合球与焊盘之间的结合强度。

### 测试方法

```
① 显微镜定位键合球
② 剪切工具水平推进 (在球上方 2~5μm)
③ 记录球被剪掉时的力
④ 检查断裂模式 (Failure Mode)

剪切力规格 (参考 MIL-STD-883):
  球径 25μm (1mil): > 12g (Au 线)
  球径 50μm (2mil): > 45g

断裂模式:
  球内断裂: 合格 (键合强度好)
  焊盘剥离: 不合格 (焊盘问题)
  界面分离: 不合格 (键合问题)
```

### 样本与时机

```
样本: 10 颗 × 3 批 (每颗测 5~10 个球)
时机:
  ① 封装后 (初始验证)
  ② TC 后 (热循环后验证)
  ③ 可靠性测试后 (抽查)
```

---

## 三、WBP (Wire Bond Pull / 键合线拉力)

### 目的

验证键合线本体的强度和两端键合质量。

### 测试方法

```
① 钩子勾住线弧中点
② 垂直向上拉
③ 记录线断时的力
④ 检查断点位置

拉力规格 (参考):
  25μm 金线: > 3g
  50μm 金线: > 12g

断点分析:
  线颈断 (Neck Break): 常见, 合格
  球颈断 (Ball Neck): 合格
  线中断 (Mid Span): 合格
  焊盘脱落: 不合格
```

---

## 四、SD / SBS (Die Shear / Ball Shear)

### DS (Die Shear / 芯片剪切)

```
目的: 验证芯片与框架/基板的粘接强度

方法:
  ① 剪切工具对准芯片侧面
  ② 水平推进
  ③ 记录芯片脱落的力

规格: 取决于芯片面积 (如 2×2mm: > 2.5kg)
```

### SBS (Solder Ball Shear / 焊球剪切)

```
目的: 验证 BGA 焊球与基板的结合强度

方法:
  ① 剪切工具对准焊球
  ② 水平推进
  ③ 记录剪切力

规格: 取决于球径 (如 0.5mm 球: > 800g)
```

---

## 五、PD (Physical Dimensions / 外形尺寸)

### 目的

验证封装外形尺寸符合规范 (JEDEC 标准)。

### 测试内容

```
① 封装长宽高
② 引脚间距 (Pitch)
③ 引脚共面性 (Coplanarity)
④ 引脚宽度/厚度
⑤ 翘曲 (Warpage) — 尤其 BGA/QFN

工具: 光学测量仪 / 激光共面度仪 / 三坐标测量
```

---

## 六、LI (Lead Integrity / 引脚完整性)

### 目的

验证引脚在弯曲应力下的结构完整性 (SMT 组装可靠性)。

### 测试方法

```
① 引脚弯曲测试 (Lead Fatigue):
   引脚反复弯曲 ±15° × 3 次
   → 引脚不断裂/开裂

② 引脚拉力测试:
   轴向拉力 → 引脚不从塑封体拔出
```

## 七、Group C 测试时机与关联

```
Group C 测试的三个时机:

┌─────────────────────────────────────┐
│ ① T=0 (封装完成后):                   │
│    初始封装质量验证                   │
│    WBS/WBP/SD/PD 全测                │
├─────────────────────────────────────┤
│ ② 环境应力后 (TC/HAST 后):            │
│    验证应力对封装的影响               │
│    WBS/WBP 抽查                      │
├─────────────────────────────────────┤
│ ③ 寿命测试后 (HTOL 后):               │
│    长期可靠性后的封装完整性           │
│    WBS/SBS 抽查                      │
└─────────────────────────────────────┘
```
