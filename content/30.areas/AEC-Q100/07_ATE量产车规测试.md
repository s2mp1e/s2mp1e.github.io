# ATE 量产车规测试 / Automotive Production ATE Test

---

## 一、车规量产测试与消费级的区别

| 维度 | 消费级量产 | 车规量产 |
|------|-----------|---------|
| 温度覆盖 | 25°C (单温) 为主 | **三温全测** (Cold/Room/Hot) |
| 测试覆盖率 | 关键参数 | **全参数** |
| Burn-In | 无/可选 | **100% 必做** |
| PAT/Outlier | 部分 | **必做** |
| 数据保留 | 短 (1~3 年) | **长 (15 年+)** |
| 可追溯性 | Lot 级 | **颗级 (Unit Level)** |
| QA Gate | 简单 | 严格 (车厂要求) |
| 测试时间 | 优化优先 | 覆盖率优先 |

---

## 二、车规量产测试流程

```
典型车规 PMIC/MCU 产线流程:

┌─────────────────────────────────────────┐
│ ① CP (晶圆测试)                          │
│    三温 CP (可选, 高价值芯片)              │
│    Trim + 全参数                          │
├─────────────────────────────────────────┤
│ ② 封装 (Assembly)                        │
│    车规封装厂认证 (IATF 16949)            │
├─────────────────────────────────────────┤
│ ③ FT1 (封装后预筛)                       │
│    全参数, Room + Hot                     │
├─────────────────────────────────────────┤
│ ④ Burn-In (100%)                        │
│    125~150°C, 6~48h                      │
├─────────────────────────────────────────┤
│ ⑤ FT2 (BI 后终测)                        │
│    三温全参数 (Cold/Room/Hot)             │
│    PAT (Outlier 筛查)                     │
├─────────────────────────────────────────┤
│ ⑥ QA Gate                               │
│    抽检 + 数据审核                        │
├─────────────────────────────────────────┤
│ ⑦ 出货                                  │
│    带完整测试数据 + 追溯信息              │
└─────────────────────────────────────────┘
```

## 三、三温测试的车规特殊性

### 3.1 温度分级与测试点

| Grade | 温度范围 | 三温测试点 |
|-------|---------|-----------|
| Grade 0 | -40~150°C | -40°C / 25°C / 150°C |
| Grade 1 | -40~125°C | -40°C / 25°C / 125°C |
| Grade 2 | -40~105°C | -40°C / 25°C / 105°C |
| Grade 3 | -40~85°C | -40°C / 25°C / 85°C |

### 3.2 车规三温测试要点

```
① 温度精度: ±3°C (比消费级严格)
② 热平衡: 芯片结温充分稳定 (Handler Soak)
③ 高温测试: 150°C 需要专用 Handler/材料
④ 数据要求: 三温数据全部保留

⑤ 温度相关 Trim:
   - 参数温度漂移控制 (TC)
   - 多温度点 Trim (如 OSC 2~3 点)
   - 温度补偿表
```

## 四、PAT 在量产中的实现

### 4.1 PAT 流程

```
量产 PAT 实施:

① 数据收集: 每颗芯片的关键参数
② 统计分析: 
   实时更新 Mean/σ (滑动窗口)
   或使用固定基线 (Qual 阶段确定)
③ 判定:
   |Param - Mean| > 6σ → PAT Fail
④ PAT Fail 芯片 → 单独 Bin (分析用)

关键参数选择:
  PMIC: VOUT, Iq, Fsw
  MCU: ADC Offset, OSC Freq, Idd
```

### 4.2 PAT 的意义

```
案例: 某 MCU 的 Idd 分布

     正常分布        异常群
   ╱        ╲      ╱  ╲
  ╱          ╲    ╱    ╲ ← PAT 捕获
 ╱            ╲  ╱      ╲   (规格内但异常)
└──────────────────────────→ Idd
              ↑
            规格上限

异常群芯片 → 潜在缺陷 (栅氧薄弱等)
→ 即使规格内也判废 → 提升可靠性
```

## 五、数据管理与追溯

### 5.1 颗级追溯 (Unit Level Traceability)

```
车规要求每颗芯片可追溯:

① 芯片唯一标识:
   - Wafer ID + Die XY (CP 记录)
   - 封装后 Lot + 序列号
   - 激光打标 (Marking)

② 测试数据关联:
   CP 数据 → FT1 数据 → BI 数据 → FT2 数据
   → 全部按颗级关联存储

③ 追溯查询:
   客户反馈失效芯片 → 查询该颗全部数据
   → 分析根因 (工艺/测试/使用)
```

### 5.2 数据保留要求

```
车规数据保留 (典型要求):

  测试原始数据: 15 年+
  测试程序版本: 15 年+
  DIB/Handler 校准记录: 15 年+
  变更记录: 永久
```

---

## 六、车规测试硬件要求

```
① ATE: 支持三温 Handler + 精确温控
② DIB: 耐高温材料 (150°C 长期)
③ Socket: 耐高温、低磨损 (车规量大)
④ 校准: 三温下分别校准
⑤ GR&R: 测试系统重复性/再现性验证
⑥ 防静电: 全线 ESD 防护
```
