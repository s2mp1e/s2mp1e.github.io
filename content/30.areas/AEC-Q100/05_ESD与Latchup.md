# ESD 与 Latch-up 测试 / ESD & Latch-up (Group E)

---

## 一、ESD 测试模型

### 1.1 三种 ESD 模型对比

| 模型 | 模拟场景 | 电压范围 | 波形 |
|------|---------|---------|------|
| **HBM** | 人体接触放电 | 250V ~ 8kV | 150pF + 1.5kΩ (双指数) |
| **CDM** | 器件带电放电 | 250V ~ 2kV | 器件自身电容放电 (ns 级) |
| **MM** | 机器接触放电 | 50V ~ 400V | 200pF + 0Ω (振荡) |

### 1.2 HBM (Human Body Model)

```
HBM 电路模型:

HV ──R1──┬──┬──── 被测器件
      C1 ─  │
      150pF │
      GND  R2 (1.5kΩ)

放电波形 (2kV):
  峰值电流: 1.33A
  上升时间: 2~10ns
  衰减时间: ~150ns
```

### 1.3 CDM (Charged Device Model)

```
CDM 原理:

器件在电场中充电 (器件自身是电容)
→ 引脚接触地 → 瞬间放电

特点:
  上升时间极快 (< 400ps)
  峰值电流大 (几 A)
  对先进工艺 (小尺寸) 危害最大
```

## 二、ESD 测试方法 (以 HBM 为例)

### 2.1 测试流程

```
① 样本准备: 3 颗/电压级 × 3 批
② 初始电测 (全参数)
③ ESD 打击:
   引脚组合: 每引脚 vs VDD, 每引脚 vs GND, 引脚-引脚
   极性: 正负双向
   电压级: 从低到高 (如 250V → 500V → 1kV → 2kV → 4kV)
④ 每级打击后电测
⑤ 失效电压确定
⑥ 数据判读

打击次数: 每引脚/组合 3 次 (JEDEC 标准)
```

### 2.2 失效判据

```
ESD 后判定:

① 完全失效: 功能丧失/大漏电 → Fail
② 参数漂移: 超出规格 → Fail
③ 恢复性失效: 暂时失效可恢复 → 记录
④ 通过: 电参数全在规格内 → Pass

注意: 车规要求即使通过也要做数据记录
```

### 2.3 车规 ESD 目标

```
AEC-Q100 建议目标 (参考):

HBM: ≥ 2000V (2kV)
CDM: ≥ 500V (Corner Pin), ≥ 750V (推荐)
MM: ≥ 200V

实际车厂要求可能更高 (如 HBM 4kV)
```

## 三、Latch-up (闩锁) 测试

### 3.1 Latch-up 原理

```
CMOS 寄生 SCR (可控硅) 结构:

VDD ──┬─ P+ ─┬─ N-well ─┬─ P-sub ─┬─ N+ ──┬── GND
       │      │          │         │       │
      ───    ───        ───       ───     ───
       │      │          │         │       │
       └── 寄生 PNP ──────┘ 寄生 NPN ┘       │
                  └──────────┘

触发: 瞬态电流注入 → 寄生双极导通 → 正反馈 → 大电流
结果: 芯片闩锁在大电流状态 (可能烧毁)
```

### 3.2 测试方法 (JEDEC JESD78)

```
① I-Test (电流触发):
   每引脚注入正/负电流脉冲
   触发电流: ±100mA (典型)
   监测 VDD 电流

② V-Test (过压触发):
   引脚加过压脉冲 (1.5 × VDD_max)
   监测 VDD 电流

③ 判定:
   注入后 VDD 电流 < 阈值 → Pass
   注入后 VDD 电流 > 阈值 (闩锁) → Fail
   闩锁后需要断电恢复

④ 温度: 高温测试 (125°C, 更严格)
```

### 3.3 ATE 测试实现

```
ATE 上的 Latch-up 测试:

硬件:
  ① 每引脚 PMU (独立限流)
  ② 快速电流监测 (闩锁后几 μs 内检测)
  ③ 电源过流保护 (防芯片烧毁)

流程:
  ① 芯片上电, 正常工作
  ② 引脚注入触发电流 (PMU)
  ③ 快速检测 VDD 电流
  ④ 若闩锁 → 立即断电
  ⑤ 恢复 → 继续下一引脚
```
