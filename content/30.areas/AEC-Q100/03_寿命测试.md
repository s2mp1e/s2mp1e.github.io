# 寿命测试 / Accelerated Lifetime Simulation (Group B)

---

## 一、测试项目一览

| 缩写 | 测试名称 | 条件 (典型) | 时长 |
|------|---------|------------|------|
| **HTOL** | High Temp Operating Life | 125°C~150°C + 动态工作 | 1000h |
| **ELFR** | Early Life Failure Rate | 125°C~150°C + 动态工作 | 48h |
| **EDR** | Endurance/Data Retention | 循环擦写 + 烘烤 | 10k 次 + 1000h |

---

## 二、HTOL (高温工作寿命)

### 2.1 目的

验证芯片在高温 + 动态工作条件下的长期寿命，是**最重要的可靠性测试**。

### 2.2 条件

```
温度: 125°C (Grade 0: 150°C)
偏压/信号: 动态工作 (芯片执行功能)
时间: 1000 小时 (Qual)
样本: 77 × 3 批 = 231 颗

等效寿命计算 (Arrhenius):
  HTOL 1000h @ 150°C, Ea=0.7eV
  ≈ 9700h @ 105°C (Grade 2 使用温度)
  ≈ 97000h ≈ 11 年 @ 85°C
```

### 2.3 测试板设计 (Burn-In Board)

```
HTOL 板设计要点:

① 动态工作: 芯片正常执行功能 (非静态偏置)
   - MCU: 运行测试程序 (读写外设/内存)
   - PMIC: 带负载开关切换

② 时钟/信号: 板上提供或芯片自产生

③ 供电: 每颗芯片独立限流 (防止一颗短路影响全部)

④ 监控: 定期检查电流/功能 (每 168h)

⑤ 散热: 腔体强制对流
```

### 2.4 测试流程

```
① 初始电测 (Full Test)
② 装板 → HTOL 腔体
③ 125/150°C 动态工作
④ 定期监控: 168h/500h/1000h 电测
⑤ 完成 → 最终电测
⑥ 数据判读

监控方式:
  在线: 监测电流异常
  离线: 定期取出电测 (常见做法)
```

### 2.5 失效判据

```
① 电参数超出规格 → Fail
② 功能失效 → Fail
③ 电流异常增大 → Fail
④ 间歇性失效 → Fail (需复测确认)
```

## 三、ELFR (早期失效率)

### 3.1 目的

验证量产芯片的早期失效率 (浴盆曲线左段)。

### 3.2 条件

```
温度: 125°C~150°C
时间: 48 小时
样本: 800 颗 (典型, 远大于其他测试)
```

### 3.3 ELFR 的意义

```
车规零缺陷目标:

  早期失效 (Infant Mortality) 必须在交付前暴露:

方法对比:
  ① ELFR 测试: 48h 高温工作 → 筛除早期失效
  ② 量产 Burn-In: 每颗芯片 100% 短时间 BI
  ③ 两者结合: ELFR 验证有效性 + 量产 BI 执行
```

## 四、EDR (Endurance & Data Retention)

### 4.1 目的

验证非易失存储 (Flash/EEPROM/OTP) 的擦写寿命和数据保持。

### 4.2 条件 (Flash 示例)

```
Endurance:
  擦写循环: 10k 次 (规格值)
  温度: 室温 或 高温 (加速)
  
Data Retention:
  编程后 150°C 烘烤 1000h
  → 数据仍可正确读出
```

### 4.3 测试流程

```
① 初始电测
② Endurance 循环:
   编程 → 擦除 → 验证 (重复 10k 次)
③ 中间检查 (5k 次后)
④ 完成 → 编程测试数据
⑤ 150°C × 1000h 烘烤
⑥ 读回验证数据完整性
⑦ 判定
```

## 五、Group B 与 ATE 的关系

```
ATE 在寿命测试中的角色:

① 初始/最终电测: ATE 全参数测试
② 定期监控电测: ATE 关键参数测试
③ 测试数据: 与可靠性工程师共享
④ HTOL 板验证: 板级功能确认

典型 ATE 参与:
  Pre-Stress: Full Test (10~30s/DUT)
  Mid-Stress: Spot Test (关键参数, 1~2s/DUT)
  Post-Stress: Full Test
```
