# Burn-In 与筛片 / Defect Screening (Group F)

---

## 一、Burn-In 概述

### 1.1 什么是 Burn-In？

Burn-In (老化/煲机) 是在高温 + 偏压条件下对每颗芯片进行的短时间老化测试，用于**筛除早期失效**。

```
浴盆曲线与 Burn-In:

失效率
  │ ╲                    
  │  ╲  ← 早期失效区     
  │   ╲   (Burn-In 筛除)  
  │    ╲─────
  │         ╲──────── 正常区 (低失效率)
  └──────────────────→ 时间
              ↑
           BI 后交付
```

### 1.2 车规 Burn-In 要求

```
车规芯片的 BI 策略:

① 100% BI (全筛): 高可靠性要求芯片
② Sample BI: 质量监控用途
③ 免 BI: 成熟工艺 + ELFR 验证充分 (需车厂认可)

典型 BI 条件:
  温度: 125°C ~ 150°C
  时间: 6~48 小时 (取决于失效率要求)
  偏压: 动态工作 (静态偏置效果差)
```

## 二、Burn-In 硬件与流程

### 2.1 Burn-In 板 (BIB)

```
BIB (Burn-In Board) 设计:

┌─────────────────────────────────┐
│  Burn-In Board                  │
│  ┌──┐ ┌──┐ ┌──┐ ... ┌──┐       │
│  │DUT│ │DUT│ │DUT│     │DUT│    │  ← 多颗芯片并联
│  └──┘ └──┘ └──┘     └──┘       │
│  每颗独立限流电阻                  │
│  公共电源/时钟总线                 │
│  监控信号 (每颗或分组)             │
└─────────────────────────────────┘

板设计要点:
  • 每颗芯片独立限流 (防短路连锁)
  • 高温材料 (PCB 板材耐 150°C+)
  • 插座耐高温 (BI Socket)
  • 供电网络低阻抗
```

### 2.2 Burn-In 系统

```
Burn-In Oven 系统:

┌───────────┐
│ BI Chamber │ ← 温控腔体 (125~150°C)
│  ┌─────┐  │
│  │ BIB │  │ ← 插满 BI 板
│  │ BIB │  │
│  │ BIB │  │
│  └─────┘  │
│ 电源 + 监控 │ ← 腔外电源, 腔体穿线
└───────────┘

监控:
  ① 电流监控 (每板)
  ② 温度监控 (腔体均匀性)
  ③ 定期功能检查 (可选)
```

### 2.3 BI 后测试 (Post-BI Test)

```
BI 完成后的 ATE 测试:

① 100% 全参数 FT (BI 后的必测)
② 与 BI 前数据对比
③ 失效芯片 → Bin 判定
④ 数据追踪 (BI 前后参数漂移分析)

BI 后 FT 是车规产线的标准流程:
  封装 → FT1 (预筛) → BI → FT2 (终测) → QA → 出货
```

## 三、Group F 测试项目

### 3.1 PAT (Process Average Testing)

```
PAT (Part Average Test / 过程平均测试):

目的: 检测参数异常的芯片 (Outlier 检测)

方法 (SBL/SBA 技术):
  ① 收集参数分布 (大量芯片数据)
  ② 计算 Mean 和 σ
  ③ 设定动态上限: Mean + 6σ
  ④ 超出动态上限的芯片 → 判废 (即使满足规格)

意义:
  参数在规格内但远离主分布 → 可能有潜在缺陷
  → PAT 筛除潜在可靠性风险芯片
```

### 3.2 SBA (Statistical Bin Analysis)

```
SBA (Statistical Bin/Yield Analysis):

目的: 良率统计监控 (量产持续监控)

方法:
  ① 按 Wafer/Lot 统计各 Bin 比例
  ② 监控异常良率波动
  ③ 良率突降 → 停线分析
  ④ 特定 Bin 比例升高 → 工艺问题信号
```

### 3.3 IDDQ 筛片

```
IDDQ 测试作为筛片手段:

原理: 静态电流异常 → 潜在缺陷

车规应用:
  ① 100% IDDQ 测试 (量产)
  ② 多状态点 IDDQ (提高覆盖率)
  ③ 结合 PAT 分析
```

## 四、车规量产筛片策略

```
车规芯片完整筛片流程:

封装
  ↓
① FT1 (全参数, 预筛)
  ↓
② Burn-In (125~150°C, 6~48h)
  ↓
③ FT2 (全参数, BI 后终测)
  ↓
④ PAT (Outlier 分析)
  ↓
⑤ QA Gate (抽样复测)
  ↓
出货 (附带完整测试数据)
```
