# AEC-Q100 概述 / AEC-Q100 Overview

---

## 一、什么是 AEC-Q100？

**AEC-Q100** (Automotive Electronics Council - Q100) 是汽车电子委员会制定的**集成电路 (IC) 车规级应力测试认证标准**。

```
AEC 标准体系:

AEC-Q100: 集成电路 (IC)        ← 本知识库主题
AEC-Q101: 分立半导体 (MOSFET/二极管)
AEC-Q102: 分立光电子 (LED)
AEC-Q103: 传感器 (MEMS)
AEC-Q104: 多芯片模块 (MCM)
AEC-Q200: 无源元件 (电阻/电容/电感)
```

### 核心目的

> 验证 IC 在汽车环境的整个寿命周期内的可靠性：
> - 温度极端: -40°C ~ +150°C
> - 振动/湿度/热循环
> - 15 年寿命 (典型目标)
> - 零缺陷目标 (Zero Defect)

## 二、AEC-Q100 测试组结构

### 2.1 七大测试组

```
┌─────────────────────────────────────────┐
│ Group A: 加速环境应力 (Accelerated Env)  │
│   PC 预处理, TC 温度循环, PTC 功率循环    │
│   HTSL 高温存储, THB/HAST 温湿度偏压      │
├─────────────────────────────────────────┤
│ Group B: 加速寿命模拟 (Lifetime)         │
│   HTOL 高温工作寿命, ELFR 早期失效率      │
├─────────────────────────────────────────┤
│ Group C: 封装组装完整性 (Package)        │
│   WBS 键合剪切, WBP 键合拉力, SD 锡球剪切 │
├─────────────────────────────────────────┤
│ Group D: 芯片制造可靠性 (Die Fab)        │
│   EM 电迁移, TDDB 栅氧击穿, HCI 热载流子  │
├─────────────────────────────────────────┤
│ Group E: 电气验证 (Electrical)           │
│   HBM/CDM ESD, LU 闩锁, ED 电气分布       │
├─────────────────────────────────────────┤
│ Group F: 缺陷筛查 (Defect Screening)     │
│   PAT 粒子分析, SBA 统计良率分析          │
├─────────────────────────────────────────┤
│ Group G: 腔体封装完整性 (Cavity Package) │
│   MS 机械冲击, VFV 振动, GFL 粗漏检       │
└─────────────────────────────────────────┘
```

### 2.2 样本量与批次要求

| 测试组 | 样本/批 | 批次 | 总计 |
|--------|--------|------|------|
| A/B (主要) | 77 | 3 | 231 |
| C | 10~40 | 3 | 30~120 |
| E | 3~30 | 3 | 9~90 |
| G | 8~40 | 3 | 24~120 |

> ⚠ 所有测试需要 **3 个不连续的晶圆批次** (3 Non-Consecutive Wafer Lots)

## 三、Qualification vs 量产

### 3.1 Qualification (认证测试)

```
目的: 证明设计 + 工艺的可靠性能力

时机:
  • 新产品开发完成时
  • 工艺/封装变更时
  • 设计重大变更时

特点:
  • 全项目测试 (所有 Group)
  • 大样本量 (77×3)
  • 时间长 (3~6 个月)
  • 一次通过即可
```

### 3.2 量产可靠性监控 (Production Monitoring)

```
目的: 持续监控量产可靠性

定期项目 (每季度/每半年):
  • HTOL (每季度, 简化样本)
  • TC (每半年)
  • HAST/THB (每季度)
  • ESD/LU (定期抽测)
  • PAT/SBA (持续)

特点:
  • 样本量小 (45~77 颗)
  • 只做代表测试
  • 数据累积分析
```

## 四、关键概念

### 4.1 失效率与 FIT

```
FIT (Failure In Time): 每 10^9 小时失效数

车规目标: 
  早期失效: 通过 ELFR 验证
  使用期失效率: < 1~10 FIT
  磨损期: 通过 HTOL 验证 > 15 年寿命
```

### 4.2 浴盆曲线 (Bathtub Curve)

```
失效率
  │
  │ ╲         ─────────────        ╱
  │  ╲                          ╱
  │   ╲                        ╱
  │    ╲                      ╱
  │     ╲                    ╱
  └────────────────────────────────→ 时间
     早期失效   正常使用期     磨损期
     (ELFR)   (低失效率)    (HTOL 验证)
```

### 4.3 加速模型 (Arrhenius)

$$
AF = \exp\left[\frac{E_a}{k}\left(\frac{1}{T_{use}} - \frac{1}{T_{stress}}\right)\right]
$$

- AF: 加速因子
- Ea: 激活能 (典型 0.7~1.1 eV)
- k: 玻尔兹曼常数

示例: Ea=0.7eV, Tuse=105°C, Tstress=150°C
```
AF = exp[0.7/8.617e-5 × (1/378 - 1/423)] = 9.7 倍
→ HTOL 1000h @ 150°C ≈ 9700h @ 105°C
```

## 五、车规 vs 消费级差异

| 维度 | 消费级 | 车规级 |
|------|--------|--------|
| 工作温度 | 0~70°C | -40~150°C |
| 寿命要求 | 3~5 年 | 15 年+ |
| 失效率 | 100~1000 FIT | < 10 FIT |
| 认证 | 无强制 | AEC-Q100 必须 |
| 变更管理 | 宽松 | 严格 (PCN 需车厂批准) |
| 文档 | 简单 | PPAP 全套 |
| 测试成本 | 1x | 2~5x |
