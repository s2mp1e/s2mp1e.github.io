# 电机控制模块测试详解

---

## 一、BLDC 电机控制架构

```
MCU 驱动 BLDC 电机 (三相):

             ┌────────────────────┐
             │        MCU         │
             │                    │
             │  Advanced Timer    │
             │  ┌──────┐          │
             │  │CH1/CH1N│────────┤──→ UH / UL (上/下桥臂)
             │  │CH2/CH2N│────────┤──→ VH / VL
             │  │CH3/CH3N│────────┤──→ WH / WL
             │  └──────┘          │
             │                    │
             │  ADC ←── 电流采样   │←── 分流电阻
             │                    │
             │  Comparator ←──────┼── 过流检测
             └────────────────────┘
```

### BLDC 控制方式

| 方式 | 原理 | 测试要点 |
|------|------|---------|
| **6 步换相 (Trapezoidal)** | 方波驱动 | 换相时序 |
| **FOC (正弦)** | 矢量控制 | PWM 精度/ADC 同步 |
| **无感 (Sensorless)** | BEMF 检测 | 比较器采样 |

## 二、高级定时器测试

### 2.1 互补 PWM 输出

```
互补输出 (CH1 + CH1N):

CH1:  ┌────┐    ┌────┐
──────┘    └────┘    └──

CH1N:    ┌────┐    ┌────┐
─────────┘    └────┘    └────

测试:
  ① 频率: CH1 与 CH1N 频率一致 (TMU 测量)
  ② 占空比: 互补 (Duty_CH1N = 1 - Duty_CH1)
  ③ 死区: 切换沿之间无重叠 (防直通)
```

### 2.2 Dead Time 测试

```
死区时间 (Dead Time):

CH1:  ──────┐         ┌──────────
            │         │
            └─────────┘
                  ↑ Dead Time (上升沿延迟)
CH1N:      ┌─────────┐
      ─────┘         └────────────

测试:
  ① 配置死区寄存器 (如 100ns)
  ② TMU 测量实际死区时间
  ③ 精度: ±10% (典型)
  ④ 多档死区配置验证 (50ns~2μs)
```

### 2.3 紧急关断 (Break Function)

```
BRK 引脚: 外部故障信号 (过流/过压)

测试:
  ① 正常输出 PWM
  ② BRK 引脚触发 (低电平/高电平)
  ③ PWM 输出立即停止 (关断或安全状态)
  ④ 响应时间: < 100ns (硬件路径)
  ⑤ BRK 解除 → 恢复输出 (自动/手动)
```

### 2.4 换相时序验证

```
6 步换相测试 (Trapezoidal):

步骤:
  ① 配置换相事件 (比较匹配 → 换相)
  ② 输出 6 步波形序列
  ③ Digitizer 采样 3 路输出
  ④ 验证每步的导通相和极性

典型 6 步序列:
  步1: UH+VL
  步2: UH+WL
  步3: VH+WL
  步4: VH+UL
  步5: WH+UL
  步6: WH+VL
```

## 三、编码器接口测试

```
正交编码器接口 (QEI):

A 相: ┌─┐  ┌─┐  ┌─┐
      └─┘  └─┘  └─┘

B 相:   ┌─┐  ┌─┐  ┌─┐
      ──┘ └──┘ └──┘ └── (与 A 相差 90°)

测试:
  ① ATE 产生正交信号 (A/B 相)
  ② MCU 编码器接口计数
  ③ 正转: 计数递增
  ④ 反转: 计数递减
  ⑤ 计数精度: N 个脉冲 → 计数 = N×4 (4 倍频)
```

---

## 四、过流保护测试

```
电机过流保护链路:

分流电阻 → PGA 放大 → Comparator → BRK → PWM 关断

测试:
  ① 模拟电流信号 (电压注入)
  ② 超过阈值 → Comparator 触发
  ③ BRK 响应 → PWM 关断
  ④ 测量: 触发到关断的总延迟
  ⑤ 典型: < 1μs (PGA+Comp+BRK 全硬件路径)
```

## 五、ADC 同步采样测试

```
FOC 控制需要精确的电流采样时机:

PWM 周期: ┌─────────┬─────────┬─────────┐
          │         │         │         │
采样点:       ↑         ↑         ↑
          (PWM 中心对齐时的中点采样)

测试:
  ① 配置 ADC 由 Timer 触发 (TRGO)
  ② 验证采样点与 PWM 中心对齐
  ③ 测量采样时序偏差
```
