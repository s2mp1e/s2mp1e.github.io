# BLE / RF 测试详解

---

## 一、BLE 基础

### 1.1 BLE 物理层

```
BLE (Bluetooth Low Energy) 物理层:

  频段: 2.400 ~ 2.4835 GHz (ISM)
  信道: 40 个 (37 数据 + 3 广播), 2MHz 间隔
  调制: GFSK (高斯频移键控)
  速率: 1 Mbps (LE 1M) / 2 Mbps (LE 2M)
  发射功率: -20 ~ +10 dBm (典型 0 dBm)
  灵敏度: -70 ~ -100 dBm
```

### 1.2 GFSK 调制

```
GFSK = 高斯滤波 + FSK

  逻辑 1 → 频偏 +Δf (如 +250kHz)
  逻辑 0 → 频偏 -Δf (如 -250kHz)

关键参数:
  频偏 (Frequency Deviation): ±250kHz (BLE 1M)
  调制指数: 0.5 (BLE)
  高斯滤波 BT: 0.5
```

## 二、RF ATE 资源

### 2.1 必备 RF 仪器

| 仪器 | 功能 | 用途 |
|------|------|------|
| **VSA (Vector Signal Analyzer)** | 分析 RF 信号 | TX 测试 (功率/频率/调制/频谱) |
| **VSG (Vector Signal Generator)** | 产生 RF 信号 | RX 测试 (发送标准 BLE 包) |
| **频谱仪** | 频域分析 | 杂散/谐波/掩模 |
| **功率计** | 精确功率测量 | 输出功率校准 |

### 2.2 主流 RF ATE 方案

| 方案 | 说明 | 适用 |
|------|------|------|
| **V93000 RF + SmarTest** | Advantest 集成 RF | 高端 |
| **UltraFLEX + UltraWave** | Teradyne 集成 RF | 主流 |
| **J750 + RF Option** | 中端 RF | 低成本 |
| **外部仪器 + 控制** | ATE 控制外部 VSG/VSA | 灵活方案 |
| **专用 BLE 测试仪** | Anritsu/R&S/LitePoint | 产测专用 |

### 2.3 RF DIB 设计要求

```
RF 测试板特殊要求:

① RF 走线: 50Ω 特征阻抗 (微带线/带状线)
② RF 连接器: SMA/SMP 连接器
③ 屏蔽: RF 区域金属屏蔽罩 (防串扰)
④ 接地: 大面积接地层 (回流路径)
⑤ 隔离: RF 信号与其他信号充分隔离
⑥ 天线匹配网络: DUT 到连接器的匹配
⑦ Socket 影响: RF 引脚的低寄生 Socket
```

## 三、TX (发射) 测试

### 3.1 输出功率测试

```
测试:
  ① 芯片进入 TX 模式 (连续发送或 DTM)
  ② 设置目标功率 (如 0 dBm)
  ③ VSA/功率计测量实际输出功率
  ④ 计算与目标的偏差

典型规格:
  TX Power: 0 dBm ± 2dB (室温)
  功率控制范围: -20 ~ +10 dBm
  功率步进: 1~2 dB (多档验证)
```

### 3.2 频率精度测试

```
测试:
  ① TX 发送载波 (或连续包)
  ② VSA 测量载波频率
  ③ 计算频偏: F_err = F_meas - F_center

典型规格:
  频偏 < ±40kHz (室温, 未校准前 ±100kHz)
  
频偏来源:
  晶振精度 (如 ±20ppm @ 2.4GHz → ±48kHz)
  → 需要晶振校准或温度补偿
```

### 3.3 调制质量测试

```
关键参数:

① Frequency Deviation (频偏):
   目标 ±250kHz, 规格 ±10%

② DEVM (Differential Error Vector Magnitude):
   综合调制质量指标

③ Drift Rate (频率漂移):
   包内频率漂移 (如 < 50kHz/50μs)

④ FSK Error:
   频偏偏差的统计值
```

### 3.4 频谱掩模测试 (Spectral Mask)

```
BLE 频谱掩模要求:

功率
 │  ┌─────┐
 │  │     │  ← 主信道 (±1MHz 内)
 │  └─────┘
 │    ╲   ╱  ← 过渡带
 │      ╲╱
 │   ←±2MHz→ 邻信道
 │
 └──────────────────→ 频率

测试:
  ① TX 发送标准包
  ② 频谱仪扫频
  ③ 各频偏点的功率
  ④ 与掩模要求比对 (如 ±2MHz 处 < -20dBm)
```

### 3.5 杂散与谐波测试

```
测试:
  ① TX 输出功率已知
  ② 频谱仪扫描宽频段 (如 30MHz ~ 13GHz)
  ③ 检查谐波 (2 次: 4.8GHz, 3 次: 7.2GHz)
  ④ 检查非谐波杂散

典型规格:
  2 次谐波: < -30 dBc
  3 次谐波: < -40 dBc
  带外杂散: 符合法规 (FCC/ETSI)
```

## 四、RX (接收) 测试

### 4.1 灵敏度测试 (Sensitivity)

```
定义: 满足 PER ≤ 30.8% 的最小输入功率

测试:
  ① VSG 产生标准 BLE 包 (固定功率)
  ② 芯片接收, 统计 PER (Packet Error Rate)
  ③ 逐步降低 VSG 功率
  ④ 找到 PER = 30.8% 的功率点
  ⑤ 该功率 = 灵敏度

典型规格:
  BLE 1M: -97 dBm (理想), -93 dBm (典型规格)
  BLE 2M: -92 dBm

PER 统计:
  至少 1500 包 (BLE 规范要求)
  测试时间: ~几秒/功率点
```

### 4.2 PER vs 输入功率曲线

```
PER
100% │╲
     │ ╲
     │  ╲
     │   ╲
 30% │────╲────────── 阈值线
     │     ╲
     │      ╲
  0% │       ╲______
     └──────────────────→ 输入功率 (dBm)
              ↑
            灵敏度

量产策略:
  固定功率点测试 (如 -93dBm 处 PER < 30.8%)
  → 快速判定, 无需完整扫描
```

### 4.3 阻塞测试 (Blocking)

```
定义: 在干扰信号存在下的接收能力

测试:
  ① 有用信号: -67 dBm (强信号)
  ② 干扰信号: 邻道/带内/带外
  ③ 测量 PER
  ④ PER < 30.8% → 通过

阻塞分类 (BLE):
  同道: ±0MHz
  邻道: ±1MHz, ±2MHz, ±3MHz
  带内: ±5MHz ~ ±10MHz
  带外: 2.4GHz 之外 (2GHz/3GHz 等)
```

### 4.4 频率容限测试

```
RX 频率容限:

测试:
  ① VSG 载波频率偏移 ±Δf (如 ±50kHz, ±100kHz)
  ② 每个偏移点测 PER
  ③ 芯片仍能正常接收 → 通过

反映: RX 解调器的频率容限能力
```

## 五、DTM 测试模式 (Direct Test Mode)

### 5.1 DTM 概述

```
DTM (BLE Direct Test Mode):

BLE 芯片的标准化测试模式 (蓝牙规范定义):

控制接口: UART (2-wire) 或 HCI
功能:
  ① TX Test: 发送指定信道/长度的测试包
  ② RX Test: 接收测试包并统计
  ③ 结束测试

命令示例:
  LE Transmitter Test: 信道 0~39, 包长, 包类型
  LE Receiver Test: 信道, 包长
  LE Test End: 返回接收包数量
```

### 5.2 DTM 测试流程

```
① 芯片上电, 进入 DTM 模式
   (通过测试引脚或 Firmware 配置)

② UART 连接 (DTM 命令接口)
   波特率: 115200 典型

③ TX 测试:
   发送 TX Test 命令 (信道/包长)
   → 芯片持续发送测试包
   → RF 仪器测量

④ RX 测试:
   发送 RX Test 命令
   → VSG 发送 N 个标准包
   → Test End 命令 → 返回接收计数
   → PER = (N - 接收数) / N

⑤ 重复各信道/功率/包长组合
```

## 六、RF 校准 (Calibration)

### 6.1 为什么需要校准？

```
芯片间差异 + 温度影响:

TX 功率: 目标 0dBm, 芯片 A 输出 +1.5dBm, 芯片 B 输出 -2dBm
频偏: 晶振偏差导致 ±100kHz 频偏

校准项目:
  ① 晶振校准 (频偏补偿)
  ② TX 功率校准 (各功率档)
  ③ 温度补偿表 (可选)
```

### 6.2 晶振校准流程

```
① 芯片发送载波 (CW)
② VSA 测量频偏 (如 +85kHz)
③ 计算晶振修正值:
   F_err / F_RF = 85kHz / 2.4GHz = 35ppm
④ 写入校准寄存器 (调整晶振负载电容)
⑤ 复测: 频偏 < ±10kHz ✓
⑥ 校准值写入 Flash/OTP
```

### 6.3 TX 功率校准流程

```
① 设置功率档 = Target (如 0dBm)
② 测量实际输出 (如 -1.8dBm)
③ 计算补偿值: +1.8dB
④ 调整内部增益设置
⑤ 复测: 0dBm ± 0.5dB ✓
⑥ 各功率档重复 (-20~+10dBm, 步进 2dB)
⑦ 校准表写入 Flash

量产简化:
  只校准 2~3 个代表功率档
  其他档用插值
```

## 七、量产测试策略

### 7.1 RF FT 测试流程

```
无线 MCU RF FT 典型流程:

① 常规 DC/数字测试 (与普通 MCU 相同)
    ↓
② 进入 DTM 模式
    ↓
③ 晶振校准 (每颗芯片)
    ↓
④ TX 测试 (2~3 信道代表):
   - 输出功率
   - 频偏
   - 调制质量 (DEVM/频偏误差)
    ↓
⑤ RX 测试 (1~2 功率点):
   - 灵敏度点 PER
    ↓
⑥ 校准数据写入 Flash
    ↓
⑦ RF 测试完成 → 常规测试继续
```

### 7.2 测试时间与站点

```
RF 测试耗时项:

  晶振校准: ~200ms
  TX 测试 (3 信道): ~300ms
  RX PER (1500 包): ~500ms~1s
  校准写入: ~100ms
  ────────────────────
  RF 部分总计: 1~2 秒

RF 测试通常单独建站 (RF Station):
  常规测试站 + RF 测试站 分开
  RF 站需要屏蔽箱 (Shielding Box)
```

### 7.3 RF 测试环境

```
RF FT 产线环境要求:

① 屏蔽箱 (RF Shield Box):
   - 隔离外界 2.4GHz 干扰 (WiFi 等)
   - 内部吸波材料防反射
   - 屏蔽效能: > 80dB

② 测试路径: 传导测试 (Conducted) 
   通过 RF 连接器直接连接 (非天线辐射)
   → 稳定可靠, 适合量产

③ 环境控制:
   温度控制 (RF 参数对温度敏感)
   湿度控制

④ 产线干扰:
   远离 WiFi 路由器/微波炉等 2.4GHz 源
```

## 八、常见问题

| 问题 | 可能原因 | 解决 |
|------|---------|------|
| 频偏超标 | 晶振未校准/漂移 | 校准/温度补偿 |
| TX 功率偏差 | 匹配网络/工艺 | 功率校准 |
| 灵敏度差 | 接收链路噪声 | 检查匹配/屏蔽 |
| PER 异常高 | 干扰/屏蔽不良 | 检查屏蔽箱 |
| 校准后漂移 | 温度变化 | 温度补偿表 |
| Socket 接触不良 | RF 引脚接触 | Socket 维护 |
