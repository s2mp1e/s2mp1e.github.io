# LCD 段码驱动测试详解

---

## 一、段码 LCD 驱动原理

### 1.1 LCD 段码结构

```
段码 LCD 结构:

       SEG0  SEG1  SEG2 ...
        │     │     │
COM0 ───┼─────┼─────┼──
        │  ═══│═══  │    ← 每个交叉点是显示段
COM1 ───┼─────┼─────┼──
        │     │     │
COM2 ───┼─────┼─────┼──
        │     │     │

点亮条件: COM 和 SEG 之间的电压差 > 液晶阈值
熄灭条件: 电压差 < 阈值 (交流驱动避免直流损伤)
```

### 1.2 驱动波形 (1/3 Bias, 1/4 Duty 示例)

```
COM 波形:
   ┌──┐        ┌──┐
   │  │        │  │      VLCD
   │  │        │  │
   └──┘        └──┘
      ↑ 帧周期 (30~100Hz)

SEG 波形: 与 COM 同相 → 熄灭
         与 COM 反相 → 点亮

关键: LCD 必须用交流驱动 (避免液晶电解)
```

### 1.3 偏压网络

```
VLCD ──┬── R ──┬── R ──┬── R ── GND
        │       │       │
       3/3VLCD 2/3VLCD 1/3VLCD
       
1/3 Bias: 三级电压
分压电阻: 内部集成 (低功耗) 或外接
```

## 二、关键测试参数

| 参数 | 描述 | 典型规格 |
|------|------|---------|
| **VLCD 精度** | LCD 供电电压 (内部 Charge Pump 或 LDO) | ±5% |
| **Bias 分压精度** | 1/3, 2/3 电压点精度 | ±2% |
| **帧频** | 刷新频率 | 32~100Hz |
| **波形占空比** | 1/Duty (COM 数) | 匹配配置 |
| **Charge Pump** (如有) | 升压到 VLCD (3V~5V) | ±5% |
| **对比度控制** | VLCD 可调范围 | 2.5V~5V |

## 三、ATE 测试方法

### 3.1 偏压测试

```
① VLCD 电压测试:
   - 使能 LCD 模块
   - 测 VLCD 引脚电压
   - 判断: 目标值 ±5%

② Bias 分压测试:
   - 测 1/3 和 2/3 电压点 (测试引脚或间接)
   - 判断: 理论值 ±2%

③ Charge Pump 测试 (如内部升压):
   - VDD=1.8V → VLCD=3.3V (升压正确)
   - 多档 VLCD 配置验证
```

### 3.2 驱动波形测试

```
① 帧频测试:
   - 使能 LCD, 输出到引脚
   - TMU 测 COM 波形周期
   - F_frame = 1/T (32~100Hz)

② 波形正确性:
   - Digitizer 采样 COM/SEG 波形
   - 验证: 电平数量 (Bias 相关)
   - 验证: 占空比 (1/Duty)
   - 验证: 相位关系

③ 点亮测试:
   - 配置全段点亮
   - 验证 SEG 波形与 COM 反相
   - 配置全段熄灭
   - 验证 SEG 波形与 COM 同相
```

### 3.3 功耗测试

```
LCD 显示模式 (低功耗应用关键):

条件: LCD 显示 + CPU 深度睡眠
测量: VDD 电流

典型: 1~5μA (取决于 LCD 面积和帧频)

LCD 时钟来源:
  LSE 32.768kHz (外晶振) — 精确帧频
  LSI (内部) — 低功耗但精度低
```

### 3.4 量产测试策略

```
CP:
  ① 偏压分压比测试
  ② Charge Pump 电压测试
  ③ 帧频快速验证

FT:
  ① 功能: 使能 LCD → 波形存在
  ② 帧频: 全测 (TMU 快速)
  ③ VLCD: 全测
  ④ 波形细节: 代表配置
```

## 四、常见问题

| 问题 | 可能原因 |
|------|---------|
| 显示对比度差 | VLCD 电压偏差 |
| 段闪烁 (Flicker) | 帧频过低/波形不对称 |
| 显示鬼影 (Ghosting) | 偏压不准确 |
| 功耗超标 | Charge Pump 效率/时钟配置 |
| 液晶损伤 | 直流分量 (波形不对称) |
