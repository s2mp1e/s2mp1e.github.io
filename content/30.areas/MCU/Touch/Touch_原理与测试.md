# Touch 电容触摸测试详解

---

## 一、电容触摸原理

### 1.1 基本概念

```
手指触摸电极 → 改变电极对地电容

无触摸:  C = C_base (电极固有电容, ~5~20pF)
有触摸:  C = C_base + C_finger (手指耦合, ~0.5~5pF)

检测: 测量电容变化 ΔC → 超过阈值 → 判定触摸
```

### 1.2 充电转移法 (Charge Transfer)

```
原理 (TSC 外设常用):

周期:
  ① 开关 S1 闭合: 电源向 Cx (电极电容) 充电到 VDD
  ② S1 断开, S2 闭合: Cx 电荷转移到 Cs (采样电容)
  ③ 重复 N 次 → Cs 电压上升到阈值
  ④ N 与 Cx 成反比: Cx 大 → N 小

测量: 记录 N (充放电次数)
  Cx 大 (有触摸) → N 减小 → 检测到变化
```

```
硬件结构 (每通道):

VDD ──S1──┬─── Cx ─── GND
           │
          S2
           │
          ─── Cs (采样电容)
           │
          ADC / 比较器 → 计数值 N
```

## 二、关键测试参数

| 参数 | 描述 | 规格 |
|------|------|------|
| **Base Count** | 无触摸时的计数值 | 芯片间一致性 ±20% |
| **Touch Delta** | 触摸引起的计数变化 | > 阈值的 2 倍 |
| **灵敏度** | ΔC 检测能力 | 最小可检测 ~0.1pF |
| **SNR** | 信号噪声比 | > 5:1 |
| **响应时间** | 触摸到检测的时间 | < 30ms |
| **通道一致性** | 各通道 Base Count 差异 | < ±10% |
| **抗扰性** | 电源/EMI 干扰下误触发 | 不误触发 |

## 三、ATE 测试方法

### 3.1 基础功能测试

```
① Base Count 测试:
   - 无触摸状态 (无外部电容负载)
   - 读取各通道计数值
   - 判断: 在预期范围内 (工艺相关)

② 通道一致性:
   - 各通道 Base Count 对比
   - 差异 < ±10%

③ 模拟触摸测试:
   通过 DIB 上的电容阵列模拟手指:

   正常:   C_base (如 10pF)
   触摸:   C_base + ΔC (如 10pF + 2pF)

   实现: 继电器切换电容 (1~5pF 模拟手指)
   测试: 切换后计数值变化 > 阈值 → 检测到触摸
```

### 3.2 阈值验证

```
测试:
  ① 设置检测阈值 (寄存器配置)
  ② 无触摸 → 不触发
  ③ 模拟小电容变化 (< 阈值) → 不触发
  ④ 模拟大电容变化 (> 阈值) → 触发
  ⑤ 验证边沿情况 (阈值 ±10%)
```

### 3.3 测试硬件实现

```
DIB 触摸测试电路:

Touch 引脚 ──┬── 1pF (模拟小触摸)
             ├── 2pF (模拟标准触摸)
             ├── 5pF (模拟大触摸)
             └── Relay 切换 (ATE 控制)

注意:
  • 触摸电容精度: ±5% (高精度电容)
  • 走线寄生: 越短越好 (< 5pF)
  • 继电器寄生电容: 选低寄生型
  • 屏蔽: 模拟区屏蔽防 EMI
```

### 3.4 量产测试策略

```
CP:
  ① Base Count 测试 (Pad 接触)
  ② 通道一致性
  ③ Trim (如需要: 通道补偿)

FT:
  ① Base Count 复测
  ② 模拟触摸检测 (1~2 通道代表)
  ③ 全通道功能 (快速扫描)

Sample:
  ④ 灵敏度全参数
  ⑤ 抗扰性测试
```

## 四、常见问题

| 问题 | 可能原因 |
|------|---------|
| Base Count 超范围 | 电极电容偏差/工艺 |
| 触摸不触发 | 灵敏度不足/阈值过高 |
| 误触发 | 噪声大/阈值过低 |
| 通道差异大 | 走线不对称/寄生差异 |
| 温度漂移 | C_base 温漂 (需要温度补偿) |
