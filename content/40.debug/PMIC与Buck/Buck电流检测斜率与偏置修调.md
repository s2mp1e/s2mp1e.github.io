# Buck 电流检测斜率与偏置修调

**来源：** 用户提供的对话资料。实际检测架构、修调码和规格需以 DUT 设计文件为准。

## 线性模型

若检测输出近似满足：

```text
y = kx + b
```

其中 `x` 是实际电流或 Sense 输入，`y` 是检测输出；`k` 表示增益 / 斜率，`b` 表示零点偏置。

```text
检测输出 y
  ↑                 ● 高电流点
  │             ●
  │         ●
  │     ●  ← 斜率 k
  │ ●
  └────────────────────→ 输入电流 x
    ↑
    偏置 b（x = 0 时的截距）
```

## 修调与调试步骤

1. 在零输入或规定的零点条件测 `b`，区分真实偏置与仪表零点误差。
2. 在至少两个已知电流点计算斜率 `k = (y₂-y₁)/(x₂-x₁)`。
3. 先修零点还是先修增益，应依据码位耦合与设计方案决定；修完后需重新测量多个点。
4. 用未参与修调的中间点检查线性残差，识别非线性、饱和或温漂。
5. 保存原始值、Trim code、温度、量程、负载和仪器校准信息。

## 工程补充

两点可以拟合直线，但不足以证明全量程线性。若 `k` 与 `b` 共用码位或校准链路耦合，应迭代并验证修调顺序；不能只看修调后的单个测试点。
