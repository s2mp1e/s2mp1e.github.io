# 数字 Pattern 符号 H、L、0、1、X、Z、M

符号含义受测试机、Pattern 格式、Pin 配置和项目约定影响。下表是常见理解，不应代替项目 Pattern 规范。

| 符号 | 常见含义 | 调试时确认 |
|---|---|---|
| H / L | 常见为驱动高 / 驱动低 | 驱动电平、负载和边沿 |
| 1 / 0 | 常见为期望高 / 期望低或逻辑期望值 | 是驱动还是比较期望 |
| X | 常见为不比较 / 不关心；有时与驱动状态另有关联 | Pin 是否仍驱动、是否高阻 |
| Z | 常见为高阻 / 释放引脚 | Pin Electronics 与终端状态 |
| M | 常见为 Mask / 屏蔽比较 | 屏蔽范围、是否影响数据记录 |

## 排查建议

1. 查看项目 Pattern 语言和 Pin State 定义。
2. 对照 Timing、Levels、Load / Term 和比较器配置。
3. 用单 Pin 小 Pattern 或资源诊断验证实际电气行为。
4. 不把“符号看起来像逻辑值”当成电气驱动定义。
