# V93000：DigCap 标签与代码调用位置

**分类：** 数字采集 / 结果命名  
**状态：** 待核实  
**来源：** 用户提供的对话资料；未提供项目代码和 SmarTest 版本

## 现象

代码中看到 `DIGCAP("label")`、`DigCap("xxx")` 或类似写法，不清楚 `label` 指什么，也不清楚它和 Pattern 名称是否相同。

## 条件

- 项目使用的 SmarTest 版本：资料未提供
- 实际 API、TestMethod 和 Pattern：资料未提供

## 排查与发现

1. 区分 **Pattern / Burst 名称** 与 **DigCap 结果标签**：前者通常用于选择或执行测试数据；后者可能用于标识采集结果。实际含义以项目 API 为准。
2. 在项目代码中搜索该标签的定义、调用、结果读取及数据记录位置。
3. 检查标签作用域、复用规则、多 Site 行为及结果是否会被覆盖。
4. 对照对应 SmarTest 版本的 TDC 和项目已有范例，确认 API 的真实语义。

## 原因与处理

- **当前理解：** 对话资料把 DigCap 标签解释为采集结果的标识名，并指出它与 Pattern 标签用途不同。
- **待核实：** 具体标签是否对应独立缓存、如何读取、是否必须唯一，取决于实际 API 和项目实现；不能只凭示例代码确定。
- **建议处理：** 贴出项目中 DigCap 调用及结果读取的代码片段，再按实际版本确认。

## 经验

不要把看起来相似的 Pattern 名称和 Capture 标签混为一谈；先从调用点追踪到结果读取点，并用当前版本文档确认。
