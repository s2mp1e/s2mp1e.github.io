# 缓冲器与电压跟随器的测试接口理解

**关键区别：** 电压跟随器通常描述运放的单位增益反馈接法；缓冲器描述隔离前后级、提供驱动能力的电路功能。实际电路常由电压跟随器实现缓冲功能。

```mermaid
flowchart LR
  SRC[高输出阻抗信号源] -->|高输入阻抗| BUF[缓冲级 / 电压跟随器]
  BUF -->|较低输出阻抗| LOAD[ATE输入或后级负载]
```

| 检查项 | 调试意义 |
|---|---|
| 输入阻抗 | ATE 是否加载被测节点 |
| 输出阻抗与驱动能力 | 缓冲器能否驱动线缆、继电器和后级负载 |
| 偏置、失调和增益 | 解释缓冲前后电压差 |
| 带宽与稳定性 | 解释瞬态、振铃和不同采样条件下的差异 |

调试时在缓冲器前后同时量测，并使用已知负载确认信号变化；不要仅凭“Buffer”或“Follower”名称推断具体电路性能。
