# V93000：Ramp 方向 NEG 的含义

**分类：** 电源量测 / Ramp 扫描  
**状态：** 待核实  
**来源：** 用户提供的对话资料；未提供 Ramp API 文档或项目代码

## 现象

项目代码中出现 `.direction(NEG)`，需要判断扫描的先后方向及其对电流或电压测试的影响。

## 条件

- 实际 Ramp API、起点、终点和步进：资料未提供
- 使用的仪器资源及 SmarTest 版本：资料未提供

## 排查与发现

1. 查看该 API 对 `direction` 的定义，确认它代表数值递增 / 递减、源极性还是其他方向选项。
2. 同时核对起点、终点、步进、量程和停止条件，不能只看 `NEG` 判断实际扫描路径。
3. 用安全的小范围扫描检查实际输出顺序，并确认电流符号约定。
4. 若用于 OCP、UVLO 等保护测试，确认扫描方向不会跳过触发点，也不会超出 DUT 和仪器安全范围。

## 原因与处理

- **对话中的解释：** 将 `NEG` 解释为数值向较小方向扫描，并举例说明负载电流由较小负值逐渐到较大负值。
- **待核实：** 这是对话中的一般解释，不是所用 API 的定义。实际起止顺序必须依照对应版本文档和代码确认。
- **处理方式：** 记录 API 定义、起止值和实测序列；确认后再把结论标为已验证。

## 经验

`NEG` 不能单独决定实际波形。必须联合检查方向参数、起止点、步进及仪器的正负号约定。
