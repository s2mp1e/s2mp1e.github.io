# V93000：DPS128 电压测量与采样率

**分类：** 电源量测 / 测量时序  
**状态：** 待核实  
**来源：** 用户提供的对话资料；未提供 Measure API、配置或对应手册页

## 现象

需要确认 DPS128 Measure Voltage 的采样率。原对话指出，普通 DC 电压测量返回值、测量窗口 / 积分时间和高速波形采样不能混为一谈；但没有提供可确认的具体采样率。

## 条件

- SmarTest 版本及 Measure API：未提供
- 测量模式、量程、积分 / 平均设置：未提供
- 是否使用专用动态测量资源：未提供

## 排查与发现

1. 找到项目实际调用的 Measure Voltage 方法和配置项。
2. 查阅对应版本 TDC，区分测量窗口、积分时间、采样点数、结果更新率和高速 Digitizer 采样率。
3. 若要测 Buck 启动或纹波波形，确认所用资源是否支持波形采集，并核对带宽、采样率、触发和输入范围。
4. 用已知信号验证记录时间和结果行为；不要把普通 DC 测量 API 当作示波器采样。

## 原因与处理

- **整理结论：** 当前资料没有 DPS128 Measure Voltage 的官方采样率数值。
- **处理方式：** 暂不填写数值；依据实际 API、测量模式和仪器版本查证后再补充。
- **验证结果：** 待提供代码片段和 TDC 依据。

## 经验

“采样率”“测量窗口”“返回结果的更新速度”是不同指标，询问或记录时要注明具体测量模式。
