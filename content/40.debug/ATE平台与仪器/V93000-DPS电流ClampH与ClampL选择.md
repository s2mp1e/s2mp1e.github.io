# V93000：DPS 电流 Clamp H 与 Clamp L 选择

**分类：** 电源量测 / 电流保护设置  
**状态：** 待核实  
**来源：** 用户提供的对话资料；未提供实际代码、仪器版本和接线图

## 现象

在 DUT 输出端使用机台拉载时，需要判断应设置电流上限 Clamp H 还是 Clamp L。原对话按“流入 DUT 为正、DUT 向测试机回流为负”给出了选择建议。

## 条件

- 仪器资源及电流符号定义：未提供
- 实际接线、量测端口和代码配置：未提供
- 拉载方向和预期电流范围：未提供

## 排查与发现

1. 从对应资源手册确认电流正方向定义，不能把其他机台或其他资源的符号约定直接套用。
2. 查看实测电流符号，确认 DUT 是向资源供电还是由资源向 DUT 供电。
3. 确认 Clamp H / Clamp L 的 API 定义、设置单位、包含关系及触发后的行为。
4. 在安全的小电流条件下验证实际限制方向，并检查过载或夹限状态。

## 原因与处理

- **对话中的建议：** 把吸收 DUT 输出电流的场景归为负电流，并建议检查 Clamp L。
- **待核实：** 是否适用于当前资源、机台版本和接线，必须由手册与实测确认。
- **处理方式：** 根据本机电流符号和 API 定义设置保护限值；保留足够的瞬态余量，但不得超过 DUT、负载和仪器安全边界。

## 经验

不要根据“拉电流”口语直接选 Clamp。先确认当前接线下电流的实际符号，再确认 Clamp 的资源定义。
