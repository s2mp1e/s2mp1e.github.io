# PMIC 项目启动与 ATE 计划

**来源：** 用户提供的项目计划问答。以下为示例排期框架，不是承诺周期；实际计划取决于回片、规格冻结、硬件和资源。

## Kickoff 必须确认

- 产品配置、规格版本、测试插入点、目标平台和量产地点
- 设计 / DFT / 封装接口、样品数量、回片与封装时间
- ATE、Probe Card、Load Board、Socket、Handler 及校准资源
- Trim / OTP 方案、数据格式、Bin、并行度、测试时间目标
- 风险、责任人、依赖项和每阶段退出条件

## 参考时间轴

| 阶段 | 示例周次 | ATE 主要输出 / 退出条件 |
|---|---|---|
| 需求与架构 | W1–W2 | 测试策略、资源预算、风险清单、初版测试计划 |
| 程序与硬件设计 | W3–W5 | 测试方法、接口定义、Pattern / Flow 草案、板卡需求 |
| 硬件制作与离线验证 | W6–W8 | 接口检查、资源验证、测试程序编译和模拟 |
| 首硅 Bring-up | W9–W10 | 基本功能、电源、通信、保护和 Trim 可行性 |
| Characterization 与相关性 | W11–W13 | 参数分布、限值依据、Site / 平台 / 温度相关性 |
| 量产准备与放行 | W14–W16 | 程序冻结、量产流程、数据追溯、放行评审 |

## 调试风险提示

把回片时间、板卡交付、样品数量、温控、Trim 编程权限和跨平台相关性列为关键路径；每个阶段设置可验收的退出标准，避免仅按日期推进。
